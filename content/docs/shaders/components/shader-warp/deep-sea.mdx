Installs [Warp](/docs/shaders/components/shader-warp) as a dependency. This file only fixes its look: the preset object at the top holds every value, so edit it in place to make the preset your own.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShaderWarpDeepSea } from "@/components/remocn/shader-warp-deep-sea";

export const RemotionRoot = () => (
  <Composition
    id="ShaderWarpDeepSea"
    component={ShaderWarpDeepSea}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

ShaderWarpDeepSea takes the same props as `ShaderWarp`. Props you pass override the preset, except `speed`, which scales the preset's own pace: `speed={2}` is twice as fast as the preset, whatever its base speed.
