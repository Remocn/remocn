Installs [Mesh Gradient](/docs/shaders/components/shader-mesh-gradient) as a dependency. This file only fixes its look: the preset object at the top holds every value, so edit it in place to make the preset your own.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShaderMeshGradientEmber } from "@/components/remocn/shader-mesh-gradient-ember";

export const RemotionRoot = () => (
  <Composition
    id="ShaderMeshGradientEmber"
    component={ShaderMeshGradientEmber}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

ShaderMeshGradientEmber takes the same props as `ShaderMeshGradient`. Props you pass override the preset, except `speed`, which scales the preset's own pace: `speed={2}` is twice as fast as the preset, whatever its base speed.
