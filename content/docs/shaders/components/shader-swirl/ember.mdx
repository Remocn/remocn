Installs [Swirl](/docs/shaders/components/shader-swirl) as a dependency. This file only fixes its look: the preset object at the top holds every value, so edit it in place to make the preset your own.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShaderSwirlEmber } from "@/components/remocn/shader-swirl-ember";

export const RemotionRoot = () => (
  <Composition
    id="ShaderSwirlEmber"
    component={ShaderSwirlEmber}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

ShaderSwirlEmber takes the same props as `ShaderSwirl`. Props you pass override the preset, except `speed`, which scales the preset's own pace: `speed={2}` is twice as fast as the preset, whatever its base speed.
