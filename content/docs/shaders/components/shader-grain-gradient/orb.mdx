Installs [Grain Gradient](/docs/shaders/components/shader-grain-gradient) as a dependency. This file only fixes its look: the preset object at the top holds every value, so edit it in place to make the preset your own.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShaderGrainGradientOrb } from "@/components/remocn/shader-grain-gradient-orb";

export const RemotionRoot = () => (
  <Composition
    id="ShaderGrainGradientOrb"
    component={ShaderGrainGradientOrb}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

ShaderGrainGradientOrb takes the same props as `ShaderGrainGradient`. Props you pass override the preset, except `speed`, which scales the preset's own pace: `speed={2}` is twice as fast as the preset, whatever its base speed.
