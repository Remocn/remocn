The preview studio plays your video, but it isn't a file. Nothing to upload, nothing to send. Rendering fixes that: it turns the preview into a real mp4, and it's one prompt.

## The one move

When the video looks right in the player, paste:

<GuidePrompt copyLabel="Copy" size="lg">

```text
Render the video to an mp4 in the project folder, and tell me the full path
to the file when it's done.
```

</GuidePrompt>

That's it. Your agent runs the render and tells you where the file landed.

<GuideExportPipeline />

## What to expect

Rendering builds the file frame by frame — every frame of your video gets drawn and encoded. A thirty-second video takes a few minutes, longer than the video itself. That's normal, not a sign something is stuck. Let it finish; your agent will report back with the path.

## Where the file goes next

The mp4 is ready to upload as-is. X, YouTube and LinkedIn all take the horizontal file directly — no conversion, no export settings, no editor in between.

## Changed something after rendering?

Just render again. The old file is not precious — a render costs a few minutes, so tweak the video, paste the same prompt, get a fresh mp4. Render as many times as it takes.
