To make animated text effects in Remotion, every style value of the text (opacity, position,
blur, letter spacing) has to be computed from the current frame with `useCurrentFrame()` and
`interpolate()` or `spring()`. You split the text into words or letters and offset each one's
start frame. Or you install a finished effect: Remocn has 256 free, MIT-licensed text animation
components for Remotion, plus 31 caption styles, added with
`npx shadcn@latest add @remocn/<name>`.

Each component is copied into your project as one TypeScript file. There is no runtime package to
depend on, and you can edit the source.

## How to animate text in Remotion

A word-by-word reveal written by hand looks like this:

```tsx
import { interpolate, useCurrentFrame } from "remotion";

export const WordReveal = ({ text }: { text: string }) => {
  const frame = useCurrentFrame();

  return (
    <h1 style={{ fontSize: 96 }}>
      {text.split(" ").map((word, i) => {
        // Each word starts 4 frames after the previous one and takes 12 frames.
        const progress = interpolate(frame - i * 4, [0, 12], [0, 1], {
          extrapolateLeft: "clamp",
          extrapolateRight: "clamp",
        });
        return (
          <span
            key={i}
            style={{
              display: "inline-block",
              marginRight: "0.25em",
              opacity: progress,
              translate: `0 ${(1 - progress) * 20}px`,
            }}
          >
            {word}
          </span>
        );
      })}
    </h1>
  );
};
```

The same effect from Remocn, followed by a highlighted line:

```bash
npx shadcn@latest add @remocn/staggered-fade-up @remocn/marker-highlight
```

```tsx
import { AbsoluteFill, Sequence } from "remotion";
import { MarkerHighlight } from "@/components/remocn/marker-highlight";
import { StaggeredFadeUp } from "@/components/remocn/staggered-fade-up";

export const Hook = () => (
  <AbsoluteFill>
    <Sequence durationInFrames={90}>
      <StaggeredFadeUp text="Every launch needs a video" staggerDelay={4} />
    </Sequence>
    <Sequence from={90} durationInFrames={90}>
      <MarkerHighlight before="Yours ships " highlight="today" after="." />
    </Sequence>
  </AbsoluteFill>
);
```

Every component page lists the component's props and its natural length in frames at 30fps.
That length is the minimum for its `Sequence`. Add hold frames on top if the text should stay on
screen after it settles.

## Remotion text animation pitfalls

These are the mistakes that make text flicker, jump or render differently from the preview.
Remocn's text components handle each of them in their source, which you can read after install.

- **CSS transitions and keyframes don't render.** Remotion renders frames out of order and in
  parallel, so wall-clock animation never reaches the MP4. None of the typography components uses
  a CSS `transition`, `animation` or `@keyframes`; every value comes from the frame.
- **`Math.random()` changes on every render.** Scrambles and glitches built on it flicker and
  differ between render threads. None of the components calls `Math.random()`. The ones with
  randomness in them, such as `matrix-decode`, `rgb-glitch-text` and `type-wall`, use Remotion's
  seeded `random()`, so frame 40 always looks the same.
- **The font isn't loaded on the first frame.** The text renders in a fallback font, and anything
  measured from it (line widths, where a highlight or caret sits) is wrong. Most of the
  components load their font through `@remotion/google-fonts`, and most of the ones that lay text out
  by measuring it hold the render with `delayRender()` until the font has loaded and the measurement
  is done.
- **Unclamped `interpolate()` keeps going.** Without `extrapolateRight: "clamp"`, a fade passes 1
  and a slide overshoots its end position. The components clamp their interpolations.
- **Timing written in frames breaks at another frame rate.** `typewriter` takes
  `charsPerSecond` and converts it with the composition's `fps`. Almost every component also
  takes a `speed` prop that retimes the whole effect without editing its code.
- **Spaces collapse when text is split into spans.** Splitting per character drops the spaces
  between words. Per-letter components such as `soft-blur-in` and `typewriter` render with
  `white-space: pre`, so the spaces stay.

## Remocn vs Remotion Bits vs snapcn vs hand-rolled

Facts about the other libraries come from their own sites, checked on November 9, 2026.

| | Hand-rolled | [Remotion Bits](https://remotion-bits.dev) | [snapcn](https://snapcn.dev) | Remocn |
|---|---|---|---|---|
| What you get | Your own code | One configurable `AnimatedText` (split by character, word or line, with stagger) plus `Typewriter`; about 14 text examples | Twelve free text components on its text-animation page; its Text & Titles list has more, some marked Pro | 256 text animation components plus 31 caption styles, one component per effect |
| Install | — | `npm install remotion-bits`, or copy the source with jsrepo | `npx shadcn@latest add @snapcn/<name>` | `npx shadcn@latest add @remocn/<name>` |
| Price and license | Free | Free, MIT | 60 components MIT, 81 Pro (site-wide, per its footer) | Free, MIT, every component |
| Pick it when | You need one simple effect and want zero dependencies | You want one primitive you configure yourself | You want its specific look and its notes on rendering scaled type | You want a finished, distinct effect for each beat without writing the motion |

The options combine. A Remocn component is plain Remotion code in your project, so you can put it
next to Remotion Bits primitives or your own effects in the same composition.

## FAQ

<Faq>

**How do I animate text in Remotion?**
Compute every style value from `useCurrentFrame()` with `interpolate()` or `spring()`, split the text into words or letters, and give each one a later start frame. Or install a ready-made effect with `npx shadcn@latest add @remocn/<name>`.

**Are there free text animation components for Remotion?**
Yes. Remocn has 256 free, MIT-licensed text animation components and 31 caption styles. You install them with the shadcn CLI, and the source is copied into your project.

**Can I use CSS animations for text in Remotion?**
No. Remotion renders frames out of order and in parallel, so CSS transitions and keyframes don't show up in the render. Every value has to come from the current frame.

**How do I make a typewriter effect in Remotion?**
Install it with `npx shadcn@latest add @remocn/typewriter` and pass `text` and `charsPerSecond`. The cursor blink is computed from the frame, so it is the same in every render.

**Why does my text flicker or jump in the rendered video?**
The usual causes are `Math.random()` in the render, a font that loaded after the first frame, or an `interpolate()` without clamping. See the [pitfalls](#remotion-text-animation-pitfalls) above.

**Do Remocn components need a runtime dependency?**
No. The shadcn CLI copies each component's source into your project. Remotion is the only runtime, and it keeps [its own license](https://www.remotion.dev/docs/license).

**Can I change the font, colors and timing?**
Yes. Props cover text, colors, sizes and a `speed` multiplier on most components, and the source is yours to edit.

**Is Remocn made by Remotion or shadcn?**
No. Remocn is an independent open-source project, not affiliated with Remotion or shadcn. It is listed on Remotion's resources page.

</Faq>
