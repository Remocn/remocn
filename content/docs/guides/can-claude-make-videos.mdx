_Last updated: November 18, 2026_

Claude doesn't generate video footage the way text-to-video models do. What it does well is write
code, and a video can be code: with [Remotion](https://www.remotion.dev), a React component renders
frame by frame into an MP4. So the practical way to have Claude make a video is Claude Code (or
another coding agent) in a Remotion project: it writes the scenes, you preview them, and one command
renders the file. Remocn gives Claude ready-made, tuned scenes to build with, so the result looks
designed rather than improvised.

The same works with ChatGPT's coding agent, Codex: see
[Remotion with ChatGPT](/docs/guides/remotion-chatgpt).

## What Claude-made videos are good at

- **Motion graphics:** animated titles, product screens, charts, numbers, logos, transitions.
- **Your real copy and brand:** it reads your README and site and uses your words and colors.
- **Edits in plain language:** "make the second title slower" is a change to a number in the code.

And what they're not:

- **Live-action footage.** People, places and cinematic shots come from a camera or a video model.
- **One-click results in a chat window.** Building and rendering needs a project on your computer,
  which is why Claude Code, not claude.ai, does the building.

## Do it

1. **Install the Remocn plugin** in Claude Code. It adds a `/remocn:video` workflow and Remocn's
   component catalog:

   ```text
   /plugin install remocn --marketplace Remocn/remocn
   ```

2. **Ask for a video** from your project's folder:

   ```text
   /remocn:video 30-second launch video for my app: the problem, the product, three features, the URL
   ```

   Claude shows a storyboard first and waits for your go-ahead. If there's no Remotion project yet,
   it creates one.

3. **Preview and direct.** Open the project in [Remocn Studio](https://remocn.studio) (macOS and
   Linux) or run `npx remotion studio`, then ask for changes in sentences.

4. **Render:** ask Claude to "Render the video." and you get an `.mp4`.

[Setup](/docs/guides/setup) has the full one-time setup, including the agent skill for other agents.

## In claude.ai

In the Claude app you can plan the video: add Remocn's free MCP server (`https://remocn.dev/mcp`) as
a connector to search components, get a beat-by-beat plan and preview components in the chat. Then
take the plan to Claude Code to build and render it.
[MCP server](/docs/getting-started/mcp-server) has the steps.

## Why do Claude's videos all look the same?

Asked for "a launch video" with nothing else, an agent improvises every animation and reaches for
the same glow and pop-in each time. [Non-generic AI video](/docs/guides/non-generic-ai-video) explains
the tells and how tuned components and taste rules fix them.

<Faq>

**Is it free?**
Remocn is free and MIT-licensed. Claude Code needs a Claude subscription or API key. Remotion is free
for individuals and small companies, with a [company license](https://www.remotion.dev/license) for
larger ones.

**Can Claude add a voiceover?**
Not by itself. Record one or generate it with a text-to-speech service, then Claude can place it and
add [word-by-word captions](/docs/guides/word-by-word-captions).

</Faq>
