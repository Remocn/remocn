_Last updated: November 24, 2026._

To animate a logo in Remotion, build a short composition where the mark arrives, the wordmark
reveals beside it, one frame lands as the hit, and the finished logo holds still until the cut.
Every value comes from `useCurrentFrame()` through `spring()` or `interpolate()`. Or install a
finished one: Remocn has 45 free, MIT-licensed logo stings for Remotion, added with
`npx shadcn@latest add @remocn/<name>`.

Each sting is copied into your project as source, so you can edit it. There is no runtime package
besides Remotion.

## What makes a logo sting land

A logo sting is punctuation, not a scene. Three things decide whether it reads as a brand moment
or as a slow fade nobody remembers.

- **Length: one to three seconds of motion.** Most Remocn stings finish their own movement in 26
  to 150 frames at 30 fps (about 1 to 5 seconds). Past that, the viewer is waiting for the logo
  instead of seeing it.
- **A hit: one frame where the logo is finished.** Everything before it is build-up, everything
  after it is settle. The hit is where a sound goes and where the eye locks on. Spread the arrival
  over a long ease and there is no hit, only drift.
- **An end on a hold.** Leave the lockup still for at least half a second, and a full second on
  the last shot of a video. A logo that is still moving when the video cuts never registers.

Two smaller rules follow from those three:

- **Keep the final frame plain.** Mark, name, maybe one short line. Particles, rings and light
  are lead-in, and they should be gone or quiet by the hold.
- **Don't scale the wordmark text.** A mark (an SVG or image) scales cleanly. Text under a moving
  `scale` steps from pixel to pixel in Chrome and shimmers. Reveal the name with a clip and a
  short horizontal slide instead.

## How to animate a logo in Remotion: mark plus wordmark

A minimal reveal: the mark springs in, the wordmark wipes out from behind it, a sound plays on the
hit, and the lockup holds. Timings are written in seconds and converted with the composition's
`fps`, so the sting runs the same length at 30 or 60 fps.

```tsx
import {
  AbsoluteFill,
  Audio,
  Easing,
  Img,
  Sequence,
  interpolate,
  spring,
  staticFile,
  useCurrentFrame,
  useVideoConfig,
} from "remotion";

export const LogoSting = () => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const s = (seconds: number) => Math.round(seconds * fps);

  // The mark lands without overshoot: damping 200 stops the wobble.
  const mark = spring({ frame, fps, config: { damping: 200 }, durationInFrames: s(0.6) });

  // The wordmark starts once the mark is nearly settled, and finishes on the hit.
  const hit = s(1.1);
  const reveal = interpolate(frame, [s(0.45), hit], [0, 1], {
    extrapolateLeft: "clamp",
    extrapolateRight: "clamp",
    easing: Easing.out(Easing.cubic),
  });

  return (
    <AbsoluteFill
      style={{ alignItems: "center", justifyContent: "center", background: "#0B0B0C" }}
    >
      <div style={{ display: "flex", alignItems: "center", gap: 28 }}>
        <Img
          src={staticFile("mark.svg")}
          style={{ height: 120, scale: String(0.6 + 0.4 * mark), opacity: mark }}
        />
        <span
          style={{
            fontSize: 112,
            fontWeight: 700,
            color: "#FFFFFF",
            // Clip from the right and slide horizontally: no scale on the text.
            clipPath: `inset(0 ${(1 - reveal) * 100}% 0 0)`,
            translate: `${(1 - reveal) * -32}px 0`,
          }}
        >
          acme
        </span>
      </div>
      {/* The sound starts on the hit frame. */}
      <Sequence from={hit}>
        <Audio src={staticFile("hit.wav")} />
      </Sequence>
    </AbsoluteFill>
  );
};
```

Register it for 2.5 seconds: 1.1 seconds to the hit and 1.4 seconds of hold.

```tsx
<Composition
  id="LogoSting"
  component={LogoSting}
  durationInFrames={150}
  fps={60}
  width={1920}
  height={1080}
/>
```

Why it is built this way:

- **The layout never moves.** The mark and the name sit where they end up from frame 0, and only
  `scale`, `clip-path` and `translate` change. Animating `margin`, `gap` or `left` reflows the
  line and makes text jump by whole pixels.
- **The wordmark move is horizontal only.** A slow vertical slide on text steps unevenly in
  Chrome; a horizontal one does not.
- **The hit is a named frame.** The sound, and any flash or shake you add later, hang off `hit`,
  so changing the timing moves them together.
- **No CSS transitions, no `Math.random()`.** Remotion renders frames out of order and in
  parallel, so every value has to come from the frame.

## Ready-made logo stings in Remocn

The same job from Remocn, with the hit and the hold already timed. Install one:

```bash
npx shadcn@latest add @remocn/orbit-lock
```

```tsx
import { Img, staticFile } from "remotion";
import { OrbitLock } from "@/components/remocn/orbit-lock";

export const LogoSting = () => (
  <OrbitLock moons={3} tilt={64}>
    <Img src={staticFile("logo.svg")} style={{ height: 120 }} />
  </OrbitLock>
);
```

Moons collapse into a core that bursts into a ring flash at frame 30 (30 fps), and your logo
springs in. Give the sequence about a second after frame 50 so the logo holds.

## Where a logo sting goes: the open or the close

Put the sting in the first or last `Sequence` of the video. Most Remocn stings fill the frame and
play their own lead-in, so they don't need a transition into them.

```tsx
import { Img, Series, staticFile } from "remotion";
import { Spotlight } from "@/components/remocn/spotlight";

// fps={60}: Spotlight moves for 50 frames at 30 fps, so 100 here, plus a 1-second hold.
export const Video = () => (
  <Series>
    <Series.Sequence durationInFrames={160}>
      <Spotlight>
        <Img src={staticFile("logo.svg")} style={{ height: 120 }} />
      </Spotlight>
    </Series.Sequence>
    <Series.Sequence durationInFrames={600}>{/* the product */}</Series.Sequence>
  </Series>
);
```

- **At the open:** keep it short (under about 2 seconds with the hold). The viewer came for the
  product, so a fast sting like Accordion Unfold or Puzzle Snap fits.
- **At the close:** this is where the logo should be remembered. A longer sting with a tagline or
  URL, such as Introducing or First Light, and a longer hold of 1.5 to 2 seconds.
- **Both:** use the same sting at both ends, or a short one first and the full lockup last. Two
  different long stings make the video feel like two videos.

The [launch video](/docs/guides/launch-video) and [teaser](/docs/guides/teaser) guides show a sting
inside a full video.

## FAQ

<Faq>

**How do I animate a logo in Remotion?**
Compute the mark's scale and opacity from `useCurrentFrame()` with `spring()`, reveal the wordmark with a `clip-path` driven by `interpolate()`, pick one frame as the hit, and hold the finished lockup for at least half a second. Or install a ready-made sting with `npx shadcn@latest add @remocn/<name>`.

**How long should a logo sting be?**
One to three seconds of motion plus a hold of half a second to two seconds. Remocn stings state their motion length in 30 fps frames on each page; that number is the minimum for the `Sequence`.

**How do I add a sound to a logo animation in Remotion?**
Put an `<Audio>` inside a `<Sequence from={hit}>`, where `hit` is the frame the logo is finished. For a Remocn sting, the hit frame is in the Timing table on its docs page (Orbit Lock bursts at frame 30 at 30 fps, so frame 60 in a 60 fps composition). Remocn stings ship without sound, so bring your own sound effect and check that its license allows commercial use.

**Should a logo sting go at the start or the end of the video?**
Either, or both. At the open keep it short so the product starts fast; at the close give it a tagline or URL and a longer hold, since that is the frame people remember. See [the section above](#where-a-logo-sting-goes-the-open-or-the-close).

**Can I use my own logo with Remocn stings?**
Yes. Most stings take your logo as `children` (an `<Img>`, an SVG or any React node) or as a `logo` / `name` prop. A few draw their own mark and take only your wordmark. Each component page lists its props.

**Should I scale text in a logo animation?**
Scale the mark, not the wordmark. Text under a moving `scale` or slow vertical `translate` steps from pixel to pixel in Chrome. Reveal the name with a clip and a horizontal slide.

**Are Remocn logo stings free?**
Yes. Every Remocn component is free and MIT-licensed, and the source is copied into your project. Remotion keeps [its own license](https://www.remotion.dev/docs/license).

**Is Remocn made by Remotion or shadcn?**
No. Remocn is an independent open-source project, not affiliated with Remotion or shadcn. It is listed on Remotion's resources page.

</Faq>
