You need two things: an AI coding agent and an empty folder.

<GuideChecklist title="One-time setup" description="About ten minutes, all copy-paste." done={1} total={2}>

<GuideStep state="done" title="Get an agent">

We recommend [Claude Code](/docs/ai/claude-code) — also works with [ChatGPT](/docs/ai/chat-gpt), [opencode](/docs/ai/opencode) and others.

<GuideAgentPicker />

</GuideStep>

<GuideStep state="current" step={2} title="Open the agent in an empty folder and paste:">

<GuidePrompt>

```text
Set up a new Remotion video project in this folder, then install the remocn
agent skill: npx skills add Remocn/remocn --yes. When you're done, start the
preview studio so I can watch the video while we work.
```

</GuidePrompt>

<GuidePluginAside>

**Or use the [plugin](/docs/getting-started/plugin)** in Claude Code or Codex, instead of the skill.

Then start any video with `/remocn:video` and a one-line brief.

</GuidePluginAside>

</GuideStep>

<GuideStep state="next" title="You're ready">

When a browser tab opens with an empty video player, you're ready. Pick a guide and make it yours.

<GuideStudioPreview />

<GuideReadyRow>

Finished videos you can make yours — pick one, fill in your words, paste a prompt. [Pick a guide](/docs/guides)

</GuideReadyRow>

</GuideStep>

</GuideChecklist>
