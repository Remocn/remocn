**Short answer:** the best Claude Code skills for making videos in 2026 are Remotion's Agent Skills
(with `remotion-best-practices`) and Remocn for React videos, HyperFrames for videos written in HTML
and CSS, and ffmpeg-skill or video-use for editing footage you already have. Which one is best depends
on what you start from: a brief and a React project, a brief and no React, or a folder of recordings.

Remocn is not a replacement for Remotion's skill. It sits on top of it: Remotion's skills teach
Claude Code to write correct Remotion code, and Remocn decides what goes on screen, from 935
MIT-licensed components that the agent installs into your project.

Remocn has three entry points with the same catalog behind them. The

## Remocn sits on top of remotion-best-practices

Install both. They answer different questions:

- **Remotion's Agent Skills** teach Claude Code the Remotion API. `remotion-best-practices` is the
  catch-all skill among them; others create projects, open the Studio, render and handle captions.
  They leave the visual direction to your brief, so the agent writes every animation itself.
- **Remocn** teaches Claude Code what to put on screen: which component plays each beat, how many
  frames it needs, and design rules so the result doesn't look generic. The agent installs each piece
  as source with `npx shadcn@latest add @remocn/<name>`.

With Remocn's skill, the agent reads the live component index from remocn.dev
([`/llms-components.txt`](https://remocn.dev/llms-components.txt)) instead of a bundled copy, so a
component added today is visible to a skill installed months ago. The agent needs network access to
remocn.dev for that.

```bash
npx skills add remotion-dev/skills
npx skills add Remocn/remocn
```

Or, in Claude Code, the plugin and a brief:

```text
/plugin install remocn --marketplace Remocn/remocn
/remocn:video 30-second launch video for my app: the problem, the product, three features, the URL
```

The plugin shows a storyboard first and waits for your go-ahead; if the folder has no Remotion
project, it creates one. Each component it picks lands in your repo the same way you would add one by
hand:

```bash
npx shadcn@latest add @remocn/soft-blur-in
```

See [Soft Blur In](/docs/typography/soft-blur-in) for that component, and
[Installation](/docs/getting-started/installation) for adding Remocn to an existing Remotion project.

## Which Claude Code video skill should I use?

- **Pick Remotion's Agent Skills** for any Remotion project. They are the base layer; on their own
  they suit you when you want Claude to write every animation from scratch to your own design.
- **Pick Remocn** when you work in React and want a launch, product demo, feature announcement or
  changelog video that looks designed, built from tuned components and full templates you own as
  source. It is free and MIT, and the [launch video guide](/docs/guides/launch-video) walks through a
  first video from a brief.
- **Pick HyperFrames** when your team writes HTML, CSS and GSAP rather than React, or when you need a
  permissive licence at any company size: HyperFrames is Apache 2.0, while Remotion needs a paid
  Company License above 3 people. It also has voice, music and HeyGen's generative models in its paid
  Studio tier, which Remocn doesn't have.
- **Pick ffmpeg-skill** to cut, caption, reframe or re-encode recordings you already have, locally and
  without API keys.
- **Pick video-use** to turn a folder of raw talking-head takes into an edited `final.mp4`, if you are
  fine giving it an ElevenLabs key.

## When is Remocn the wrong choice?

- **You are editing footage.** Remocn makes motion graphics; it does not cut, trim or grade recorded
  video. Use ffmpeg-skill or video-use, or a video editor.
- **You don't have Node.js, or don't want React.** Remocn components are React code rendered by
  Remotion, which runs on Node.js. Without that, HyperFrames (also Node.js, but HTML instead of React)
  or an FFmpeg skill fits better.
- **You need a permissive licence at a company above 3 people and won't buy Remotion's.** Remocn is
  MIT, but it needs Remotion, and Remotion's own licence applies.
- **You want a hosted service that renders for you.** Remocn has no account and no render servers. Its
  MCP server plans and previews; rendering happens wherever you run Remotion.
- **You want a timeline.** Remocn has no timeline editor. You write or prompt code and watch the result
  in Remotion Studio or [Remocn Studio](https://remocn.studio).

## FAQ

<Faq>

**What are the best Claude Code skills for making videos?**
Remotion's Agent Skills (`npx skills add remotion-dev/skills`) and Remocn (`npx skills add Remocn/remocn`, or the plugin with `/remocn:video`) for React videos, HyperFrames (`npx skills add heygen-com/hyperframes`) for HTML and CSS videos, and ffmpeg-skill or video-use for editing existing footage.

**Can Claude Code render an MP4 locally?**
Yes. With Remotion, Claude Code runs `npx remotion render` on your machine; with HyperFrames, `npx hyperframes render`; FFmpeg skills run FFmpeg locally. Remotion also renders on AWS through `@remotion/lambda` if you set it up. Remocn adds no render step of its own: the components render wherever you run Remotion.

**Do Claude Code video skills need an API key?**
Claude Code itself needs a Claude subscription or an Anthropic API key. Beyond that, Remotion's skills, Remocn's skill, plugin and MCP server, HyperFrames' free skills and ffmpeg-skill need no key. video-use needs an ElevenLabs key, and HeyGen Skills need a HeyGen key.

**Does Remocn replace Remotion's remotion-best-practices skill?**
No. Remotion's skills teach Claude Code how to write correct Remotion code; Remocn adds ready-made components and design rules on top. Install both.

**Is the Remocn skill free?**
Yes. The skill, the Claude Code plugin, the MCP server and every component are free and MIT licensed, with no account. Remotion keeps its own licence: free for teams of up to 3 people, a paid Company License above that.

**Can a Claude Code skill edit my screen recordings?**
Remocn can't: it makes motion graphics, not footage edits. ffmpeg-skill cuts, captions and reframes recordings, and video-use turns raw takes into an edited video.

**Is Remocn affiliated with Remotion, HyperFrames or Anthropic?**
No. Remocn is an independent open-source project. It is listed on Remotion's resources page.

</Faq>
