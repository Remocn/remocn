## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FrostedClear } from "@/components/remocn/frosted-clear";

const FrostedClearScene = () => <FrostedClear title="10×" kicker="Faster renders" />;

export const RemotionRoot = () => (
  <Composition
    id="FrostedClear"
    component={FrostedClearScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A rounded frosted panel blurs a gradient scene and a big `title` behind it. A clear circle opens from the center of the panel with a glinting edge, the content settles and the panel border returns. Pass a short `title` (for example "10×") and a `kicker`. Ships dark and light via `theme`.
