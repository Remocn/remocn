## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LedTicker } from "@/components/remocn/led-ticker";

const LedTickerScene = () => (
  <LedTicker text="remocn is live" highlightWord="live" />
);

export const RemotionRoot = () => (
  <Composition
    id="LedTicker"
    component={LedTickerScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Text scrolls in from the right across a grid of LED dots with a short trailing glow, locks centered, and the `highlightWord` flashes through a warm-to-accent gradient. Pass `text` and `highlightWord`; the dot font covers A to Z, digits and common punctuation, and text is drawn in uppercase. Ships dark and light via `theme`.
