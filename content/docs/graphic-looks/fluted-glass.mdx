## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlutedGlass } from "@/components/remocn/fluted-glass";

const FlutedGlassScene = () => <FlutedGlass title="In focus." />;

export const RemotionRoot = () => (
  <Composition
    id="FlutedGlass"
    component={FlutedGlassScene}
    durationInFrames={145}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A sheet of vertical glass flutes covers the frame, refracting an orb and the `title` into stretched slivers while the backdrop drifts. The sheet then slides off to the right, leaving the sharp orb and headline. Pass a short `title`. Ships dark and light via `theme`.
