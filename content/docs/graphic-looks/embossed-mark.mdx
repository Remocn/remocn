## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EmbossedMark } from "@/components/remocn/embossed-mark";

const EmbossedMarkScene = () => <EmbossedMark name="emocn" />;

export const RemotionRoot = () => (
  <Composition
    id="EmbossedMark"
    component={EmbossedMarkScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A mark is pressed into a grey surface; a raking light sweeps around it, deepening the shadows. The camera eases out, a foil fill appears in the mark and the `name` letters fade in after it. Pass a custom `logo` node (square slot, black fill) to replace the default R and set `name` to the letters that follow. Ships dark and light via `theme`.
