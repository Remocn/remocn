## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LaunchDays } from "@/components/remocn/launch-days";

const LaunchDaysScene = () => (
  <LaunchDays
    week="Launch Week 01"
    active={2}
    days={[{ day: "Mon", title: "Captions" }, { day: "Tue", title: "Transitions" }, { day: "Wed", title: "Templates", description: "Whole launch films you own." }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LaunchDays"
    component={LaunchDaysScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A header reads the `week` name while the day panels rise in a strip. The `active` day widens into a card showing its number, title and description under a `label` pill, and the other days shrink to slivers. Pass your own `days`, `week` and `active`; set `from` to start with another day lit and swap to `active`. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
