## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RimDrawCard } from "@/components/remocn/rim-draw-card";

const RimDrawCardScene = () => (
  <RimDrawCard
    line="Just tell it once."
    command="/brand-voice"
    title="Brand voice"
    uses={["Launch posts", "Changelog", "Release emails"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RimDrawCard"
    component={RimDrawCardScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A headline `line` and a slash `command` chip lead in, then a beam of light draws around a card's rim. The card fills with a title, a field that types the `instructions`, usage chips and a preview, and the save button presses to show `done`. Pass your own `line`, `command`, `title`, `instructions` and `uses`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
