## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ToolbarUnfurl } from "@/components/remocn/toolbar-unfurl";

const ToolbarUnfurlScene = () => (
  <ToolbarUnfurl
    accent="#3B5BFD"
    lines={["Leave a note.", "Sketch the shot.", "Type on the frame.", "Select any layer."]}
    finalLine="Every tool, one tap away."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ToolbarUnfurl"
    component={ToolbarUnfurlScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A cursor taps a round accent button that unfurls into a four-tool strip, hopping from tool to tool while a caption names each one. The strip then retracts and the `finalLine` lands. Pass your own `lines` (up to four captions, one per tool) and `finalLine`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
