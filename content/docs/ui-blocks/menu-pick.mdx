## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MenuPick } from "@/components/remocn/menu-pick";

const MenuPickScene = () => (
  <MenuPick
    prompt="Choose your launch"
    options={["Keyframe every beat", "Wait on an agency", "Install the scenes"]}
    pick={2}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MenuPick"
    component={MenuPickScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A panel appears with a `prompt` and a list of `options`. A selection bar hops between rows, confirms with a quick blink on the `pick` row, and the other rows dim. Pass your own `prompt`, `options` and a zero-based `pick`; it ships light and dark through `theme`. Use `speed` to slow or quicken the hops.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
