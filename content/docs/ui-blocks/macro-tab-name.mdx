## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MacroTabName } from "@/components/remocn/macro-tab-name";

const MacroTabNameScene = () => (
  <MacroTabName
    name="Launch Assets"
    path={["Marketing", "Launch week"]}
    docMeta="Edited 2 min ago · 14 files"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MacroTabName"
    component={MacroTabNameScene}
    durationInFrames={108}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera starts in macro on a document tab. A cursor clicks it, the `name` types in character by character, a brief spinner shows the save, and the tab resolves into the finished title over a breadcrumb and meta line. Pass your own `name`, `path` and `docMeta`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
