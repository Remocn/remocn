## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BorderBeam } from "@/components/remocn/border-beam";

const BorderBeamScene = () => (
  <BorderBeam
    title="Version 2.0"
    description="Launch videos, written in React."
    command="npx shadcn add @remocn/launch-film"
    showLogo={false}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BorderBeam"
    component={BorderBeamScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A card rises in and a beam laps its border once. As the tail passes, a logo, the `title`, the `description` and the mono `command` line fade in one by one. Pass your own `title`, `description` and `command`; set `showLogo` to false to hide the built-in wordmark. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
