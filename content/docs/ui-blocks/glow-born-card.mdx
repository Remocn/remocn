## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlowBornCard } from "@/components/remocn/glow-born-card";

const GlowBornCardScene = () => (
  <GlowBornCard
    before="Or import a scene from"
    after="your repo"
    title="Import from repository"
    value="lumen-labs/launch"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GlowBornCard"
    component={GlowBornCardScene}
    durationInFrames={136}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A headline reads `before` and `after` while a glow ignites in the gap and condenses into a card. A field types the `value`, the button presses, and a done state pops in. Pass your own `before`, `after`, `title`, `label` and `value`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
