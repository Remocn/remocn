## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KeycapPress } from "@/components/remocn/keycap-press";

const KeycapPressScene = () => (
  <KeycapPress
    keys={[{ label: "⌘", sub: "command", width: 1.25 }, { label: "K" }]}
    label="Everything, one shortcut away"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KeycapPress"
    component={KeycapPressScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Keycaps rise into a tilted 3D view, press one after another as a chord with a ripple, then lift while the `label` writes in below. Pass your own `keys` as strings or objects with a legend, a sub label and a width. `material` sets the keycap finish and `theme` the stage; the symbols for command, option and shift are drawn as icons.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
