## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { QueryCascade } from "@/components/remocn/query-cascade";

const QueryCascadeScene = () => (
  <QueryCascade
    hero="how to make a launch video"
    term="launch video"
    answerBefore="Your"
    answerAfter="is ready."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="QueryCascade"
    component={QueryCascadeScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A long list of `queries` scrolls past with motion blur and decelerates until the `hero` query sits in a search box. The `term` inside it is highlighted, the box clears, and the line resolves into `answerBefore`, the term and `answerAfter`. Pass your own `hero`, `term` and answer words; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
