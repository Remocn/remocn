## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GhostComplete } from "@/components/remocn/ghost-complete";

const GhostCompleteScene = () => (
  <GhostComplete
    title="Launch notes"
    typed="Ship the"
    suggestions={["launch video", "\nbefore lunch."]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GhostComplete"
    component={GhostCompleteScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A card titled `title` types the `typed` text, then each entry in `suggestions` appears as grey ghost text and fills in with a Tab press. A suggestion starting with a newline continues on a second line. Pass your own `typed` text and `suggestions`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
