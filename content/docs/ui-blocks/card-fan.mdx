## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CardFan } from "@/components/remocn/card-fan";

const CardFanScene = () => (
  <CardFan
    title="Your top formats"
    accentWord={2}
    pick={1}
    caption="Launch films are 41% of this month’s renders"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CardFan"
    component={CardFanScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A title writes in while a stack of cards drops, fans out, and lifts the `pick` card forward. A caption then writes in word by word. Pass your own `title` (with `accentWord` tinting one word), up to six `cards`, the `pick` index and the `caption`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
