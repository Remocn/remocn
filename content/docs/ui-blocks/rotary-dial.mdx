## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RotaryDial } from "@/components/remocn/rotary-dial";

const RotaryDialScene = () => (
  <RotaryDial
    from={1}
    to={10}
    unit="×"
    label="Render speed"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RotaryDial"
    component={RotaryDialScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A label and value write in, a cursor grabs a metal dial and turns it, and the value counts from `from` to `to` as an arc heats up. The dial clicks into its final detent with a bloom of light. Pass your own `from`, `to`, `unit` and `label`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
