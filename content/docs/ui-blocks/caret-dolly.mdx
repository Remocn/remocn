## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CaretDolly } from "@/components/remocn/caret-dolly";

const CaretDollyScene = () => (
  <CaretDolly
    prompt="Make a launch video for our new app with a bold title and a calm ending"
    focus="launch video"
    modelLabel="Remocn 1"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CaretDolly"
    component={CaretDollyScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera rides the caret as the `prompt` types, then punches in huge on the `focus` phrase, pulls back to show the full box and types the rest. A cursor then presses the send button. Pass your own `prompt` and a `focus` phrase that occurs inside it; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
