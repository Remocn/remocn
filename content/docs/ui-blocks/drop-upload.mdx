## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DropUpload } from "@/components/remocn/drop-upload";

const DropUploadScene = () => (
  <DropUpload
    title="Drop in your launch notes"
    fileName="launch-notes.md"
    fileKind="MD"
    fileSize="2.4 MB"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DropUpload"
    component={DropUploadScene}
    durationInFrames={162}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A drop zone appears with a title and hint, a file card flies in and drops, then collapses into an upload row. A progress bar fills and the row ends on a check mark. Pass your own `title`, `fileName`, `fileKind`, `fileSize` and `hint`; the `history` rows only show in portrait. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
