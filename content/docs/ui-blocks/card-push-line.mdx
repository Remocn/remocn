## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CardPushLine } from "@/components/remocn/card-push-line";

const CardPushLineScene = () => (
  <CardPushLine
    line="You can just write it"
    command="/launch-video"
    prompt="a teaser for the 2.0 release"
    attachName="release-notes-2.0.md"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CardPushLine"
    component={CardPushLineScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `line` headline lands word by word, then a prompt card pushes in. It types the `command` as a chip, attaches a file tile and types the `prompt` until the send button arms. Pass your own `line`, `command`, `prompt` and `attachName`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
