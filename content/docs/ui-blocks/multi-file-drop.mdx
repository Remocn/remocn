## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MultiFileDrop } from "@/components/remocn/multi-file-drop";

const MultiFileDropScene = () => (
  <MultiFileDrop
    heading="What are we launching?"
    prompt="Build a launch page with a hero video and a pricing table."
    files={[{ name: "brief.pdf", kind: "doc", size: "412 KB" }, { name: "hero.jpg", kind: "image", src: "/hero.jpg" }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MultiFileDrop"
    component={MultiFileDropScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A heading and prompt card appear, then a fan of up to four files flies in, drops into the card and deals into slots. Each file shows a progress ring that resolves into a thumbnail, and the cursor presses send. Pass your own `heading`, `prompt` and `files`; it ships light and dark through `theme`. The default image file uses a `staticFile` that only exists in the remocn repo, so give your own image through `files[].src`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
