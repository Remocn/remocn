## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UrlBarCta } from "@/components/remocn/url-bar-cta";

const UrlBarCtaScene = () => (
  <UrlBarCta
    url="remocn.dev"
    headline="Ship your launch video this afternoon."
    cta="Browse components"
    image="/clip-thumb.jpg"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="UrlBarCta"
    component={UrlBarCtaScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large address bar types the `url` with a suggestion list, presses Enter and docks into the toolbar of a browser window. The landing page then fades up with the `headline`, `body`, a `cta` button, an install `command` and a clip card. Pass your own `url`, `headline`, `body`, `cta` and `command`, an `image` for the clip card, or `children` to replace the page. The default clip image is a `staticFile` that only exists in the Remocn repo. It ships light and dark through `theme`. The length depends on the `url` length and `typingSpeed`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
