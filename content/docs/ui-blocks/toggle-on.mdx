## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ToggleOn } from "@/components/remocn/toggle-on";

const ToggleOnScene = () => (
  <ToggleOn
    label="Auto-captions"
    state="On"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ToggleOn"
    component={ToggleOnScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big switch presses and flips on, the surrounding stage brightens, and the `label` and `state` words write in beside it. Pass your own `label` and `state` text; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
