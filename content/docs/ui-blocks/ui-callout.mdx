## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UiCallout } from "@/components/remocn/ui-callout";

const UiCalloutScene = () => (
  <UiCallout
    src="/screens/dashboard.png"
    screenshotWidth={1440}
    screenshotHeight={900}
    callouts={[{ x: 358, y: 113, title: "Status at a glance", body: "Every issue shows its state." }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="UiCallout"
    component={UiCalloutScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A screenshot window rises in and callouts arrive in turn, each pinned to a target point with a pulsing marker and a card or pill that holds its `title` and `body`. Earlier callouts fold away as the next lands. Pass your own screenshot through `src` or `children`, with `screenshotWidth` and `screenshotHeight`, and list `callouts` whose x and y are in screenshot pixels. With neither `src` nor `children` it shows a built-in issue-tracker mock. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
