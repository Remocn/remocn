## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PillMorph } from "@/components/remocn/pill-morph";

const PillMorphScene = () => (
  <PillMorph
    name="Lumen"
    features={["Transitions", "Captions", "Backgrounds"]}
    src="/product-shot.jpg"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PillMorph"
    component={PillMorphScene}
    durationInFrames={240}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A logo pill pops in and grows into a card showing a product clip, then collapses to a bar and splits into three feature pills before merging into an app tile with the name written below. Pass your own `logo` and `name`, the three `features`, and either a `src` image or `children` for the card. With no `src` or `children` it shows a built-in editor mock that uses a `staticFile` image from the Remocn repo. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
