## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ColorBars } from "@/components/remocn/color-bars";

const ColorBarsScene = () => (
  <ColorBars
    images={["/shots/before.png", "/shots/after.png"]}
    direction="right"
    bars={5}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ColorBars"
    component={ColorBarsScene}
    durationInFrames={86}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two to six slanted bars, tinted from `accent`, whip across the frame in a stagger. The outgoing shot is shoved along while the incoming shot arrives late and settles. Pass the two shots as `scenes` (React nodes) or `images`, set the travel with `direction` and `angle`, and without either it plays a built-in pair of scenes. It ships light and dark; the bars finish and the scene settles by frame 69 with 5 bars.
