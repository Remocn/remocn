## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BatonWord } from "@/components/remocn/baton-word";

const BatonWordScene = () => (
  <BatonWord
    scenes={[
      "The app is ready for launch.",
      "Launch day needs a film.",
      "Film it in code.",
    ]}
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BatonWord"
    component={BatonWordScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each sentence in `scenes` rises in word by word. Its last word then lights up in the accent color, travels along an arc, and becomes the first word of the next sentence, so end each line with the word the next one starts with. The motion finishes at frame 177 at speed 1 with the default three lines, and longer or more lines take longer; it ships light and dark.
