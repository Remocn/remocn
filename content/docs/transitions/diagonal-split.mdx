## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DiagonalSplit } from "@/components/remocn/diagonal-split";

const DiagonalSplitScene = () => (
  <DiagonalSplit
    from="Built in a weekend"
    to="Launched on Monday"
    angle={28}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DiagonalSplit"
    component={DiagonalSplitScene}
    durationInFrames={100}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A bright seam opens at `angle`, then the outgoing `from` scene is shoved off along the seam while the `to` scene settles in behind it on a fluted gradient. Pass `from` and `to` as short text or any React node and tune `angle`; it ships light and dark and the motion ends at frame 70.
