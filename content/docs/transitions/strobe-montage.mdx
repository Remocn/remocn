## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StrobeMontage } from "@/components/remocn/strobe-montage";

const StrobeMontageScene = () => (
  <StrobeMontage
    lead="Six weekends"
    accentWord="of making."
    prompt="A 30-second film for our 2.0 release"
    images={["/shots/a.jpg", "/shots/b.jpg", "/shots/c.jpg"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="StrobeMontage"
    component={StrobeMontageScene}
    durationInFrames={128}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is an opener with a lead phrase and an accent word. A strobe of images flashes frame by frame, growing in size and punching in, then lands on scene B, a prompt box with a heading, a file chip and a typed request. Pass `lead`, `accentWord`, `heading` and `prompt` for the copy, and your own `images` through the montage options (the defaults exist only in the Remocn repo); it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
