## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HairlineOpen } from "@/components/remocn/hairline-open";

const HairlineOpenScene = () => (
  <HairlineOpen
    from="Write the story"
    to="Ship the film"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HairlineOpen"
    component={HairlineOpenScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` statement sits on the stage. A hairline of light draws across the middle, shears slightly, then opens like a slit as the outgoing scene splits away, revealing the `to` statement on a soft gradient. Pass `from` and `to` as short text or any React node; it ships light and dark and settles by frame 78.
