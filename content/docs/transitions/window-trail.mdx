## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WindowTrail } from "@/components/remocn/window-trail";

const WindowTrailScene = () => (
  <WindowTrail
    from="Old look."
    text="New look, same product."
    tagline="Repainted in one render."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WindowTrail"
    component={WindowTrailScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` line sits on the field, then an orange window is thrown up over it, leaving a short trail of stamps. The `text` line is then dragged up from the bottom of the frame the same way, and the `tagline` rises in word by word underneath. Pass your own `from`, `text` and `tagline`; it ships light and dark, and the motion ends at frame 86 at speed 1.
