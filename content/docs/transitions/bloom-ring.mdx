## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BloomRingDemo } from "@/components/remocn/bloom-ring";

const BloomRingDemoScene = () => (
  <BloomRingDemo
    lead="Your store goes live"
    accentLine="in fifteen minutes."
    tagline="Launch films, built from blocks you own."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BloomRingDemo"
    component={BloomRingDemoScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A rises in a two-line headline, a lead plus an accent line. A ring of blurred, striped warm cells blooms outward from the center, swaps the scene, and fades, leaving scene B: the Remocn mark with a tagline. Pass `lead`, `accentLine` and `tagline` for the copy and `ring` to tune the origin and colors; it ships light and dark.
