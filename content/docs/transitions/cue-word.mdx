## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CueWord } from "@/components/remocn/cue-word";

const CueWordScene = () => (
  <CueWord
    scenes={[
      { text: "This line slides left.", cue: "slides left", cut: "slide" },
      { text: "The next one drops in.", cue: "drops in", cut: "drop" },
      { text: "And this one cuts.", cue: "cuts", cut: "cut" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CueWord"
    component={CueWordScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each entry in `scenes` fills the frame with large centered type. The words rise in, the `cue` words land in the accent color, and the line then leaves with its `cut`: slide, drop, lift or an instant cut. Lines alternate between the base field and an accent field. The timeline is 176 frames at speed 1 with the default four lines; it ships light and dark.
