## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DiscPopDemo } from "@/components/remocn/disc-pop";

const DiscPopDemoScene = () => (
  <DiscPopDemo
    prompt="Make a launch film for our piano app: bold title, three product shots, calm ending."
    overline="LAUNCH FILM · 01"
    title="Keys, in an afternoon."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DiscPopDemo"
    component={DiscPopDemoScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is a prompt card with a greeting that types a request and presses send. A grid of colored discs, each carrying a glyph such as play, spark or arrow, pops across the frame and swaps the scene for scene B, a video player with an overline, a title and a progress bar. Pass `greeting`, `prompt`, `overline` and `title`, plus your own `image`; it ships light and dark.
