## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ColumnSlide } from "@/components/remocn/column-slide";

const ColumnSlideScene = () => (
  <ColumnSlide
    from="Plan the launch"
    to="Launch day"
    columns={5}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ColumnSlide"
    component={ColumnSlideScene}
    durationInFrames={96}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` headline sits on the stage. Between 3 and 7 vertical columns, set by `columns`, then slide across in a stagger, each carrying a slice of both headlines, and the new scene settles with a slight scale-down. Pass `from` and `to` as short strings; it ships light and dark and the move finishes at frame 66.
