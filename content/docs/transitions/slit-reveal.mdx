## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlitReveal } from "@/components/remocn/slit-reveal";

const SlitRevealScene = () => (
  <SlitReveal
    title="Introducing remocn"
    src="/images/app-screenshot.png"
    opening="letterbox"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SlitReveal"
    component={SlitRevealScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A point of light draws out into a hairline with the `title` riding on it. The line then opens like a slit, letterbox style or sideways, onto the scene you pass as `children` or `src`, which settles out of a soft blur. Without either it shows a built-in product mock. With `opening="letterbox"` the reveal settles by frame 132, and sideways by frame 152.
