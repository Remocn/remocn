## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RingCut } from "@/components/remocn/ring-cut";

const RingCutScene = () => (
  <RingCut
    from="One idea"
    to="Now live"
    origin={{ x: 0.2, y: 0.74 }}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RingCut"
    component={RingCutScene}
    durationInFrames={96}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` headline holds, then a sequence of rings in alternating tones and thin lines expands from `origin`. The last ring carries the `to` scene across the frame and it settles into place; `to="remocn"` sets the Remocn logo. Place `origin` as fractions of the frame, for example on the control that triggers the cut. With the default origin the scene settles by frame 57.
