## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LetterGateDemo } from "@/components/remocn/letter-gate";

const LetterGateDemoScene = () => (
  <LetterGateDemo
    text="Start building"
    gate="bu"
    prompt="A launch film for v2"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LetterGateDemo"
    component={LetterGateDemoScene}
    durationInFrames={118}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A shows a short headline while the camera punches in twice. It then pushes into the letter pair named by `gate`, and the pair opens like a gate onto scene B, a prompt box with a label and a next step. Set `text` and make sure `gate` is a two-letter run inside it, then pass `prompt`, `placeholder`, `label` and `nextLabel` for scene B; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
