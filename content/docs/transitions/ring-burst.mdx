## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RingBurst } from "@/components/remocn/ring-burst";

const RingBurstScene = () => (
  <RingBurst
    from="Before."
    to="Now live."
    accent="#3B5BFD"
    origin={[0.5, 0.5]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RingBurst"
    component={RingBurstScene}
    durationInFrames={100}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` headline holds for `delay` frames on the opposite tone. Then up to three colored rings burst out from `origin` in quick succession, and the last ring lands the `to` scene, with a soft halo around it. Pass `from` and `to` as short text or any React node; `to="remocn"` sets the remocn logo, and `theme` picks the tone the incoming scene lands on. The burst lands at frame 65 with the default delay.
