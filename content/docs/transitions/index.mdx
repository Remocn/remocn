_Last updated: November 9, 2026_

Yes, there is a library of ready-made transitions for Remotion: Remocn has 59 scene transitions, free
and MIT licensed. 41 of them are presentations for `TransitionSeries` from `@remotion/transitions`,
so you drop one into a `TransitionSeries.Transition` and pace it with `linearTiming` or
`springTiming`. The other 18 are self-contained components that play the whole cut themselves.

Install any of them with `npx shadcn@latest add @remocn/<name>`, for example
`npx shadcn@latest add @remocn/zoom-blur`. The shadcn CLI copies the source into your project, so you
own the file and can change it. There is no Remocn runtime package.

| | |
|---|---|
| Transitions | 59: 41 `TransitionSeries` presentations, 16 transition scenes, 2 scene sequencers |
| Install | `npx shadcn@latest add @remocn/<name>` ([setup](/docs/getting-started/installation)) |
| License | MIT, free. Remotion keeps [its own license](https://www.remotion.dev/docs/license) |
| Requires | An existing Remotion project. Presentations also use `@remotion/transitions` |
| Length | Every transition states its natural length in frames at 30fps |

Want to see them move? Every transition has a live preview in the
[gallery at the bottom of this page](#camera-motion) and on its own docs page.

## All 59 Remocn transitions

"Natural length" is how many frames the transition's own motion takes at 30fps. For a presentation,
pass it to `linearTiming({ durationInFrames })`. For a scene, it is when the cut has finished, so
give the `Sequence` at least that many frames plus any hold.

## How to use a Remocn transition in Remotion

Add Remocn to an existing Remotion project once ([installation](/docs/getting-started/installation)),
then install a transition by name:

```bash
npx shadcn@latest add @remocn/zoom-blur
```

The file lands in `components/remocn/`. A presentation goes between two sequences in a
`TransitionSeries`, and the timing sets the pace:

```tsx
import { TransitionSeries, linearTiming } from "@remotion/transitions";
import { zoomBlur } from "@/components/remocn/zoom-blur";

export const MyVideo = () => (
  <TransitionSeries>
    <TransitionSeries.Sequence durationInFrames={70}>
      <SceneA />
    </TransitionSeries.Sequence>
    <TransitionSeries.Transition
      timing={linearTiming({ durationInFrames: 18 })}
      presentation={zoomBlur()}
    />
    <TransitionSeries.Sequence durationInFrames={70}>
      <SceneB />
    </TransitionSeries.Sequence>
  </TransitionSeries>
);
```

A transition scene is an ordinary component. Give it both sides of the cut as props:

```tsx
import { BandShift } from "@/components/remocn/band-shift";

export const Swap = () => <BandShift from="Before." to="Now live." bands={6} />;
```

Each transition's page lists its props, a usage example, and when to use it or pick something else.

## Options for Remotion transitions

There are four ways to get scene transitions into a Remotion video. They work together: Remocn's
presentations run on Remotion's own `TransitionSeries`.

| Option | What you get | License | Pick it when |
|---|---|---|---|
| **[`@remotion/transitions`](https://www.remotion.dev/docs/transitions)** (official) | `TransitionSeries`, `linearTiming` and `springTiming`, and the built-in presentations. Version 4.0.530 ships `fade`, `slide`, `wipe`, `flip`, `clockWipe`, `iris`, `none` and WebGL ones such as `dissolve`, `crosswarp`, `filmBurn`, `ripple` and `zoomBlur`. Install with `npx remotion add @remotion/transitions` | [Remotion License](https://www.remotion.dev/docs/license) | A clean, standard cut is enough. You need this package for any presentation, Remocn's included |
| **[`@remotion/light-leaks`](https://www.remotion.dev/docs/light-leaks)** (official) | A WebGL light-leak effect from Remotion, which you place over a cut with `TransitionSeries.Overlay` | Remotion License | You want a light-leak overlay on top of a cut rather than a transition between scenes |
| **Custom presentations and shaders** | Write your own [custom presentation](https://www.remotion.dev/docs/transitions/presentations/custom) in React and CSS, or a WebGL2 shader through [`makeHtmlInCanvasPresentation()`](https://www.remotion.dev/docs/transitions/make-html-in-canvas-presentation), for example a port of a GLSL transition in the gl-transitions style | Yours | You need one specific effect nobody has built, and you have time to write and tune it |
| **Remocn** (this page) | 59 ready-made transitions: 41 presentations for `TransitionSeries`, 16 transition scenes and 2 sequencers, installed with `npx shadcn@latest add @remocn/<name>` | MIT | You want a wider choice of styled cuts for a product, launch or social video, as source you can edit |

What Remocn adds on top of `@remotion/transitions`:

- **Range.** 59 transitions in camera, shader, pixel, graphic, light, type and match-cut styles,
  next to the built-in set.
- **Source in your project.** The shadcn CLI copies each transition into `components/remocn/`. There
  is no Remocn package to keep up to date, and you can edit the code.
- **Timing you can plan with.** Every transition states its natural length in frames, plus when to
  use it and when to pick another one.
- **Few dependencies.** Most need only Remotion packages. The shader dissolves also install
  `@paper-design/shaders-react` through a Remocn shader component, which the CLI adds for you.

What it doesn't change: presentations still run on `@remotion/transitions`, and Remotion's license
applies to Remotion. The five canvas transitions (Glitch Cut, Ember Burn, Particle Dissolve, Grid
Wave, Displacement) read real pixels through the experimental html-in-canvas API. Chrome 149+ with
`chrome://flags/#canvas-draw-element` shows the full effect, and other browsers get a CSS
approximation, so previews and renders don't break.

Community repos exist as well. As of November 2026,
[Ashad001/remotion-transitions](https://github.com/Ashad001/remotion-transitions) is a Claude Code
skill with six `TransitionPresentation` patterns, and
[GTKottman/remotion-transitions](https://github.com/GTKottman/remotion-transitions) is a library of 50
transitions you copy in by hand, with a `catalog.json`. Both are MIT.

Remocn is an independent community project. It is not affiliated with Remotion or shadcn, and it is
listed on Remotion's resources page.

## Using Remocn transitions with an AI agent

Agents can pick and install transitions without reading this page:

- **[MCP server](/docs/getting-started/mcp-server)** at `https://remocn.dev/mcp`, no auth.
  `search_components` with a query such as `"transition"` or `"glitch cut"` returns matching
  transitions with natural length, use and avoid notes, and the install command. `get_component`
  returns one transition's full docs.
- **[Claude Code / Codex plugin](/docs/getting-started/plugin)**:
  `/plugin install remocn --marketplace Remocn/remocn`, then `/remocn:video <brief>` plans a
  storyboard, installs the components it picks, transitions included, and writes the video.
- **[Agent skill](/docs/getting-started/agent-skill)**: `npx skills add Remocn/remocn` teaches any
  skill-loading agent Remocn's timing rules. It reads the live component index from remocn.dev.
- **Markdown:** this page is at [`/docs/transitions.md`](/docs/transitions.md), and every transition
  is listed with its use and avoid notes in [`/llms-components.txt`](/llms-components.txt).

## FAQ

<Faq>

**Is there a library of ready-made transitions for Remotion?**
Yes. Remocn has 59 ready-made scene transitions for Remotion, free and MIT licensed. 41 are presentations for `TransitionSeries` and 18 are self-contained components. Install one with `npx shadcn@latest add @remocn/<name>`. Remotion's own `@remotion/transitions` package also ships a smaller built-in set, such as `fade`, `slide` and `wipe`.

**Is Remocn the same as @remotion/transitions?**
No. `@remotion/transitions` is Remotion's official package: it provides `TransitionSeries`, the timings and the built-in presentations. Remocn is an independent registry whose presentations plug into that same `TransitionSeries`, so you use both together.

**Are Remocn transitions free?**
Yes. Remocn is MIT licensed and free. Remotion and `@remotion/transitions` keep [Remotion's license](https://www.remotion.dev/docs/license), which can require a company license for larger companies.

**How do I add a transition to my Remotion video?**
Run `npx shadcn@latest add @remocn/<name>` in your Remotion project, import the presentation from `components/remocn/<name>`, and pass it as the `presentation` of a `TransitionSeries.Transition` with `linearTiming` or `springTiming`.

**Which transition should I use by default?**
[Zoom Blur](/docs/transitions/zoom-blur) is the general-purpose cut for product demos, at 18 frames. [Whip Pan](/docs/transitions/whip-pan) is faster and more energetic, and [Focus Pull](/docs/transitions/focus-pull) is calmer.

**Can I change how a transition looks?**
Yes. Each transition takes props such as colors, direction or timing, and because the source is copied into your project you can edit the code itself.

**Do the transitions work in every browser?**
Yes. The five canvas transitions show their full pixel effect only in Chrome with the html-in-canvas flag. Everywhere else they fall back to a CSS version of the same cut, so nothing breaks.

**Does Remocn render the video?**
No. Remocn gives you components. You preview and render with Remotion as usual, for example with `npx remotion studio` and `npx remotion render`.

</Faq>
