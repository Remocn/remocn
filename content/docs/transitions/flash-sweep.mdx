## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlashSweep } from "@/components/remocn/flash-sweep";

const FlashSweepScene = () => (
  <FlashSweep
    images={["/shots/one.png", "/shots/two.png", "/shots/three.png"]}
    direction="right"
    hold={30}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FlashSweep"
    component={FlashSweepScene}
    durationInFrames={156}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A tilted band of light, or a shadow in the `dark` variant, crosses the frame, blows out at the middle and swaps the shot, which then settles. Pass `scenes` for a chain where every neighboring pair gets one sweep, or `from` and `to` for a single swap, or `images` for screenshots. With the default four shots it ends at frame 140; each extra shot adds `hold` plus `duration` frames, and a single pair ends at frame 56.
