## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TileWave } from "@/components/remocn/tile-wave";

const TileWaveScene = () => (
  <TileWave
    from="Idea."
    to="Shipped."
    rows={8}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TileWave"
    component={TileWaveScene}
    durationInFrames={94}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` scene holds for `delay` frames, then a diagonal wave shrinks the tile grid of the outgoing scene to dots and regrows the tiles carrying the `to` scene on a cold blue gradient. Pass `from` and `to` as short text or any React node, and raise `rows` for finer tiles; `theme` sets the stage between the tiles. The wave lands by frame 64 and the gradient settles by frame 94 with the default delay.
