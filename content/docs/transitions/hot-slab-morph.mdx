## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HotSlabMorphDemo } from "@/components/remocn/hot-slab-morph";

const HotSlabMorphDemoScene = () => (
  <HotSlabMorphDemo
    lineA="Start from a template"
    lineB="or just describe it"
    prompt="A 30-second launch film for our new editor"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HotSlabMorphDemo"
    component={HotSlabMorphDemoScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is a headline above a panel of template rows. The panel lights up as a hot slab, morphs with a haze into the position of the input card, and settles into scene B, a prompt box that types your request with a second headline above it. Pass `lineA`, `lineB` and `prompt` for the copy; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
