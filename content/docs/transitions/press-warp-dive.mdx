## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PressWarpDiveDemo } from "@/components/remocn/press-warp-dive";

const PressWarpDiveDemoScene = () => (
  <PressWarpDiveDemo
    prompt="A 30-second teaser for our new editor"
    headingB="Your teaser is ready"
    title="Editor teaser, v1"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PressWarpDiveDemo"
    component={PressWarpDiveDemoScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is a prompt composer: a suggestion appears, the prompt types, and a cursor presses send. The press pinches the frame, an orb grows from the button, and the camera dives through it into scene B, a result screen with a heading, your image and a title. Pass `heading`, `prompt`, `headingB` and `title` for the copy and `image` for your own picture; it ships light and dark, and the transition itself is also exported as `pressWarpDive()` for a 30-frame `linearTiming` in your own `TransitionSeries`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
