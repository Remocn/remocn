## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BeamSweepDemo } from "@/components/remocn/beam-sweep";

const BeamSweepDemoScene = () => (
  <BeamSweepDemo
    line="Just describe the launch."
    sub="Every scene is cut to your product."
    images={["/shots/one.png", "/shots/two.png", "/shots/three.png"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BeamSweepDemo"
    component={BeamSweepDemoScene}
    durationInFrames={108}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is a page builder with a progress bar and three images on a page. A diagonal beam of shader light sweeps across, burns the builder away, and reveals scene B, a statement with a supporting line over a glowing ground. Pass `pageTitle`, `line` and `sub` for the copy and your own `images` (the defaults exist only in the Remocn repo); it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
