## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LightBurnToLineDemo } from "@/components/remocn/light-burn-to-line";

const LightBurnToLineDemoScene = () => (
  <LightBurnToLineDemo
    line="Now ship your first film."
    cta="Start free"
    url="remocn.dev/new"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LightBurnToLineDemo"
    component={LightBurnToLineDemoScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A is a browser window with a chat, a check and a few product shots. The window burns into soft discs of light that gather and travel into a horizontal line, which then opens onto scene B: a closing headline with a call-to-action pill and a URL. Pass `line`, `cta` and `url` for the ending; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
