## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BandOpen } from "@/components/remocn/band-open";

const BandOpenScene = () => (
  <BandOpen
    line="Launch day"
    src="/images/hero.jpg"
    meta="Thursday · 09:00 · remocn.dev"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BandOpen"
    component={BandOpenScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A stacks the headline into repeating rows that rise in and fade out above and below the center. A band opens across the middle and expands to full frame, revealing scene B, a photo with the same headline and a meta caption below. Pass `line`, `meta` and your own `src` (the default exists only in the remocn repo); it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
