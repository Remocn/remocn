## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BandShift } from "@/components/remocn/band-shift";

const BandShiftScene = () => (
  <BandShift
    from="Before."
    to="Now live."
    bands={6}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BandShift"
    component={BandShiftScene}
    durationInFrames={90}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` headline holds for `delay` frames. Then 5 to 7 horizontal bands slide across in alternating directions, each carrying a colored block, and the `to` scene lands as they pass. Pass `from` and `to` as short text or any React node; `to="remocn"` sets the Remocn logo. With the defaults the shift ends at frame 55.
