## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShapeCut } from "@/components/remocn/shape-cut";

const ShapeCutScene = () => (
  <ShapeCut
    from="Ideas move fast"
    to="Now live"
    shape="pill"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShapeCut"
    component={ShapeCutScene}
    durationInFrames={110}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A shape slides in from the left edge and swells until it covers the `from` headline, then shrinks down to a small mark beside the `to` text, which settles into place. Choose `shape` as circle, square or pill (the pill ends as an underline bar), and pass `to="remocn"` to set the Remocn logo. It ships light and dark, and the cut finishes at frame 76.
