## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CardSwipeCoverDemo } from "@/components/remocn/card-swipe-cover";

const CardSwipeCoverDemoScene = () => (
  <CardSwipeCoverDemo
    line="Every launch asset, *in one place.*"
    title="Launch kits"
    subtitle="Four films, ready to render."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CardSwipeCoverDemo"
    component={CardSwipeCoverDemoScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Scene A types a headline; the text between asterisks is set in the accent style. A card then swipes in from the bottom corner and covers the frame, and scene B shows a title, a subtitle, filter tabs and a grid of cover cards. Pass `line`, `title`, `subtitle` and your own `covers`; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
