## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ReplayWipe } from "@/components/remocn/replay-wipe";

const ReplayWipeScene = () => (
  <ReplayWipe
    accent="#3B5BFD"
    wipeAt={[26, 84]}
    wipeLength={18}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ReplayWipe"
    component={ReplayWipeScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A huge LIVE frame with a ticking clock holds, then a stinger carrying the remocn R mark spins across on a fluted gradient streak and wipes to the Replay shot in slow motion, then wipes back. Pass your own shots as `from` and `to`, set the frames with `wipeAt` and tune the stinger with `wipeLength`; it ships light and dark.
