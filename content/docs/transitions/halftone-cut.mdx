## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HalftoneCut } from "@/components/remocn/halftone-cut";

const HalftoneCutScene = () => (
  <HalftoneCut
    from="Draft one"
    to="Final cut"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HalftoneCut"
    component={HalftoneCutScene}
    durationInFrames={108}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` headline, set in italic serif, is eaten away by a halftone dot pattern that shrinks along a diagonal wave. The dots then regrow to reveal the `to` headline in upright serif on a tinted gradient. Pass `from` and `to` as short strings; `accent` tints the gradient and it ships light and dark. The cut lands at frame 76.
