## Usage

`Stage` turns its children into one studio object. It renders the backdrop, floor reflection, contact shadow, subject, and light treatment, then settles the subject into its final pose over 24 frames.

```tsx
import { Stage } from "@/components/remocn/stage";

export const ProductShot = () => (
  <Stage>
    <YourDashboard />
  </Stage>
);
```

The child can be an image, a video, a live React component, or a whole Remotion scene. Descendants keep animating, but they share one 3D plane — `Stage` does not infer depth from the child tree.

## Direct the set

All visual props are independent, so the studio can follow the product rather than forcing a named preset:

```tsx
<Stage
  backdrop="radial-gradient(circle at 35% 10%, #403a72, #111117 58%, #08080b)"
  rotateX={6}
  rotateY={-16}
  perspective={1600}
  scale={0.78}
  radius={1.8}
  reflection={0.2}
  shadow={0.8}
  light={0.65}
>
  <YourProductScene />
</Stage>
```

`reflection`, `shadow`, and `light` are strengths from `0` to `1`. They clamp safely outside that range. `radius` follows the same convention as `Backdrop`: it is a percentage of the composition width, so the corner treatment scales across 720p, 1080p, and 4K renders.

<Note title="One subject, one plane">
  Stage applies perspective to the child tree as a single composited surface. If two cards need different depths, wrap each card in its own Stage or build a purpose-specific 3D layout.
</Note>

## Compose with camera movement

`Stage` controls how the subject looks. [`Camera`](/docs/layout/camera-move) controls how the operator moves. Nest them to combine the soft 24-frame set entrance with a longer, independent camera path:

```tsx
import { Camera } from "@/components/remocn/camera-move";
import { Stage } from "@/components/remocn/stage";

<Camera moves={[{ at: 0, zoom: 1 }, { at: 120, zoom: 1.12 }]}>
  <Stage rotateX={8} rotateY={-12}>
    <YourProductScene />
  </Stage>
</Camera>
```

For an optical finish, put [`CameraLens`](/docs/filters/components/camera-lens) outside the camera wrapper. `Stage` supplies the physical set, `Camera` supplies blocking, and `CameraLens` supplies bloom, softness, chromatic aberration, and vignette.
