## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TallCount } from "@/components/remocn/tall-count";

const TallCountScene = () => (
  <TallCount value={240} prefix="+" suffix="%" label="more watch time on launch posts that move" />
);

export const RemotionRoot = () => (
  <Composition
    id="TallCount"
    component={TallCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The caption rises in while the figure counts from `from` to `value`, growing wider as it goes, then springs up into place. Prefix and suffix such as plus and percent are part of the figure. Pass `value`, `prefix`, `suffix` and `label`; it ships light and dark through `theme`.
