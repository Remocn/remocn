## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MaxQ } from "@/components/remocn/max-q";

const MaxQScene = () => (
  <MaxQ velocity={1880} speedUnit="km/h" altitude={14.2} altitudeUnit="km" event="Max Q" />
);

export const RemotionRoot = () => (
  <Composition
    id="MaxQ"
    component={MaxQScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Labels and two figures rise in and race up together while a trajectory curve draws between them. At the peak a banner wipes across, a marker drops on the curve, and a status settles under the numbers. Pass `velocity`, `altitude`, their labels and units, `event` and `status`; it ships light and dark through `theme`.
