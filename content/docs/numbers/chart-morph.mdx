## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChartMorph } from "@/components/remocn/chart-morph";

const ChartMorphScene = () => (
  <ChartMorph
    suffix="k"
    caption="renders in May"
    data={[
      { label: "Jan", value: 12 },
      { label: "Feb", value: 18 },
      { label: "Mar", value: 23 },
      { label: "Apr", value: 31 },
      { label: "May", value: 46 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ChartMorph"
    component={ChartMorphScene}
    durationInFrames={182}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A segmented ring unrolls into a stacked bar, the segments tip upright into columns, and the columns collapse into a line chart with an area fill that ends on the last value. Pass `data` (label and value per point), `suffix` for the unit, and `caption` for the line under the value. Ships dark and light via `theme`.
