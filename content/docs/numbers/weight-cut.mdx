## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WeightCut } from "@/components/remocn/weight-cut";

const WeightCutScene = () => <WeightCut value={6.8} from={94} suffix="KB" eyebrow="Per scene, gzipped" label="Lighter than your logo file." />;

export const RemotionRoot = () => (
  <Composition
    id="WeightCut"
    component={WeightCutScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A heavy figure counts down from `from` to `value` while its stroke weight thins from bold to light, and a small unit suffix sits beside it. An eyebrow and a caption stack in a column next to the figure. Pass `value`, `from`, `suffix`, `eyebrow` and `label`; `lightWeight` sets the final stroke weight and `accent` colors the suffix. It ships light and dark through `theme`.
