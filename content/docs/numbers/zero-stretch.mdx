## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ZeroStretch } from "@/components/remocn/zero-stretch";

const ZeroStretchScene = () => (
  <ZeroStretch value="200" label="components" caption="Ready to ship. Copy one in, own every frame." />
);

export const RemotionRoot = () => (
  <Composition
    id="ZeroStretch"
    component={ZeroStretchScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The digits rise in, then the first zero springs open into a glossy pill that carries the label word. The caption rises in below. Pass `value` (a zero is added if it has none), `label` and `caption`; it ships light and dark through `theme`.
