## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SparklineThread } from "@/components/remocn/sparkline-thread";

const SparklineThreadScene = () => (
  <SparklineThread
    values={[20, 26, 24, 35, 34, 49, 56, 64, 77]}
    metric="+212%"
    label="weekly renders"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SparklineThread"
    component={SparklineThreadScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Data points pop in, a glowing thread draws through them and thickens into an area fill, then a bloom at the last point leads to the metric counting up with its label. Pass `values` (one number per point), `metric` and `label`. Ships dark and light via `theme`.
