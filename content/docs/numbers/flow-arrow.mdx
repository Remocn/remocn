## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlowArrow } from "@/components/remocn/flow-arrow";

const FlowArrowScene = () => <FlowArrow metric="3×" label="faster growth" />;

export const RemotionRoot = () => (
  <Composition
    id="FlowArrow"
    component={FlowArrowScene}
    durationInFrames={155}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Dotted particles stream into a zigzag arrow that climbs diagonally, then a gradient sweep lands the metric and its label. Pass `metric` (for example 3x) and `label`. Ships dark and light via `theme`.
