## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VersusSplit } from "@/components/remocn/versus-split";

const VersusSplitScene = () => (
  <VersusSplit
    away="The old way"
    stats={[
      { label: "Time to ship", home: "1 day", away: "3 weeks" },
      { label: "Cost", home: "$0", away: "$12K" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="VersusSplit"
    component={VersusSplitScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The frame splits on a diagonal, both halves slam in and meet on a flashing seam, and a VS mark drops onto it. Stat rows then land one by one with the Remocn value on the left and the opponent value on the right, and a gradient wipe lights the Remocn half while the other side dims. Pass `away`, the two labels and `stats` as label, home and away strings. It ships light and dark through the `theme` prop.
