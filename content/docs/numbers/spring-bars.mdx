## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpringBars } from "@/components/remocn/spring-bars";

const SpringBarsScene = () => (
  <SpringBars
    values={[0.58, 0.72, 0.52, 0.66, 0.97, 0.62, 0.7]}
    accentIndex={4}
    value="3.4×"
    caption="Least sag under the same load"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SpringBars"
    component={SpringBarsScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Bars drop in as coiled springs and compress to their heights with a bounce, then the chart morphs so the highlighted bar becomes a gradient hero under its stat and caption. Pass `values` (relative heights from 0 to 1), `accentIndex`, `value` and `caption`. Ships dark and light via `theme`.
