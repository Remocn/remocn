## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LogRescale } from "@/components/remocn/log-rescale";

const LogRescaleScene = () => (
  <LogRescale
    title="remocn renders per year"
    data={[
      { label: "2023", value: 4800 },
      { label: "2024", value: 18000 },
      { label: "2025", value: 96000 },
      { label: "2026", value: 2400000 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LogRescale"
    component={LogRescaleScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Bars rise on a linear axis where only the last one is visible, then the axis morphs to a log scale, the smaller bars grow into view, and their values label in. Pass `data` (label and value per bar), `accentIndex` for the hero bar (defaults to the largest), and a `title`. Ships dark and light via `theme`.
