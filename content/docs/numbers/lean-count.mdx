## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LeanCount } from "@/components/remocn/lean-count";

const LeanCountScene = () => (
  <LeanCount value={3.2} suffix="×" label="Faster renders on the laptop you already own." />
);

export const RemotionRoot = () => (
  <Composition
    id="LeanCount"
    component={LeanCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The label words rise in while the figure counts from `from` up to `value` in `steps` surges, each surge swinging the slant from leaning back to leaning forward. The suffix is drawn in the accent color. Pass `value`, `suffix` and `label` to make it yours; it ships light and dark through `theme`.
