## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IpoOpen } from "@/components/remocn/ipo-open";

const IpoOpenScene = () => <IpoOpen symbol="RMCN" ipoPrice={18} openPrice={42.6} label="Listed today" />;

export const RemotionRoot = () => (
  <Composition
    id="IpoOpen"
    component={IpoOpenScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A mono line and a huge ticker symbol rise in with the IPO price underneath; on the bell a two-frame flash cuts in, the corner clock flips to the open time and a shockwave line tears across. The opening price then races up on rolling digit reels, a percent-up chip counts with it, and a sunrise gradient climbs behind. Pass `symbol`, `ipoPrice`, `openPrice` and `label`; use `name` or `logo` for the corner bug. It ships light and dark through `theme`.
