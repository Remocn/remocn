## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SmashCount } from "@/components/remocn/smash-count";

const SmashCountScene = () => <SmashCount value={64} from={1} cuts={6} label="scenes, zero keyframes" />;

export const RemotionRoot = () => (
  <Composition
    id="SmashCount"
    component={SmashCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A giant numeral hard-cuts through a series of larger and larger values, each cut punching in at a new corner of the frame and the cuts speeding up, until the final value lands large at the bottom left and a caption appears in the top right. Pass `value`, `from`, `cuts` and `label`; `accent` is the numeral color. It ships light and dark through `theme`.
