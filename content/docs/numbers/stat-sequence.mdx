## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StatSequence } from "@/components/remocn/stat-sequence";

const StatSequenceScene = () => (
  <StatSequence name="remocn" eyebrow="in numbers" beat={26} stats={[{ value: "10,000", unit: "+", label: "builders" }, { value: "99.9", unit: "%", label: "uptime" }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="StatSequence"
    component={StatSequenceScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each stat rises in at monumental size with its label and detail and is replaced by the next one every `beat` frames. The final stat then shrinks and all stats settle into a row. Pass `stats` and `name`; the total length is about 74 + (stats - 1) × `beat` frames, and it ships light and dark through `theme`.
