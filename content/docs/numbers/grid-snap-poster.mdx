## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GridSnapPoster } from "@/components/remocn/grid-snap-poster";

const GridSnapPosterScene = () => <GridSnapPoster number="3.0" title={"Launch films,\nset in motion."} body="Install a component, drop in your words, render." />;

export const RemotionRoot = () => (
  <Composition
    id="GridSnapPoster"
    component={GridSnapPosterScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A 12-column grid draws in with hairlines and bands, then a giant gradient number, the headline, the body copy and the logo each step across it in discrete snaps with a brief flash on landing; the grid fades and the layout settles. Pass `title` (use a newline for line breaks), `number`, `body`, and `name` or `logo` for the mark. It ships light and dark through `theme`.
