## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FigureToLabel } from "@/components/remocn/figure-to-label";

const FigureToLabelScene = () => <FigureToLabel value="$6.4B" word="valuation" eyebrow="Series B" />;

export const RemotionRoot = () => (
  <Composition
    id="FigureToLabel"
    component={FigureToLabelScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A figure built from a halftone dot field pops onto a ruled card, a wave sweeps across and the dots resolve left to right into solid digits. The card then collapses, the figure takes the accent color and the label word types out beside it with a caret, under the Remocn mark. Pass `value`, `word` and an optional `eyebrow`. It ships light and dark through `theme`; `ground` and `groundParams` change the animated background.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
