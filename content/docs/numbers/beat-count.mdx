## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BeatCount } from "@/components/remocn/beat-count";

const BeatCountScene = () => <BeatCount value={64} beats={8} bpm={120} label="cuts, each one landing on the kick" />;

export const RemotionRoot = () => (
  <Composition
    id="BeatCount"
    component={BeatCountScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big numeral steps from `from` to `value` in `beats` equal jumps, one per beat at the given `bpm`. On each beat it squashes down and thins its weight before releasing, and the last beat rebounds with a spring. A small caption fades in at the top left after the first beat. Pass `value`, `beats`, `bpm`, `label`, and optionally `prefix`, `suffix` and `decimals`. It ships light and dark through the `theme` prop.
