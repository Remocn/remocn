## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TMinus } from "@/components/remocn/t-minus";

const TMinusScene = () => (
  <TMinus
    from={10}
    beat={8}
    title="Liftoff"
    subtitle="remocn 2.0 is live"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TMinus"
    component={TMinusScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big T-minus numeral counts down with one hard cut per beat while a small clock above it rolls and edge telemetry flickers. At T-0 a warm bloom fires from the bottom, 'LIFTOFF' slams in and the small clock flips to counting up. Pass `from`, `beat`, `title`, `subtitle`, `stage` and `status`. It ships light and dark through the `theme` prop. The length shown is for the defaults; in general it is `14 + (from - 1) * beat + 22`.
