## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DistributionShift } from "@/components/remocn/distribution-shift";

const DistributionShiftScene = () => (
  <DistributionShift before={840} after={120} unit="ms" label="p99 latency" />
);

export const RemotionRoot = () => (
  <Composition
    id="DistributionShift"
    component={DistributionShiftScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A bell-shaped latency curve rises with a marker at its slow tail, then morphs left and tightens as the marker slides to the new value and the percent change appears. Pass `before` and `after` in the same `unit`, plus a `label` for the metric. Ships dark and light via `theme`.
