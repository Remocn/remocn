## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NumberMosaic } from "@/components/remocn/number-mosaic";

const NumberMosaicScene = () => <NumberMosaic value="10,000" name="acme" label="launch videos rendered" />;

export const RemotionRoot = () => (
  <Composition
    id="NumberMosaic"
    component={NumberMosaicScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dim field of ticking digits fills the frame while the cells that form the number light up into a gradient and the rest fall back; a lockup of mark, product name and label then appears under the figure. Pass `value` as a string such as "10,000" or "2.4M", plus `name` and `label`, or `logo` to swap the mark. It ships light and dark through `theme`.
