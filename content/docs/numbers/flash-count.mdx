## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlashCount } from "@/components/remocn/flash-count";

const FlashCountScene = () => <FlashCount value={3600} from={120} eyebrow="f/8  ·  1/250 s" flashAt={54} />;

export const RemotionRoot = () => (
  <Composition
    id="FlashCount"
    component={FlashCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large light-weight number counts up from `from` and the number drifts and scales slightly into place. At `flashAt` the screen pops with a camera flash, the number lands on `value`, and the eyebrow with its marker dot and the caption fade in. Pass `value`, `from`, `label`, `eyebrow` and `flashAt`. It ships light and dark through the `theme` prop.
