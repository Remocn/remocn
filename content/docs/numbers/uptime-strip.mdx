## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UptimeStrip } from "@/components/remocn/uptime-strip";

const UptimeStripScene = () => (
  <UptimeStrip value="99.99%" days={90} incidents={[27, 63]} label="uptime" />
);

export const RemotionRoot = () => (
  <Composition
    id="UptimeStrip"
    component={UptimeStripScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A sweep fills the strip tick by tick, with the days named in `incidents` standing out as outages, then the ticks settle into the final strip. The uptime figure rises in letter by letter beside an italic label word. Pass `value`, `days`, `incidents` and `label`; it ships light and dark through `theme`.
