## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FreeAsIn } from "@/components/remocn/free-as-in";

const FreeAsInScene = () => <FreeAsIn word="Free" glosses={["as in beer.", "as in speech.", "as in no seats.", "as in yours."]} />;

export const RemotionRoot = () => (
  <Composition
    id="FreeAsIn"
    component={FreeAsInScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big word fades in on the left, then a series of short glosses slide in one at a time beside it, each pushing the previous gloss up and dimming it; the last gloss lands in the accent color. Pass `word` and a `glosses` array. The gloss pacing stretches to fill the composition, so give it about 150 frames.
