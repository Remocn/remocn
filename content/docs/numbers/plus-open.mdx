## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PlusOpen } from "@/components/remocn/plus-open";

const PlusOpenScene = () => (
  <PlusOpen value="150" label="updates in this release" next="Here’s everything new." />
);

export const RemotionRoot = () => (
  <Composition
    id="PlusOpen"
    component={PlusOpenScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The figure rises in and a plus sign spins into place beside it, arms extending. The plus then opens, splitting the frame to reveal the next statement over a soft aurora ground. Pass `value`, `label` and `next`; it ships light and dark through `theme`.
