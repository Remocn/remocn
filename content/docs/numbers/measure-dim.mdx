## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MeasureDim } from "@/components/remocn/measure-dim";

const MeasureDimScene = () => (
  <MeasureDim
    value="184 fps"
    before="60 fps"
    beforeLabel="Before"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MeasureDim"
    component={MeasureDimScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A gradient bar draws in, extension lines drop and a dimension arrow counts the new value along it. A ghost bar for the previous value then appears below and gets its own dimension line. Pass `value` and `before` with their units, and `label` and `beforeLabel` to name the two bars. It ships light and dark through the `theme` prop.
