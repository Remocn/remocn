## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Beeswarm } from "@/components/remocn/beeswarm";

const BeeswarmScene = () => (
  <Beeswarm
    count={200}
    domain={[0, 14]}
    axisLabel="launch videos shipped per quarter"
    totalLabel="200 teams"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Beeswarm"
    component={BeeswarmScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A pour of dots falls onto an axis as one grey swarm, then splits into a before group and an after group that slide to their medians and label themselves. Pass `before` and `after` as groups (label, median, spread), `count` of dots, and the axis `domain` and `axisLabel`. Ships dark and light via `theme`.
