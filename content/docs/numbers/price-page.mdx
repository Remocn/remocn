## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PricePage } from "@/components/remocn/price-page";

const PricePageScene = () => <PricePage lines={["Starter, Pro, Team, Enterprise", "Per seat, per month", "Overage fees may apply"]} price="Free." />;

export const RemotionRoot = () => (
  <Composition
    id="PricePage"
    component={PricePageScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A small label tops a stack of fine-print pricing lines; the lines drop out one by one in a scrambled order until the list is gone, then a huge price lands and a note fades in beneath it. Pass `lines`, `price` and `note`. The timing stretches to the composition length, so give it about 180 frames. It ships light and dark through `theme`.
