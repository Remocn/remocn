## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StripeCount } from "@/components/remocn/stripe-count";

const StripeCountScene = () => <StripeCount value={184} accent="#FF4F00" label="scenes that take your brand colour from one prop" />;

export const RemotionRoot = () => (
  <Composition
    id="StripeCount"
    component={StripeCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The frame floods with the accent color and a dark caption band sits at the top. The figure counts up as an outline while horizontal stripes sweep across and thicken until the digits are solid dark; the caption rises in word by word. Pass `value`, `from` and `label`; `stripes` sets the stripe count and `accent` the frame color. It ships light and dark through `theme`.
