## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlimCount } from "@/components/remocn/slim-count";

const SlimCountScene = () => <SlimCount value={0} from={100} label="Keyframes left to set by hand" />;

export const RemotionRoot = () => (
  <Composition
    id="SlimCount"
    component={SlimCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A tall condensed numeral counts from `from` down to `value` while a wavy fill drains out of its outline like a tank; a bold caption rises in word by word beside it at the start. Pass `value`, `from` and `label`, with `prefix`, `suffix` or `decimals` if needed; `accent` colors the fill. It ships light and dark through `theme`.
