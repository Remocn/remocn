## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LevelUp } from "@/components/remocn/level-up";

const LevelUpScene = () => (
  <LevelUp level={41} title="LEVEL UP" stat={{ label: "Render speed", value: 40, suffix: "%" }} />
);

export const RemotionRoot = () => (
  <Composition
    id="LevelUp"
    component={LevelUpScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The XP bar builds, XP chips fly into it one by one until it maxes out and collapses, then the title erupts with rays and a shockwave and the level digit rolls to the next number. A stat line ticks up last. Pass `level`, `startXp`, `maxXp`, `chips` (they should add up to `maxXp - startXp`), `title` and `stat`; it ships light and dark through `theme`.
