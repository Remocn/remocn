## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ResClimb } from "@/components/remocn/res-climb";

const ResClimbScene = () => <ResClimb value="200+" eyebrow="Component registry" label="components, ready to drop in" />;

export const RemotionRoot = () => (
  <Composition
    id="ResClimb"
    component={ResClimbScene}
    durationInFrames={115}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big number first appears as a coarse block grid, then re-renders through a few sharper resolutions in quick snaps until it lands crisp in a blue gradient. A small eyebrow sits above and a caption fades in below. Pass `value` as a string such as "200+", plus `label` and `eyebrow`; `steps` sets the grid resolutions. It ships light and dark through `theme`.
