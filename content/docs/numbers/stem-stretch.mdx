## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StemStretch } from "@/components/remocn/stem-stretch";

const StemStretchScene = () => (
  <StemStretch value="4 hours" label="back, every week" steps={4} />
);

export const RemotionRoot = () => (
  <Composition
    id="StemStretch"
    component={StemStretchScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The figure rises in, then in `steps` springy snaps its vertical stems stretch apart into long stripes with a gradient glow. The caption rises in word by word below. Pass `value`, `label` and `steps`; it ships light and dark through `theme`.
