## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SplitFlash } from "@/components/remocn/split-flash";

const SplitFlashScene = () => (
  <SplitFlash
    time="1:12.408"
    delta="−0.412"
    flashLabel="Fastest lap"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SplitFlash"
    component={SplitFlashScene}
    durationInFrames={96}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A lap clock runs with rolling tenths while an accent sector line draws under it. When the line is crossed the clock freezes on its final time, the line shoots up into a full-width purple band that blinks once, and the delta slides down from under it. Pass `time` as m:ss.mmm, plus `delta`, `label` and `flashLabel`. It ships light and dark through the `theme` prop.
