## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TimingTower } from "@/components/remocn/timing-tower";

const TimingTowerScene = () => (
  <TimingTower code="RMC" lap={41} laps={58} interval="+12.408" intervalLabel="Gap to P2" />
);

export const RemotionRoot = () => (
  <Composition
    id="TimingTower"
    component={TimingTowerScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The tower wipes in with ten cars, then the hero car passes the car ahead each lap while the gaps rewrite, until it turns purple at P1. The tower then peels off and a poster with the code and the interval counts in. Pass `code`, `field`, `lap`, `laps`, `interval` and `intervalLabel`; it ships light and dark through `theme`.
