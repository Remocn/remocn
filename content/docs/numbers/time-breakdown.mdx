## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TimeBreakdown } from "@/components/remocn/time-breakdown";

const TimeBreakdownScene = () => (
  <TimeBreakdown
    title="Where the time goes"
    caption="less time per video"
    before={[
      { label: "Editing", value: 62 },
      { label: "Rendering", value: 24 },
      { label: "Export", value: 14 },
    ]}
    after={[
      { label: "Editing", value: 6 },
      { label: "Rendering", value: 24 },
      { label: "Export", value: 14 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TimeBreakdown"
    component={TimeBreakdownScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A segmented bar splits into time blocks, then the slow segment collapses and the bar shrinks while the saved percentage counts up with its caption. Pass `before` and `after` as lists of segments (label and value), and set `title`, `beforeLabel`, `afterLabel` and `caption`. Ships dark and light via `theme`.
