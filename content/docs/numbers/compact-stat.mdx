## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CompactStat } from "@/components/remocn/compact-stat";

const CompactStatScene = () => <CompactStat value={1200000} decimals={1} label="frames rendered with remocn" />;

export const RemotionRoot = () => (
  <Composition
    id="CompactStat"
    component={CompactStatScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The full number rises in digit by digit, then its trailing digits retract on a reel and a magnitude suffix (K, M, B or T) springs in; the shortened figure scales up in a gradient with a soft ground glow, under a caption. Pass `value` as the full number, with `decimals`, `prefix` and `label`; the suffix is picked automatically unless you pass `suffix`. It ships light and dark through `theme`.
