## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ComboCounter } from "@/components/remocn/combo-counter";

const ComboCounterScene = () => (
  <ComboCounter
    hits={["Captions", "Transitions", "Charts", "Templates"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ComboCounter"
    component={ComboCounterScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Feature names hit one after another with a star flash and slash, each hit faster than the last, while a combo meter on the left counts up and its rating swaps from Nice to Great to PERFECT. After the final hit the frame flashes, the meter glides to the centre as a poster with a gradient number, and the logo rises in. Pass `hits` and optionally `ratings`. It ships light and dark through the `theme` prop.
