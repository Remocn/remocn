## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StudioReflection } from "@/components/remocn/studio-reflection";

const StudioReflectionScene = () => (
  <StudioReflection value="250+" eyebrow="In the library" label="launch-ready scenes, one command away" />
);

export const RemotionRoot = () => (
  <Composition
    id="StudioReflection"
    component={StudioReflectionScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Bands of light glide across the frame and park on the figure, which takes on a chrome gradient with a mirrored reflection beneath it. The eyebrow and label rise in last. Pass `value`, `eyebrow` and `label`; it ships light and dark through `theme`.
