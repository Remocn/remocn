## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BubblePack } from "@/components/remocn/bubble-pack";

const BubblePackScene = () => (
  <BubblePack
    highlight={0}
    items={[
      { label: "Launch videos", value: 420 },
      { label: "Demos", value: 180 },
      { label: "Changelogs", value: 150 },
      { label: "Tutorials", value: 70 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BubblePack"
    component={BubblePackScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Category bubbles pop in and pack together; the highlighted one swells into a large gradient bubble while its value counts up. Pass `items` (label and value, up to 16) and `highlight`, the index of the hero item. Ships dark and light via `theme`.
