## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShareDonut } from "@/components/remocn/share-donut";

const ShareDonutScene = () => (
  <ShareDonut
    highlight={0}
    segments={[
      { label: "remocn", value: 38 },
      { label: "Kitebase", value: 24 },
      { label: "Lumen", value: 17 },
      { label: "Other", value: 21 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShareDonut"
    component={ShareDonutScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A gradient donut sweeps around one segment after another, then the highlighted slice detaches, the rest dim, and its percentage counts up in the center. Pass `segments` (label and value) and `highlight`, the index of the hero slice. Ships dark and light via `theme`.
