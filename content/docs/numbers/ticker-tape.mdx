## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TickerTape } from "@/components/remocn/ticker-tape";

const TickerTapeScene = () => (
  <TickerTape symbol="RMCN" price="128.40" change={12.4} name="remocn" />
);

export const RemotionRoot = () => (
  <Composition
    id="TickerTape"
    component={TickerTapeScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Seven bands of quotes run at speed in alternating directions, then brake until the middle band stops on the hero symbol. The side bands clear away and the hero quote scales into a poster with price and move. Pass `symbol`, `price`, `change`, `symbols` and `name`; it ships light and dark through `theme`.
