## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CandleRally } from "@/components/remocn/candle-rally";

const CandleRallyScene = () => (
  <CandleRally
    symbol="ACME"
    price={96.5}
    prevHigh={88}
    headline="Record"
    headline2="quarter"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CandleRally"
    component={CandleRallyScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Candlesticks build left to right, the last one breaks through a dashed previous-high line, and a price tag rides its wick before a two-line headline slams in. Pass `symbol`, `price`, `prevHigh`, and the `headline` and `headline2` words. Ships dark and light via `theme`.
