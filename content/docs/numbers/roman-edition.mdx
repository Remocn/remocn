## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RomanEdition } from "@/components/remocn/roman-edition";

const RomanEditionScene = () => (
  <RomanEdition value={14} eyebrow="Launch Week" tagline="Five days of new scenes, one every morning." />
);

export const RemotionRoot = () => (
  <Composition
    id="RomanEdition"
    component={RomanEditionScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The band wipes in and the numeral ticks through the sequence from `from` to `value`, slow at first, quick through the middle, then easing onto the final edition. The tagline rises in after it lands. Pass `value`, `eyebrow` and `tagline`; it ships light and dark through `theme`.
