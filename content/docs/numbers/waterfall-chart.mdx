## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WaterfallChart } from "@/components/remocn/waterfall-chart";

const WaterfallChartScene = () => (
  <WaterfallChart
    title="Net revenue, Q3"
    start={{ label: "Start", value: 52 }}
    steps={[
      { label: "Churn", value: -7 },
      { label: "New", value: 24 },
      { label: "Expansion", value: 12 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WaterfallChart"
    component={WaterfallChartScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A starting column is set, then each step floats up or down as a green gain or red loss, and the total rises last in gradient while its value counts up. Pass `start`, `steps` (label and signed value), `totalLabel` and `title`; use `format` to control how numbers print. Ships dark and light via `theme`.
