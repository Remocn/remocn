## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ActivityRings } from "@/components/remocn/activity-rings";

const ActivityRingsScene = () => (
  <ActivityRings
    title="This quarter"
    rings={[
      { label: "Renders", value: 2400, goal: 1.2 },
      { label: "Templates", value: 64, goal: 1.1 },
      { label: "Hours saved", value: 420, unit: "h", goal: 1.05 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ActivityRings"
    component={ActivityRingsScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Three concentric rings fill clockwise one after another, snap closed, then lap past their goal with a check mark while the labels count up beside them. Pass `rings` (label, value, optional unit, and a `goal` fraction such as 1.14) and a `title`. Ships dark and light via `theme`.
