## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LumenCount } from "@/components/remocn/lumen-count";

const LumenCountScene = () => <LumenCount value={200} suffix="+" label="components for your launch video" />;

export const RemotionRoot = () => (
  <Composition
    id="LumenCount"
    component={LumenCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big number counts up on a dark stage while its fill brightens from dim to a glowing gradient, flares once on arrival and casts a soft reflection on the floor; the caption fades in underneath. Pass `value` and `label`, plus optional `suffix` and `eyebrow`. It ships light and dark through `theme`.
