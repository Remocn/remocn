## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TheTab } from "@/components/remocn/the-tab";

const TheTabScene = () => <TheTab items={[{ item: "Every component" }, { item: "Every template" }]} price="$0" total="one Sunday morning." />;

export const RemotionRoot = () => (
  <Composition
    id="TheTab"
    component={TheTabScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A receipt builds line by line, each item joined to its price by a dotted leader; a rule draws under the list and the total lands word by word in the accent color. Pass `items` (each `{ item, price? }`), `price` as the default per-line price, and `totalLabel` with `total`. The row pacing stretches to the composition length, so give it about 170 frames. It ships light and dark through `theme`.
