## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DumbbellShift } from "@/components/remocn/dumbbell-shift";

const DumbbellShiftScene = () => (
  <DumbbellShift
    beforeLabel="Before"
    afterLabel="With remocn"
    rows={[
      { label: "Launch videos", before: 2, after: 9 },
      { label: "Changelogs", before: 4, after: 7 },
      { label: "Social clips", before: 3, after: 19 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DumbbellShift"
    component={DumbbellShiftScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Rows enter with a before dot and an after dot, the dots slide apart row by row, then the rows sort and the biggest gain is lit with a summary caption. Pass `rows` (label, before, after), plus `beforeLabel`, `afterLabel` and an optional `summaryCaption`. Ships dark and light via `theme`.
