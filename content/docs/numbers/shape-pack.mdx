## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShapePack } from "@/components/remocn/shape-pack";

const ShapePackScene = () => (
  <ShapePack value={3.2} decimals={1} suffix="×" label="faster renders" />
);

export const RemotionRoot = () => (
  <Composition
    id="ShapePack"
    component={ShapePackScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Blocks fall one after another and pack into a twelve by eight grid, leaving a slot that the last block fills. That block counts up to `value` with its suffix and label. Pass `value`, `suffix`, `label` and optionally your own `logo` node; it ships light and dark through `theme`.
