## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VersionHero } from "@/components/remocn/version-hero";

const VersionHeroScene = () => (
  <VersionHero version="2.0" name="remocn" label="Now available" />
);

export const RemotionRoot = () => (
  <Composition
    id="VersionHero"
    component={VersionHeroScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The numeral's slices stack up in 3D under a slow orbiting camera, dock into a solid object while a disc of light rises behind it, and a specular sweep crosses its faces. The label lands beneath. Pass `version`, `name` and `label`; `theme` picks brushed aluminium in dark or matte paper stock in light.
