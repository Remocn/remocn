## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LaunchDate } from "@/components/remocn/launch-date";

const LaunchDateScene = () => (
  <LaunchDate
    date={{ month: 10, day: 30, year: 2026 }}
    label="Coming soon"
    order="month-day"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LaunchDate"
    component={LaunchDateScene}
    durationInFrames={195}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A calendar month draws itself line by line and the days sweep on until the launch day lights up. The camera pushes in, a ring is drawn around that day, and the day glides into a large lockup where the ring becomes the full stop between day and month. A label fades in underneath. Pass `date` as month, day and year, `label` and `order`. It ships light and dark through the `theme` prop.
