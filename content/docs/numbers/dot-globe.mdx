## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotGlobe } from "@/components/remocn/dot-globe";

const DotGlobeScene = () => <DotGlobe count={142} prefix="Live in" suffix="countries" />;

export const RemotionRoot = () => (
  <Composition
    id="DotGlobe"
    component={DotGlobeScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dotted globe fades in and keeps rotating while accent arcs lift off one city and land on another along great circles; each landing pulses a ring, drops a labeled pin and ticks the counter up by one, ending on the final count in big type. Pass `count`, `prefix`, `suffix` and `routes` (pairs of `{ name, lat, lon }` cities). It ships light and dark through `theme`.
