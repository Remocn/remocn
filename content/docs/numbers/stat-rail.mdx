## Usage

```tsx
// src/Root.tsx
import { Composition, staticFile } from "remotion";
import { StatRail } from "@/components/remocn/stat-rail";

const StatRailScene = () => (
  <StatRail image={staticFile("hero.jpg")} tagline="The *future* of launch video is code" stats={[{ value: "120", label: "components ready to install" }, { value: "4", label: "minutes to first render" }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="StatRail"
    component={StatRailScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The tagline fills the frame over the image, then the image shrinks to the right as the rail slides in and each stat steps up in turn, the last one landing as a chip. By default it uses a stock image that only exists in the remocn repo, so pass your own `image` URL or `staticFile(...)`. Wrap a tagline word in asterisks to set it in the accent serif; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
