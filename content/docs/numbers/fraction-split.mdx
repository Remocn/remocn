## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FractionSplit } from "@/components/remocn/fraction-split";

const FractionSplitScene = () => <FractionSplit line="Renders in 1/8 the time." highlight="1/8" accentPiece={0} />;

export const RemotionRoot = () => (
  <Composition
    id="FractionSplit"
    component={FractionSplitScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A bar of eight segments splits into halves, quarters and eighths with a fraction label at each stage; then all but one piece drain away, the bar shifts up and the headline appears word by word with the `highlight` text in gradient. Pass `line` and `highlight`; `accentPiece` picks which of the eight pieces stays. It ships light and dark through `theme`.
