## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AreaCompare } from "@/components/remocn/area-compare";

const AreaCompareScene = () => (
  <AreaCompare
    label="Bundle size"
    beforeValue={1200}
    afterValue={84}
    unit="KB"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AreaCompare"
    component={AreaCompareScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two discs, sized by area, start at the same scale, then the second shrinks to its true ratio while a tag appears and the multiplier settles in large type with the verdict word. Pass `before` and `after` names, `beforeValue` and `afterValue` with a `unit`, and set `shape` to circle or square. Ships dark and light via `theme`.
