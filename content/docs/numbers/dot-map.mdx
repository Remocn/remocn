## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotMap } from "@/components/remocn/dot-map";

const DotMapScene = () => <DotMap count={142} label="countries" />;

export const RemotionRoot = () => (
  <Composition
    id="DotMap"
    component={DotMapScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dotted world map fades in and cities light up from west to east, each with a ripple ring, while the count rises with them to its final value and a label sits beneath. Pass `count`, `label` and `cities` as `{ lon, lat }` points. It ships light and dark through `theme`.
