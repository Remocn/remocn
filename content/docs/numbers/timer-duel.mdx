## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TimerDuel } from "@/components/remocn/timer-duel";

const TimerDuelScene = () => (
  <TimerDuel
    before={2718.4}
    after={70.9}
    beforeLabel="Before"
    afterLabel="With remocn"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TimerDuel"
    component={TimerDuelScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two stopwatch readouts start together. The faster one stops first and lights up in the accent colour, then the slower one runs on, slows and freezes dimmed. The row rises and a large multiplier such as '38x faster' lands below it. Pass `before` and `after` in seconds, and `beforeLabel` and `afterLabel` to name the two clocks. It ships light and dark through the `theme` prop.
