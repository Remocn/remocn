## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChevronRun } from "@/components/remocn/chevron-run";

const ChevronRunScene = () => <ChevronRun value="+312%" caption="growth since launch" />;

export const RemotionRoot = () => (
  <Composition
    id="ChevronRun"
    component={ChevronRunScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A full-frame wall of up-chevrons races upward in staggered columns, then column by column brakes and locks into one giant chevron that fuses solid in a gradient. The figure drops into the cut-out under it and a serif caption follows. Pass `value` and `caption`. It ships light and dark through `theme`.
