## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RadialBars } from "@/components/remocn/radial-bars";

const RadialBarsScene = () => (
  <RadialBars values={[8, 14, 22, 40, 90, 64, 30, 18]} value="2.4M" label="renders in the peak hour" />
);

export const RemotionRoot = () => (
  <Composition
    id="RadialBars"
    component={RadialBarsScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Bars grow around the dial in a sweep, the peak group is picked out with a bracket and a soft glow, and the center figure counts up under its label. Pass `values` (one bar each), `highlight`, `value`, `label` and `ticks`; it ships light and dark through `theme`.
