## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PixelBars } from "@/components/remocn/pixel-bars";

const PixelBarsScene = () => (
  <PixelBars
    values={[31, 38, 35, 44, 41, 50, 84]}
    metric="+64%"
    label="this quarter"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PixelBars"
    component={PixelBarsScene}
    durationInFrames={115}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Columns of LED-style pixels light up bar by bar; the last column climbs past the previous best, turns orange and blue, and the metric counts up beside the chart. Pass `values` (one number per column), `metric` and `label`. Ships dark and light via `theme`.
