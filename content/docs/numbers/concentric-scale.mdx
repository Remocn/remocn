## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ConcentricScale } from "@/components/remocn/concentric-scale";

const ConcentricScaleScene = () => <ConcentricScale steps={[{ value: "1" }, { value: "100" }, { value: "10,000", label: "creators" }]} />;

export const RemotionRoot = () => (
  <Composition
    id="ConcentricScale"
    component={ConcentricScaleScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Dotted discs scale up one at a time as the camera pulls back, each ring labeled with a step value, until the last disc glows at its rim and its large figure and label land beside it. Pass `steps` as 2 to 7 entries of `{ value, label? }`; the label of the final step becomes the caption. It ships light and dark through `theme`.
