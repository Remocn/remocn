## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Ridgeline } from "@/components/remocn/ridgeline";

const RidgelineScene = () => (
  <Ridgeline
    labels={["2022", "2023", "2024", "2025"]}
    highlightLabel="With remocn"
    value="2.6×"
    caption="more videos per team"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Ridgeline"
    component={RidgelineScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Grey ridgelines for each period draw in one after another, then a lit gradient ridge rises to the right and shifts the peak while the multiplier stat and caption land. Pass `labels` for the period rows, `highlightLabel` for the lit row, and `value`, `caption`, `axisLabel` and `ticks` for the text. Ships dark and light via `theme`.
