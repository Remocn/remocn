## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CarryCount } from "@/components/remocn/carry-count";

const CarryCountScene = () => (
  <CarryCount
    from={2855}
    value={13580}
    label={"scenes students\nbuilt in week one"}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CarryCount"
    component={CarryCountScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large number starts at `from` and adds in `steps` chunks. Each change squashes the changed digit and, where a column overflows, a small disc carries a 1 over to the next column, growing a new digit at the left when needed. A caption of one or more lines slides up beside the number. Pass `value`, `from`, `steps` and `label` with a line break. It ships light and dark through the `theme` prop.
