## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotSort } from "@/components/remocn/dot-sort";

const DotSortScene = () => (
  <DotSort
    highlight={0}
    groups={[
      { label: "remocn", value: 41 },
      { label: "Kitebase", value: 23 },
      { label: "Lumen", value: 17 },
      { label: "Other", value: 19 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DotSort"
    component={DotSortScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Four hundred dots start in a cloud, then sort into rows by group; the highlighted row gets the gradient, the rest dim, and its percentage and caption land. Pass `groups` (label and value) and `highlight`, the index of the hero group. Ships dark and light via `theme`.
