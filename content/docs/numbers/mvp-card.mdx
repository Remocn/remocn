## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MvpCard } from "@/components/remocn/mvp-card";

const MvpCardScene = () => (
  <MvpCard title="MVP" role="Carry" number="01" stats={[{ value: 12.4, decimals: 1, label: "Renders / min" }, { value: 100, suffix: "%", label: "Uptime" }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="MvpCard"
    component={MvpCardScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The card slams up and opens from its centre line, the giant title rises letter by letter behind it, and the logo, role and event lines slide in. Three stats then count in a stagger. Pass `title`, `kicker`, `event`, `role`, `number` and `stats`; it ships light and dark through `theme`.
