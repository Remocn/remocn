## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HexFill } from "@/components/remocn/hex-fill";

const HexFillScene = () => <HexFill value={86} label="of renders served from cache" rings={7} />;

export const RemotionRoot = () => (
  <Composition
    id="HexFill"
    component={HexFillScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A honeycomb of outlined hexagons appears ring by ring, then cells pop in with a gradient in a sweep around the circle up to the percentage, while a large reading counts up beside it with a label. Pass `value` as a percent from 0 to 100, plus `label`; `rings` sets the grid size. It ships light and dark through `theme`.
