## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NumberSplit } from "@/components/remocn/number-split";

const NumberSplitScene = () => (
  <NumberSplit total="300+" label="components" parts={[{ label: "animations", value: 120 }, { label: "transitions", value: 90 }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="NumberSplit"
    component={NumberSplitScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The total sits large, a gradient bar slides in beneath it and splits into segments joined by a bracket, then each part counts up with its label. Pass `total`, `label` and `parts`; it ships light and dark through `theme`.
