## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Streamgraph } from "@/components/remocn/streamgraph";

const StreamgraphScene = () => (
  <Streamgraph
    highlight={2}
    label="of new projects"
    series={[
      { label: "Kitebase", values: [12, 14, 17, 19, 18, 16, 15, 13] },
      { label: "Lumen", values: [9, 10, 12, 14, 15, 13, 11, 9] },
      { label: "remocn", values: [2, 3, 5, 9, 13, 19, 25, 33] },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Streamgraph"
    component={StreamgraphScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Stacked layers draw from left to right as a flowing stream, then the highlighted layer takes the gradient while the others dim, and its share counts up with a label. Pass `series` (label and one value per time step), `highlight` and `label`. Ships dark and light via `theme`.
