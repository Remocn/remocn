## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MagnitudePush } from "@/components/remocn/magnitude-push";

const MagnitudePushScene = () => (
  <MagnitudePush value="1000" suffix="×" label="fewer keyframes to set by hand" />
);

export const RemotionRoot = () => (
  <Composition
    id="MagnitudePush"
    component={MagnitudePushScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The first digit rises alone, then every further digit pushes in with a spring while the camera pulls back to keep the whole figure in frame. A caption settles last. Pass `value`, `suffix` and `label`; it ships light and dark through `theme`.
