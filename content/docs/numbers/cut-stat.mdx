## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CutStat } from "@/components/remocn/cut-stat";

const CutStatScene = () => (
  <CutStat
    value={44}
    label="less time to a finished cut"
    caption="vs. keyframing every scene by hand"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CutStat"
    component={CutStatScene}
    durationInFrames={115}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A bar graph wipes up, then a cut sweeps it down with a flash as the big minus percentage words in and the caption follows. Pass `value` (the percent cut, 5 to 95), `label` for the claim, and `caption` for the comparison. Ships dark and light via `theme`.
