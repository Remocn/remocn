## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MoireReveal } from "@/components/remocn/moire-reveal";

const MoireRevealScene = () => (
  <MoireReveal value="10×" caption="faster first frame on remocn render" />
);

export const RemotionRoot = () => (
  <Composition
    id="MoireReveal"
    component={MoireRevealScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A field of fine lines turns and drifts until it locks into the figure, then a small pill caption fades in beneath. Pass `value` and `caption`, or set `shape` to `mark` to reveal the Remocn mark instead of text; it ships light and dark through `theme`.
