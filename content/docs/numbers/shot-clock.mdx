## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShotClock } from "@/components/remocn/shot-clock";

const ShotClockScene = () => (
  <ShotClock
    from={24}
    title="Shipped"
    subtitle="at the buzzer"
    period="Q4 · 00:24"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShotClock"
    component={ShotClockScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large shot clock drops in with a light bar above and a possession bar below. Whole seconds tick down, the clock turns red at the tenths threshold and counts tenths, and at 0.0 the frame flashes and the light stays lit. The clock then shrinks upward and the title and subtitle slam in. Pass `from`, `title`, `subtitle`, `label` and `period`. It ships light and dark through the `theme` prop.
