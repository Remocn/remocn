## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RadarCompare } from "@/components/remocn/radar-compare";

const RadarCompareScene = () => (
  <RadarCompare
    axes={["Speed", "Docs", "Price", "Support", "Polish", "Fit"]}
    brandLabel="remocn"
    caption="Strong on every axis."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RadarCompare"
    component={RadarCompareScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A radar grid appears and the competitor outline draws and fills. The brand polygon then springs out axis by axis over it, the chart slides left and the brand name, competitor name and a caption appear on the right. Pass `axes` with matching `competitor` and `brand` values from 0 to 1, plus `brandLabel`, `competitorLabel` and `caption`. It ships light and dark through the `theme` prop.
