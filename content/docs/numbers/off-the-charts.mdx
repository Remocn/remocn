## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { OffTheCharts } from "@/components/remocn/off-the-charts";

const OffTheChartsScene = () => (
  <OffTheCharts
    target={100}
    caption="of the Q4 target"
    data={[
      { label: "Q1", value: 58 },
      { label: "Q2", value: 74 },
      { label: "Q3", value: 86 },
      { label: "Q4", value: 260 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="OffTheCharts"
    component={OffTheChartsScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Quarterly bars climb against a dashed target line inside a framed axis; the last bar presses against the ceiling, snaps through it, and the overshoot value slams in with its caption. Pass `data`, `target`, and `max` (the axis ceiling), with `unit`, `value` and `caption` for the text. Ships dark and light via `theme`.
