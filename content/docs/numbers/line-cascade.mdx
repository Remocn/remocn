## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LineCascade } from "@/components/remocn/line-cascade";

const LineCascadeScene = () => (
  <LineCascade value="240" caption="launch films rendered with remocn today" />
);

export const RemotionRoot = () => (
  <Composition
    id="LineCascade"
    component={LineCascadeScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Gradient lines rain down and land as flutes on a floor, drawing the figure's strokes until they snap into the solid numeral and a caption rises beneath. Pass `value` (digits plus a few symbols such as `.`, `+`, `%` and `k`) and `caption`; it ships light and dark through `theme`.
