## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FuchidoriCount } from "@/components/remocn/fuchidori-count";

const FuchidoriCountScene = () => <FuchidoriCount value={4096} from={1} label="captions styled without opening an editor" maxBorders={4} />;

export const RemotionRoot = () => (
  <Composition
    id="FuchidoriCount"
    component={FuchidoriCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large number rises into place and counts from `from` to `value` on a log-like curve. Each time it crosses a power of ten a new outline ring springs out around the glyphs, up to `maxBorders` rings, alternating through the border colours. A vertical caption fades in beside it. Pass `value`, `from`, `label`, `maxBorders` and optionally `colors`. It ships light and dark through the `theme` prop.
