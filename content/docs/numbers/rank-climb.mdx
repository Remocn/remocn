## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RankClimb } from "@/components/remocn/rank-climb";

const RankClimbScene = () => (
  <RankClimb brand="remocn" from={8} to={1} eyebrow="Product of the day" caption="on the leaderboard" />
);

export const RemotionRoot = () => (
  <Composition
    id="RankClimb"
    component={RankClimbScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The list builds, then the brand's row overtakes the rows above it one at a time, speeding up, until it lands at the target rank and the win callout settles. Pass `items` (label and votes), `brand` (a label from the list), `from`, `to`, `eyebrow` and `caption`; it ships light and dark through `theme`.
