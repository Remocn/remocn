## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlopeChart } from "@/components/remocn/slope-chart";

const SlopeChartScene = () => (
  <SlopeChart
    highlight={{ before: 6, after: 41 }}
    value="6.8×"
    label="more launch videos shipped"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SlopeChart"
    component={SlopeChartScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Grey lines draw between a before and an after axis, then the hero line starts low, climbs steeply with a dot and ring, and the multiplier stat and label land. Pass `lines` for the grey context, `highlight` for the hero line, and `value`, `label`, `beforeLabel` and `afterLabel`. Ships dark and light via `theme`.
