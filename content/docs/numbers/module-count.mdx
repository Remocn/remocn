## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ModuleCount } from "@/components/remocn/module-count";

const ModuleCountScene = () => <ModuleCount value={120} suffix="+" label="Scenes snapped to one grid" />;

export const RemotionRoot = () => (
  <Composition
    id="ModuleCount"
    component={ModuleCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A five-row block-pixel number snaps through a series of stepped values on a faint grid, each step morphing the modules, then locks on the final figure while a short caption fades in word by word. Pass `value`, optional `prefix` and `suffix`, and `label`; `steps` sets how many readings it snaps through. It ships light and dark through `theme`.
