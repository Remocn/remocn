## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PointHop } from "@/components/remocn/point-hop";

const PointHopScene = () => (
  <PointHop value={0.0000342} unit="s" label="scene refresh after a prop change" />
);

export const RemotionRoot = () => (
  <Composition
    id="PointHop"
    component={PointHopScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The tiny value starts as a long string of zeros. Its decimal point hops three digits at a time while the unit prefix swaps, once per step, until the figure reads cleanly. Pass `value` in base units, `unit`, `prefixes` and `label`; it ships light and dark through `theme`.
