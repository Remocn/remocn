## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ThreadWeave } from "@/components/remocn/thread-weave";

const ThreadWeaveScene = () => (
  <ThreadWeave value="24" caption="frames per second" />
);

export const RemotionRoot = () => (
  <Composition
    id="ThreadWeave"
    component={ThreadWeaveScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Warp threads set up the loom, then every row of the pattern is woven across in alternating directions until the figure appears in blue and orange cells. A caption settles under it. Pass `value` and `caption`, or set `motif` to `mark` to weave the Remocn mark; it ships light and dark through `theme`.
