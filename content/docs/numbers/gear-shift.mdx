## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GearShift } from "@/components/remocn/gear-shift";

const GearShiftScene = () => <GearShift value={42} gears={4} label="scenes in one launch film" />;

export const RemotionRoot = () => (
  <Composition
    id="GearShift"
    component={GearShiftScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A coloured side panel with numbered gear steps fades in beside a number that counts from `from` to `value`. Each gear is a faster, heavier-weight stretch of the count, with a small jolt at every shift and a final landing jolt on the top gear. A caption sits in the panel. Pass `value`, `from`, `label` and `gears`. It ships light and dark through the `theme` prop.
