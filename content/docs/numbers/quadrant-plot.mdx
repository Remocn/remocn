## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { QuadrantPlot } from "@/components/remocn/quadrant-plot";

const QuadrantPlotScene = () => (
  <QuadrantPlot
    xLabels={["Slow", "Fast"]}
    yLabels={["Hard", "Easy"]}
    brand={{ label: "remocn", x: 0.9, y: 0.88 }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="QuadrantPlot"
    component={QuadrantPlotScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Axes and corner marks draw in, the competitor dots drop onto the grid, and then the brand marker flies in along a curved path and lands in its quadrant. A ring, a wash and a guide line spotlight it afterwards. Pass `points` and `brand` as 0-1 coordinates, and `xLabels` and `yLabels` for the two axes. It ships light and dark through the `theme` prop.
