## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BenchmarkRace } from "@/components/remocn/benchmark-race";

const BenchmarkRaceScene = () => (
  <BenchmarkRace
    statement="12× faster"
    title="Cold render, 1080p · median of 50 runs"
    lanes={[
      { label: "remocn", seconds: 0.42, highlight: true },
      { label: "Kitebase", seconds: 2.38 },
      { label: "Before", seconds: 5.06 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BenchmarkRace"
    component={BenchmarkRaceScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Lanes arrive and race on a shared clock; the highlighted lane hits the finish first and its time freezes with a pulse while the others dim and keep crawling. The camera then glides down and the `statement` rolls in above. Pass `lanes` (label, seconds, optional highlight), `statement` and `title`. Ships dark and light via `theme`.
