## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AbacusCount } from "@/components/remocn/abacus-count";

const AbacusCountScene = () => <AbacusCount value={48216} label="renders this week" />;

export const RemotionRoot = () => (
  <Composition
    id="AbacusCount"
    component={AbacusCountScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Rods and beads fade in beside a large readout. Beads slide along each rod in springy steps, carrying over into the next rod, while the matching digit in the readout updates and the leading digit takes a gradient. A caption fades in after the last step. Pass `value` up to 999,999 and `label`. It ships light and dark through the `theme` prop.
