## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Countdown } from "@/components/remocn/countdown";

const CountdownScene = () => (
  <Countdown
    from={3}
    finalLabel="Live"
    caption="remocn 2.0"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Countdown"
    component={CountdownScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Giant numerals count down from `from`, each held for `beat` frames and leaving by a ring wipe, a horizontal slice or a rush past the camera. The final label then hits with a spring over a glowing halo, with an accent dot and a small caption lockup underneath. Pass `from`, `finalLabel` and `caption`. It ships light and dark through the `theme` prop. The length shown is for the defaults of 3 numerals at 20 frames; it is `from * beat + 32` in general.
