## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PackedCount } from "@/components/remocn/packed-count";

const PackedCountScene = () => <PackedCount value={41900} from={120} label="replays on a single launch clip" />;

export const RemotionRoot = () => (
  <Composition
    id="PackedCount"
    component={PackedCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Digits rise out of a mask as the counter climbs from a small start, packing tight and gaining a place each time a new digit joins. A caption slides in above at the start, and once the count lands a blue fill sweeps across the figure digit by digit. Pass `value`, `from` and `label`; `accent` recolors the fill. It ships light and dark through `theme`.
