## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StackedShift } from "@/components/remocn/stacked-shift";

const StackedShiftScene = () => (
  <StackedShift
    years={["2023", "2024", "2025"]}
    caption="of launch videos"
    series={[
      { label: "remocn", values: [6, 24, 52] },
      { label: "Kitebase", values: [34, 28, 18] },
      { label: "Other", values: [60, 48, 30] },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="StackedShift"
    component={StackedShiftScene}
    durationInFrames={178}
    fps={30}
    width={1280}
    height={720}
  />
);
```

One stacked share bar shifts from year to year, the segments sliding to new sizes with the year label changing, until the highlighted series reaches its final share and its caption lands. Pass `series` (label and one value per year), `years`, `highlight` and `caption`. Ships dark and light via `theme`.
