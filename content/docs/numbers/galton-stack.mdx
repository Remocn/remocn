## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GaltonStack } from "@/components/remocn/galton-stack";

const GaltonStackScene = () => (
  <GaltonStack count={260} label="95% of renders under 2s" markerLabel="2s" />
);

export const RemotionRoot = () => (
  <Composition
    id="GaltonStack"
    component={GaltonStackScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Dots fall through a field of pegs into bins and stack into a bell curve, then the camera settles on a marker line and the label lands. Pass `count` of dots, `marker` (0 to 1 across the bins) and its `markerLabel`, plus a `label` for the claim. Ships dark and light via `theme`.
