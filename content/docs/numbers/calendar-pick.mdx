## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CalendarPick } from "@/components/remocn/calendar-pick";

const CalendarPickScene = () => (
  <CalendarPick
    title="Launch day, booked."
    month="June"
    year="2026"
    pickDay={18}
    eventLabel="Launch"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CalendarPick"
    component={CalendarPickScene}
    durationInFrames={168}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A tilted month calendar rises in and the day cells fade in row by row while the camera pushes toward one day. A cursor glides in and clicks it, the cell opens into an input that types a time range, then floods with the accent colour and shows an event label. Pass `month`, `year`, `firstWeekday`, `daysInMonth`, `pickDay` and `timeRange` to fit your date. It ships light and dark through the `theme` prop and has no `speed` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
