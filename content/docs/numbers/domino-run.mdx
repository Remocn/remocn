## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DominoRun } from "@/components/remocn/domino-run";

const DominoRunScene = () => <DominoRun count={13} value="10x" caption="Every push tips a bigger one." />;

export const RemotionRoot = () => (
  <Composition
    id="DominoRun"
    component={DominoRunScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A row of dominoes, each taller than the one before, tips over one after another until the largest falls and the big value and caption fade in. Pass `count` (5 to 24) for the number of dominoes, plus `value` and `caption`. It ships light and dark through `theme`.
