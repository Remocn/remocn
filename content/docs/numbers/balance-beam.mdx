## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BalanceBeam } from "@/components/remocn/balance-beam";

const BalanceBeamScene = () => (
  <BalanceBeam
    items={["$4,800", "62 hours", "3 tools", "9 revisions"]}
    accentLabel="remocn"
    title="One block."
    subtitle="Outweighs the whole stack."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BalanceBeam"
    component={BalanceBeamScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Blocks labeled with costs drop one by one onto a seesaw and weigh it down, then the hero block lands on the other side and tips the beam while the title and subtitle fade in. Pass `items` (up to eight labels), `accentLabel` for the hero block, and `title` and `subtitle`. Ships dark and light via `theme`.
