## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RasterPaint } from "@/components/remocn/raster-paint";

const RasterPaintScene = () => (
  <RasterPaint title="10x" label="Faster renders in remocn 2.0" />
);

export const RemotionRoot = () => (
  <Composition
    id="RasterPaint"
    component={RasterPaintScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A scan line sweeps down the frame, painting the pixelated figure tile by tile, with a warm to blue gradient trailing behind it. A label fades in once the scan is done. Pass `title` and `label`; it ships light and dark through `theme`.
