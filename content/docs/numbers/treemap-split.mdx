## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TreemapSplit } from "@/components/remocn/treemap-split";

const TreemapSplitScene = () => (
  <TreemapSplit
    items={[
      { label: "Captions", value: 38 },
      { label: "Transitions", value: 16 },
      { label: "Text", value: 12 },
      { label: "Shaders", value: 8 },
      { label: "Icons", value: 6 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TreemapSplit"
    component={TreemapSplitScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A rectangle splits recursively with drawn lines into category tiles, then the highlighted tile fills with gradient, the rest dim, and its share counts up with its label. Pass `items` (label and value, up to ten) and optionally `highlight`, the index of the hero item; it defaults to the largest. Ships dark and light via `theme`.
