## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScoreBug } from "@/components/remocn/score-bug";

const ScoreBugScene = () => (
  <ScoreBug
    away="Old way"
    score={2}
    scorers={["Install 12′", "Ship 47′"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ScoreBug"
    component={ScoreBugScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A broadcast score panel opens with the Remocn block on the left and an opponent block on the right. The home digit flips once per goal and a scorer line drops in under the block each time. After the last goal a gradient flash band sweeps across, the tab changes to the full-time label and the opponent dims. Pass `away`, `score`, `scorers` and `flash`. It ships light and dark through the `theme` prop.
