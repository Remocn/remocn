## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StatInline } from "@/components/remocn/stat-inline";

const StatInlineScene = () => (
  <StatInline value="12,480" text="Builders shipped {value} launch videos this year." label="Launch videos shipped" />
);

export const RemotionRoot = () => (
  <Composition
    id="StatInline"
    component={StatInlineScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The value appears large with a label, then moves into its slot in the sentence while the surrounding words rise in around it. Put `{value}` in `text` where the number belongs. Pass `value`, `text`, `label` and `align`; it ships light and dark through `theme`.
