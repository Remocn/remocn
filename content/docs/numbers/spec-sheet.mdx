## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpecSheet } from "@/components/remocn/spec-sheet";

const SpecSheetScene = () => (
  <SpecSheet title="Tech specs" highlight={3} rows={[{ label: "Resolution", value: "4K" }, { label: "Frame rate", value: "60 fps" }, { label: "Install", value: "1 command" }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="SpecSheet"
    component={SpecSheetScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Hairline rules draw across and the labels and values reveal row by row, the values typing in. Then the highlighted row expands and its value grows in the accent gradient. Pass `rows`, `highlight` (row index), `title` and `name` (shown in the bottom lockup); it ships light and dark through `theme`.
