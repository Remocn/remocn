## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PitchOver } from "@/components/remocn/pitch-over";

const PitchOverScene = () => <PitchOver value={7200} label="Frames rendered, T+04:00" />;

export const RemotionRoot = () => (
  <Composition
    id="PitchOver"
    component={PitchOverScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large number counts up while a ruler of major and minor ticks draws beneath it; at the end a marker turns and slides along the ruler, then a caption fades in below. Pass `value` with `decimals`, `prefix` or `suffix` as needed, and `label`; `accent` colors the marker. It ships light and dark through `theme`.
