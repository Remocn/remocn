## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TimesTurn } from "@/components/remocn/times-turn";

const TimesTurnScene = () => (
  <TimesTurn value="3" before="%" label="more launch cuts from the same storyboard" />
);

export const RemotionRoot = () => (
  <Composition
    id="TimesTurn"
    component={TimesTurnScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The figure rises in beside a small unit. A multiplication sign then turns in on the panel while the unit exits, the figure swells to fill the space, and the label rises in word by word. Pass `value`, `before` and `label`; it ships light and dark through `theme`.
