## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BlockCity } from "@/components/remocn/block-city";

const BlockCityScene = () => (
  <BlockCity value={340} prefix="+" suffix="%" caption="renders" />
);

export const RemotionRoot = () => (
  <Composition
    id="BlockCity"
    component={BlockCityScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A camera flies low over a grid of blocks that rise like a city, then cranes up into a front view where the tallest tower is lit and the stat counts up beside it. Pass `value`, `prefix`, `suffix` and `caption` for the number, and `data` (one number per column) to shape the skyline. Ships dark and light via `theme`.
