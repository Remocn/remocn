## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChurnCount } from "@/components/remocn/churn-count";

const ChurnCountScene = () => <ChurnCount value={72960} label="frames played back live, straight from your props" />;

export const RemotionRoot = () => (
  <Composition
    id="ChurnCount"
    component={ChurnCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A giant number sits at the bottom right and counts from `from` to `value` with a fast ease-out. Digits that are still changing are drawn thin and in the accent colour, then thicken back to full weight as they settle. A small caption fades in beside it. Pass `value`, `from` and `label`. It ships light and dark through the `theme` prop.
