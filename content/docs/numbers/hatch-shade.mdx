## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HatchShade } from "@/components/remocn/hatch-shade";

const HatchShadeScene = () => <HatchShade value="24" caption="new components, drawn for launch week" />;

export const RemotionRoot = () => (
  <Composition
    id="HatchShade"
    component={HatchShadeScene}
    durationInFrames={155}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A serif number is drawn in with pen-stroke hatch lines in three passes - two crossing passes in ink, then a copper pass - before a crisp outline appears and the caption fades in. Pass `value` as a string and `caption`. It ships light and dark through `theme`.
