## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TallyMarks } from "@/components/remocn/tally-marks";

const TallyMarksScene = () => <TallyMarks value={1240} label="videos rendered on launch day" />;

export const RemotionRoot = () => (
  <Composition
    id="TallyMarks"
    component={TallyMarksScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Hand-drawn tally strokes scratch in across the frame while the camera drifts over them, then straighten into neat tally groups before collapsing into a gradient total with a label beneath. Pass `value` and `label`; `rows` and `groupsPerRow` size the tally field and `accent` colors the numeral. It ships light and dark through `theme`.
