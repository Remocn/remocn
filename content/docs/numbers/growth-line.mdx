## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GrowthLine } from "@/components/remocn/growth-line";

const GrowthLineScene = () => (
  <GrowthLine value="100k" label="creators in the first year" steepness={4.6} />
);

export const RemotionRoot = () => (
  <Composition
    id="GrowthLine"
    component={GrowthLineScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An exponential curve draws across the frame while the camera tracks the tip, popping each milestone along the way, then the endpoint value lands with a ring. Pass `value`, `label`, and `milestones`; tune the curve with `steepness`. Ships dark and light via `theme`.
