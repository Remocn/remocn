## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PressStat } from "@/components/remocn/press-stat";

const PressStatScene = () => (
  <PressStat before="Edit time down" value={73} suffix="%" />
);

export const RemotionRoot = () => (
  <Composition
    id="PressStat"
    component={PressStatScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The caption rises in letter by letter, then presses open to make room while the figure inflates and counts from `from` up to `value`. Pass `before`, `value` and `suffix`; it ships light and dark through `theme`.
