## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SankeyFlow } from "@/components/remocn/sankey-flow";

const SankeyFlowScene = () => (
  <SankeyFlow
    target="remocn"
    label="videos rendered"
    sources={[
      { label: "Marketing", value: 4100 },
      { label: "Product", value: 3200 },
      { label: "Docs", value: 2400 },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SankeyFlow"
    component={SankeyFlowScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Source nodes appear on the left, then flows of different widths draw one by one into a single target block that lands with the combined total and label. Pass `sources` (label and value), `target`, and `label`; the total is the sum unless you set `total`. Ships dark and light via `theme`.
