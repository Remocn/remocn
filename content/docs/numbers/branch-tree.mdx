## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BranchTree } from "@/components/remocn/branch-tree";

const BranchTreeScene = () => <BranchTree depth={3} branching={[3, 4, 4]} title="variants" rootLabel="1 component" />;

export const RemotionRoot = () => (
  <Composition
    id="BranchTree"
    component={BranchTreeScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A single root node branches level by level into a growing fan of leaves, then the leaf count lands in large type with a caption. The count is the product of the branching, so 3 by 4 by 4 gives 48. Pass `depth` (1 to 5), `branching` as one number or one per level, `title` for the word after the count, and `rootLabel`. It ships light and dark through `theme`.
