## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RowCount } from "@/components/remocn/row-count";

const RowCountScene = () => <RowCount value={27300000} label="frames rendered in every region, every night" />;

export const RemotionRoot = () => (
  <Composition
    id="RowCount"
    component={RowCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The number counts up on a log curve beside a stack of ruled rows; each thousands group gets its own row, and a new row springs in as the count crosses 1,000, 1,000,000 and beyond, with the newest row tinted in the accent. A small label sits to the side. Pass `value`, `from`, `prefix` and `label`. It ships light and dark through `theme`.
