## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BracketFocus } from "@/components/remocn/bracket-focus";

const BracketFocusScene = () => <BracketFocus subject="1.8s" tag="Render time" />;

export const RemotionRoot = () => (
  <Composition
    id="BracketFocus"
    component={BracketFocusScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dotted grid ripples in around a big value, and four viewfinder corner brackets fly in from the edges of the frame and snap tight around it with a springy settle. A tag chip and a size readout appear and the background dims around the focus. Pass `subject` and `tag`; `accent` colors the highlights. It ships light and dark through `theme`.
