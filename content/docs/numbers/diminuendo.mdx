## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Diminuendo } from "@/components/remocn/diminuendo";

const DiminuendoScene = () => <Diminuendo value={860000} label="frames rendered from the registry last month" ratio={0.8} />;

export const RemotionRoot = () => (
  <Composition
    id="Diminuendo"
    component={DiminuendoScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big figure counts from `from` to `value` on a log-like curve, adding new leading digits as it passes each power of ten. Each digit group to the right is drawn smaller and fainter by `ratio`, and digits roll as they change. A caption fades in at the top left. Pass `value`, `label`, `ratio` and optionally `prefix`, `suffix` and `separator`. It ships light and dark through the `theme` prop.
