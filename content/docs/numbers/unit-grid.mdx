## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UnitGrid } from "@/components/remocn/unit-grid";

const UnitGridScene = () => (
  <UnitGrid total={100} highlighted={33} caption="1 in 3 teams ship weekly" />
);

export const RemotionRoot = () => (
  <Composition
    id="UnitGrid"
    component={UnitGridScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Dots fade in across the grid, then the highlighted dots flip to the accent color in a sweeping order while the stat line and caption come in. Pass `total`, `highlighted` and `caption`; a total of 100 lays out as ten by ten, and it ships light and dark through `theme`.
