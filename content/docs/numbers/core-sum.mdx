## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoreSum } from "@/components/remocn/core-sum";

const CoreSumScene = () => <CoreSum value={2097152} parts={8} label="frames per night, every core busy" />;

export const RemotionRoot = () => (
  <Composition
    id="CoreSum"
    component={CoreSumScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A column of partial figures counts up row by row, each labelled like 'core 01'. They then merge pairwise, level by level, until a single total remains, which fills with the accent colour and shows the main caption. Pass `value`, `parts`, `label` and `partLabel`. The length shown is for the default of 8 parts. It ships light and dark through the `theme` prop.
