## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LiveTicker } from "@/components/remocn/live-ticker";

const LiveTickerScene = () => (
  <LiveTicker
    value={12480312}
    unit="renders"
    kicker="Live"
    feed={["Lumen", "Kite", "Orbit"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LiveTicker"
    component={LiveTickerScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large comma-separated counter rises into place with its columns already ticking, while dots and small pills slide in from both edges and get swallowed by the number, each giving it a bump. The streams then dry up, the columns brake and settle on `value`, and a label with a unit word and the product name rises beneath. Pass `value`, `unit`, `name`, `kicker` and `feed`. It ships light and dark through the `theme` prop.
