## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FigureReels } from "@/components/remocn/figure-reels";

const FigureReelsScene = () => <FigureReels from={396} to={400} prefix="$" suffix="M" images={["https://example.com/a.jpg", "https://example.com/b.jpg"]} />;

export const RemotionRoot = () => (
  <Composition
    id="FigureReels"
    component={FigureReelsScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The figure rolls its last digits up like an odometer (for example from $396M to $400M) while two reels of images scroll in above and below it, and a lockup with the remocn mark and a label fades in. The default images are files that only exist in the remocn repo, so pass `images` with your own URLs or paths from your `public` folder. It ships light and dark through `theme`; `ground` and `groundParams` change the animated background.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
