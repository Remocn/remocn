## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SingleStroke } from "@/components/remocn/single-stroke";

const SingleStrokeScene = () => (
  <SingleStroke
    value="27"
    unit="Mar"
    label="Demo day. Every team shows a film."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SingleStroke"
    component={SingleStrokeScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A coloured panel slides in and the number is drawn as one continuous stroke with a bright pen tip. As the stroke finishes, the unit text appears on the panel and the label fades in word by word. Pass `value` as digits only, plus `unit` and `label`. It ships light and dark through the `theme` prop; `accent` recolours the panel in dark and the stroke in light.
