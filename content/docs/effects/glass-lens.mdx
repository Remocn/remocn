## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlassLens } from "@/components/remocn/glass-lens";

const GlassLensScene = () => (
  <GlassLens
    lines={["Every frame,", "composed."]}
    focus={{ line: 0, word: 1 }}
    cta="Start building"
    src="/images/product.png"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GlassLens"
    component={GlassLensScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Headline lines rise in on the left and a glass drop slides in, settling on the `focus` word to magnify it. The drop then glides to the highlighted clip in the product pane, travels down to the call-to-action slot, flattens into a pill and fills with the accent, and the `cta` label and arrow land at frame 180. Pass `lines`, `cta` and your own `src` or `children` for the pane; it ships light and dark.
