## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RingAlign } from "@/components/remocn/ring-align";

const RingAlignScene = () => <RingAlign word="Aligned." rings={6} />;

export const RemotionRoot = () => (
  <Composition
    id="RingAlign"
    component={RingAlignScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Rings of dots spin from offset angles and lock one by one, outer ring first, each with a small settle. Once the last ring locks, a bright beam sweeps through the aligned channel and leaves your `word` filled in a gradient. Pass `word` and `rings` (3 to 9). Ships dark and light via `theme`.
