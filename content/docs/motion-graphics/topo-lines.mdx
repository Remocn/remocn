## Usage

`TopoLines` draws the contour map of a seeded height field. The terrain is a
few cone-shaped peaks spread around the center, blended so they share outer
rings without creases, plus a little low ripple. Contours are evenly spaced
like a survey map. Every few contours an index line is drawn heavier, and
one contour is picked out in `accent`.

The terrain moves slowly. Each peak drifts on a small orbit, swells and
shrinks by about 5%, and its outline rotates through gentle two- and
three-lobed bulges. The rings tighten, merge, and pull apart, and after one
loop the field is back where it started.

```tsx
import { TopoLines } from "@/components/remocn/topo-lines";

export const MapBed = () => <TopoLines />;
```

The component fills its parent and paints its own `background`. The terrain
is laid out in units of the short side, so the peaks keep their shape at
16:9, 1:1 and 9:16, and line widths are in px at 720p. The contours are
traced with marching squares on a sampling grid each frame; everything comes
from the Remotion frame and the seed, so renders are deterministic.

## Timing

The terrain repeats every `loopFrames / speed` frames, 300 frames (10
seconds) at the defaults. The last frame flows into the first without a
seam, so a `Sequence` of any multiple of the period, or a Remotion `<Loop>`
of that length, plays as a continuous background. There is no build-up:
frame 0 already shows the full map.

## Performance

`resolution` is the number of sampling cells across the short side. The
default of 90 samples about 14,600 points per frame at 16:9; doubling it
quadruples the work. Lower it for drafts, raise it only if contours look
faceted at a large output size.

## Contours

`levels` contours are spread evenly over the same fixed height range, so
more levels means tighter spacing. They are counted from 0 at the lowest. `highlight` picks the accent contour
by that count, and `-1` turns it off. `indexEvery={4}` makes every fourth
contour an index line; `0` turns index lines off. The accent wins when both
apply to the same contour.

## Variations

`peaks={1}` gives a single hill of nested rings; three reads best as a
landscape. More `levels` tighten the spacing for a busier map.

```tsx
<TopoLines
  levels={24}
  peaks={2}
  highlight={14}
  indexEvery={5}
  loopFrames={450}
  background="#f1eee7"
  color="#3b3a36"
  accent="#d97757"
  seed={6}
/>
```
