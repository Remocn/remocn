## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotFieldMorph } from "@/components/remocn/dot-field-morph";

const DotFieldMorphScene = () => (
  <DotFieldMorph labels={["Animations", "Transitions", "Captions", ""]} count={2000} />
);

export const RemotionRoot = () => (
  <Composition
    id="DotFieldMorph"
    component={DotFieldMorphScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A scattered field of dots drifts, then swirls into the first shape, holds with a caption, and morphs through the next shapes until the last one, the wordmark, holds. Pass `shapes` (SVG path data or parts, stroked or filled) and matching `labels`; with the default set it shows three icons then the Remocn wordmark. Ships dark and light via `theme`.
