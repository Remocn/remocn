## Usage

`SwissGrid` is a title card in the International Typographic Style. It sets a
kicker, a headline, a big numeral and a meta line on a strict modular grid, and
every graphic element is there for the text:

- A vertical spine on the left anchors the text column.
- A heavy rule above the headline is exactly as wide as the headline.
- A thin rule under the headline is as wide as its last line, and the meta line
  hangs from it. When the numeral drops below the headline, the thin rule runs
  under the numeral across the whole column instead.
- One red square marks the top-right corner.
- The big numeral sits on the right as the headline's counterweight.

The card builds in reading order. Faint column and baseline guides draw across
the frame first, so the grid shows before anything lands. Then the spine drops,
the kicker lines set in, the heavy rule grows, and the headline sets in one
word at a time. The numeral and the square land next, then the thin rule and
the meta line. Every rule grows from a pinned edge that never moves, with a
fast acceleration and a hard stop in a single frame. Type rises onto its
baseline inside its own line box and stops the same way. Nothing fades or
types in, and the guides are gone before the card holds.

The component paints no background. Put a `Backdrop` in the paper color behind
it, with no padding, so the grid spans the whole frame.

```tsx
import { Backdrop } from "@/components/remocn/backdrop";
import { SwissGrid } from "@/components/remocn/swiss-grid";

export const TitleCard = () => (
  <Backdrop
    fill={{ type: "color", value: "#f1eee7" }}
    padding={0}
    radius={0}
    shadow=""
  >
    <SwissGrid
      kicker={"Launch week\nDay 02"}
      title="Pricing that scales with you"
      number="02"
      metaStart="remocn.dev"
      metaEnd="Sep 2026"
    />
  </Backdrop>
);
```

### Your own message

Only `title` is required. The headline wraps itself into at most three
balanced lines. Put `\n` in the title to choose the breaks yourself, and in the
kicker to split it into two lines. Leave `kicker`, `number` or the meta props
empty and the card closes up around what is left.

The rules take their length from the rendered text, not from a number in the
code, so any title and any font keep them exact. Pass the family of a font you
have loaded as `fontFamily` to set the card in your own typeface. Here is a
changelog header in Inter that exits at the end of its sequence:

```tsx
import { loadFont } from "@remotion/google-fonts/Inter";
import { Sequence } from "remotion";
import { Backdrop } from "@/components/remocn/backdrop";
import { SwissGrid } from "@/components/remocn/swiss-grid";

const { fontFamily } = loadFont("normal", {
  weights: ["400", "700"],
  subsets: ["latin"],
});

export const ChangelogHeader = () => (
  <Backdrop
    fill={{ type: "color", value: "#f1eee7" }}
    padding={0}
    radius={0}
    shadow=""
  >
    <Sequence durationInFrames={152}>
      <SwissGrid
        kicker={"Changelog\nOctober release"}
        title={"Faster renders\nfor every frame"}
        number="4.2"
        metaStart="remocn.dev/changelog"
        metaEnd="Oct 2026"
        fontFamily={fontFamily}
        exit
      />
    </Sequence>
  </Backdrop>
);
```

With `exit`, the build plays in reverse over the last frames of the sequence.
The meta line leaves first and the spine last. Every rule retracts into its
pinned edge and every word sinks below its baseline with the same snap, so the
last frame is empty and the next scene can cut in. The exit never starts
before the build has landed, so size the sequence with
`getSwissGridDuration({ ...content, exit: true })` or a sequence that is too
short will cut the exit off.

## Timing

At 30 fps, `speed={1}` and the default content:

| Frames | Motion |
| --- | --- |
| 0–13 | Column guides drop from the top edge, then baseline guides draw in from the left |
| 10–17 | The spine drops from its pinned top edge |
| 15–24 | "Launch week" and "Day 02" rise onto their baselines, three frames apart |
| 20–28 | The heavy rule grows to the width of the headline |
| 25–44 | The five headline words set in one at a time, three frames apart |
| 40–48 | The numeral rises into place |
| 44–56 | The guides fade out |
| 48–52 | The red square drops into the top-right corner |
| 48–56 | The thin rule grows to the width of the last line |
| 54–63 | The meta line sets in, start and then end |
| 63–100 | Hold on the finished card |

Siblings land three frames apart and parts four frames apart. Each extra
headline word adds three frames. An empty kicker or meta line saves seven
frames, and an empty `number` saves four.

- `swissGridLength` is 63, the frame where the default card is complete.
- `getSwissGridDuration({ ...content, exit, speed })` returns the preview
  length in frames at 30 fps: the build, a 36-frame hold and, with `exit`, the
  exit. That is 100 frames by default and 152 with `exit`, whose exit takes the
  last 52.
- `getSwissGridTimeline(getSwissGridLayout(content)).cues` lists every part
  with its enter and exit frames, so you can time other layers to your own
  card.
- At another speed or frame rate, divide by `speed` and multiply by `fps / 30`.

## Grid

The module is `min(width, height) / modules`, so the card composes the same way
at 16:9, 1:1 and 9:16 and at any resolution. With the default 24 modules, a
1280×720 frame has 30 px modules. Kicker and meta are set at 0.8 of a module on
a one-module pitch, and the headline at a three-module pitch. Every baseline,
rule and edge sits on a grid line.

The layout picks the largest arrangement that fits the frame. The headline
keeps its three-module pitch when it can and drops to two modules for long
titles. The numeral sits beside the headline and moves below it when the
column is too narrow for both, as it is in portrait with the default content.
There the thin rule spans the column under the numeral, so the meta line still
hangs from a rule that closes the card. Titles up to about 40 characters fit
at every aspect ratio. Fewer `modules` make everything larger.
