## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FourierSum } from "@/components/remocn/fourier-sum";

const FourierSumScene = () => (
  <FourierSum harmonics={[1, 3, 5, 7, 9]} title="Many parts. One signal." />
);

export const RemotionRoot = () => (
  <Composition
    id="FourierSum"
    component={FourierSumScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Rows of sine waves draw in one by one. They then merge in order into a summed wave while a running "1× + 3× + 5×" caption builds, and the `title` fades in below. Pass `harmonics` (odd numbers give a square wave), `title` and `periods`. Ships dark and light via `theme`.
