## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PatternTile } from "@/components/remocn/pattern-tile";

const PatternTileScene = () => (
  <PatternTile steps={["tile", "rotate 90°", "mirror", "translate"]} unit="tiles" />
);

export const RemotionRoot = () => (
  <Composition
    id="PatternTile"
    component={PatternTileScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

One quarter-disc tile appears, rotates into a rosette, mirrors across an axis and slides out into a full wall while a four-step label highlights the current operation. A counter ends on the total tile count with an accent marker. Pass `steps` (four labels) and `unit`. Ships dark and light via `theme`.
