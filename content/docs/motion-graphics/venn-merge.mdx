## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VennMerge } from "@/components/remocn/venn-merge";

const VennMergeScene = () => (
  <VennMerge
    sets={["Design", "Code"]}
    center="Kitebase"
    caption="Motion design, written as code."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="VennMerge"
    component={VennMergeScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Outlined circles draw in, slide together until they overlap, and the shared lens fills with a gradient. The `center` text (or the Remocn logo for the default) fades into the lens and the `caption` appears below. Pass 2 or 3 `sets` labels, a `center` and a `caption`. Ships dark and light via `theme`.
