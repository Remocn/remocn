## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlockForm } from "@/components/remocn/flock-form";

const FlockFormScene = () => <FlockForm count={340} accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="FlockForm"
    component={FlockFormScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A flock flies in from the edges and snaps into an arrow with accent-coloured lead birds, then the arrow launches along a curved path and the birds stream back to land in the Remocn R mark. Pass `count` to change how many birds there are. The mark is built into the file; edit `REMOCN_R_PATH` to use another logo. Ships dark and light via `theme`.
