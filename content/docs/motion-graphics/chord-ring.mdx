## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChordRing } from "@/components/remocn/chord-ring";

const ChordRingScene = () => (
  <ChordRing
    segments={["Acme", "Kitebase", "Lumen", "Fernway", "Quarry", "Orbitly"]}
    brandIndex={0}
    caption="Connects to everything"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ChordRing"
    component={ChordRingScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Ring segments grow in around a glowing center, then curved chords draw between them, with the `brandIndex` segment linked to every other one in the accent color. At the end the ring dims and the `caption` lands in the center. Pass up to 12 `segments` names (a segment named "remocn" renders as the Remocn logo) and a `caption`. Ships dark and light via `theme`.
