## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IndentSteps } from "@/components/remocn/indent-steps";

const IndentStepsScene = () => (
  <IndentSteps
    lines={["Fork the scene.", "Change the props.", "Render tonight."]}
    highlight="tonight"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="IndentSteps"
    component={IndentStepsScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line rises from a mask and tabs one step further right with a small snap and a guide line, with optional line numbers in the gutter. Once the last line lands, the `highlight` word fills with a gradient. Pass up to five `lines`; set `exit` to outdent and slide them out over the last 18 frames. It ships light and dark.
