## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IndexList } from "@/components/remocn/index-list";

const IndexListScene = () => (
  <IndexList
    items={["Scenes", "Captions", "Transitions", "Templates"]}
    title="What is inside 2.0"
    highlight={2}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="IndexList"
    component={IndexListScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Hairline rules draw across and a numbered list rises row by row under a logo and title; a gradient band then wipes in and travels down to the `highlight` row, where it parks with an arrow while the other rows dim. Pass `items`, `title`, the zero-based `highlight` index, and your own `logo` node (the default is the Remocn wordmark). It ships light and dark.
