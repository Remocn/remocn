Remocn has 256 free, MIT-licensed text animation components for Remotion: word and letter
reveals, highlights, typewriters, word swaps, counters, glitches, kinetic posters and pull quotes.
Each one installs with the shadcn CLI and lands in your project as a single TypeScript file, with
no runtime dependency besides Remotion.

```bash
npx shadcn@latest add @remocn/staggered-fade-up
```

```tsx
import { Composition } from "remotion";
import { StaggeredFadeUp } from "@/components/remocn/staggered-fade-up";

const Title = () => <StaggeredFadeUp text="Ship videos faster" staggerDelay={4} />;

export const RemotionRoot = () => (
  <Composition id="Title" component={Title} durationInFrames={90} fps={30} width={1280} height={720} />
);
```

Length is the frames of motion at 30fps, the minimum for the component's `Sequence`. For how to
animate text by hand, the Remotion pitfalls these components handle and a comparison with other
libraries, read [Remotion text animations](/docs/guides/remotion-text-animations). For subtitles
timed to speech, see the 31 caption styles in
[Captions](/docs/captions/getting-started/introduction).

Agents can read this whole section, every component's props and usage included, as one file at
[/llms-full/typography.txt](https://remocn.dev/llms-full/typography.txt).
