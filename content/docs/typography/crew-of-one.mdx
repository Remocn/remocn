## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CrewOfOne } from "@/components/remocn/crew-of-one";

const CrewOfOneScene = () => <CrewOfOne roles={["Written by", "Directed by", "Shipped by"]} name="you" />;

export const RemotionRoot = () => (
  <Composition
    id="CrewOfOne"
    component={CrewOfOneScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Credit-style role lines roll upward in turn, then gather into place under a large name that has been waiting at the center. Pass `roles` (one string per credit) and `name`; it spaces the roll to fit the composition length.
