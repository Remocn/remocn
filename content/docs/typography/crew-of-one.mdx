In Remotion, Crew of One is a mock credits roll: lines like Written by, Directed by and Shipped by roll upward one after another, then gather under one big name, "you" by default, as the joke. Use it as a closing credits beat or a solo-builder message in a launch or demo video.

## How to build this in Remotion

You don't have to build the roll by hand with `useCurrentFrame()`, `interpolate()` and `measureText`. Install the component and pass your roles:

```bash
npx shadcn@latest add @remocn/crew-of-one
```

The roll is one scene with a schedule in `timeline.ts` that spaces the roles across the composition; the motion runs on `interpolate()` with `Easing` curves, and the copy is measured before the first frame (held with `delayRender`) so the roles line up under the name.

## Good to know

- Length: 138 frames of motion at 30 fps (276 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 170 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Length stretch: the schedule spreads the roles over the whole `durationInFrames` (at least 90 frames at 30 fps), so a longer composition rolls slower instead of freezing.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Gabarito itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CrewOfOne } from "@/components/remocn/crew-of-one";

const CrewOfOneScene = () => <CrewOfOne roles={["Written by", "Directed by", "Shipped by"]} name="you" />;

export const RemotionRoot = () => (
  <Composition
    id="CrewOfOne"
    component={CrewOfOneScene}
    durationInFrames={340}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Credit-style role lines roll upward in turn, then gather into place under a large name that has been waiting at the center. Pass `roles` (one string per credit) and `name`; it spaces the roll to fit the composition length.

## Common questions

### How do I build a mock credits roll in Remotion that all points at one big 'you'?

Install Crew of One with `npx shadcn@latest add @remocn/crew-of-one`, pass `roles` such as Written by, Directed by, Shipped by, and keep `name="you"` or pass a real name.

### Do I need to load the Gabarito font?

No. The component loads Gabarito itself. Load a font yourself only when you pass a different `fontFamily`.
