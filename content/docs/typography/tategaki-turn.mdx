## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TategakiTurn } from "@/components/remocn/tategaki-turn";

const TategakiTurnScene = () => <TategakiTurn text="Read it both ways." highlight={3} />;

export const RemotionRoot = () => (
  <Composition
    id="TategakiTurn"
    component={TategakiTurnScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word of `text` drops in as a vertical column, letter by letter. After a hold, the columns swing 90 degrees and travel into a single horizontal line while the type scales up. The `highlight` word, the last by default, takes the accent color; it ships light and dark through `theme`.
