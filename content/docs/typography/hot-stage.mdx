## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HotStage } from "@/components/remocn/hot-stage";

const HotStageScene = () => (
  <HotStage
    lines={["Write the scene.", "Render the cut.", "Ship it."]}
    log={["T+00:00  Draft", "T+02:10  Render", "T+04:00  Live"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HotStage"
    component={HotStageScene}
    durationInFrames={155}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The first line fades up beside a dim monospaced log. Every `stage` frames the next line pushes in with a flash of thin vent ticks, the previous line goes dim and falls away, and the matching log entry lights up. Pass your own `lines` and a `log` with one entry per line. It ships light and dark.
