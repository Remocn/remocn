## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PostScript } from "@/components/remocn/post-script";

const PostScriptScene = () => (
  <PostScript
    signoff="Thanks for watching."
    signature="— the Acme team"
    ps="Your next launch film is a prop away."
    install="npx shadcn add @acme/launch-film"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PostScript"
    component={PostScriptScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `signoff` rises word by word with the `signature` beneath it. A P.S. line (`label` in the accent color, then `ps`) follows, the signoff shrinks and dims upward as the P.S. grows to full size, and the `install` command wipes in at the bottom. The defaults mention Remocn, so pass your own `signature` and `install`. It ships light and dark.
