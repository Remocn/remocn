## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InProportion } from "@/components/remocn/in-proportion";

const InProportionScene = () => (
  <InProportion
    pairs={[
      { worry: "It will look templated.", answer: "It will look like your app." },
      { worry: "I will drown in keyframes.", answer: "You will write a component." },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="InProportion"
    component={InProportionScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A worry builds word by word in large white type, then shrinks into a dimmed note in the top corner while the answer rises in the accent color along the bottom. The next pair repeats. Pass `pairs` as `{ worry, answer }` objects; timing compresses to fit the composition and leaves about 18% hold at the end. It ships light and dark.
