In Remotion, In Proportion handles objections on screen: each worry builds word by word in large type, shrinks into a dim note in the corner, and a bigger accent-colored reply rises to answer it. Use it for an FAQ or objection-handling beat in a launch or product video, with two or three worry and answer pairs.

## How to build this in Remotion

You don't need `TransitionSeries`, a `Series` per line or `fitText` for this. Install the component and pass your pairs:

```bash
npx shadcn@latest add @remocn/in-proportion
```

It is one scene driven by a schedule in `timeline.ts`: every word, shrink and answer has a start frame, and the motion is `interpolate()` over `Easing` curves. Word widths are measured on a canvas while `delayRender` holds the first frame until Hubot Sans has loaded, so lines break the same way in preview and render.

## Good to know

- Length: 180 frames of motion at 30 fps (360 at 60 fps) with the default props; the demo plays 200 frames, which adds a hold. Each pair costs about 4 + (worry words + answer words) × `stagger` + 52 frames, plus 24 between pairs. If that does not fit, the whole schedule compresses to fit the composition and keeps at least 18% (and no less than 30 frames) as a final hold; it never stretches. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Hubot Sans itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Colors: the answer uses one accent for every pair, `#FFE14D` in dark and `#9A7A00` in light; `accent` overrides it for all pairs at once. There is no per-pair color or timing prop.
- More than three pairs work, but each one adds words to the same clip, so the schedule compresses; give the composition more frames rather than letting it squeeze.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InProportion } from "@/components/remocn/in-proportion";

const InProportionScene = () => (
  <InProportion
    pairs={[
      { worry: "It will look templated.", answer: "It will look like your app." },
      { worry: "I will drown in keyframes.", answer: "You will write a component." },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="InProportion"
    component={InProportionScene}
    durationInFrames={400}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A worry builds word by word in large white type, then shrinks into a dimmed note in the top corner while the answer rises in the accent color along the bottom. The next pair repeats. Pass `pairs` as `{ worry, answer }` objects; timing compresses to fit the composition and leaves about 18% hold at the end. It ships light and dark.

## Common questions

### How do I put objections on screen in Remotion, a dim worry and a bigger reply?

Install In Proportion with `npx shadcn@latest add @remocn/in-proportion` and pass `pairs` as `{ worry, answer }` objects. Each worry builds word by word, shrinks into a dim corner note, and the answer rises in the accent color.

### How many pairs can I use?

Two or three read best. More pairs play, but the timing compresses to fit the composition, so raise `durationInFrames`.
