## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HookUncurl } from "@/components/remocn/hook-uncurl";

const HookUncurlScene = () => (
  <HookUncurl question="Why make the video?" answer="Just make the video." />
);

export const RemotionRoot = () => (
  <Composition
    id="HookUncurl"
    component={HookUncurlScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Stacked caps lines enter curled, uncurl into place, then swap in a rolling change from the question to the answer. Pass `question` and `answer`; it ships light and dark.
