In Remotion, Hook Uncurl stacks a question in condensed all-caps lines, then the question mark uncurls into the answer's period or exclamation mark as the answer rolls in, ending on a line such as "Just make the video.". Use it for a hook at the start of a launch or social video.

## How to build this in Remotion

You don't need `rotateX` and perspective tricks. Install the component and write the question and answer:

```bash
npx shadcn@latest add @remocn/hook-uncurl
```

The caps words rise in with `spring()` and `interpolate()`; the question mark is drawn as a curve that straightens over time, and the answer rolls in on the schedule in `timeline.ts`. Letter metrics are measured on a canvas while `delayRender()` holds the first frame.

## Good to know

- Length: 78 frames of motion at 30 fps (156 at 60 fps) with the default props. The demo plays 125 frames, which adds a hold: frames past the end of the motion hold the final frame. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Barlow Condensed itself through `@remotion/google-fonts`, so there is nothing to load for the default. Pass `fontFamily` to use your own face, and load that font in your project.
- `answerAt` (default 40, in 30 fps frames) is when the question mark uncurls; `stagger` (default 3) spaces the question words.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HookUncurl } from "@/components/remocn/hook-uncurl";

const HookUncurlScene = () => (
  <HookUncurl question="Why make the video?" answer="Just make the video." />
);

export const RemotionRoot = () => (
  <Composition
    id="HookUncurl"
    component={HookUncurlScene}
    durationInFrames={250}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Stacked caps lines enter curled, uncurl into place, then swap in a rolling change from the question to the answer. Pass `question` and `answer`; it ships light and dark.

## Common questions

### How do I make a hook where stacked condensed caps lines ask a question and end on the answer?

Install Hook Uncurl with `npx shadcn@latest add @remocn/hook-uncurl` and pass `question` and `answer`.

### Do I need to load Barlow Condensed?

No. The component loads it through `@remotion/google-fonts`.

### How long is it?

78 frames at 30 fps (156 at 60 fps); the demo plays 125 to hold on the answer.
