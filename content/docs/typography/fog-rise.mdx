In Remotion, Fog Rise makes big display text materialize out of fog: it sharpens from heavy blur from the center outward while the word stands up toward the viewer, as if rising along the z-axis. Use it for a dramatic title or a single big word in a brand or launch video.

## How to build this in Remotion

You don't need SVG `feTurbulence`, CSS masks or `@remotion/motion-blur`. Install the component and pass your word:

```bash
npx shadcn@latest add @remocn/fog-rise
```

The letters fade in ring by ring from the center, scheduled in `timeline.ts`. The stand-up is a `spring()` driving a `rotateX` tilt in perspective, a lift and a closing letter gap; the blur is a CSS `blur()` on each letter that clears over `resolveFrames` through `interpolate()`.

## Good to know

- Length: 27 frames of motion at 30 fps (54 at 60 fps) with the default props. The demo plays 90 frames. By default the word starts falling at `exitAt` (frame 60); set `exitAt={0}` to keep it on screen. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file.
- For a word that is already at its final size and position, set `tilt={0}`, `lift={0}`, `spreadGap={0}`, `drift={0}` and `exitAt={0}`: what remains is the center-out blur and fade. There is no separate streak control.
- The default spring (`mass` 1.3, `stiffness` 60, `damping` 13) is slightly underdamped, so the stand-up overshoots a little. Raise `damping` to about 18 for no overshoot. It uses the 30 fps scene clock, so it settles the same at any frame rate.

## Usage

The word starts lying face-down — rotated back around its baseline inside a real CSS perspective — and is thrown upright by a configurable spring (mass, stiffness, damping), travelling up as it stands while each character dissolves in from translucent blur. Characters start slightly spread apart and pull together on the same spring. The choreography has three phases, matching the reference: the enter — spring stand-up, lift and blur dissolve; a slow perpetual `drift` upward so the word never freezes; and at `exitAt` the exit, accelerating the word upward with no fade, meant to be hard-cut by the next scene. The reveal order runs center-out via `stagger`. Motion profile measured frame-by-frame from the reference footage.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FogRise } from "@/components/remocn/fog-rise";

const FogRiseScene = () => <FogRise text="Remocn" />;

export const RemotionRoot = () => (
  <Composition
    id="FogRise"
    component={FogRiseScene}
    durationInFrames={180}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. The reference look pairs a light text color with a dark-to-blue vertical gradient so the word reads as embedded in fog.

```tsx
import { Composition } from "remotion";
import { FogRise } from "@/components/remocn/fog-rise";
import { Backdrop } from "@/components/remocn/backdrop";

const FogRiseScene = () => (
  <Backdrop
    fill={{
      type: "gradient",
      value: "linear-gradient(180deg, #04070f 30%, #1e4f8f 100%)",
    }}
  >
    <FogRise text="Remocn" color="#eaf2ff" />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="FogRise"
    component={FogRiseScene}
    durationInFrames={180}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I make big display text in Remotion materialize out of fog, sharpening from the center outward?

Install Fog Rise with `npx shadcn@latest add @remocn/fog-rise` and pass `text`. The letters clear from heavy blur, center first, while the word stands up toward the viewer.

### Can the word stay in place without the 3D stand-up?

Yes. Set `tilt`, `lift`, `spreadGap` and `drift` to 0; set `exitAt` to 0 to remove the fall at the end.

### Can I remove the exit?

Set `exitAt={0}` and the word holds.
