## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GotEm } from "@/components/remocn/got-em";

const GotEmScene = () => (
  <GotEm pending="Entry submitted" title="GOT ’EM" subline="You got Acme 2.0." />
);

export const RemotionRoot = () => (
  <Composition
    id="GotEm"
    component={GotEmScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A suspense line with an animated ellipsis holds, then the payoff explodes in huge over a gradient sunburst with a subline beneath. Pass `pending`, `title`, `subline` and your own `logo`; it ships light and dark.
