In Remotion, Got Em is a giveaway payoff: a suspense line with an animated ellipsis holds, then explodes into a huge "GOT 'EM" over a gradient sunburst, with a subline beneath. Use it for a giveaway, contest entry or drop reveal.

## How to build this in Remotion

You don't need `@remotion/shapes`, `@remotion/motion-blur` or a conic-gradient hack. Install the component:

```bash
npx shadcn@latest add @remocn/got-em
```

The sunburst rays are SVG polygons, and the ellipsis, the flash and the slam of the title run on `interpolate()` with `Easing` curves scheduled in `timeline.ts`.

## Good to know

- Length: 90 frames of motion at 30 fps (180 at 60 fps) with the default props. The demo plays 140 frames, which adds a hold: frames past the end of the motion hold the final frame. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Unbounded (the title), Geist and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to change the title face, and load that font in your project.
- Sunburst colors are fixed per theme: dark uses `#3d4dff`, `#e2457a`, `#ffb36b`, `#fff4ec` on `#0A0A0B`; light uses `#ffb36b`, `#e2457a`, `#3d4dff` on `#F5F4F0`. `accent` is accepted but not used, so to recolor the rays edit the `rays` arrays in the copied file. The `rays` prop sets how many rays there are (default 40).
- `pause` (default 14) is how many frames the suspense line holds before the payoff.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GotEm } from "@/components/remocn/got-em";

const GotEmScene = () => (
  <GotEm pending="Entry submitted" title="GOT ’EM" subline="You got Acme 2.0." />
);

export const RemotionRoot = () => (
  <Composition
    id="GotEm"
    component={GotEmScene}
    durationInFrames={280}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How can I do a giveaway payoff in Remotion where a suspense line explodes into a huge GOT 'EM over a sunburst?

Install Got Em with `npx shadcn@latest add @remocn/got-em` and pass `pending`, `title`, `subline` and your `logo`.

### Can I change the sunburst colors?

Not through props: the ray colors live in the copied file, one set per theme.

### How long is it?

90 frames at 30 fps (180 at 60 fps) with the defaults; the demo plays 140 to hold on the payoff.
