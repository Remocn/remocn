## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FeatureHeadline } from "@/components/remocn/feature-headline";

const FeatureHeadlineScene = () => (
  <FeatureHeadline
    tag="New"
    label="Captions"
    headline="Captions that move with every word."
    highlight="every word"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FeatureHeadline"
    component={FeatureHeadlineScene}
    durationInFrames={90}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A pill with a tag and label opens, the headline words rise in turn with `highlight` in the accent, and the subhead fades in; with `exit` on, everything lifts away in the last frames of the Sequence. Pass `tag`, `label`, `headline`, `highlight` and `subhead`; it ships light and dark through `theme`.
