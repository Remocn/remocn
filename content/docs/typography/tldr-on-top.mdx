In Remotion, Tldr on Top stacks a short summary above a dense paragraph, and the paragraph fades back into the background so the summary is what you read. Use it for a beat that admits the full explanation is long and gives the short version first.

## Good to know

- Length: 130 frames of motion at 30 fps (260 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Rubik itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TldrOnTop } from "@/components/remocn/tldr-on-top";

const TldrOnTopScene = () => (
  <TldrOnTop label="TL;DR" lines={["Every scene is a component.", "Your brand is one file."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="TldrOnTop"
    component={TldrOnTopScene}
    durationInFrames={400}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A label and summary lines open one by one above a long body paragraph that dims behind them. Pass `lines` for the summary, `text` for the body, and `label` to rename the tag. It ships in light and dark through the `theme` prop.
