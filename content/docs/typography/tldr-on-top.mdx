## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TldrOnTop } from "@/components/remocn/tldr-on-top";

const TldrOnTopScene = () => (
  <TldrOnTop label="TL;DR" lines={["Every scene is a component.", "Your brand is one file."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="TldrOnTop"
    component={TldrOnTopScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A label and summary lines open one by one above a long body paragraph that dims behind them. Pass `lines` for the summary, `text` for the body, and `label` to rename the tag. It ships in light and dark through the `theme` prop.
