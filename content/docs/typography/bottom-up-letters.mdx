In Remotion, Bottom-Up Letters animates a short word, such as a product acronym, so each letter rises up from below in a clear staircase, one character after another. Use it when a short punchy word should land with visible per-character energy.

## How to build this in Remotion

You don't have to hand-write per-character `spring()` offsets. Install the component and pass your word:

```bash
npx shadcn@latest add @remocn/bottom-up-letters
```

Each character fades and rises with `interpolate()` on an `Easing.bezier` curve, starting `staggerDelay` frames after the previous one; `distance` sets how far it travels. The schedule lives in `timeline.ts`.

## Good to know

- Length: 60 frames of motion at 30 fps (120 at 60 fps) with the default props. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Duration: the last letter starts at (letters − 1) × `staggerDelay` and takes 12 frames, all at 30 fps. A 5-letter word with the default stagger of 3 finishes at frame 24.
- Easing is a fixed `Easing.bezier` curve; there are no easing or spring props.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file; a `className` font does not override an inline style.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BottomUpLetters } from "@/components/remocn/bottom-up-letters";

const BottomUpLettersScene = () => (
  <BottomUpLetters text="Shift" staggerDelay={3} distance={46} />
);

export const RemotionRoot = () => (
  <Composition
    id="BottomUpLetters"
    component={BottomUpLettersScene}
    durationInFrames={120}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. It ships single-theme; edit the copied file to re-theme colors.

Pair with `Backdrop` to place the text inside a full-frame fill with a rounded, shadowed content frame:

```tsx
import { Composition } from "remotion";
import { BottomUpLetters } from "@/components/remocn/bottom-up-letters";
import { Backdrop } from "@/components/remocn/backdrop";

const BottomUpLettersScene = () => (
  <Backdrop fill={{ type: "color", value: "#ffffff" }}>
    <BottomUpLetters text="Shift" staggerDelay={3} distance={46} />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="BottomUpLetters"
    component={BottomUpLettersScene}
    durationInFrames={120}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I animate a short word in Remotion so each letter rises from below in a staircase?

Install Bottom-Up Letters with `npx shadcn@latest add @remocn/bottom-up-letters`, pass `text` and set `staggerDelay` for the gap between letters.

### How long does it take?

(letters − 1) × `staggerDelay` + 12 frames at 30 fps.
