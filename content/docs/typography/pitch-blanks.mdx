## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PitchBlanks } from "@/components/remocn/pitch-blanks";

const PitchBlanksScene = () => (
  <PitchBlanks
    line="{Acme} is a {motion toolkit} for {small teams}."
    labels={["product", "category", "audience"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PitchBlanks"
    component={PitchBlanksScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The sentence appears with each braced phrase in `line` shown as an empty underline carrying a small caps label from `labels`. The blanks then fill in one by one: the underline stretches to fit, the word rises in, and the underline and label turn the accent color. Wrap phrases in curly braces and give `labels` one entry per blank; timing stretches to fit the composition, and 141 frames assumes three blanks in 170. It ships light and dark.
