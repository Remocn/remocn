## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PromptRestyle } from "@/components/remocn/prompt-restyle";

const PromptRestyleScene = () => (
  <PromptRestyle headline="Launch videos from parts you own." highlight="you own" />
);

export const RemotionRoot = () => (
  <Composition
    id="PromptRestyle"
    component={PromptRestyleScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Small instruction lines are typed one after another, and after each the headline changes size, tracking and style, ending with the highlight phrase in a serif italic gradient. Pass `headline`, `highlight` and your own `instructions` (up to three); it ships light and dark.
