## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MacroLetterPan } from "@/components/remocn/macro-letter-pan";

const MacroLetterPanScene = () => (
  <MacroLetterPan line="Ship it today." word="today" firstShot={12} />
);

export const RemotionRoot = () => (
  <Composition
    id="MacroLetterPan"
    component={MacroLetterPanScene}
    durationInFrames={129}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera cuts between tight close-ups of letter pairs inside `word`, each shot shorter than the last, then springs back to show the whole `line`, with the key word tinting to the accent color. Pass `line` and `word` (a substring of the line). It takes a `theme` prop and ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
