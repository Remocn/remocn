## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChangelogScroll } from "@/components/remocn/changelog-scroll";

const ChangelogScrollScene = () => <ChangelogScroll title="Changelog" url="remocn.dev/changelog" focus={9} />;

export const RemotionRoot = () => (
  <Composition
    id="ChangelogScroll"
    component={ChangelogScrollScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A tall changelog list scrolls fast then eases to a stop on one row, which enlarges into a highlighted entry on a glowing panel while the title and URL chrome fade in. Pass `entries` (date, text and optional version), `focus` for the row index to enlarge, `title` and `url`.
