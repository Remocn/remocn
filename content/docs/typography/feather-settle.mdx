## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FeatherSettle } from "@/components/remocn/feather-settle";

const FeatherSettleScene = () => (
  <FeatherSettle text="Your launch, landing softly." highlight="softly" stagger={13} />
);

export const RemotionRoot = () => (
  <Composition
    id="FeatherSettle"
    component={FeatherSettleScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word falls from above with a gentle side-to-side sway and tilt, staggered in order, and settles into the sentence; `highlight` is set in the accent. Pass `text`, `stagger`, `fall` and `sway` to tune the drift; it ships light and dark through `theme`.
