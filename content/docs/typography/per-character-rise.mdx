  - "A short word or phrase needs a crisp, sharp character-by-character entrance with even, readable stagger."
  - "The tone is clean and precise — no blur, no dramatic staircase, just steady letters rising into position."
  - "A heading needs more kinetic energy than `micro-scale-fade` but less theatrical drama than `bottom-up-letters`."
avoidWhen:
  - "You want a dramatic staircase effect where each letter visibly lags the previous — use `bottom-up-letters` for the pronounced, wide-gap stagger instead."

  - "The reveal should include blur or atmospheric softness — use `focus-blur-resolve` (blurred entrance) or `blur-out-up` (blurred exit) when sharpness is not the goal."

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PerCharacterRise } from "@/components/remocn/per-character-rise";

const PerCharacterRiseScene = () => (
  <PerCharacterRise text="One more thing." distance={32} fontSize={72} />
);

export const RemotionRoot = () => (
  <Composition
    id="PerCharacterRise"
    component={PerCharacterRiseScene}
    durationInFrames={60}
    fps={30}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. It ships single-theme; edit the copied file to re-theme colors.

Pair with `Backdrop` to place the text inside a full-frame fill with a rounded, shadowed content frame:

```tsx
import { Composition } from "remotion";
import { PerCharacterRise } from "@/components/remocn/per-character-rise";
import { Backdrop } from "@/components/remocn/backdrop";

const PerCharacterRiseScene = () => (
  <Backdrop fill={{ type: "color", value: "#ffffff" }}>
    <PerCharacterRise text="One more thing." distance={32} fontSize={72} />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="PerCharacterRise"
    component={PerCharacterRiseScene}
    durationInFrames={60}
    fps={30}
    width={1280}
    height={720}
  />
);
```
