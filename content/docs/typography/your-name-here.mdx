## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { YourNameHere } from "@/components/remocn/your-name-here";

const YourNameHereScene = () => (
  <YourNameHere lead="A launch film for" slot="yourProduct" brand="Acme" note="Swap one prop. The film is yours." />
);

export const RemotionRoot = () => (
  <Composition
    id="YourNameHere"
    component={YourNameHereScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A lead-in line runs to a highlighted slot that swaps from `slot` to `brand`, then a closing note lands below. Pass `lead`, `brand`, `slot` and `note` to personalize it. It ships in light and dark through the `theme` prop.
