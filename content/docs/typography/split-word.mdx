## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SplitWord } from "@/components/remocn/split-word";

const SplitWordScene = () => <SplitWord word="Now" insert="Available" accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="SplitWord"
    component={SplitWordScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

`word` rises in letter by letter, a hairline cuts through its middle, and the two halves slide apart to open an aurora-gradient band where `insert` sits. The halves then settle back with a small offset. It ships light and dark through `theme`.
