In Remotion, Word Gap Media opens a gap in the middle of a headline, for example between Launch all and of this, and slides a media tile into it that cycles through images with captions. Use it to show the screens behind a claim inside the sentence.

## Good to know

- Length: 142 frames of motion at 30 fps (284 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `gsh`, `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Sans itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The tile cycles still images from `images`; it does not play video. Set `background` to a solid color to drop the shader ground.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordGapMedia } from "@/components/remocn/word-gap-media";

const WordGapMediaScene = () => (
  <WordGapMedia before="Launch all" after="of this" images={["/shots/hero.jpg", "/shots/gallery.jpg"]} aspects={[0.8, 1.36]} captions={["Hero", "Gallery"]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordGapMedia"
    component={WordGapMediaScene}
    durationInFrames={336}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A sentence is split around a gap and a media tile opens inside it, cycling through your images with progress bars and captions. By default it uses `staticFile` images that only exist in the Remocn repo, so pass your own `images` (public paths or full URLs). It ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
