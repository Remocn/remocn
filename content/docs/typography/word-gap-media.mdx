## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordGapMedia } from "@/components/remocn/word-gap-media";

const WordGapMediaScene = () => (
  <WordGapMedia before="Launch all" after="of this" images={["/shots/hero.jpg", "/shots/gallery.jpg"]} aspects={[0.8, 1.36]} captions={["Hero", "Gallery"]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordGapMedia"
    component={WordGapMediaScene}
    durationInFrames={168}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A sentence is split around a gap and a media tile opens inside it, cycling through your images with progress bars and captions. By default it uses `staticFile` images that only exist in the Remocn repo, so pass your own `images` (public paths or full URLs). It ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
