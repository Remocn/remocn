## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PulseLine } from "@/components/remocn/pulse-line";

const PulseLineScene = () => (
  <PulseLine text="Every frame has a pulse." highlight="a pulse." beats={2} />
);

export const RemotionRoot = () => (
  <Composition
    id="PulseLine"
    component={PulseLineScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A heartbeat pulse travels through the headline glyphs and lights the highlight phrase in an aurora gradient, then the caption fades in. Pass `text`, `highlight`, `caption` and `beats` (1 to 4 pulses); it ships light and dark.
