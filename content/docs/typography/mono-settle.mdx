## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MonoSettle } from "@/components/remocn/mono-settle";

const MonoSettleScene = () => (
  <MonoSettle lines={["From your editor", "to the edit."]} highlight="the edit." />
);

export const RemotionRoot = () => (
  <Composition
    id="MonoSettle"
    component={MonoSettleScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The lines rise in monospace, a wave of morphing turns each glyph into proportional type, and `highlight` takes the accent color. Pass `lines` and `highlight`; it ships light and dark through `theme`.
