## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PinnedWord } from "@/components/remocn/pinned-word";

const PinnedWordScene = () => (
  <PinnedWord lines={["Ship a video tonight.", "Own every video frame."]} word="video" hold={36} />
);

export const RemotionRoot = () => (
  <Composition
    id="PinnedWord"
    component={PinnedWordScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `word` stays fixed in italic serif while the lines around it swap in turn. Pass `lines` that each contain `word` and set `hold` for pacing. It ships in light and dark through the `theme` prop.
