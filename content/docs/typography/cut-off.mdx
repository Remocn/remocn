In Remotion, Cut Off is a text joke where a long, boring explanation types in word by word and gets interrupted mid-word by a white card that answers it, for example "Or let the code cut it." Use it for a before-and-after beat where a slow workflow is cut short by a simple one.

## How to build this in Remotion

You don't need a hand-built typewriter with `interpolate()` and `fitText`. Install the component and pass the two lines:

```bash
npx shadcn@latest add @remocn/cut-off
```

One scene with a schedule in `timeline.ts`: the words of `line` arrive at even gaps, the broken last word types per letter (`charFrames`), then the card cuts in and the reply lands. Motion uses `interpolate()` with `Easing` curves; text is measured on a canvas before the first frame, held with `delayRender`.

## Good to know

- Length: 110 frames of motion at 30 fps (220 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 150 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Length stretch: the word gaps of `line` stretch to fit `durationInFrames`, so the setup reads slower in a longer composition.
- Card color: in the dark theme the reply card is `#FFFFFF` with `#0A0A0A` text and the highlight is `#FF3EA5`; in the light theme the card is black. `replyBackground` overrides the card fill.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Syne itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CutOff } from "@/components/remocn/cut-off";

const CutOffScene = () => <CutOff line="So first I export the clips, redo all the captions, then line up the mus" reply="Or let the code cut it." highlight="the code" />;

export const RemotionRoot = () => (
  <Composition
    id="CutOff"
    component={CutOffScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A line types in word by word and breaks off mid-word with a dash, then a card cuts in and the reply words land on it in a hard hit, with one phrase highlighted. Pass `line` (the sentence that gets cut off), `reply` and `highlight`.

## Common questions

### How do I make a Remotion text joke where a long explanation is interrupted by a white card?

Install Cut Off with `npx shadcn@latest add @remocn/cut-off`, pass the boring sentence as `line`, the answer as `reply` and the phrase to color as `highlight`.

### Is the card white by default?

Yes in the dark theme (`#FFFFFF`). In the light theme it is black; pass `replyBackground` to set it yourself.
