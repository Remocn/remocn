## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CutOff } from "@/components/remocn/cut-off";

const CutOffScene = () => <CutOff line="So first I export the clips, redo all the captions, then line up the mus" reply="Or let the code cut it." highlight="the code" />;

export const RemotionRoot = () => (
  <Composition
    id="CutOff"
    component={CutOffScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line types in word by word and breaks off mid-word with a dash, then a card cuts in and the reply words land on it in a hard hit, with one phrase highlighted. Pass `line` (the sentence that gets cut off), `reply` and `highlight`.
