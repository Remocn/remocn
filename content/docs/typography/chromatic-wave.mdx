In Remotion, Chromatic Wave sends a slow ambient wave down a title: where it passes, the letters ripple and split into red, green and blue fringes, and behind it they settle back to white. Use it for a held title such as an album cover, a poster hold or a music-video loop, where the text should stay alive rather than make a one-shot entrance.

## How to build this in Remotion

You don't have to wire `@remotion/noise` and SVG filters together yourself. Install the component and pass your text:

```bash
npx shadcn@latest add @remocn/chromatic-wave
```

It is a single SVG filter chain driven by the current frame: `feTurbulence` and `feGaussianBlur` shape a moving depth map, `feDisplacementMap` warps three copies of the text, and `feColorMatrix` splits them into red, green and blue channels that recombine with `screen` blending. The band's travel is one `interpolate()` over `mapTravelFrames`. No font loading and no `@remotion/noise` are involved.

## Good to know

- Length: 150 frames of motion at 30 fps (300 at 60 fps) with the default props. The demo composition plays 100 frames, which adds a hold. The wave crosses in `mapTravelFrames` (150 at 30 fps); the demo cuts at 100. A composition longer than the travel holds the settled white title. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: a Helvetica / Arial system stack for both lines, set through `headlineFontFamily` and `kickerFontFamily`. Nothing is loaded.
- It paints its own `background` (default `#000000`), because the red, green and blue copies only add back up to white over black.
- The kicker lines are always drawn; pass `kicker=""` to leave them empty.
- Positions are in absolute pixels for a 1920×1080 frame (`width`, `height`, `textCenterX`, baselines). At another size, set those props to match.
- The filter chain is heavy to paint: expect slower renders than a plain text animation.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChromaticWave } from "@/components/remocn/chromatic-wave";

const ChromaticWaveScene = () => (
  <ChromaticWave headline="MUSIC" kicker="APPLES" />
);

export const RemotionRoot = () => (
  <Composition
    id="ChromaticWave"
    component={ChromaticWaveScene}
    durationInFrames={200}
    fps={60}
    width={1920}
    height={1080}
  />
);
```

Three copies of the type are displaced by the same traveling wave at three
different depths — one per color channel — and summed back together with
`screen` blending. Where the copies still coincide the sum is white; where the
depths pull them apart, red, green and blue fringes appear. The component
paints its own `background` (default black) because the reassembly is only
exact over black.

## Common questions

### How do I get a slow wave to ripple down a title and split the letters into RGB fringes?

Install Chromatic Wave with `npx shadcn@latest add @remocn/chromatic-wave` and pass `headline` and `kicker`. The wave crosses over `mapTravelFrames` and leaves the title white.

### Can I hide the small kicker lines?

Yes, pass an empty `kicker`.

### Can it sit over a photo or transparent background?

Not cleanly. The color split only recombines to white over black, so it paints a black background by default.
