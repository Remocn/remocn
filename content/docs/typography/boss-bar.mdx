In Remotion, Boss Bar is a video game boss health bar: the HP bar fills, each named hit slams in and drains it, and when the bar breaks a "DEFEATED" label slams in under the boss name, such as "The old workflow". Use it for a playful beat where your features defeat a legacy workflow one hit at a time.

## How to build this in Remotion

You don't have to build the bar, hits and slam from `spring()` and `random()`. Install the component and pass the boss and hits:

```bash
npx shadcn@latest add @remocn/boss-bar
```

Hits, the bar drain, the shatter and the defeated slam are scheduled in `timeline.ts` and animated with `interpolate()` on `Easing.bezier` curves; the bar is SVG. The defeated impact lands at 44 + (hits − 1) × `hitGap`, shakes the camera and starts the glow.

## Good to know

- Length: 124 frames of motion at 30 fps (248 at 60 fps) with the default props; the demo plays 160 frames, which adds a hold. Its length follows the hits: 72 + (hits − 1) × `hitGap` frames at 30 fps, so the default three hits 26 frames apart give 124. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Chakra Petch and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load it in your project.
- A screen shake on the defeated impact is built in. There is no sound; add an `Audio` on that frame in your composition.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BossBar } from "@/components/remocn/boss-bar";

const BossBarScene = () => (
  <BossBar boss="THE OLD WORKFLOW" hits={[{ label: "Captions", damage: 800 }, { label: "Templates", damage: 1200 }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="BossBar"
    component={BossBarScene}
    durationInFrames={320}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I build a video game boss health bar in Remotion that hits drain until DEFEATED slams in?

Install Boss Bar with `npx shadcn@latest add @remocn/boss-bar`, pass `boss="The old workflow"`, `hits` (each a `label` and `damage`) and `defeated`.

### How long does it take with more hits?

72 + (hits − 1) × `hitGap` frames at 30 fps. Double it for a 60 fps composition.
