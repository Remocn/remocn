## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlitScan } from "@/components/remocn/slit-scan";

const SlitScanScene = () => (
  <SlitScan word="Faster." caption="First render in 1.8s, down from 4.7s" />
);

export const RemotionRoot = () => (
  <Composition
    id="SlitScan"
    component={SlitScanScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A word streaks through vertical fluted slices and resolves into clean type, then a caption with a stat fades in under it. Pass `word`, `caption` and `slices`; it ships light and dark.
