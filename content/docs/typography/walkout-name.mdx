## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WalkoutName } from "@/components/remocn/walkout-name";

const WalkoutNameScene = () => (
  <WalkoutName
    name={["The", "Launch", "Kid"]}
    nickname="Zero downtime"
    record="40–2"
    finishes="31 KO"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WalkoutName"
    component={WalkoutNameScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The name whips in as an extreme close-up of line one, hard-cuts to line two, then slams down line three with an inverted impact frame and shake. The camera pulls out, a light band sweeps across the stack, the record and finishes stats punch in, and the serif nickname wipes in beside the last line. Pass `name` (three short lines read best), `nickname`, `record` and `finishes` to make it yours; it ships light and dark through `theme`.
