## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MonoVoice } from "@/components/remocn/mono-voice";

const MonoVoiceScene = () => (
  <MonoVoice text={"Same script.\nA whole new\ndelivery."} highlight="delivery." />
);

export const RemotionRoot = () => (
  <Composition
    id="MonoVoice"
    component={MonoVoiceScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Lines rise in monospace, a sweep shifts each glyph into a proportional voice, and `highlight` grows large in the accent color. Pass `text` (newlines split lines) and `highlight`; it ships light and dark through `theme`.
