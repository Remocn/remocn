## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AcronymExpand } from "@/components/remocn/acronym-expand";

const AcronymExpandScene = () => (
  <AcronymExpand
    short="SDK"
    full="Software Development Kit"
    eyebrow="Now available"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AcronymExpand"
    component={AcronymExpandScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The short form appears first, its letters spread apart and unfold into the full words, then the eyebrow and subhead fade in. Pass `short`, `full`, `eyebrow` and `subhead` to make it yours; it ships light and dark through `theme`.
