## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RulerAlign } from "@/components/remocn/ruler-align";

const RulerAlignScene = () => <RulerAlign text="Made to measure." accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="RulerAlign"
    component={RulerAlignScene}
    durationInFrames={225}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The letters appear scattered at uneven heights, a ruler slides in beneath them, levels, then lifts so high letters drop onto its edge. Two taps then nudge the spacing tight. Pass `text` for your own line; letters without descenders sit best on the edge. It takes a `theme` prop and ships light and dark.
