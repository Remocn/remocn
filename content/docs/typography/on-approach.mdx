## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { OnApproach } from "@/components/remocn/on-approach";

const OnApproachScene = () => (
  <OnApproach lead="Wheels up" steps={["in June.", "next week.", "tomorrow.", "today."]} interval={30} />
);

export const RemotionRoot = () => (
  <Composition
    id="OnApproach"
    component={OnApproachScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `lead` phrase holds still while each entry in `steps` swaps in, counting closer to the last one. Pass `lead`, `steps` and `interval` to set the countdown. It ships in light and dark through the `theme` prop.
