In Remotion, Filler Cut animates a transcript where filler words like "um" get cut out, so it collapses into a clean line such as "Ship your launch video today." Use it in a captions, podcast or editing-tool demo that shows filler words being removed from speech.

## How to build this in Remotion

You don't need `@remotion/captions` or `@remotion/layout-utils` for this beat. Install the component and pass the messy and clean text:

```bash
npx shadcn@latest add @remocn/filler-cut
```

The schedule in `timeline.ts` lines up each spoken word, the mark, each cut, the reflow and the final set; every move is `interpolate()` with `Easing`. Word widths are measured on a canvas before the first frame, held with `delayRender`, so the remaining words close the gaps through `transform` without a layout jump.

## Good to know

- Length: 114 frames of motion at 30 fps (228 at 60 fps) with the default props. The demo plays 150 frames, which adds a hold. The length grows with the number of words and cuts: each extra cut adds `stagger` frames. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Schibsted Grotesk and Geist Mono (for the timecode) itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The words of `keep` are matched in order against the transcript, and every transcript word left unmatched is cut. `showTime={false}` hides the timecode.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FillerCut } from "@/components/remocn/filler-cut";

const FillerCutScene = () => <FillerCut transcript="So, um, ship your, like, launch video, uh, today. You know?" keep="Ship your launch video today." highlight="today." />;

export const RemotionRoot = () => (
  <Composition
    id="FillerCut"
    component={FillerCutScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A spoken-style transcript appears with filler words marked, the filler is cut out one phrase at a time with a timecode, and the remaining words reflow and set into a clean headline with the last word highlighted. Pass `transcript` (the messy text), `keep` (the clean line) and `highlight`.

## Common questions

### How do I animate a transcript in Remotion where filler words like um get cut out?

Install Filler Cut with `npx shadcn@latest add @remocn/filler-cut` and pass `transcript` (with the filler), `keep` (the clean line) and `highlight`. The filler is marked, cut one piece at a time and the rest reflows into the clean line.

### Do I need to load Schibsted Grotesk?

No, it loads itself. Only a custom `fontFamily` needs loading.

### How long should the composition be?

At least 114 frames at 30 fps (228 at 60 fps) for the default transcript; add your own hold after the line sets.
