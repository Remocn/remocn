## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FillerCut } from "@/components/remocn/filler-cut";

const FillerCutScene = () => <FillerCut transcript="So, um, ship your, like, launch video, uh, today. You know?" keep="Ship your launch video today." highlight="today." />;

export const RemotionRoot = () => (
  <Composition
    id="FillerCut"
    component={FillerCutScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A spoken-style transcript appears with filler words marked, the filler is cut out one phrase at a time with a timecode, and the remaining words reflow and set into a clean headline with the last word highlighted. Pass `transcript` (the messy text), `keep` (the clean line) and `highlight`.
