## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EllipsisResolve } from "@/components/remocn/ellipsis-resolve";

const EllipsisResolveScene = () => (
  <EllipsisResolve word="Shipped" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="EllipsisResolve"
    component={EllipsisResolveScene}
    durationInFrames={131}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Three dots pulse in turn, stretch apart, and a gradient sweep turns them into the letters of the word, ending on a period. Pass `word` to set the result; it ships light and dark through `theme`.
