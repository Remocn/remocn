In Remotion, Ellipsis Resolve turns three pulsing dots into a gradient word like "Shipped" followed by a period: the dots pulse like a typing indicator, stretch apart, and a sweep reveals the word, with the last dot landing as the full stop. Use it for a loading-to-done moment in a product or release video.

## How to build this in Remotion

You don't need to wire it up from `interpolate()` and `spring()` by hand. Install the component and pass the word:

```bash
npx shadcn@latest add @remocn/ellipsis-resolve
```

One scene with a schedule in `timeline.ts`: the dots pulse until `resolveAt`, stretch, and a bar sweeps over `sweepFrames` to reveal the word. Motion uses `interpolate()` with `Easing` curves, and the dot that becomes the period recolors with `interpolateColors`.

## Good to know

- Length: 94 frames of motion at 30 fps (188 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 131 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Gradient: the word has a fixed silk sheen (`#F3D6C0` to `#8A7BFF` in dark, `#14163F` to `#8A7BFF` in light). `accent` colors the period dot; `ink` replaces the sheen with one solid color.
- The demo composition is 131 frames at 30 fps (262 at 60 fps), which adds a hold after the 94 frames of motion.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Serif itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EllipsisResolve } from "@/components/remocn/ellipsis-resolve";

const EllipsisResolveScene = () => (
  <EllipsisResolve word="Shipped" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="EllipsisResolve"
    component={EllipsisResolveScene}
    durationInFrames={262}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Three dots pulse in turn, stretch apart, and a gradient sweep turns them into the letters of the word, ending on a period. Pass `word` to set the result; it ships light and dark through `theme`.

## Common questions

### How can three pulsing dots turn into a gradient word like 'Shipped.' in Remotion?

Install Ellipsis Resolve with `npx shadcn@latest add @remocn/ellipsis-resolve` and pass `word`. The period is added for you.

### Can I change the gradient colors?

Only partly: `accent` sets the period and `ink` makes the word one solid color. The sheen stops live in the copied file.
