## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Overheard } from "@/components/remocn/overheard";

const OverheardScene = () => <Overheard lines={[{ quote: "Who made our launch video?", name: "Mia Okafor, CEO" }, { quote: "I did. It’s in the repo.", name: "Leo Marsh, engineer" }]} highlight="It’s in the repo." />;

export const RemotionRoot = () => (
  <Composition
    id="Overheard"
    component={OverheardScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two voices play as dialogue: the first quote types in word by word with natural pauses, its speaker tag fades in, then the second quote answers below, ending with a highlighted phrase. Pass `lines` (quote and name pairs) and `highlight` for the phrase to color; it fits the typing pace to the composition length.
