In Remotion, Torn Edge rips a torn paper sheet away to reveal a bold headline printed on a gradient background. Use it for an intro or reveal that should feel physical and tactile instead of a clean wipe.

## Good to know

- Length: 76 frames of motion at 30 fps (152 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Bricolage Grotesque itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TornEdge } from "@/components/remocn/torn-edge";

const TornEdgeScene = () => <TornEdge title="Make it yours." accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="TornEdge"
    component={TornEdgeScene}
    durationInFrames={220}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A gradient paper sheet tears across the frame, the halves part, and the headline is printed on the stage underneath. Pass `title` and `accent` (the mid colour of the sheet gradient); it ships light and dark.
