## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TornEdge } from "@/components/remocn/torn-edge";

const TornEdgeScene = () => <TornEdge title="Make it yours." accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="TornEdge"
    component={TornEdgeScene}
    durationInFrames={110}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A gradient paper sheet tears across the frame, the halves part, and the headline is printed on the stage underneath. Pass `title` and `accent` (the mid colour of the sheet gradient); it ships light and dark.
