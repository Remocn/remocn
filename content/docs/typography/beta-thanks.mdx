## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BetaThanks } from "@/components/remocn/beta-thanks";

const BetaThanksScene = () => <BetaThanks tag="beta" status="is out." before="Thank you," after="testers." />;

export const RemotionRoot = () => (
  <Composition
    id="BetaThanks"
    component={BetaThanksScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The logo and a small tag appear, the tag lifts out and slides into place beside the logo as the status word lands, then a thank-you line fades in below. Pass `tag`, `status`, `before` and `after`, or a `logo` node of your own; it speeds up to fit shorter compositions.
