In Remotion, Handwrite makes captions, labels and headlines look pen-written on paper: letters appear one at a time in a handwriting font on a choppy stop-motion beat. Use it as the text voice of a stop-motion or scrapbook scene.

## How to build this in Remotion

You don't need opentype.js stroke paths or `evolvePath()` from `@remotion/paths`. Install the component:

```bash
npx shadcn@latest add @remocn/handwrite
```

Letters arrive on the quantized clock from `@remocn/stop-motion`: one pose every `step` frames, each letter with a small seeded jitter, so every render matches the preview. `handwriteDuration(text)` returns how many frames the string needs, so a `Sequence` can be sized to the writing.

## Good to know

- Length: 120 frames of motion at 30 fps (240 at 60 fps) with the default props. The real length depends on the text; use `handwriteDuration()`. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `stop-motion`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Caveat itself through `@remotion/google-fonts`, with a cursive fallback. Pass `fontFamily` to use another hand, and load it in your project.
- `step` and `handwriteDuration()` count in 30 fps frames at any composition frame rate: `step={3}` is ten poses a second. In a 60 fps composition, double the `handwriteDuration()` value you hand to a `Sequence`.
- The component is transparent; put the paper color on the layer behind it. It is not timed to speech; for subtitles from a transcript use the [Captions](/docs/captions/getting-started/introduction) components.

## Usage

```tsx
// src/Root.tsx
import { AbsoluteFill, Composition } from "remotion";
import { Handwrite } from "@/components/remocn/handwrite";

const HandwriteScene = () => (
  <AbsoluteFill style={{ background: "#f1eee7" }}>
    <Handwrite text="Made by hand" fontSize={72} />
  </AbsoluteFill>
);

export const RemotionRoot = () => (
  <Composition
    id="Handwrite"
    component={HandwriteScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The component is transparent — put the paper colour on the layer behind it.

`handwriteDuration` returns how many frames a string needs, so a `<Sequence>` can
be sized to the writing instead of guessed:

```tsx
import { Sequence } from "remotion";
import { Handwrite, handwriteDuration } from "@/components/remocn/handwrite";

const title = "Made by hand";
const subtitle = "one pose at a time";

const Titles = () => (
  <>
    <Sequence durationInFrames={handwriteDuration(title) * 2}>
      <Handwrite text={title} fontSize={72} />
    </Sequence>
    <Sequence from={handwriteDuration(title) * 2}>
      <Handwrite text={subtitle} fontSize={44} />
    </Sequence>
  </>
);
```

Letters arrive on the stop-motion clock, so `step` is the tempo control: `3`
frames per pose is ten poses a second, counted at 30 fps. Raise it for a slower, more
deliberate hand. The component holds still between poses — wrap it in
`paper-wobble` if the whole sheet should breathe.

## Common questions

### How do I make captions look pen-written on paper in Remotion, one letter at a time on a stop-motion beat?

Install Handwrite with `npx shadcn@latest add @remocn/handwrite` and pass `text`. Raise `step` for a slower hand.

### Does the step clock depend on the composition fps?

No. It counts in 30 fps frames, so the pace in seconds is the same at 30 or 60 fps.

### How do I underline the text after it is written?

Add Ink Underline and set its `delay` from `handwriteDuration()`.
