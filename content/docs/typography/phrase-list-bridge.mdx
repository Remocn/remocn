## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PhraseListBridge } from "@/components/remocn/phrase-list-bridge";

const PhraseListBridgeScene = () => (
  <PhraseListBridge
    left="Pick from"
    right="ready-made scenes"
    items={["Hero intro", "Feature tour", "Pricing beat", "Closing card"]}
    pickedIndex={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PhraseListBridge"
    component={PhraseListBridgeScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `left` and `right` phrases appear as one line, then split apart as a floating panel deals in your `items` between them. A highlight steps down to the row at `pickedIndex`, which turns accent-colored with a check while the other rows fall away, and the panel closes into a chip that bridges the two phrases. Pass `left`, `right`, up to eight `items`, and `pickedIndex`; the default items are remocn component names. It ships light and dark, each over a gradient ground.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop. It ships light and dark.
