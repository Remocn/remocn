## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordActs } from "@/components/remocn/word-acts";

const WordActsScene = () => (
  <WordActs
    acts={[
      { word: "stretch", act: "stretch" },
      { word: "heavy", act: "heavy" },
      { word: "rebuilt", act: "rebuilt" },
    ]}
    hold={30}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WordActs"
    component={WordActsScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Words play one after another, each performing its meaning: `stretch`, `split`, `heavy` (falls and lands), `faster` (rushes in and snaps) and `rebuilt` (strokes scatter and reassemble). Pass `acts` as a list of `{ word, act, frames? }`; the last word also holds for `hold` frames. Total length is the sum of the acts' frames plus the hold, and it ships light and dark through `theme`.
