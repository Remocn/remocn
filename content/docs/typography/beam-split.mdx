## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BeamSplit } from "@/components/remocn/beam-split";

const BeamSplitScene = () => (
  <BeamSplit title="Ship the story" inner="with motion you own" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="BeamSplit"
    component={BeamSplitScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A bold title rises, a thin beam draws across its middle and pushes the halves apart, and the italic phrase fades in between before the gap closes again. Pass `title` and `inner` to set the two texts; it ships light and dark through `theme`.
