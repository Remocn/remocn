In Remotion, Beam Split has a beam of light slice a bold headline in two, push the halves apart and reveal a serif italic phrase in the gap, then close again. Use it for a headline that sets up a punchline, such as a launch or feature reveal.

## How to build this in Remotion

You don't have to animate `clip-path` halves and load a serif by hand. Install the component and pass the two texts:

```bash
npx shadcn@latest add @remocn/beam-split
```

The halves are `clip-path` crops moved with `interpolate()` on `Easing.bezier` curves; the beam is an SVG with a CSS mask. The schedule lives in `timeline.ts`.

## Good to know

- Length: 116 frames of motion at 30 fps (232 at 60 fps) with the default props; the demo plays 150 frames, which adds a hold. The timing is fixed: a longer composition only holds the last frame longer. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Bricolage Grotesque for the title and Instrument Serif italic for the inner phrase itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face for the title, and load it in your project.
- At 60 fps, give Remotion 232 frames or more; the Usage example's 300 frames at 60 fps adds a hold.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BeamSplit } from "@/components/remocn/beam-split";

const BeamSplitScene = () => (
  <BeamSplit title="Ship the story" inner="with motion you own" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="BeamSplit"
    component={BeamSplitScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A bold title rises, a thin beam draws across its middle and pushes the halves apart, and the italic phrase fades in between before the gap closes again. Pass `title` and `inner` to set the two texts; it ships light and dark through `theme`.

## Common questions

### How can a beam of light slice a headline in two in Remotion and reveal a phrase in the gap?

Install Beam Split with `npx shadcn@latest add @remocn/beam-split` and pass `title` and `inner`. The inner phrase is set in Instrument Serif italic, loaded by the component.

### Which serif is used?

Instrument Serif italic, loaded through `@remotion/google-fonts`.
