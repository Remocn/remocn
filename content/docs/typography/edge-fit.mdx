## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EdgeFit } from "@/components/remocn/edge-fit";

const EdgeFitScene = () => (
  <EdgeFit words={["intros", "teasers", "recaps"]} caption="Fresh from the registry" />
);

export const RemotionRoot = () => (
  <Composition
    id="EdgeFit"
    component={EdgeFitScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word is fitted to the full frame width and its letters rise in, one word after another, with a caption and logo beneath. Pass `words`, `caption` and your own `logo`; it ships light and dark.
