## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { YesRun } from "@/components/remocn/yes-run";

const YesRunScene = () => (
  <YesRun questions={["Vertical?", "Captions?", "Your fonts?"]} answer="Yes." />
);

export const RemotionRoot = () => (
  <Composition
    id="YesRun"
    component={YesRunScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each question in `questions` is answered by the `answer` tag landing next to it, quickening as they go. Pass `questions` and `answer` to answer your own FAQ. It ships in light and dark through the `theme` prop.
