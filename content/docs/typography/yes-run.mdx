In Remotion, Yes Run animates a series of short customer questions, each answered with the same bold Yes tag on a bright orange background. Use it for an objections-handling beat.

## Good to know

- Length: 130 frames of motion at 30 fps (260 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Unbounded itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { YesRun } from "@/components/remocn/yes-run";

const YesRunScene = () => (
  <YesRun questions={["Vertical?", "Captions?", "Your fonts?"]} answer="Yes." />
);

export const RemotionRoot = () => (
  <Composition
    id="YesRun"
    component={YesRunScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each question in `questions` is answered by the `answer` tag landing next to it, quickening as they go. Pass `questions` and `answer` to answer your own FAQ. It ships in light and dark through the `theme` prop.
