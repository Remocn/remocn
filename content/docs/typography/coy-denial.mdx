In Remotion, Coy Denial sets a huge line such as "Don't check the site at nine." and then tucks a tiny sheepish "(Do.)" into the corner that undoes it. Use it for a reverse-psychology teaser or a comedic beat before a launch, one denial and aside after another.

## How to build this in Remotion

No need for `fitText`, a `TransitionSeries` of rounds or a manual font setup. Install the component and pass your rounds:

```bash
npx shadcn@latest add @remocn/coy-denial
```

Each round is a pair of `say` and `aside`. The big line builds word by word, the aside appears, then the round exits for the next; every move is `interpolate()` over an `Easing` curve on a schedule from `timeline.ts`. The component wraps and sizes the big line itself, balancing it over up to three rows (six in portrait) so the widest row fits the frame, and holds the first frame with `delayRender` until the font is ready.

## Good to know

- Length: 144 frames of motion at 30 fps (288 at 60 fps) with the default props. The demo composition plays 180 frames, which adds a hold. The pace fits the composition: a longer `durationInFrames` gives each round more read time. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Funnel Display itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Long lines are fine: "Don't check the site at nine." wraps into balanced rows at 1280×720. All rounds share one font size, set by the longest line.
- `rounds` defaults to two pairs: "Nothing is launching on Thursday." / "(Something is.)" and "Don't check the site at nine." / "(Do.)". Pass one pair for a single gag.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoyDenial } from "@/components/remocn/coy-denial";

const CoyDenialScene = () => <CoyDenial rounds={[{ say: "Nothing is launching on Thursday.", aside: "(Something is.)" }]} />;

export const RemotionRoot = () => (
  <Composition
    id="CoyDenial"
    component={CoyDenialScene}
    durationInFrames={360}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A big statement builds word by word, then a sheepish parenthetical aside appears in the corner that contradicts it; the round exits and the next one follows. Pass `rounds` (say and aside pairs); it fits the pace to the composition length.

## Common questions

### How do I make a huge line with a tiny sheepish aside in the corner that undoes it?

Install Coy Denial with `npx shadcn@latest add @remocn/coy-denial` and pass `rounds`, for example `[{ say: "Don't check the site at nine.", aside: "(Do.)" }]`.

### Will a long line wrap well?

Yes. The component splits it into balanced rows and scales it to fit, so you don't need `fitText`.

### Do I need to load Funnel Display?

No, the component loads it. Load your own font only if you pass `fontFamily`.
