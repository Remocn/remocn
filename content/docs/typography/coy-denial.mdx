## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoyDenial } from "@/components/remocn/coy-denial";

const CoyDenialScene = () => <CoyDenial rounds={[{ say: "Nothing is launching on Thursday.", aside: "(Something is.)" }]} />;

export const RemotionRoot = () => (
  <Composition
    id="CoyDenial"
    component={CoyDenialScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big statement builds word by word, then a sheepish parenthetical aside appears in the corner that contradicts it; the round exits and the next one follows. Pass `rounds` (say and aside pairs); it fits the pace to the composition length.
