## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FeatureChipsFlow } from "@/components/remocn/feature-chips-flow";

const FeatureChipsFlowScene = () => (
  <FeatureChipsFlow features={["Captions", "Transitions", "Templates", "Export"]} name="Acme" />
);

export const RemotionRoot = () => (
  <Composition
    id="FeatureChipsFlow"
    component={FeatureChipsFlowScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Rows of feature chips stream across the frame, the first ones converge and snap into a cluster around the logo, and the rest dissolve. Pass `features` (strings or chips with icon and variant), `name` and your own `logo`; it ships light and dark.
