## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LineRelief } from "@/components/remocn/line-relief";

const LineReliefScene = () => <LineRelief word="LAUNCH" accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="LineRelief"
    component={LineReliefScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Forty thin horizontal lines sweep across the frame and rise into the shape of the word like a relief map. They then flatten while the solid word resolves out of a soft blur. Pass `word` (short, caps work best); `accent` tints the night sky, and it ships light and dark through `theme`.
