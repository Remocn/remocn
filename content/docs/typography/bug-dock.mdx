## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BugDock } from "@/components/remocn/bug-dock";

const BugDockScene = () => <BugDock name="remocn" headline="Playing on every screen you ship." highlight="every screen" />;

export const RemotionRoot = () => (
  <Composition
    id="BugDock"
    component={BugDockScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large logo-and-name lockup fades in, its letters tuck away until only the mark remains, and the mark docks to the bottom corner like a broadcast bug while the headline appears with one phrase highlighted. Pass `name` ("remocn" uses the real logo), `headline` and `highlight`.
