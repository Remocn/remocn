In Remotion, Bug Dock is a TV-broadcast style title: the brand lockup shrinks down until only the mark is left, which docks at the bottom of the frame like a corner bug while the main message takes over the screen. Use it for a broadcast-style launch title with one phrase highlighted.

## How to build this in Remotion

You don't need `@remotion/transitions` or an `Img` per step. Install the component and pass your name and headline:

```bash
npx shadcn@latest add @remocn/bug-dock
```

The name's letters tuck away and the mark docks with `interpolate()` on `Easing.bezier` curves; letter widths are measured on a canvas before the first frame (held with `delayRender`). The headline words rise on the schedule in `timeline.ts`; `tuckAt` moves the tuck.

## Good to know

- Length: 114 frames of motion at 30 fps (228 at 60 fps) with the default props; the demo plays 150 frames, which adds a hold. The timing is fixed: a longer composition only holds the last frame longer. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Urbanist (variable) and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load it in your project.
- There is no prop for a custom logo image or SVG. `name="remocn"` draws the remocn mark; any other name uses its first letter as the mark and tucks the rest away. For your own logo, replace the mark in the copied file.
- The dock position is fixed in the source; there is no prop for corner versus bottom center.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BugDock } from "@/components/remocn/bug-dock";

const BugDockScene = () => <BugDock name="remocn" headline="Playing on every screen you ship." highlight="every screen" />;

export const RemotionRoot = () => (
  <Composition
    id="BugDock"
    component={BugDockScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I do a TV-broadcast style title in Remotion where the logo shrinks into a corner bug?

Install Bug Dock with `npx shadcn@latest add @remocn/bug-dock` and pass `name`, `headline` and `highlight`.

### Can I use my own logo?

Not through a prop. The first letter of `name` becomes the mark; swap in your SVG in the copied file.
