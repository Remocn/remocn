In Remotion, Inline Pill Takeover makes a pill shape inside a sentence expand, push the surrounding words apart and then take over the whole frame as a call to action, without cutting to a new title card. Use it to turn a line of copy into a CTA or an end card in one continuous move.

## How to build this in Remotion

You don't need `measureText()`, `@remotion/shapes` or a transition for this. Install the component and pass the sentence in three parts:

```bash
npx shadcn@latest add @remocn/inline-pill-takeover
```

The pill opening, the words fading, the pill growing and the camera push are elements in `timeline.ts`, each driven by `interpolate()` over `Easing` curves. The words sit in a flex row on either side of the pill, so they move apart as it widens.

## Good to know

- Length: 30 frames of motion at 30 fps (60 at 60 fps) with the default props; the demo plays 45 frames, which adds a hold. The takeover settles at frame 30: the pill opens over 12 frames, grows from frame 12, and the camera pushes and settles by 30. The demo holds the end for 15 more. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback, set inline; change it in the copied file.
- Pill width does not fit the `insert` text: it opens to `pillWidth` (260 px by default). Tune `pillWidth` to your insert text.
- The background is transparent; put your own scene behind it.

## Usage

The line starts with a short pill between `before` and `after`. Its first animation changes explicit background width and height values, so the shape expands outward from center without scaling its contents. The full-size `insert` text appears through a hard opacity switch and is cropped by `overflow: hidden` until the pill opens around it. When that reveal finishes, a second local pill animation increases the background width and height through independent controls without changing the text's local font size. An independent camera wrapper begins its approach at the same time, cuts instantly to 86% of its final close-up, then settles to 100%. The pill and camera therefore move toward one another, and the pill keeps growing briefly after the camera settles. All timings were measured frame-by-frame from the reference footage.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InlinePillTakeover } from "@/components/remocn/inline-pill-takeover";

const InlinePillTakeoverScene = () => (
  <InlinePillTakeover
    before="powering 20%"
    insert="Start building"
    after="of the Internet."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="InlinePillTakeover"
    component={InlinePillTakeoverScene}
    durationInFrames={90}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component paints no background. The reference pairs warm white type and pill with an orange radial glow.

```tsx
import { Composition } from "remotion";
import { InlinePillTakeover } from "@/components/remocn/inline-pill-takeover";
import { Backdrop } from "@/components/remocn/backdrop";

const InlinePillTakeoverScene = () => (
  <Backdrop
    fill={{
      type: "gradient",
      value:
        "radial-gradient(circle at 50% 108%, #ffd77a 0%, #ff6840 31%, #f13d21 78%)",
    }}
  >
    <InlinePillTakeover
      before="powering 20%"
      insert="Start building"
      after="of the Internet."
    />
  </Backdrop>

);
```

## Common questions

### How do I make a pill inside a sentence expand and take over the frame in Remotion?

Install Inline Pill Takeover with `npx shadcn@latest add @remocn/inline-pill-takeover` and pass `before`, `insert` and `after`. The pill opens, the words move apart and fade, and the pill fills the frame.

### Does the pill size itself to the text?

No. Set `pillWidth` so the insert text fits.
