## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TheyAreYou } from "@/components/remocn/they-are-you";

const TheyAreYouScene = () => (
  <TheyAreYou
    facts={[
      "They write React for a living.",
      "They have a launch on Monday.",
      "They have never touched a timeline.",
    ]}
    from="They"
    to="You"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TheyAreYou"
    component={TheyAreYouScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each fact rises in with its leading `from` word (They by default) in medium weight. After a beat the leading words flip one by one to the `to` word (You) in the accent color. Each fact must begin with the `from` word to flip; pass `facts`, `from` and `to`. It ships light and dark.
