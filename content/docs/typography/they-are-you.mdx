In Remotion, They Are You raises short statements about a person one by one, then flips the leading word They into an accent-colored You on every line. Use it for an audience-recognition beat that describes the viewer and then turns it on them.

## Good to know

- Length: 93 frames of motion at 30 fps (186 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Gabarito itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TheyAreYou } from "@/components/remocn/they-are-you";

const TheyAreYouScene = () => (
  <TheyAreYou
    facts={[
      "They write React for a living.",
      "They have a launch on Monday.",
      "They have never touched a timeline.",
    ]}
    from="They"
    to="You"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TheyAreYou"
    component={TheyAreYouScene}
    durationInFrames={320}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each fact rises in with its leading `from` word (They by default) in medium weight. After a beat the leading words flip one by one to the `to` word (You) in the accent color. Each fact must begin with the `from` word to flip; pass `facts`, `from` and `to`. It ships light and dark.
