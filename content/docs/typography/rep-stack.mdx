## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RepStack } from "@/components/remocn/rep-stack";

const RepStackScene = () => <RepStack word="AGAIN." reps={6} accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="RepStack"
    component={RepStackScene}
    durationInFrames={96}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A reel of outlined copies of the word runs upward through a cap-height gate, braking, and the last copy settles into it as a cutout of the dusk band. The echoes above and below dim back. Pass `word` (one short word, trailing punctuation takes the accent) and `reps` for the number of copies; it ships light and dark through `theme`.
