## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PosterCrop } from "@/components/remocn/poster-crop";

const PosterCropScene = () => (
  <PosterCrop title={"Ship the film,\nnot the deck."} kicker="Acme 3.0" meta="Oct 24, 2026" />
);

export const RemotionRoot = () => (
  <Composition
    id="PosterCrop"
    component={PosterCropScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera pulls out from a tight crop of the headline, line by line, while ruled grid lines and corner labels (kicker, date, note) fade in. Pass `title` (use `\n` for line breaks), `kicker`, `meta`, `note` and your own `logo`; it ships light and dark.
