## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IntelligenceGlow } from "@/components/remocn/intelligence-glow";

const IntelligenceGlowScene = () => (
  <IntelligenceGlow
    question="Cut a teaser for Friday?"
    answerLead="Done."
    answer="9 shots, timed to the beat."
    showLogo={false}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="IntelligenceGlow"
    component={IntelligenceGlowScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The question rises in word by word while a colored light breathes around the frame edge, shimmers through the words as it thinks, then collapses into a thin rule. The `answerLead` word resolves in serif italic, followed by the rest of the `answer`, and the logo fades in last. It ships light and dark; `accent` tints the glow on dark only.
