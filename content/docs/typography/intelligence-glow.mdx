In Remotion, Intelligence Glow builds an AI-style prompt scene: a question rises in under a breathing edge glow, the glow collapses into a line, and an answer led by a serif italic word resolves word by word. Use it for an AI feature beat that shows a prompt and its one-line result.

## How to build this in Remotion

You don't need `@remotion/noise`, a typewriter helper or your own font loading. Install the component and pass the question and answer:

```bash
npx shadcn@latest add @remocn/intelligence-glow
```

The intro, the thinking glow, the squeeze into a line and the answer words are elements in `timeline.ts`; everything moves with `interpolate()` over `Easing` curves, and the glow is CSS radial gradients drifting across the frame.

## Good to know

- Length: 148 frames of motion at 30 fps (296 at 60 fps) with the default props; the demo plays 180 frames, which adds a hold. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Instrument Sans for the copy, Instrument Serif italic for the answer's lead word, and Manrope itself, through `@remotion/google-fonts`. `fontFamily` changes the question and answer; the serif lead face is not a prop, so change it in the copied file.
- Glow colors come from the theme (dark `#FFF4EC`, `#FFB36B`, `#E2457A`; light `#FFC83D`, `#FF8A3D`, `#FF3D9A`, `#7A5CFF`); `intensity` scales the glow.
- `background="transparent"` drops the stage fill, and the glow still draws on top, so it can sit over other footage.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IntelligenceGlow } from "@/components/remocn/intelligence-glow";

const IntelligenceGlowScene = () => (
  <IntelligenceGlow
    question="Cut a teaser for Friday?"
    answerLead="Done."
    answer="9 shots, timed to the beat."
    showLogo={false}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="IntelligenceGlow"
    component={IntelligenceGlowScene}
    durationInFrames={360}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The question rises in word by word while a colored light breathes around the frame edge, shimmers through the words as it thinks, then collapses into a thin rule. The `answerLead` word resolves in serif italic, followed by the rest of the `answer`, and the logo fades in last. It ships light and dark; `accent` tints the glow on dark only.

## Common questions

### How do I make an AI prompt scene in Remotion with a glowing edge and a resolving answer?

Install Intelligence Glow with `npx shadcn@latest add @remocn/intelligence-glow` and pass `question`, `answerLead` and `answer`.

### Can I change the serif face of the answer's first word?

Not through a prop: it is Instrument Serif italic. Swap the font in the copied file.
