## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StripeMask } from "@/components/remocn/stripe-mask";

const StripeMaskScene = () => <StripeMask title="Faster. Every frame." slant={18} />;

export const RemotionRoot = () => (
  <Composition
    id="StripeMask"
    component={StripeMaskScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Slanted stripes sweep in and mask the headline into view, then widen and retract, one line per sentence. Pass `title` (it breaks after each sentence) and `slant`; it ships light and dark.
