## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NegationDrop } from "@/components/remocn/negation-drop";

const NegationDropScene = () => (
  <NegationDrop
    lines={["You can’t animate.", "You don’t have a team.", "It isn’t done."]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NegationDrop"
    component={NegationDropScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Condensed all-caps lines rise in one after another. Then, line by line, the first contraction (can't, don't, isn't) loses its negation, which falls away, and the remaining stem word lands on a highlighted block while the line closes up. Pass `lines` that each contain a can't, don't or isn't style contraction. It ships light and dark.
