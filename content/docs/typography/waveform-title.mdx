## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WaveformTitle } from "@/components/remocn/waveform-title";

const WaveformTitleScene = () => (
  <WaveformTitle title="Your voice, captioned" accentWords={1} />
);

export const RemotionRoot = () => (
  <Composition
    id="WaveformTitle"
    component={WaveformTitleScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An aurora waveform line opens and sweeps across the frame, settles into an underline, and the headline rises above it, with the trailing word(s) in italic serif. Pass `title` and `accentWords`; it ships light and dark.
