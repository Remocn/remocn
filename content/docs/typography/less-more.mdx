## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LessMore } from "@/components/remocn/less-more";

const LessMoreScene = () => (
  <LessMore less="Less explaining." more="More showing." />
);

export const RemotionRoot = () => (
  <Composition
    id="LessMore"
    component={LessMoreScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `less` line enters and fades back while the `more` line lands below it in the accent color. Pass `less` and `more` for your own contrast pair. It ships in light and dark through the `theme` prop.
