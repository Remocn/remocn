In Remotion, Echo Stack shows one word in focus at the center with outline copies above and below that keep drifting like a spinning drum, so the screen stays alive while the word holds. Use it for a one-word value or promise that has to hold the screen for a while.

## How to build this in Remotion

You don't need `WebkitTextStroke` copies or `@remotion/transitions` for this. Install the component and pass your word:

```bash
npx shadcn@latest add @remocn/echo-stack
```

The word focuses in, the echoes unfold out of it, and then the column scrolls one row every `cycle` frames and loops without a seam. Motion uses `interpolate()` and `Easing`; the outline is an SVG filter built from the filled glyphs, so overlapping contours in variable fonts don't show.

## Good to know

- Length: 26 frames of motion at 30 fps (52 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 120 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Length: 26 frames is the entrance; after that the drift continues as long as the composition runs.
- It paints no background and centers the word in its parent, so place it over your own background.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Inter itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { AbsoluteFill, Composition } from "remotion";
import { EchoStack } from "@/components/remocn/echo-stack";

const Beat = () => (
  <AbsoluteFill style={{ backgroundColor: "#0a0a0a" }}>
    <EchoStack text="Bold." />
  </AbsoluteFill>
);

export const RemotionRoot = () => (
  <Composition
    id="EchoStack"
    component={Beat}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The word focuses in over 14 frames. From frame 8 the echoes unfold out of it:
the column starts compressed and opens to its full pitch by frame 26. After
that the column keeps scrolling one row every `cycle` frames in `direction`,
and loops without a seam. Echoes are hidden while they pass behind the word
and fade out toward the edges, so only about `echoes` rows show on each side.

The echo outline is built from the filled glyphs with an SVG filter rather than
a text stroke. Variable fonts keep overlapping contours inside letters like M
and K, and a text stroke draws them. The component paints no background and
centers the word in its parent. Sizes scale with `height / 720`.

## Common questions

### How can I show one word in focus with outline copies drifting above and below, like a drum?

Install Echo Stack with `npx shadcn@latest add @remocn/echo-stack` and pass `text`. `echoes`, `direction` and `cycle` tune the drum.

### How do I use another font?

Pass `fontFamily` and load that font in your project first, for example with `loadFont()` from `@remotion/google-fonts`. Inter is loaded for you.
