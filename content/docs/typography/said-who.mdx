## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SaidWho } from "@/components/remocn/said-who";

const SaidWhoScene = () => <SaidWho quote="Took me one evening." highlight="one evening" name="Tobias Lind" details={["backend engineer", "never edited a video before"]} />;

export const RemotionRoot = () => (
  <Composition
    id="SaidWho"
    component={SaidWhoScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big serif quote appears word by word, then the attribution line builds beneath it a piece at a time: first the name, then each detail, while the quote slowly grows and its highlighted phrase turns to the accent color. Pass `quote`, `highlight`, `name` and `details`; it spaces the builds to fit the composition length.
