## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NdotResolve } from "@/components/remocn/ndot-resolve";

const NdotResolveScene = () => (
  <NdotResolve text="Less noise. More launch." emphasis="launch" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="NdotResolve"
    component={NdotResolveScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The headline appears row by row as dot-matrix glyphs, then a wipe converts each letter to solid type in sequence, with `emphasis` in the accent. Pass `text` and `emphasis`; it ships light and dark through `theme`.
