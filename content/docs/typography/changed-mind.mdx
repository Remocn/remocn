## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChangedMind } from "@/components/remocn/changed-mind";

const ChangedMindScene = () => <ChangedMind name="Ines Vargas, solo founder" steps={[{ quote: "Another tool I won’t use.", when: "on day one" }, { quote: "The only tool I use now.", when: "two months in" }]} />;

export const RemotionRoot = () => (
  <Composition
    id="ChangedMind"
    component={ChangedMindScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big serif quote types in word by word, then twice rewrites itself: shared words glide to their new spots while changed words swap and glow in the accent color, with the time tag under the attribution updating each time. Pass `steps` (quote and when pairs) and `name`; it ships light and dark, and spaces the steps to fit the composition length.
