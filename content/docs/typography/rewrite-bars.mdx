## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RewriteBars } from "@/components/remocn/rewrite-bars";

const RewriteBarsScene = () => (
  <RewriteBars headlines={["Scenes you copy.", "Captions that follow the voice.", "Rendered from code."]} highlight="rendered from code" />
);

export const RemotionRoot = () => (
  <Composition
    id="RewriteBars"
    component={RewriteBarsScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Bars sweep over the current headline, collapse, and reflow it into the next one, with a small eyebrow label above each. Pass `headlines`, `eyebrows` and the `highlight` phrase; it ships light and dark.
