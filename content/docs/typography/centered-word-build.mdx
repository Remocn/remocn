In Remotion, Centered Word Build assembles a short statement one word at a time: each word pops in sharply from below, the visible phrase stays centered, and the whole line pushes a little closer with every new word. Use it for a beat-synced tagline or hook line, ending with a soft left-to-right wipe.

## How to build this in Remotion

No need for a `spring()` per word plus `measureText` to keep the line centered. Install the component and pass the text:

```bash
npx shadcn@latest add @remocn/centered-word-build
```

Each word is an element in the schedule in `timeline.ts`, with gaps that shrink by `accel` so the build speeds up. The rise, the zoom step and the exit wipe are `interpolate()` calls over an `Easing` curve. Centering is done by the browser layout, so no `@remotion/layout-utils` is needed.

## Good to know

- Length: 63 frames of motion at 30 fps (126 at 60 fps) with the default props. The demo composition plays 75 frames, which adds a hold. The motion lasts until the later of the last word settling and `exitAt + exitFrames`. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable with a system sans fallback, set inline. There is no `fontFamily` prop: change it in the copied file.
- The background is transparent and the default text color is cream (`#fff3df`), so place it over a dark layer or pass a dark `color` on a light one.
- The exit wipe starts at `exitAt` (frame 51 at 30 fps). To keep the line on screen, set `exitAt` past the end of your composition.
- Keep it short: every word stays on one centered line.

## Usage

The visible prefix is laid out as one centered line. Each word becomes fully visible on a hard cut `rise` em below the baseline and settles upward over `settleFrames`; opacity is never animated. In the same frame, the whole phrase starts another cumulative `zoomStep` push-in and holds the closer scale until the next word. The first two word gaps establish the rhythm; later gaps are multiplied by `accel` to tighten the cadence. At `exitAt`, a broad opacity mask wipes through the completed phrase from left to right. All timings were measured frame-by-frame from the reference footage.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CenteredWordBuild } from "@/components/remocn/centered-word-build";

const CenteredWordBuildScene = () => (
  <CenteredWordBuild text="everything we learn from" />
);

export const RemotionRoot = () => (
  <Composition
    id="CenteredWordBuild"
    component={CenteredWordBuildScene}
    durationInFrames={150}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I build a statement word by word that stays centered and pushes closer?

Install Centered Word Build with `npx shadcn@latest add @remocn/centered-word-build` and pass `text`. Words rise in one by one, the line stays centered and zooms by `zoomStep` per word.

### Can I turn off the exit wipe?

Set `exitAt` to a frame after your composition ends and the line simply holds.

### Why can't I see the text?

The background is transparent and the default color is cream. Put it over a dark background or pass `color`.
