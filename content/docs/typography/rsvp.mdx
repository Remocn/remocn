## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Rsvp } from "@/components/remocn/rsvp";

const RsvpScene = () => (
  <Rsvp
    headline="You are invited."
    fields={[
      { label: "What", value: "The 2.0 launch film" },
      { label: "When", value: "Tuesday, 9 AM" },
    ]}
    rsvp="acme.dev/launch"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Rsvp"
    component={RsvpScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `headline` rises word by word, then rows of label and value (the `fields`) build below it, ending on an accent row labeled `rsvpLabel` that shows the `rsvp` text and pulls focus as the other rows dim. The default `rsvp` is a remocn install command, so pass your own link or command. It ships light and dark.
