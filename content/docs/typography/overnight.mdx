## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Overnight } from "@/components/remocn/overnight";

const OvernightScene = () => (
  <Overnight
    evening={{ slug: "Thursday, 6:00 PM", line: "The launch was at nine the next morning." }}
    night={{ slug: "Friday, 12:50 AM", line: "The demo video was still a blank file." }}
    morning={{ slug: "Friday, 8:55 AM", line: "The demo went up before the post did." }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Overnight"
    component={OvernightScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An evening line sits under a timestamp on a warm ground. A dark night panel then descends over it and the night line rises in, before a bright morning panel sweeps up from the bottom and the morning line lands in dark ink. Pass `evening`, `night` and `morning` as `{ slug, line }`. It ships light and dark; 150 frames is measured for a 16:9 frame at 180 frames.
