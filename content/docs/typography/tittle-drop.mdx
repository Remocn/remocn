## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TittleDrop } from "@/components/remocn/tittle-drop";

const TittleDropScene = () => <TittleDrop title="Ship it in minutes." subline="Launch videos from ready-made Remotion components." accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="TittleDrop"
    component={TittleDropScene}
    durationInFrames={225}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The headline fades in word by word with its i and j dots missing, while a bubble of dots waits above. The dots hop down one at a time onto the letters, the last one becoming the full stop, then the subline fades in. Pass `title`, `subline` and `accent`; it ships light and dark.
