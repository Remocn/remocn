## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AnswerFirst } from "@/components/remocn/answer-first";

const AnswerFirstScene = () => <AnswerFirst answer="A pull request." question="Who made this video?" />;

export const RemotionRoot = () => (
  <Composition
    id="AnswerFirst"
    component={AnswerFirstScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big answer rises word by word first, then slides up and shrinks as the question types in below it, so the reader sees the answer before the question. Pass `answer` and `question`.
