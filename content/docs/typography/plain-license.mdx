## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PlainLicense } from "@/components/remocn/plain-license";

const PlainLicenseScene = () => (
  <PlainLicense
    clauses={[
      { legal: "Permission is hereby granted, free of charge,", plain: "Free," },
      { legal: "to any person obtaining a copy of this software,", plain: "for anyone," },
      { legal: "to use, copy, modify, merge, publish and distribute it.", plain: "for anything." },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PlainLicense"
    component={PlainLicenseScene}
    durationInFrames={220}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each clause starts as dim legal text, then is swapped by its short plain phrase, which rises in the accent color and cools to ink when the next one takes over. At the end the plain phrases zoom into one big line, with the `highlight` clause keeping the accent. Pass `clauses` as `{ legal, plain }` pairs. It ships light and dark.
