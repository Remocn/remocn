## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { QuoteHero } from "@/components/remocn/quote-hero";

const QuoteHeroScene = () => <QuoteHero quoteDuration={120} quotes={[{ quote: "We shipped our launch video in an afternoon.", highlight: "in an afternoon", name: "Maya Chen", role: "Head of Design", company: "Kitebase" }]} />;

export const RemotionRoot = () => (
  <Composition
    id="QuoteHero"
    component={QuoteHeroScene}
    durationInFrames={246}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big serif pull quote rises line by line beside an oversized opening mark, then the author row settles in and a marker sweeps behind the highlighted phrase before the quote exits and the next one plays. Pass `quotes` (quote, highlight, name, role, company, optional avatar) and `quoteDuration`; the total length is 6 plus quotes times `quoteDuration`.
