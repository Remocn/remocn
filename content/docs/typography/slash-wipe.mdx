## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlashWipe } from "@/components/remocn/slash-wipe";

const SlashWipeScene = () => (
  <SlashWipe sections={[{ title: "captions", sub: "Styles that follow every word." }, { title: "transitions", sub: "Cuts that land on the beat." }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="SlashWipe"
    component={SlashWipeScene}
    durationInFrames={110}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A gradient slash sweeps across the frame and reveals the first title, then another slash wipes in the next, each with a one-line sub. Pass `sections` (title and optional sub) and your own `logo`; it ships light and dark.
