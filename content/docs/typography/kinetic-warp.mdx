title: Kinetic Warp
description: A coarse mesh warp bends a whole word in staccato beats, one axis moving per keyframe
component: kinetic-warp
vibe: playful
length: 100
useWhen:
  - "A short, heavy display word needs a bold kinetic-typography moment where the whole word bends and snaps instead of individual letters animating."
  - "You want a rhythmic, beat-synced distortion — the mesh stops dead at every keyframe, so each pose lands like a drum hit (tune `keyframeStride` to the tempo)."
  - "The type is a huge condensed display font filling the frame — the warp reads best when the word owns the canvas."
avoidWhen:
  - "You need a text entrance — the word is fully visible from frame 0 and only distorts; use `tracking-in` or `soft-blur-in` for reveals."
  - "The text is long or small — the mesh bends quarters of the frame, so a paragraph turns to mush; use `per-character-rise` for body-size text motion."
  - "The vibe is corrupted or digital rather than elastic — use `rgb-glitch-text` for a glitch read."

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KineticWarp } from "@/components/remocn/kinetic-warp";

const KineticWarpScene = () => (
  <KineticWarp
    text={"REM\nOCN"}
    fontFamily="Passion One"
    fontUrl="https://fonts.googleapis.com/css2?family=Passion+One:wght@700&display=block"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KineticWarp"
    component={KineticWarpScene}
    durationInFrames={120}
    fps={30}
    width={1920}
    height={1080}
  />
);
```

The component renders to a canvas, so the font must actually be loaded before the text is drawn — pass `fontUrl` for any webfont and the render is held (via `delayRender`) until it lands.
