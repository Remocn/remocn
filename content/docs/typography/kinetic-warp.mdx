In Remotion, Kinetic Warp takes a heavy display word that is visible from the first frame and bends and snaps it with a coarse mesh warp in staccato steps, instead of animating letter by letter. Use it for a bold kinetic-typography moment on a short word.

## How to build this in Remotion

You don't need `@remotion/three`, three.js or `@remotion/paths` for this. Install the component and pass the word:

```bash
npx shadcn@latest add @remocn/kinetic-warp
```

The text is drawn once onto a 2D canvas, then resampled every frame through a mesh of columns and rows whose control lines follow five keyframed moves from `timeline.ts`, eased with `interpolate()` and an `Easing.bezier` curve. `delayRender` holds the frame until the font has loaded.

## Good to know

- Length: 100 frames of motion at 30 fps (200 at 60 fps) with the default props; the demo plays 120 frames, which adds a hold. The warp is five moves (column right, row down, column left, row up, home) of `keyframeStride` (20) frames each; after the last one the word rests in its straight shape for the rest of the clip. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: `sans-serif` by default. Pass `fontFamily`, and `fontUrl` for a webfont stylesheet; the render waits for the font through `document.fonts` before drawing.
- Positions are in composition pixels for a 1920×1080 frame (`compWidth`, `compHeight`, `colRestX`, `rowRestY` and the other column and row values). At another resolution, set `compWidth` and `compHeight` and retune those values.
- The word is fully visible from frame 0; it distorts, it does not enter.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KineticWarp } from "@/components/remocn/kinetic-warp";

const KineticWarpScene = () => (
  <KineticWarp
    text={"REM\nOCN"}
    fontFamily="Passion One"
    fontUrl="https://fonts.googleapis.com/css2?family=Passion+One:wght@700&display=block"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KineticWarp"
    component={KineticWarpScene}
    durationInFrames={240}
    fps={60}
    width={1920}
    height={1080}
  />
);
```

The component renders to a canvas, so the font must actually be loaded before the text is drawn — pass `fontUrl` for any webfont and the render is held (via `delayRender`) until it lands.

## Common questions

### How do I make a heavy word bend and snap with a mesh warp in Remotion?

Install Kinetic Warp with `npx shadcn@latest add @remocn/kinetic-warp` and pass `text` (use `\n` for line breaks), `fontFamily` and `fontUrl`.

### Does it need three.js or WebGL?

No. It warps a 2D canvas, so it renders anywhere Remotion does.
