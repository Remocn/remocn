## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WhatSticks } from "@/components/remocn/what-sticks";

const WhatSticksScene = () => (
  <WhatSticks lines={["Scenes install with one command.", "You own every file."]} keep={1} />
);

export const RemotionRoot = () => (
  <Composition
    id="WhatSticks"
    component={WhatSticksScene}
    durationInFrames={230}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A stack of claims appears while timeline captions mark what you remember tonight, tomorrow and next week. Lines fade away until one is left bright. Pass `lines`, and use `keep` to pick the survivor. It ships in light and dark through the `theme` prop.
