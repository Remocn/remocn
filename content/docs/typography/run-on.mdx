## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RunOn } from "@/components/remocn/run-on";

const RunOnScene = () => (
  <RunOn
    text="Open the old project and relink the fonts and nudge every keyframe and render and spot a typo and render it all again"
    promise="Or change one line."
    highlight="one line"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RunOn"
    component={RunOnScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `text` runs in word by word at an accelerating pace, joiner words like and dimmed, and scrolls up as it fills the frame. A final accent full stop slams in, the wall drains away, and the stop slides down to end the `promise` line, whose `highlight` phrase lights up. Pass a long `text` without its final period, plus `promise` and `highlight`. It ships light and dark.
