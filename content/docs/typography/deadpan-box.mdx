## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DeadpanBox } from "@/components/remocn/deadpan-box";

const DeadpanBoxScene = () => <DeadpanBox quote="Nobody watches launch videos." attribution="Founder. Nobody watched the launch." brand="remocn" />;

export const RemotionRoot = () => (
  <Composition
    id="DeadpanBox"
    component={DeadpanBoxScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A small box showing the brand logo grows to hug a flat quote, which holds for a deadpan beat; then the box floods the whole frame and the attribution line lands the joke before a brand sign-off. Pass `quote`, `attribution` and `brand` ("remocn" renders the real logo, anything else is set as a wordmark).
