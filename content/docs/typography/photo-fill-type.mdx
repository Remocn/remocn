## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PhotoFillType } from "@/components/remocn/photo-fill-type";

const PhotoFillTypeScene = () => (
  <PhotoFillType title="Dusk" caption="Not a photograph. Every pixel is code." src={staticFile("shots/dusk.jpg")} />
);

export const RemotionRoot = () => (
  <Composition
    id="PhotoFillType"
    component={PhotoFillTypeScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The word sits as a cutout with the image visible through its letters, then expands until the image fills the frame and a caption fades in. Pass `title` and `caption`, and `src` with your own image to replace the built-in generated landscape; it ships light and dark through `theme`.
