## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpineTurn } from "@/components/remocn/spine-turn";

const SpineTurnScene = () => <SpineTurn titles={["Kickoff", "Deep dive", "Wrap-up"]} hold={26} />;

export const RemotionRoot = () => (
  <Composition
    id="SpineTurn"
    component={SpineTurnScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each title rises in large over a hairline rule, holds, then rotates 90 degrees and shrinks into a spine at the bottom while the next title enters. The last title stays large. Pass `titles` and `hold`; `accent` and `background` override the colors, and it ships light and dark through `theme`.
