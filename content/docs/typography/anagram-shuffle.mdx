## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AnagramShuffle } from "@/components/remocn/anagram-shuffle";

const AnagramShuffleScene = () => (
  <AnagramShuffle from="listen" to="silent" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="AnagramShuffle"
    component={AnagramShuffleScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` word shows, then each letter glides to its place in the `to` word. Both words must use the same letters, so pass a matching `from` and `to` pair. It ships in light and dark through the `theme` prop.
