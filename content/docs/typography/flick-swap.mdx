In Remotion, Flick Swap cycles several one-line claims on a scrolling rail: each headline flicks up to the next, with a small label and a highlighted phrase for each. Use it for a feature rundown where three or more claims share one scene.

## How to build this in Remotion

You don't need `TransitionSeries`, a slide presentation or `fitText`. Install the component and pass your items:

```bash
npx shadcn@latest add @remocn/flick-swap
```

Each item gets a period in `timeline.ts`: a short drag back, a flick and a settle, then a `dwell` hold. The scroll is plain `interpolate()` on the scene frame, and the rail fades in at the start.

## Good to know

- Length: 122 frames of motion at 30 fps (244 at 60 fps) with the default props. Each item takes 22 frames to settle plus `dwell` (28 by default), so N items need (N − 1) × (22 + `dwell`) + 22 frames to land on the last one, plus whatever hold you want after. The demo plays 150 frames. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Bricolage Grotesque and JetBrains Mono (for the labels) itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- An empty `items` list falls back to the three default items.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlickSwap } from "@/components/remocn/flick-swap";

const FlickSwapScene = () => (
  <FlickSwap
    items={[
      { label: "Captions", headline: "Every word lands on the beat.", highlight: "on the beat" },
      { label: "Transitions", headline: "Cuts that feel expensive.", highlight: "expensive" },
    ]}
    dwell={28}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FlickSwap"
    component={FlickSwapScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A rail on the side marks position while headlines scroll upward with a quick flick and settle, holding for `dwell` frames each. Pass `items` as label, headline and highlight objects; it ships light and dark through `theme`.

## Common questions

### How do I cycle several one-line claims on a scrolling rail in Remotion?

Install Flick Swap with `npx shadcn@latest add @remocn/flick-swap` and pass `items` as `{ label, headline, highlight }` objects. Each headline flicks up to the next and holds for `dwell` frames.

### How long should the scene be for N items?

(N − 1) × (22 + `dwell`) + 22 frames at 30 fps, then your hold. For three items at the default dwell that is 122 frames (244 at 60 fps).

### Does it work at 60 fps?

Yes. Its frame counts stay on a 30 fps scale at any frame rate; double the composition length you hand Remotion at 60 fps.
