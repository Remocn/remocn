## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AspectSlit } from "@/components/remocn/aspect-slit";

const AspectSlitScene = () => <AspectSlit title="Now showing." caption="A launch film, built in React." slit={0.125} />;

export const RemotionRoot = () => (
  <Composition
    id="AspectSlit"
    component={AspectSlitScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Letterbox bars close to a thin slit, a serif title rises into it, then the bars open back to full frame as the title grows to hero size and a small caption settles underneath. Pass `title`, `caption` and `slit` (the narrowest bar gap as a share of frame height).
