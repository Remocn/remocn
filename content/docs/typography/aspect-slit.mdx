In Remotion, Aspect Slit makes a cinematic title card: letterbox bars close to a thin slit, a serif hero line rises into it, then the screen opens through the slit to full frame while a small caption settles underneath. Use it as the opening title of a release announcement or product launch video.

## How to build this in Remotion

You don't have to animate `clip-path` insets and load a serif by hand. Install the component and pass your title:

```bash
npx shadcn@latest add @remocn/aspect-slit
```

It is a single scene: the bars and the slit move with `interpolate()` on `Easing.bezier` curves, and the title is measured on a canvas before the first frame (held with `delayRender`) so it grows to hero size centered. It doesn't use `Sequence` or `TransitionSeries`; put it in your own `Sequence` and cut to the next scene.

## Good to know

- Length: 150 frames of motion at 30 fps (300 at 60 fps) with the default props; the demo plays 180 frames, which adds a hold. The timing is fixed: a longer composition only holds the last frame longer. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Serif and Instrument Sans itself through `@remotion/google-fonts`, so there is no font setup. Pass `fontFamily` to use your own face, and load that font in your project.
- Default dark theme: black bars `#0A0A0B` over a blue `#2E45B7` ground with white type and a light film grain (`grain`).

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AspectSlit } from "@/components/remocn/aspect-slit";

const AspectSlitScene = () => <AspectSlit title="Now showing." caption="A launch film, built in React." slit={0.125} />;

export const RemotionRoot = () => (
  <Composition
    id="AspectSlit"
    component={AspectSlitScene}
    durationInFrames={360}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How can I make a cinematic title card in Remotion where the screen opens through a slit?

Install Aspect Slit with `npx shadcn@latest add @remocn/aspect-slit` and pass `title` and `caption`. `slit` sets how narrow the gap gets, as a share of the frame height.

### How long should the composition be?

At least 150 frames at 30 fps, 300 at 60 fps. The Usage example's 360 frames at 60 fps adds a hold on the finished card.
