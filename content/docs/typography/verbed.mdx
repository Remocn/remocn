## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Verbed } from "@/components/remocn/verbed";

const VerbedScene = () => (
  <Verbed headword="remocn" nounSense="a set of video scenes you copy into your repo." verbSense="to make the launch film in the same pull request." />
);

export const RemotionRoot = () => (
  <Composition
    id="Verbed"
    component={VerbedScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A headword with pronunciation appears with its noun sense, then turns into its verb sense, inflections and an example sentence. Set `headword`, `nounSense`, `verbSense` and `example` to define your own product. It ships in light and dark through the `theme` prop.
