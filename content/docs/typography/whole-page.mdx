## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WholePage } from "@/components/remocn/whole-page";

const WholePageScene = () => (
  <WholePage title="What we believe" beliefs={["A launch video is part of the launch.", "Every frame you install is a file you can rewrite."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WholePage"
    component={WholePageScene}
    durationInFrames={390}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A title opens a page that fills with `beliefs` paragraph by paragraph, flowing into columns, with the active paragraph highlighted. Pass `beliefs` and `title` for your own manifesto. It ships in light and dark through the `theme` prop.
