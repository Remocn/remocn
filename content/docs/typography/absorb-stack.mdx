## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AbsorbStack } from "@/components/remocn/absorb-stack";

const AbsorbStackScene = () => <AbsorbStack lines={["made to", "sink into", "your cut,", "not sit", "on top."]} accentLine={4} />;

export const RemotionRoot = () => (
  <Composition
    id="AbsorbStack"
    component={AbsorbStackScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A stack of small lowercase lines fades in from the center outward, spread wide, then eases together into a tight block, with the last line in the accent color. Pass `lines` (one string per line) and optionally `accentLine` for which line gets the accent.
