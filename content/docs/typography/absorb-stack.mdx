In Remotion, Absorb Stack sets a short poetic statement as a centered stack of small lines on a dark brown background, with the last line, such as "on top.", in red. The lines fade in from the center outward and ease together into a tight block; use it for a brand film, a closing slogan or a quiet beat between louder scenes.

## How to build this in Remotion

You don't need to lay this out by hand with `AbsoluteFill` and a font size per line. Install the component and pass your lines:

```bash
npx shadcn@latest add @remocn/absorb-stack
```

It is one scene: each ring of lines, counted from the center out, fades in with `interpolate()` on an `Easing.bezier` curve, and the stack pulls together with a `spring()`. The schedule lives in `timeline.ts`, so single lines can be moved or stretched with the `timing` prop.

## Good to know

- Length: 60 frames of motion at 30 fps (120 at 60 fps) with the default props; the demo plays 120 frames, which adds a hold. The timing is fixed: a longer composition only holds the last frame longer. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Jost (variable) itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Default colors, dark theme: ground `#2A1C17`, lines `#E8C9B0`, accent `#C8102E`. Light theme: ground `#EAD3C3`, lines `#2A1C17`, same red accent. Override with `background`, `ink` and `accent`.
- The text is not forced to lowercase: lines render exactly as you type them. The defaults just happen to be lowercase.
- The accent goes on the last line unless you set `accentLine` (a zero-based index).

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AbsorbStack } from "@/components/remocn/absorb-stack";

const AbsorbStackScene = () => <AbsorbStack lines={["made to", "sink into", "your cut,", "not sit", "on top."]} accentLine={4} />;

export const RemotionRoot = () => (
  <Composition
    id="AbsorbStack"
    component={AbsorbStackScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A stack of small lowercase lines fades in from the center outward, spread wide, then eases together into a tight block, with the last line in the accent color. Pass `lines` (one string per line) and optionally `accentLine` for which line gets the accent.

## Common questions

### How do I set a short poetic statement as a centered stack of lines in Remotion, with the last line in red?

Install Absorb Stack with `npx shadcn@latest add @remocn/absorb-stack` and pass `lines`, one string per line. The last line takes the red accent (`#C8102E`) on a dark brown ground by default.

### Can I change which line is red?

Yes. `accentLine` picks the line by zero-based index, and `accent` sets the color.
