## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { OutOfContext } from "@/components/remocn/out-of-context";

const OutOfContextScene = () => (
  <OutOfContext claim={"Stop making\nlaunch videos"} rest="by hand." />
);

export const RemotionRoot = () => (
  <Composition
    id="OutOfContext"
    component={OutOfContextScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The claim lines fly in, one drops out of alignment and is pulled across the frame, and the closing phrase arrives in the accent color. Pass `claim` (newlines split lines) and `rest` for the closing phrase; it ships light and dark through `theme`.
