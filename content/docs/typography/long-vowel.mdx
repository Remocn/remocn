## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LongVowel } from "@/components/remocn/long-vowel";

const LongVowelScene = () => <LongVowel word="Wow" repeat={6} rest="that was fast." />;

export const RemotionRoot = () => (
  <Composition
    id="LongVowel"
    component={LongVowelScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The word rises into place, then the chosen letter is drawn out with spring-driven copies that fan into a gradient trail; the caption words then slide up under it. Pass `word`, the `letter` to stretch (defaults to the first vowel), `repeat` for how many copies, and `rest` for the caption. It takes a `theme` prop and ships light and dark.
