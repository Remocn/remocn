In Remotion, Two Hit is a premiere-style card: a right-aligned line such as Streaming now. hits on black in white, then a second hit replaces it in your accent color. Use it for a two-beat teaser or release card.

## Good to know

- Length: 91 frames of motion at 30 fps (182 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Urbanist itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- `before` and `after` are separate lines; set `accent` to the color of the second hit.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TwoHit } from "@/components/remocn/two-hit";

const TwoHitScene = () => (
  <TwoHit before="Premieres Friday." after="Streaming now." hitAt={34} />
);

export const RemotionRoot = () => (
  <Composition
    id="TwoHit"
    component={TwoHitScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The first line appears, then at `hitAt` it is hit and replaced by the second line in the accent colour, right-aligned on a flat background. Pass `before`, `after` and `hitAt`; it ships light and dark.
