## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BokehTitle } from "@/components/remocn/bokeh-title";

const BokehTitleScene = () => (
  <BokehTitle
    title="Launch films, made in code"
    subtitle="remocn · Spring release"
    pattern="grid"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BokehTitle"
    component={BokehTitleScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Out-of-focus bokeh lights drift, a focus pull snaps them into a mark or grid pattern, then they defocus again as the serif title and subtitle resolve. Pass `title` and `subtitle` (split on ' · ' for a lead and a tail) and choose `pattern` and `shape`; it ships light and dark through `theme`.
