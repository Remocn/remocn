## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChunkStack } from "@/components/remocn/chunk-stack";

const ChunkStackScene = () => (
  <ChunkStack text="learn motion by making it" highlight="making" />
);

export const RemotionRoot = () => (
  <Composition
    id="ChunkStack"
    component={ChunkStackScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The phrase rises into a stack, one word per line, then a highlighter bar opens behind the chosen word. Pass `text` and `highlight`; it ships light and dark.
