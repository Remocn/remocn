In Remotion, We Call It builds a few short descriptive lines, then resolves them into a big product name introduced by a lead-in such as we call it. Use it for a category-naming beat.

## Good to know

- Length: 164 frames of motion at 30 fps (328 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Bitter itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WeCallIt } from "@/components/remocn/we-call-it";

const WeCallItScene = () => (
  <WeCallIt descriptions={["Scenes you install like components.", "Edits that land as commits."]} lead="We call it a" name="video registry." />
);

export const RemotionRoot = () => (
  <Composition
    id="WeCallIt"
    component={WeCallItScene}
    durationInFrames={420}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Description lines stack up one at a time, then a lead-in phrase lands and the big name appears word by word. Pass `descriptions`, `lead` and `name` to name your own thing. It ships in light and dark through the `theme` prop.
