## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WeCallIt } from "@/components/remocn/we-call-it";

const WeCallItScene = () => (
  <WeCallIt descriptions={["Scenes you install like components.", "Edits that land as commits."]} lead="We call it a" name="video registry." />
);

export const RemotionRoot = () => (
  <Composition
    id="WeCallIt"
    component={WeCallItScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Description lines stack up one at a time, then a lead-in phrase lands and the big name appears word by word. Pass `descriptions`, `lead` and `name` to name your own thing. It ships in light and dark through the `theme` prop.
