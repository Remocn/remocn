## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StoryDip } from "@/components/remocn/story-dip";

const StoryDipScene = () => (
  <StoryDip
    setup={{ slug: "Wednesday, 4:00 PM", line: "The film was one render away." }}
    snag={{ slug: "4:05 PM", line: "Then the client sent a new logo." }}
    resolution={{ slug: "4:15 PM", line: "One prop later, every scene had it." }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="StoryDip"
    component={StoryDipScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Three timestamped lines enter side by side, or in two columns on a tall frame. The setup appears first, the snag then drops lower and dims, and the resolution rises to the top and turns accent-colored. Pass `setup`, `snag` and `resolution` as `{ slug, line }`, where `slug` is the small timestamp. It ships light and dark.
