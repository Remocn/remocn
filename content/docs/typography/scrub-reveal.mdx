## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScrubReveal } from "@/components/remocn/scrub-reveal";

const ScrubRevealScene = () => (
  <ScrubReveal
    text="Every frame is code. Every cut is yours. Ship the film your product deserves."
    highlight="Every cut is yours."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ScrubReveal"
    component={ScrubRevealScene}
    durationInFrames={172}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dim paragraph sits low in the frame and climbs while a soft front brightens it word by word, like a trackpad scroll. The `highlight` phrase inside `text` switches to a serif italic filled with a gradient, and at the end the plain words settle back a step. Pass your own `text` and a `highlight` that appears in it, or an empty string for none. It ships light and dark.
