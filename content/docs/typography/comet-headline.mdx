## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CometHeadline } from "@/components/remocn/comet-headline";

const CometHeadlineScene = () => (
  <CometHeadline
    eyebrow="New in remocn"
    headline="Every launch beat, already in orbit."
    highlight="in orbit"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CometHeadline"
    component={CometHeadlineScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An eyebrow fades in, then the headline words fly in one after another on comet arcs and cool into place, and the subhead follows. Pass `eyebrow`, `headline`, `highlight` and `subhead` to make it yours; it ships light and dark through `theme`.
