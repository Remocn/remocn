In Remotion, Comet Headline delivers a headline word by word while a comet streaks in an arc behind each word as it arrives, then a subhead follows and one phrase stays highlighted. Use it for a feature announcement or hero beat with an eyebrow, a headline and a short subhead.

## How to build this in Remotion

You don't need `@remotion/paths` or `@remotion/motion-blur` for the trails. Install the component and pass your copy:

```bash
npx shadcn@latest add @remocn/comet-headline
```

Each comet is an SVG quadratic curve drawn per word, and the head and tail travel along it with `interpolate()` over an `Easing` curve, on a schedule from `timeline.ts`. Words fly in, cool from the comet color into ink and settle; the highlight phrase then takes the accent.

## Good to know

- Length: 81 frames of motion at 30 fps (162 at 60 fps) with the default props. The demo composition plays 120 frames, which adds a hold. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Sora (headline and subhead) and Geist Mono (eyebrow) itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- `highlight` is matched inside `headline` without regard to case; pass an empty string for no highlight. The default accent is `#3B5BFD`.
- `flight` sets the frames each word takes to fly in on its arc (26 at 30 fps).

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CometHeadline } from "@/components/remocn/comet-headline";

const CometHeadlineScene = () => (
  <CometHeadline
    eyebrow="New in remocn"
    headline="Every launch beat, already in orbit."
    highlight="in orbit"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CometHeadline"
    component={CometHeadlineScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

An eyebrow fades in, then the headline words fly in one after another on comet arcs and cool into place, and the subhead follows. Pass `eyebrow`, `headline`, `highlight` and `subhead` to make it yours; it ships light and dark through `theme`.

## Common questions

### How do I make a comet streak in an arc behind each word of a headline?

Install Comet Headline with `npx shadcn@latest add @remocn/comet-headline` and pass `eyebrow`, `headline`, `highlight` and `subhead`. Each word arrives on its own comet arc.

### Does it need @remotion/paths or motion blur?

No. The arcs are plain SVG curves computed in the component; it installs only `remotion` and `@remotion/google-fonts`.

### Can I drop the highlight?

Yes, pass `highlight=""`.
