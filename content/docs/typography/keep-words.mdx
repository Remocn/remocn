## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KeepWords } from "@/components/remocn/keep-words";

const KeepWordsScene = () => (
  <KeepWords
    beliefs={[
      { text: "A launch film should be written like code.", keep: "written" },
      { text: "Every scene you install stays yours.", keep: "yours" },
      { text: "And it ships on time with the release.", keep: "on time" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KeepWords"
    component={KeepWordsScene}
    durationInFrames={330}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each belief builds word by word in a large serif; its keyword turns the accent color while the other words fall away, and the keyword flies down into a motto line. In the end the keywords stack into a column of one-word sentences, each ending in an accent full stop. Pass `beliefs` as `{ text, keep }` where `keep` is the exact word or phrase inside `text`. Timing stretches to fill the composition; 285 frames assumes three beliefs in 330. It ships light and dark.
