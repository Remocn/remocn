In Remotion, Keep Words builds a manifesto ending: serif belief statements build word by word, the key word of each turns red and drops into a column of one-word mottos. Use it as the closing beat of a brand film or launch video with two or three beliefs.

## How to build this in Remotion

You don't need `TransitionSeries`, `fitText` or a font loader of your own. Install the component and pass your beliefs:

```bash
npx shadcn@latest add @remocn/keep-words
```

Each belief and each motto is an element in `timeline.ts`. Words rise with `interpolate()` over `Easing` curves, the key word changes color with `interpolateColors()`, and line widths are measured on a canvas while `delayRender` holds the frame until Gloock has loaded.

## Good to know

- Length: 285 frames of motion at 30 fps (570 at 60 fps) with the default props; the demo plays 330 frames, which adds a hold. The beliefs stretch to fill the composition: each one gets an equal share of `durationInFrames`, after 6 frames in, 24 for the stack move and `hold` (34) at the end, and never less than 48 frames. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Gloock itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Accent: the key words turn `#FF4436` in dark and `#D92B1E` in light; `accent` overrides it.
- Any number of beliefs works, since the timing divides the clip between them; with more than three, give the composition more frames so each belief keeps at least 48.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KeepWords } from "@/components/remocn/keep-words";

const KeepWordsScene = () => (
  <KeepWords
    beliefs={[
      { text: "A launch film should be written like code.", keep: "written" },
      { text: "Every scene you install stays yours.", keep: "yours" },
      { text: "And it ships on time with the release.", keep: "on time" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KeepWords"
    component={KeepWordsScene}
    durationInFrames={660}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each belief builds word by word in a large serif; its keyword turns the accent color while the other words fall away, and the keyword flies down into a motto line. In the end the keywords stack into a column of one-word sentences, each ending in an accent full stop. Pass `beliefs` as `{ text, keep }` where `keep` is the exact word or phrase inside `text`. Timing stretches to fill the composition; 285 frames assumes three beliefs in 330. It ships light and dark.

## Common questions

### How do I make a manifesto ending in Remotion where key words drop into a column of mottos?

Install Keep Words with `npx shadcn@latest add @remocn/keep-words` and pass `beliefs` as `{ text, keep }` objects. `keep` is the word that turns red and joins the closing column.

### Does it work with four or five beliefs?

Yes. The clip is split evenly between them, at least 48 frames each, so raise `durationInFrames` with the count.
