## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TypoFix } from "@/components/remocn/typo-fix";

const TypoFixScene = () => (
  <TypoFix wrong="Lanuch" correct="Launch" after="day" />
);

export const RemotionRoot = () => (
  <Composition
    id="TypoFix"
    component={TypoFixScene}
    durationInFrames={116}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `wrong` word appears in a short line, gets flagged, and is corrected to `correct` in place. Pass `wrong`, `correct` and surrounding `before` and `after` text. It ships in light and dark through the `theme` prop.
