## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WakeWipe } from "@/components/remocn/wake-wipe";

const WakeWipeScene = () => (
  <WakeWipe lines={["Animations you own.", "Transitions that land.", "Ship the launch video today."]} highlight="today." />
);

export const RemotionRoot = () => (
  <Composition
    id="WakeWipe"
    component={WakeWipeScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line is revealed by a wipe with a soft wake behind it and cleared by the next, ending on the last line with its highlight word in a gradient. Pass `lines`, `highlight` and `eyebrow`; it ships light and dark.
