## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LetterRelay } from "@/components/remocn/letter-relay";

const LetterRelayScene = () => <LetterRelay word="launchpad" hop={8} mark={false} />;

export const RemotionRoot = () => (
  <Composition
    id="LetterRelay"
    component={LetterRelayScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each letter pops in, then hops over to its place in turn, squashing as it lands on a glowing floor; once the last one lands the spacing tightens to final kerning. Pass `word` for your own name and `hop` to set the pace. With `mark` on, a leading r is drawn as the Remocn R mark. It takes a `theme` prop and ships light and dark.
