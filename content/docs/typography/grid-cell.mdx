## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GridCell } from "@/components/remocn/grid-cell";

const GridCellScene = () => (
  <GridCell title="Introducing remocn 2.0" label="v2.0" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="GridCell"
    component={GridCellScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A grid fades in from the center, cells merge into one that frames the headline, the label appears in the corner, and the title is typed in with a caret before the grid dims. Pass `title` and `label`; it ships light and dark through `theme`.
