## Usage

```tsx
// src/Root.tsx
import { AbsoluteFill, Composition } from "remotion";
import { LeadBarType } from "@/components/remocn/lead-bar-type";

const Title = () => (
  <AbsoluteFill style={{ backgroundColor: "#ff4d1a" }}>
    <LeadBarType text="Every" color="#111111" />
  </AbsoluteFill>
);

export const RemotionRoot = () => (
  <Composition
    id="LeadBarType"
    component={Title}
    durationInFrames={66}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The bar crosses the word between frames 2 and 22, spending the same time on
every letter. Each letter starts once the bar is a third into its slot. It
slides in from the left, stretched horizontally and blurred along the motion,
and drops onto the baseline with a spring that dips just below the line before
it settles. When the bar reaches the end it thins and runs back to the first
letter as an underline, placed below the lowest descender of the word.

The bar walks the letters by living inside the letter it is crossing, so no
advances are measured. The baseline and the descender depth are read from the
loaded font. The component paints no background and centers the word in its
parent. Sizes scale with `height / 720`.
