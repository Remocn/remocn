In Remotion, Tagline Justify springs a closing tagline in word by word and sets it as a tidy justified block, with one word in a gradient serif italic and a logo below. Use it for the last line of a launch video, locked up like a poster.

## Good to know

- Length: 112 frames of motion at 30 fps (224 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Serif, Inter Tight and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TaglineJustify } from "@/components/remocn/tagline-justify";

const TaglineJustifyScene = () => (
  <TaglineJustify
    text="Your launch deserves a film as good as the product."
    highlight="film"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TaglineJustify"
    component={TaglineJustifyScene}
    durationInFrames={280}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Words spring in one after another and the line breaks stretch and scale so every line fills the same width, like a justified column. The `highlight` word is set in serif italic and fills with a gradient, then a hairline and a logo land beneath. The default logo is the Remocn wordmark, so pass your own `logo`. It ships light and dark.
