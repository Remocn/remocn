## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TaglineJustify } from "@/components/remocn/tagline-justify";

const TaglineJustifyScene = () => (
  <TaglineJustify
    text="Your launch deserves a film as good as the product."
    highlight="film"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TaglineJustify"
    component={TaglineJustifyScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Words spring in one after another and the line breaks stretch and scale so every line fills the same width, like a justified column. The `highlight` word is set in serif italic and fills with a gradient, then a hairline and a logo land beneath. The default logo is the Remocn wordmark, so pass your own `logo`. It ships light and dark.
