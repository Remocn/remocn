## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NotYet } from "@/components/remocn/not-yet";

const NotYetScene = () => (
  <NotYet
    lines={["It can’t write your script.", "It can’t pick your music."]}
    word="Yet."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NotYet"
    component={NotYetScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line builds word by word and finishes with the accent `word` (Yet. by default). The next line then pushes in beneath it while earlier lines shrink and dim above a thin rule, so the newest line is always the largest. Pass `lines` and optionally a different `word`. Timing compresses to fit the composition; 173 frames is the uncompressed length of the three defaults. It ships light and dark.
