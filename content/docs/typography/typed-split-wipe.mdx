In Remotion, Typed Split Wipe types a line in place with no visible cursor, then exits by splitting it: the start wipes away in one direction and the end in the other while the layout stays fixed. Use it for a product or feature intro that types cleanly and leaves with a directional exit.

## Good to know

- Length: 75 frames of motion at 30 fps (150 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file; a `className` font does not override an inline style.
- The line is passed in three parts, `prefix`, `anchor` and `suffix`: the anchor is the word that moves and closes last.

## Usage

The enter renders only the currently typed substring, so every hard character step remains centered. At `exitAt`, the component switches to a visually identical fixed layout. The prefix clips from right to left and suffix words clip from left to right with a stagger. While those gaps open, the anchor travels left by `anchorShift`, making the empty spaces on its two sides deliberately uneven before it closes last from both sides.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TypedSplitWipe } from "@/components/remocn/typed-split-wipe";

const TypedSplitWipeScene = () => (
  <TypedSplitWipe
    prefix="Introducing"
    anchor="X"
    suffix="Ads MCP"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TypedSplitWipe"
    component={TypedSplitWipeScene}
    durationInFrames={150}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component is transparent. The reference uses warm white text on an almost-black field.

```tsx
import { Composition } from "remotion";
import { Backdrop } from "@/components/remocn/backdrop";
import { TypedSplitWipe } from "@/components/remocn/typed-split-wipe";

const TypedSplitWipeScene = () => (
  <Backdrop fill={{ type: "color", value: "#101010" }}>
    <TypedSplitWipe
      prefix="Introducing"
      anchor="X"
      suffix="Ads MCP"
    />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="TypedSplitWipe"
    component={TypedSplitWipeScene}
    durationInFrames={150}
    fps={60}
    width={1280}
    height={720}
  />
);
```
