In Remotion, Word Stream builds voiceover-paced intro text: each phrase builds word by word at speaking pace while the line slowly drifts left, then cuts to the next phrase. Use it for an intro or narration that follows a voiceover.

## Good to know

- Length: 63 frames of motion at 30 fps (126 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file; a `className` font does not override an inline style.
- Phrases go in one `text` string separated by `|`. Timing comes from `wordGap` and `hold`, not from a transcript; for subtitles timed to speech, use the [Captions](/docs/captions/getting-started/introduction) components.

## Usage

Phrases are passed as a single string separated by `|`. Each phrase glides in decelerating, builds word by word while slowly drifting left, then accelerates out to the left and hard-cuts to the next phrase. The last phrase stays on screen.

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordStream } from "@/components/remocn/word-stream";

const WordStreamScene = () => (
  <WordStream text="introducing | one-tap checkout | for your store" />
);

export const RemotionRoot = () => (
  <Composition
    id="WordStream"
    component={WordStreamScene}
    durationInFrames={200}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. It ships single-theme; edit the copied file to re-theme colors.

```tsx
import { Composition } from "remotion";
import { WordStream } from "@/components/remocn/word-stream";
import { Backdrop } from "@/components/remocn/backdrop";

const WordStreamScene = () => (
  <Backdrop fill={{ type: "color", value: "#0b0b14" }}>
    <WordStream
      text="introducing | one-tap checkout | for your store"
      color="#ffffff"
    />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="WordStream"
    component={WordStreamScene}
    durationInFrames={200}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### Syncing to a voiceover

`wordGap` is the number of frames between word reveals — match it to the speaking pace of the narration (it counts 30 fps frames, so `wordGap={6}` is 5 words per second). `hold` controls how long a finished phrase stays before the next one starts. The exported `wordStreamLength(text, wordGap, hold)` helper returns the frame on which the last word finishes resolving — use it as the lower bound of the `Sequence`, doubled in a 60 fps composition.
