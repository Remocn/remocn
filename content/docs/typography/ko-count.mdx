## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KoCount } from "@/components/remocn/ko-count";

const KoCountScene = () => <KoCount word="Shipped" subline="The old workflow did not get up." />;

export const RemotionRoot = () => (
  <Composition
    id="KoCount"
    component={KoCountScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Numerals one to ten hard-cut in with tightening gaps, each as a different crop and tilt, then the word slams in from large with a short knockout flash and shake. A serif subline wipes in and the logo rises. Pass `word`, `subline` and `label` to make it yours; it ships light and dark through `theme`.
