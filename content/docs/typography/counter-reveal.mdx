## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CounterReveal } from "@/components/remocn/counter-reveal";

const CounterRevealScene = () => (
  <CounterReveal word="Beta" line="Out now." accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="CounterReveal"
    component={CounterRevealScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A giant front word rises letter by letter, then shrinks and drifts away so its counters open onto the second line behind it, which settles in. Pass `word` for the big text and `line` for the revealed line; it ships light and dark through `theme`.
