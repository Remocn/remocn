In Remotion, Counter Reveal shows a huge word like "Beta" whose letter holes reveal a second line of text over a gradient background; the word then shrinks and drifts away to uncover the line. Use it for a one-word status beat such as Beta, Live or New in a launch video.

## How to build this in Remotion

You don't need to set up an SVG mask, `mix-blend-mode` or `background-clip: text` yourself. Install the component and pass the two lines:

```bash
npx shadcn@latest add @remocn/counter-reveal
```

The big word is drawn as SVG glyph outlines whose counters (the holes in B, a, e) are cut into an SVG `mask`, so the line behind shows through them. Letters rise in and the word shrinks away with `interpolate()` over `Easing` curves on a schedule from `timeline.ts`.

## Good to know

- Length: 128 frames of motion at 30 fps (256 at 60 fps) with the default props. The demo composition plays 132 frames, which adds a hold. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Sora (weight 500) itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Built-in hole outlines exist only for the letters B, a, e and t, so "Beta" works out of the box. Other letters are drawn as plain text without see-through counters; for another word you would add outlines in the copied file.
- The gradient behind is a fixed blue mesh palette per theme; `accent` (default `#3B5BFD`) does not recolor it. Pass `background` with a solid color or `"transparent"` to replace it.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CounterReveal } from "@/components/remocn/counter-reveal";

const CounterRevealScene = () => (
  <CounterReveal word="Beta" line="Out now." accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="CounterReveal"
    component={CounterRevealScene}
    durationInFrames={264}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A giant front word rises letter by letter, then shrinks and drifts away so its counters open onto the second line behind it, which settles in. Pass `word` for the big text and `line` for the revealed line; it ships light and dark through `theme`.

## Common questions

### How do I show a huge word like Beta with a second line visible through the holes in its letters?

Install Counter Reveal with `npx shadcn@latest add @remocn/counter-reveal`, pass `word` and `line`. The line shows through the letter counters, then the word shrinks away.

### Will it work with any word?

Only B, a, e and t have built-in hole outlines. Other letters render solid, so the effect needs letters with counters from that set unless you add outlines.

### Can I change the gradient?

Not with a prop. Pass `background` for a solid color or edit the palette in the copied file.
