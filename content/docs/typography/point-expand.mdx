## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PointExpand } from "@/components/remocn/point-expand";

const PointExpandScene = () => (
  <PointExpand
    statements={["Launch films used to take weeks.", "Now they take an afternoon.", "Copy, paste, render."]}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PointExpand"
    component={PointExpandScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each statement rises word by word and ends in a round point that drops in, pulses `pulses` times, and then expands as a circle that becomes the next scene's ground, alternating a plain stage with an accent gradient. Pass up to five `statements` (trailing periods are replaced by the point) and an `accent`. It ships light and dark.
