## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScriptCut } from "@/components/remocn/script-cut";

const ScriptCutScene = () => (
  <ScriptCut
    shots={["We wrote the launch as one line,", "cut it twice,", "and every piece became a shot."]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ScriptCut"
    component={ScriptCutScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The whole script appears as a small line along the bottom, then accent ticks drop in to cut it into pieces. Each shot lights up in turn and its words fly up from the row to fill the frame at large size, then exit for the next. Pass `shots` as the script split into phrases; timing adapts to the composition length, and 176 frames assumes the three defaults in 200. It ships light and dark.
