In Remotion, Kill Feed turns a recap into a game-style kill feed: each shipped feature lands as a kill line with a streak callout, the gaps tighten, and a big gradient PENTA SHIP banner slams across the middle. Use it for a playful release recap or a week-in-review.

## How to build this in Remotion

You don't need `TransitionSeries`, `Sequence` or `spring()` for this. Install the component and pass your kills:

```bash
npx shadcn@latest add @remocn/kill-feed
```

Every kill, the banner and the caption are elements in `timeline.ts`; lines, callouts and the banner slam with `interpolate()` over `Easing` curves inside one scene.

## Good to know

- Length: 69 frames of motion at 30 fps (138 at 60 fps) with the default props; the demo plays 105 frames, which adds a hold. Kills arrive 14, 12, 10, then 8 frames apart, and the banner slams in 4 frames after the last one; more than five kills keep the 8-frame gap. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads Chakra Petch and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Callouts: callout `i` shows under kill `i` and rolls out when the next kill lands, and the last kill fires the banner instead. So `callouts` should have one fewer item than `kills`; extra callouts are ignored and missing ones leave a kill without a callout.
- The banner gradient is fixed in the copied file (`BAND`); `accent` does not recolor it.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KillFeed } from "@/components/remocn/kill-feed";

const KillFeedScene = () => (
  <KillFeed kills={["Manual keyframes", "Render queue", "Stock templates"]} banner="Triple ship" />
);

export const RemotionRoot = () => (
  <Composition
    id="KillFeed"
    component={KillFeedScene}
    durationInFrames={210}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I make a Remotion recap where features show up like a game kill feed?

Install Kill Feed with `npx shadcn@latest add @remocn/kill-feed` and pass `kills`, `callouts` and `banner`.

### Does it work with more or fewer than five kills?

Yes. Kill lines follow each other with a tightening gap and the banner follows the last one; give `callouts` one item fewer than `kills`.
