## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KillFeed } from "@/components/remocn/kill-feed";

const KillFeedScene = () => (
  <KillFeed kills={["Manual keyframes", "Render queue", "Stock templates"]} banner="Triple ship" />
);

export const RemotionRoot = () => (
  <Composition
    id="KillFeed"
    component={KillFeedScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Elimination lines drop into a game-style feed one by one with streak callouts, and the last kill fires a gradient banner with a caption. Pass `kills`, `callouts`, `banner` and `caption`; it ships light and dark.
