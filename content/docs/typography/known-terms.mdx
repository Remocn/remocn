## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KnownTerms } from "@/components/remocn/known-terms";

const KnownTermsScene = () => (
  <KnownTerms
    pairs={[
      { video: "A scene", dev: "a component." },
      { video: "An edit", dev: "a commit." },
      { video: "Your launch", dev: "a deploy." },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KnownTerms"
    component={KnownTermsScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A term appears alone in the center, then slides left as its counterpart pushes in from the right with a dim joiner word between them. Earlier pairs dim as new ones stack beneath, and the last pair turns the accent color. Pass `pairs` as `{ video, dev, joiner? }`; `joiner` sets the default connector word. Timing adapts to the composition length; 159 frames assumes five pairs in 180. It ships light and dark.
