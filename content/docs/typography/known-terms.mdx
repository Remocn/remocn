In Remotion, Known Terms animates pairs like "a scene is a component": each familiar term rises, slides aside as its definition pushes in with a joiner word, and the block moves up for the next pair until the last line lands in the accent color. Use it to map familiar concepts to your product.

## How to build this in Remotion

You don't need `TransitionSeries`, `Sequence` or `fitText` for this. Install the component and pass your pairs:

```bash
npx shadcn@latest add @remocn/known-terms
```

Every pair is an element in `timeline.ts`; terms rise and slide with `interpolate()` over `Easing` curves, the color settles with `interpolateColors()`, and widths are measured on a canvas while `delayRender` waits for Epilogue to load.

## Good to know

- Length: 159 frames of motion at 30 fps (318 at 60 fps) with the default props; the demo plays 180 frames, which adds a hold. The pairs spread to fill the clip: they start 24 to 40 frames apart, leaving `hold` (33) at the end. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Epilogue itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Accent: `#5CF2B5` in dark and `#12A06B` in light; `accent` overrides it.
- `joiner` (default "is", or per pair) can be an empty string: no connector word is drawn and the gap between the two columns stays.
- The `video` and `dev` field names are only labels for the left and right term; any pair of words works.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KnownTerms } from "@/components/remocn/known-terms";

const KnownTermsScene = () => (
  <KnownTerms
    pairs={[
      { video: "A scene", dev: "a component." },
      { video: "An edit", dev: "a commit." },
      { video: "Your launch", dev: "a deploy." },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="KnownTerms"
    component={KnownTermsScene}
    durationInFrames={360}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A term appears alone in the center, then slides left as its counterpart pushes in from the right with a dim joiner word between them. Earlier pairs dim as new ones stack beneath, and the last pair turns the accent color. Pass `pairs` as `{ video, dev, joiner? }`; `joiner` sets the default connector word. Timing adapts to the composition length; 159 frames assumes five pairs in 180. It ships light and dark.

## Common questions

### How do I animate pairs like a scene is a component in Remotion?

Install Known Terms with `npx shadcn@latest add @remocn/known-terms` and pass `pairs` as `{ video, dev }` objects.

### Can I drop the connector word?

Yes. Set `joiner=""` for all pairs, or per pair.
