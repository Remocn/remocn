## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BaselineDrop } from "@/components/remocn/baseline-drop";

const BaselineDropScene = () => (
  <BaselineDrop text="Ship the story." stagger={11} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="BaselineDrop"
    component={BaselineDropScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word drops from above and lands on a single baseline with a small bounce while a gradient streak draws in and brightens under the line, then retracts. Pass `text` (or `words` for explicit splits) and `stagger` to set the rhythm; it ships light and dark through `theme`.
