In Remotion, Baseline Drop makes the words of a closing tagline fall one after another onto a shared baseline, each landing with a small bounce, while a glowing gradient streak draws in and brightens under the line. Use it for a closing line or tagline where each word should land with weight.

## How to build this in Remotion

You don't have to stagger `spring()` calls per word or reach for `Series`. Install the component and pass your line:

```bash
npx shadcn@latest add @remocn/baseline-drop
```

Each word falls with `interpolate()` on an `Easing.bezier` curve, on a schedule in `timeline.ts` (`stagger` sets the beat between words). The streak under the baseline is an SVG with a CSS mask, drawn and retracted with `interpolate()`.

## Good to know

- Length: 94 frames of motion at 30 fps (188 at 60 fps) with the default props; the demo plays 125 frames, which adds a hold. The timing is fixed: a longer composition only holds the last frame longer. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Schibsted Grotesk itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The glow uses an aurora gradient (`#A0F0C8`, `#3FB5A3`, `#5147B6`, `#B25C9C`) in the dark theme and a pink-to-gold one in light.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BaselineDrop } from "@/components/remocn/baseline-drop";

const BaselineDropScene = () => (
  <BaselineDrop text="Ship the story." stagger={11} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="BaselineDrop"
    component={BaselineDropScene}
    durationInFrames={250}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each word drops from above and lands on a single baseline with a small bounce while a gradient streak draws in and brightens under the line, then retracts. Pass `text` (or `words` for explicit splits) and `stagger` to set the rhythm; it ships light and dark through `theme`.

## Common questions

### How can I have the words of a tagline fall one after another onto a shared baseline in Remotion?

Install Baseline Drop with `npx shadcn@latest add @remocn/baseline-drop` and pass `text`, or `words` for explicit splits. `stagger` sets the frames between words.

### Does it work for long lines?

It is built for one short line. For several rows, use Line By Line Slide.
