## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FeatureTrio } from "@/components/remocn/feature-trio";

const FeatureTrioScene = () => <FeatureTrio items={[{ title: "Fast.", description: "Drop in a scene and render it in minutes." }, { title: "Composable.", description: "Every piece is a React component you can remix." }]} />;

export const RemotionRoot = () => (
  <Composition
    id="FeatureTrio"
    component={FeatureTrioScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each feature title rises from a mask with a note beneath it while progress ticks advance, and at the end all titles resolve into a compact row with their descriptions. Pass `items` (two to four title and description pairs); it spaces the beats to fit the composition length.
