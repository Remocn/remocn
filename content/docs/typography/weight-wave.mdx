## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WeightWave } from "@/components/remocn/weight-wave";

const WeightWaveScene = () => <WeightWave text="Made to move." highlight="move." accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="WeightWave"
    component={WeightWaveScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line of text swells in font weight as a wave sweeps across it twice, then each letter settles to a resting weight while the last word takes a gradient fill. Pass `text`, optionally `highlight` for the word to color, and `from`, `peak`, `settle` to tune the weight range.
