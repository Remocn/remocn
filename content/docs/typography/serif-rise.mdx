## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SerifRise } from "@/components/remocn/serif-rise";

const SerifRiseScene = () => (
  <SerifRise lines={["From rough cut", "to final cut."]} highlight="final cut." />
);

export const RemotionRoot = () => (
  <Composition
    id="SerifRise"
    component={SerifRiseScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Large serif lines rise into place one after another under thin rules, then a sweep lights the highlight phrase in the accent colour. Pass `lines` and `highlight`; it ships light and dark.
