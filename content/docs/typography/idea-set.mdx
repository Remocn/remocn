## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IdeaSet } from "@/components/remocn/idea-set";

const IdeaSetScene = () => <IdeaSet lines={["Rough cut.", "Launch day."]} highlight="Launch day." />;

export const RemotionRoot = () => (
  <Composition
    id="IdeaSet"
    component={IdeaSetScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line rises out of a mask above a hairline rule in light italic. After `hold` frames the glyphs flip one by one to mono, then to medium sans, and the `highlight` phrase takes the accent color. Pass your own `lines`, and set `highlight` to text that appears in them. It ships light and dark.
