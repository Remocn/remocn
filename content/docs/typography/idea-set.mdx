In Remotion, Idea Set is a two-line rough-to-finished beat: both ruled lines rise in light italic, then switch typeface letter by letter, first to mono and then to sans, and one phrase turns the accent color. Use it when the second line is the payoff, such as "Napkin sketch." to "Keynote opener.".

## How to build this in Remotion

You don't need per-letter springs and two `loadFont()` calls of your own. Install the component:

```bash
npx shadcn@latest add @remocn/idea-set
```

Each line rises out of an `overflow: hidden` mask with `interpolate()` and `Easing`, then a per-letter wave from `timeline.ts` swaps the glyphs to mono and on to sans. Line widths are measured on a canvas while `delayRender()` holds the first frame.

## Good to know

- Length: 106 frames of motion at 30 fps (212 at 60 fps) with the default props. The demo plays 150 frames, which adds a hold: frames past the end of the motion hold the final frame. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Fonts: loads IBM Plex Sans (regular and italic) and IBM Plex Mono itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own sans, and load that font in your project.
- `highlight` is matched as text inside the lines (its first occurrence), so it can cover only part of a line.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { IdeaSet } from "@/components/remocn/idea-set";

const IdeaSetScene = () => <IdeaSet lines={["Rough cut.", "Launch day."]} highlight="Launch day." />;

export const RemotionRoot = () => (
  <Composition
    id="IdeaSet"
    component={IdeaSetScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each line rises out of a mask above a hairline rule in light italic. After `hold` frames the glyphs flip one by one to mono, then to medium sans, and the `highlight` phrase takes the accent color. Pass your own `lines`, and set `highlight` to text that appears in them. It ships light and dark.

## Common questions

### How do I make two ruled lines rise in light italic, switch typeface letter by letter and turn one phrase the accent color?

Install Idea Set with `npx shadcn@latest add @remocn/idea-set`, pass `lines` and set `highlight` to text that appears in them.

### Can the highlight cover only part of a line?

Yes. Any text that appears in the lines works; the first match is colored.

### How long is it?

106 frames at 30 fps (212 at 60 fps); the demo plays 150 to hold the result.
