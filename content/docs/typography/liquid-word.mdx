## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LiquidWord } from "@/components/remocn/liquid-word";

const LiquidWordScene = () => <LiquidWord from="idea" to="product" />;

export const RemotionRoot = () => (
  <Composition
    id="LiquidWord"
    component={LiquidWordScene}
    durationInFrames={145}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `from` word holds, then melts under a swirl gradient, sags, drips and slumps into one pool. The `to` word rises out of the pool letter by letter from the center, and the liquid sets into solid ink. Pass `from` and `to` for your own words. It takes a `theme` prop and ships light and dark.
