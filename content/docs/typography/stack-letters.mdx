## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StackLetters } from "@/components/remocn/stack-letters";

const StackLettersScene = () => <StackLetters word="SHIPPED" accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="StackLetters"
    component={StackLettersScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Letters drop in one by one and stack into a tower, which rocks and topples; each letter then tumbles and lands in a row that spells the word, ticking a ground rule as it lands. Pass `word` (a short caps word works best) and `accent`.
