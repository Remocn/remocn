In Remotion, Dot Type draws words like Think, Make, Ship out of round dots: a dot field collapses into the first word, then the same dots fly apart and reform into each next word, quickly, and the last word takes a gradient accent. Use it for a fast sequence of single words in a launch or brand video.

## How to build this in Remotion

You don't need to wire up canvas `getImageData` sampling and `Series` by hand. Install the component and pass your words:

```bash
npx shadcn@latest add @remocn/dot-type
```

Each word is rendered once to an offscreen canvas and sampled with `getImageData` into dot targets; the dots are drawn as SVG paths and moved with `Easing` curves on a schedule from `timeline.ts`. Sampling happens before the first frame, held with `delayRender`.

## Good to know

- Length: 158 frames of motion at 30 fps (316 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 190 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Timing: the field drifts for 14 frames, the first word forms over 32, and each next word takes 34 plus `hold`. Length = 46 + (words − 1) × (34 + hold) at 30 fps; with three words and `hold={22}` that is 158.
- Gradient: the last word runs from `accent` through `#2b3dd8`, `#ff6a3d` and `#ffd9a8` (dark theme). Only `accent` is a prop; `accentLast={false}` keeps the last word plain.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Sora itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotType } from "@/components/remocn/dot-type";

const DotTypeScene = () => (
  <DotType words={["Think.", "Make.", "Ship."]} count={1500} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="DotType"
    component={DotTypeScene}
    durationInFrames={380}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A dot field collapses into the first word, then each next word reforms from the same dots in turn; the final word can take the accent color. Pass `words` and tune `count` for dot density; it ships light and dark through `theme`.

## Common questions

### How can I draw words like Think, Make, Ship out of round dots in Remotion?

Install Dot Type with `npx shadcn@latest add @remocn/dot-type` and pass `words`. `count` sets how many dots make up each word.

### How long does it run?

46 + (words − 1) × (34 + hold) frames at 30 fps: 158 for the defaults. Double it at 60 fps.
