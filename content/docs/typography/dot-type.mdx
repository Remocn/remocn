## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DotType } from "@/components/remocn/dot-type";

const DotTypeScene = () => (
  <DotType words={["Think.", "Make.", "Ship."]} count={1500} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="DotType"
    component={DotTypeScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dot field collapses into the first word, then each next word reforms from the same dots in turn; the final word can take the accent color. Pass `words` and tune `count` for dot density; it ships light and dark through `theme`.
