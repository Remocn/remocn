## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChoreFold } from "@/components/remocn/chore-fold";

const ChoreFoldScene = () => <ChoreFold steps={["Export the audio.", "Fix every timestamp by hand."]} name="Captions" result="does all of that." payoff="You just talk." />;

export const RemotionRoot = () => (
  <Composition
    id="ChoreFold"
    component={ChoreFoldScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A list of tedious manual steps appears line by line, then folds away from the outside in until the middle is left, and the hero sentence swaps in with the tool name highlighted before the payoff line lands. Pass `steps`, `label`, `name`, `result` and `payoff`; it fits the read time to the composition length.
