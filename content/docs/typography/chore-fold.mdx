In Remotion, Chore Fold animates a list of tedious chores folding away and being replaced by one product line, such as "Captions does all of that." with "You just talk." underneath. Use it for a before-and-after or pain-point beat in a product demo or launch video, where the product takes over all the manual work.

## How to build this in Remotion

No need to chain `TransitionSeries` scenes or measure lines with `fitText`. Install the component and pass your chores:

```bash
npx shadcn@latest add @remocn/chore-fold
```

It is one scene. The schedule in `timeline.ts` brings the steps in word by word, folds them from the outside in, then swaps in the hero sentence and the payoff; each move is an `interpolate()` over an `Easing` curve. Line breaks are measured before the first frame (held with `delayRender`), so nothing reflows while it plays.

## Good to know

- Length: 146 frames of motion at 30 fps (292 at 60 fps) with the default props. The demo composition plays 180 frames, which adds a hold. It fits the read time to the composition, so a longer `durationInFrames` slows the list instead of freezing at the end. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Geologica itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Only the `name` words ("Captions") take the accent; `result` and `payoff` stay in the ink color. The default accent is teal: `#4FE3D0` on the dark theme's `#0E3B43` ground, `#0F8C7E` in light. Pass `accent` for your brand color.
- `steps` is your own list of chores; the defaults are five caption chores such as "Export the audio." and "Fix every timestamp by hand."

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChoreFold } from "@/components/remocn/chore-fold";

const ChoreFoldScene = () => <ChoreFold steps={["Export the audio.", "Fix every timestamp by hand."]} name="Captions" result="does all of that." payoff="You just talk." />;

export const RemotionRoot = () => (
  <Composition
    id="ChoreFold"
    component={ChoreFoldScene}
    durationInFrames={360}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How do I animate a list of chores being folded away and replaced by one line?

Install Chore Fold with `npx shadcn@latest add @remocn/chore-fold`, pass `steps` (the chores), `name` and `result` (the line that replaces them) and `payoff` (the line underneath).

### Is the whole sentence teal?

No. Only `name` is highlighted in the accent; the rest of the sentence is ink.

### Can I change the teal?

Yes, pass `accent`. The default is `#4FE3D0` in dark and `#0F8C7E` in light.
