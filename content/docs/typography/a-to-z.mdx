## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AToZ } from "@/components/remocn/a-to-z";

const AToZScene = () => (
  <AToZ
    entries={["animations.", "brand fonts.", "captions."]}
    finale="zero lock-in."
    connector="is for"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AToZ"
    component={AToZScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A huge letter column and a text column roll together: each entry shows its first letter with the connector, for example "A is for any aspect ratio.", ticking through the list. After the last entry the letters flick through the gap to the finale, and a slower roll lands on it. Pass `entries` in alphabetical order, plus `finale` and `connector`; it ships light and dark through `theme`, and the pacing stretches to fit the composition's duration (128 frames at the default 165).
