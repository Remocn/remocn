In Remotion, A to Z is an alphabet gag: a huge letter column rolls like a slot machine next to a text column, so each feature reads "A is for…", "B is for…", and the roll flicks through the remaining letters to land on a final Z entry. Use it for a playful feature recap or a closing punchline in a launch or changelog video.

## How to build this in Remotion

You don't have to hand-roll it with `spring()`, `Series` and a translateY slot-machine list. Install the component and pass your entries:

```bash
npx shadcn@latest add @remocn/a-to-z
```

Under the hood it is one scene, not a `Sequence` per letter: the schedule in `timeline.ts` gives each entry a start frame, and the letter and text columns roll with `interpolate()` over an `Easing.bezier` curve, clamped at both ends. Text widths are measured on a canvas before the first frame (held with `delayRender`), so a long entry wraps without the layout jumping.

## Good to know

- Length: 128 frames of motion at 30 fps (256 at 60 fps) with the default props; the demo plays 165 frames, which adds a hold. The pacing stretches to fit whatever `durationInFrames` you give it, so a longer composition rolls slower rather than freezing. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- The big letter is always the first letter of each entry. The finale is not forced to Z: it lands on the first letter of `finale`, so "zero lock-in." ends on Z and "you." would end on Y. The flick runs through every letter between the last entry and the finale.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Unbounded itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AToZ } from "@/components/remocn/a-to-z";

const AToZScene = () => (
  <AToZ
    entries={["animations.", "brand fonts.", "captions."]}
    finale="zero lock-in."
    connector="is for"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AToZ"
    component={AToZScene}
    durationInFrames={330}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A huge letter column and a text column roll together: each entry shows its first letter with the connector, for example "A is for any aspect ratio.", ticking through the list. After the last entry the letters flick through the gap to the finale, and a slower roll lands on it. Pass `entries` in alphabetical order, plus `finale` and `connector`; it ships light and dark through `theme`, and the pacing stretches to fit the composition's duration (128 frames at the default 165).

## Common questions

### Is there a way in Remotion to do an alphabet gag where letters roll from A to Z?

Yes. A to Z rolls a tall column of letters from A toward Z while each feature starts with the next letter, then lands on a final item. Install it with `npx shadcn@latest add @remocn/a-to-z` and pass `entries` in alphabetical order plus a `finale`.

### Does the last item have to start with Z?

No. The roll lands on the first letter of `finale`. Start it with Z for the full alphabet joke.

### How long should the composition be?

At least 128 frames at 30 fps (256 at 60 fps). Anything longer stretches the rolls and the final hold.
