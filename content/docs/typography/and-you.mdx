## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AndYou } from "@/components/remocn/and-you";

const AndYouScene = () => <AndYou clauses={["For the founder who launches on Monday,", "the designer who just learned React,", "the two-person studio,"]} last="and you." />;

export const RemotionRoot = () => (
  <Composition
    id="AndYou"
    component={AndYouScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A list of audiences scrolls in clause by clause, each one stacking under the last, then they dim and a big closing phrase rises at the bottom of the frame. Pass `clauses` (one string per audience) and `last` for the closing words; it spaces the clauses to fit the composition length.
