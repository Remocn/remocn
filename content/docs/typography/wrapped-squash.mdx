## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WrappedSquash } from "@/components/remocn/wrapped-squash";

const WrappedSquashScene = () => (
  <WrappedSquash lines={["WE", "SHIPPED", "IT ALL"]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WrappedSquash"
    component={WrappedSquashScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Line one grows to fill the frame, then each further line arrives on a 26-frame beat and squeezes the lines above it, and a spring lock settles every block to its final height. Blocks alternate between a window onto a shared gradient and a solid fill. Pass `lines` (two or three, set in caps); use `colors` for a flat two-color pair. It ships light and dark through `theme`, and with two lines the lock lands earlier (frame 67).
