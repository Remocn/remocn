## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RoundSlam } from "@/components/remocn/round-slam";

const RoundSlamScene = () => <RoundSlam round="ROUND 2" call="DEPLOY!" />;

export const RemotionRoot = () => (
  <Composition
    id="RoundSlam"
    component={RoundSlamScene}
    durationInFrames={110}
    fps={30}
    width={1280}
    height={720}
  />
);
```

'ROUND' then the number slam in with echoes and a shake, hold with a slow push, then the call ducks up to a label. The `call` word punches in bigger, cracks along a diagonal, and speed slashes open a band behind it before the logo rises. Pass `round` and `call`; it ships light and dark through `theme`.
