## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PointIntro } from "@/components/remocn/point-intro";

const PointIntroScene = () => <PointIntro title="Introducing Acme 2.0" accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="PointIntro"
    component={PointIntroScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A colored point appears alone, breathes, then glides to the end of the line while the headline is written word by word and the point settles as its full stop. A grey subline fades in last. Pass `title` and `subline` for your own announcement; it ships light and dark.
