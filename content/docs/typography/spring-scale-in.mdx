In Remotion, Spring Scale In makes the words of a headline pop in one after another with a bouncy overshoot: each word scales up past full size and settles back, like a spring. Use it for a product launch title, a celebration moment or a fun call to action.

## Good to know

- Length: 60 frames of motion at 30 fps (120 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file; a `className` font does not override an inline style.
- The overshoot comes from a back-out easing curve (`Easing.bezier(0.34, 1.56, 0.64, 1)`), not `spring()`, so each word lands on an exact frame. Tune it with `scaleFrom` and `staggerDelay`, or edit that curve in the copied file for more or less bounce.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpringScaleIn } from "@/components/remocn/spring-scale-in";

const SpringScaleInScene = () => (
  <SpringScaleIn text="Fast. Crisp. Fluid." staggerDelay={3} scaleFrom={0.7} />
);

export const RemotionRoot = () => (
  <Composition
    id="SpringScaleIn"
    component={SpringScaleInScene}
    durationInFrames={120}
    fps={60}
    width={1280}
    height={720}
  />
);
```

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. It ships single-theme; edit the copied file to re-theme colors.

Pair with `Backdrop` to place the text inside a full-frame fill with a rounded, shadowed content frame:

```tsx
import { Composition } from "remotion";
import { SpringScaleIn } from "@/components/remocn/spring-scale-in";
import { Backdrop } from "@/components/remocn/backdrop";

const SpringScaleInScene = () => (
  <Backdrop fill={{ type: "color", value: "#ffffff" }}>
    <SpringScaleIn text="Fast. Crisp. Fluid." staggerDelay={3} scaleFrom={0.7} />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="SpringScaleIn"
    component={SpringScaleInScene}
    durationInFrames={120}
    fps={60}
    width={1280}
    height={720}
  />
);
```
