## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Nonstop } from "@/components/remocn/nonstop";

const NonstopScene = () => (
  <Nonstop label="From idea to export" from={3} unit="stops" />
);

export const RemotionRoot = () => (
  <Composition
    id="Nonstop"
    component={NonstopScene}
    durationInFrames={185}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A label sits above a counter that rolls down from `from` to zero beside `unit`, then the line resolves into the large phrase. Pass `label`, `from` and `unit` to count your own steps. It ships in light and dark through the `theme` prop.
