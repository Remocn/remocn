## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpotlightText } from "@/components/remocn/spotlight-text";

const SpotlightTextScene = () => (
  <SpotlightText title="Launch videos, in code." eyebrow="remocn 2.0" />
);

export const RemotionRoot = () => (
  <Composition
    id="SpotlightText"
    component={SpotlightTextScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A soft spotlight enters and glides across the single-line headline, lighting it as it passes and widening until the whole line is lit. Pass `title` and `eyebrow`; it ships light and dark.
