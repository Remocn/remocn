In Remotion, Blur Out Up makes a title appear cleanly word by word, hold, and then leave by drifting upward with the words getting more blurred. Use it as an airy exit for a title or tagline before the next scene cuts in.

## How to build this in Remotion

You don't need `@remotion/transitions` for the exit. Install the component and pass your text:

```bash
npx shadcn@latest add @remocn/blur-out-up
```

Each word fades and moves with `interpolate()` on `Easing.bezier` curves, and the exit adds a CSS `filter: blur()`. The schedule in `timeline.ts` places the exit at the end of the composition, so no `premountFor` or `Sequence` juggling is needed.

## Good to know

- Length: 90 frames of motion at 30 fps (180 at 60 fps) with the default props. The exit is timed to end with the composition, so a longer composition holds the title longer before it leaves. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- There is no prop for the exit start or duration: it begins 14 frames (30 fps) plus the word stagger before the composition ends. Change the length of its `Sequence` to move it, or the `EXIT` constant in `timeline.ts` to change its duration.
- Font: Geist Sans through the `--font-geist-sans` CSS variable, with a system sans fallback. The font is set inline, so change it in the copied file; a `className` font does not override an inline style.
- Recolor with the `color` prop.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BlurOutUp } from "@/components/remocn/blur-out-up";

const BlurOutUpScene = () => (
  <BlurOutUp text="Clear in, airy out." staggerDelay={1} />
);

export const RemotionRoot = () => (
  <Composition
    id="BlurOutUp"
    component={BlurOutUpScene}
    durationInFrames={180}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each word fades and slides in cleanly, holds steady in the middle of the composition, then drifts upward with increasing blur near the end—so the duration should leave room for the exit animation.

### With Backdrop

The component renders transparent — supply the background via `Backdrop`. It ships single-theme; edit the copied file to re-theme colors.

Pair with `Backdrop` to place the text inside a full-frame fill with a rounded, shadowed content frame:

```tsx
import { Composition } from "remotion";
import { BlurOutUp } from "@/components/remocn/blur-out-up";
import { Backdrop } from "@/components/remocn/backdrop";

const BlurOutUpScene = () => (
  <Backdrop fill={{ type: "color", value: "#ffffff" }}>
    <BlurOutUp text="Clear in, airy out." staggerDelay={1} />
  </Backdrop>
);

export const RemotionRoot = () => (
  <Composition
    id="BlurOutUp"
    component={BlurOutUpScene}
    durationInFrames={180}
    fps={60}
    width={1280}
    height={720}
  />
);
```

## Common questions

### How can I make a title in Remotion appear cleanly and leave by drifting upward with the words blurring?

Install Blur Out Up with `npx shadcn@latest add @remocn/blur-out-up` and pass `text`. The exit is timed to the end of the composition.

### How do I control when the exit starts?

Set the length of the `Sequence` that holds it: the exit ends with that `Sequence`.
