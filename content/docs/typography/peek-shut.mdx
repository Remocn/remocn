## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PeekShut } from "@/components/remocn/peek-shut";

const PeekShutScene = () => (
  <PeekShut
    question="Want a peek?"
    refusal="That is all you get."
    when="The rest, Monday."
    src="/product-shot.png"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PeekShut"
    component={PeekShutScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The question rises above a hairline that opens into a narrow slit showing a slow-panning crop of an image, then the slit snaps shut and the `refusal` and `when` lines rise below it, the last in the accent color. The default image is `hero.png` from the Remocn repo, so pass your own 16:9 screenshot through `src`. Timing compresses if the composition is shorter than about 160 frames. It ships light and dark.
