## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MovesUp } from "@/components/remocn/moves-up";

const MovesUpScene = () => (
  <MovesUp
    items={["Captions", "Voiceover", "Vertical cuts", "Brand kits", "Templates"]}
    shipped="live"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MovesUp"
    component={MovesUpScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The first three `items` settle under the Now, Next and Later labels at descending sizes. Every item past the third then advances the queue: the current Now item gets a `shipped` tag and exits upward while the others move up and enlarge. Pass five or more `items` to see movement; timing adapts to the composition length, and 152 frames is the uncompressed length for five items. It ships light and dark.
