## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DropTimer } from "@/components/remocn/drop-timer";

const DropTimerScene = () => (
  <DropTimer label="DROPS IN" from={5} live="LIVE NOW" url="acme.dev" />
);

export const RemotionRoot = () => (
  <Composition
    id="DropTimer"
    component={DropTimerScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A clock counts down from `from` seconds, one film second per `tick` frames, and at zero it smashes into a full-bleed gradient payoff with your name, URL and a live dot. Pass `label`, `from`, `live`, `name` and `url`; it ships light and dark.
