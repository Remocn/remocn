## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FinePrintUp } from "@/components/remocn/fine-print-up";

const FinePrintUpScene = () => <FinePrintUp lines={["Every component you install is a file you own.", "No account and no watermark. Ever."]} closing="That’s all the fine print." />;

export const RemotionRoot = () => (
  <Composition
    id="FinePrintUp"
    component={FinePrintUpScene}
    durationInFrames={300}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line is set big in turn with a star mark, then shrinks and travels down to the fine print at the bottom of the frame, and finally the closing line lands big. Pass `lines` (the claims) and `closing`; it spaces the lines to fit the composition length.
