In Remotion, Depth Headline puts a huge serif headline behind a gradient sphere that rises in front of it, so the title feels layered with depth. Use it for a product name or hero word, and pass a transparent cutout image with `src` to put your own product in front of the type instead of the sphere.

## How to build this in Remotion

You don't need `@remotion/three` or React Three Fiber for this; it is flat layers in z order. Install the component:

```bash
npx shadcn@latest add @remocn/depth-headline
```

The headline, the sphere (or your `<Img>` cutout) and the caption are stacked layers moved with `interpolate()` and `Easing` curves. The sphere is a CSS mesh gradient, so there is no WebGL to render.

## Good to know

- Length: 62 frames of motion at 30 fps (124 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 120 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Sphere colors: a mesh of `#ecdcf2` lilac, `#8796ee` periwinkle and `#0e1645` navy with `accent` (`#3B5BFD` by default) as the main blue; only `accent` is a prop.
- The sphere rises from the bottom of the frame; its path has no prop. `riseFrames` sets how long the rise takes.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Fraunces and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DepthHeadline } from "@/components/remocn/depth-headline";

const DepthHeadlineScene = () => (
  <DepthHeadline title="Studio" caption="Studio" showLogo accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="DepthHeadline"
    component={DepthHeadlineScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The headline opens and rises behind a sphere that glides across the frame, with a caption and logo fading in underneath. Pass `title` and `caption`, and pass `src` with a transparent cutout image to replace the default sphere; it ships light and dark through `theme`.

## Common questions

### How do I get a huge serif headline to sit behind a sphere so it feels layered?

Install Depth Headline with `npx shadcn@latest add @remocn/depth-headline`, pass `title`, and either keep the gradient sphere or pass `src` with a transparent PNG.

### Do I need to load Fraunces?

No. The component loads Fraunces and Manrope itself through `@remotion/google-fonts`.
