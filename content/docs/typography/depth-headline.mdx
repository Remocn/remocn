## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DepthHeadline } from "@/components/remocn/depth-headline";

const DepthHeadlineScene = () => (
  <DepthHeadline title="Studio" caption="Studio" showLogo accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="DepthHeadline"
    component={DepthHeadlineScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The headline opens and rises behind a sphere that glides across the frame, with a caption and logo fading in underneath. Pass `title` and `caption`, and pass `src` with a transparent cutout image to replace the default sphere; it ships light and dark through `theme`.
