In Remotion, Kerning Snap animates loose, scattered letters that snap one by one into proper kerning and form a gradient serif word. Use it for a beat about typesetting, design craft or polish.

## How to build this in Remotion

You don't need `measureText()` or a staggered `spring()` of your own. Install the component and pass your word:

```bash
npx shadcn@latest add @remocn/kerning-snap
```

Each letter's snap is an element in `timeline.ts`; the snap itself is a Remotion `spring()`, and the drift and flash ticks use `interpolate()` over `Easing` curves. The gradient is one continuous fill across the word, so it only reads whole once every letter is set.

## Good to know

- Length: 80 frames of motion at 30 fps (160 at 60 fps) with the default props; the demo plays 120 frames, which adds a hold. The first letter snaps at `firstSnap` (30) and the rest follow every `interval` (7) frames, so the word is set at about `firstSnap + interval × (letters − 1)`. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Fraunces itself through `@remotion/google-fonts`. The layout uses Fraunces metrics, so another `fontFamily` may set looser or tighter; load any other face in your project.
- Gradient: dark is `#FFF4EC` → `#FFB36B` → `#E2457A` → `#8F6BFF`, light is `#F07A2A` → `#E2457A` → `#3D4DFF`. There is no prop for the stops: `ink` swaps the gradient for one solid color, and other stops mean editing `THEMES` in the copied file. `accent` only colors the flash ticks.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KerningSnap } from "@/components/remocn/kerning-snap";

const KerningSnapScene = () => (
  <KerningSnap word="Kerning" interval={6} />
);

export const RemotionRoot = () => (
  <Composition
    id="KerningSnap"
    component={KerningSnapScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Letters start scattered and loose across the frame; from the center outward, each one springs into its kerned position every `interval` frames with a brief flash on the snap ticks, and the gradient fill reads whole once the word is set. Pass `word` and tune `interval` for pacing; it ships light and dark through `theme`.

## Common questions

### How do I animate scattered letters snapping into kerning in Remotion?

Install Kerning Snap with `npx shadcn@latest add @remocn/kerning-snap` and pass `word`. Letters drift loose, then snap into place one by one with a spring.

### Can I change the gradient colors?

Not through props. Pass `ink` for a solid color, or edit the gradient in `THEMES` in the copied file.
