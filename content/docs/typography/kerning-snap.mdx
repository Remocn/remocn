## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { KerningSnap } from "@/components/remocn/kerning-snap";

const KerningSnapScene = () => (
  <KerningSnap word="Kerning" interval={6} />
);

export const RemotionRoot = () => (
  <Composition
    id="KerningSnap"
    component={KerningSnapScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Letters start scattered and loose across the frame; from the center outward, each one springs into its kerned position every `interval` frames with a brief flash on the snap ticks, and the gradient fill reads whole once the word is set. Pass `word` and tune `interval` for pacing; it ships light and dark through `theme`.
