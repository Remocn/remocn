## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoverRing } from "@/components/remocn/cover-ring";

const CoverRingScene = () => (
  <CoverRing
    images={[staticFile("shots/one.jpg"), staticFile("shots/two.jpg")]}
    line="Launch videos aren't edited anymore"
    caption="They're composed."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CoverRing"
    component={CoverRingScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Photo tiles flip in around a setup line, the line blurs away as the tiles collapse into a bar meter, and the caption lands with a pulse. Pass `images` with your own image paths (the defaults only exist in the remocn repo), plus `line` and `caption`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
