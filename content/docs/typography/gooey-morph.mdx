  - "The style is crisp and geometric rather than liquid — use `kinetic-center-build`."

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GooeyMorph } from "@/components/remocn/gooey-morph";

const GooeyMorphScene = () => (
  <GooeyMorph word="HELLO" fontFamily="'Bodoni Moda', Georgia, serif" />
);

export const RemotionRoot = () => (
  <Composition
    id="GooeyMorph"
    component={GooeyMorphScene}
    durationInFrames={120}
    fps={30}
    width={1920}
    height={1080}
  />
);
```

The melt works by blurring the alpha channel and pushing it through a
near-vertical threshold: where two shapes sit close, their blurred edges add up,
cross the threshold, and paint a solid neck between them. Everything that
should fuse lives inside the component's single filtered group — nearby
elements outside it never join the goo.
