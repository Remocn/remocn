## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RiddleClues } from "@/components/remocn/riddle-clues";

const RiddleCluesScene = () => (
  <RiddleClues
    clues={[
      { line: "It has scenes,", turn: "but no camera." },
      { line: "It has a timeline,", turn: "but no editor." },
    ]}
    closer={{ line: "Give up?", turn: "Answer on the 14th." }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RiddleClues"
    component={RiddleCluesScene}
    durationInFrames={230}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each clue shows a small numbered label and a `line` in white; a beat later its `turn` rises in the accent color beside or below it, then the clue lifts out and the next arrives. The `closer` is the last frame and stays on screen. Pass `clues` and `closer` as `{ line, turn }` pairs. Timing compresses if the composition is shorter than the 214 frames plus a short hold. It ships light and dark.
