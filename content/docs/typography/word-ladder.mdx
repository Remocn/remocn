## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordLadder } from "@/components/remocn/word-ladder";

const WordLadderScene = () => (
  <WordLadder words={["idea", "item", "stem", "step", "ship"]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordLadder"
    component={WordLadderScene}
    durationInFrames={186}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word in `words` replaces the last by changing a letter or two, stepping from the first rung to the last. Pass `words` as a chain where neighbors differ slightly. It ships in light and dark through the `theme` prop.
