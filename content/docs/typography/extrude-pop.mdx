In Remotion, Extrude Pop makes a single short word, like a score or a verdict, pop up off the page on a solid colored 3D extruded body, without a camera move. It is a flat 2D effect for a poster-style CTA, verdict or score beat.

## How to build this in Remotion

You don't need `@remotion/three`, react-three-fiber, `TextGeometry` or `Text3D`. Install the component and pass your word:

```bash
npx shadcn@latest add @remocn/extrude-pop
```

The body is a stack of SVG `text` copies offset along a fixed angle, so it renders the same in every browser and every Remotion render. One `interpolate()` with an `Easing.bezier` ease-out grows the extrusion depth; the word is fitted to `maxTextWidth` with a canvas text measurement.

## Good to know

- Length: 48 frames of motion at 30 fps (96 at 60 fps) with the default props. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: a system stack, `'Helvetica Neue', Helvetica, Arial, sans-serif`, so there is nothing to load. Pass `fontFamily` for your own face and load it in your project.
- Colors: `bodyColor` defaults to `#e8192b` and `faceColor` to `#ffffff`. The extrusion angle is `extrudeAngleDeg` (default −58.6) and the smoothness is `extrudeSteps` (default 200 layers).
- The timing is `extrudeStartFrame` and `extrudeEndFrame` (0 and 48 by default); after that the word holds.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ExtrudePop } from "@/components/remocn/extrude-pop";

const ExtrudePopScene = () => (
  <ExtrudePop letter="WIN" bodyColor="#e8192b" faceColor="#ffffff" />
);

export const RemotionRoot = () => (
  <Composition
    id="ExtrudePop"
    component={ExtrudePopScene}
    durationInFrames={180}
    fps={60}
    width={1920}
    height={1080}
  />
);
```

The body is the same glyph swept along the extrusion vector — a morphological
dilation drawn as stacked copies, back-to-front, with the white face riding the
near end. Face travel and extrusion depth are keyframed together, which is what
makes the word read as lifting off a plane rather than growing a shadow.

## Common questions

### How do I make a short word pop off the page with a solid 3D extruded body in Remotion, without a camera move?

Install Extrude Pop with `npx shadcn@latest add @remocn/extrude-pop` and pass the word as `letter`. A solid colored body grows behind the face over 48 frames; no three.js is involved.

### Can it handle a whole sentence?

Keep it to one short word. The extruded body doubles the ink and long or small text turns to mush.

### Can I change the color and angle?

Yes: `bodyColor`, `faceColor`, `extrudeAngleDeg` and `extrudeSteps` are props.
