## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EnhanceCount } from "@/components/remocn/enhance-count";

const EnhanceCountScene = () => (
  <EnhanceCount text={"Draft it fast.\nFinish it sharp."} highlight="sharp." />
);

export const RemotionRoot = () => (
  <Composition
    id="EnhanceCount"
    component={EnhanceCountScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The text enters thin and blurred, then each glyph sharpens and gains weight in a quick sweep so the line reads as finished. Pass `text` (use a newline for a second line) and `highlight` for the accented words; it ships light and dark through `theme`.
