In Remotion, Enhance Count makes text start as a blurry, thin line and sharpen into a heavier weight, glyph by glyph, with the last word in an accent color, like a draft becoming polished. Use it for a before-and-after message about quality.

## How to build this in Remotion

You don't need to set up a variable font with `@remotion/google-fonts` yourself. Install the component:

```bash
npx shadcn@latest add @remocn/enhance-count
```

Each glyph's sharpening is a `spring()` that drives both a CSS `blur()` and the `wght` axis through `fontVariationSettings`, sweeping across the text over `span` frames; the rest runs on `interpolate()` and `Easing` curves.

## Good to know

- Length: 87 frames of motion at 30 fps (174 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top (the demo plays 120 frames). The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Accent: `#6D5BFF` in both themes; pass `accent` to change it.
- The weight animation needs a variable font with a `wght` axis. The default Inter Tight is loaded as a variable font; if you pass `fontFamily`, load a variable face too.
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Inter Tight itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EnhanceCount } from "@/components/remocn/enhance-count";

const EnhanceCountScene = () => (
  <EnhanceCount text={"Draft it fast.\nFinish it sharp."} highlight="sharp." />
);

export const RemotionRoot = () => (
  <Composition
    id="EnhanceCount"
    component={EnhanceCountScene}
    durationInFrames={240}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The text enters thin and blurred, then each glyph sharpens and gains weight in a quick sweep so the line reads as finished. Pass `text` (use a newline for a second line) and `highlight` for the accented words; it ships light and dark through `theme`.

## Common questions

### How do I make text start blurry and thin and sharpen into a heavier weight in Remotion?

Install Enhance Count with `npx shadcn@latest add @remocn/enhance-count`, pass `text` and the `highlight` words. `draftWeight` and `fontWeight` set the start and end weight.

### Which font works?

Any variable font with a weight axis. Inter Tight is loaded for you.
