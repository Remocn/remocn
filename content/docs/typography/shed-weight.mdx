## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShedWeight } from "@/components/remocn/shed-weight";

const ShedWeightScene = () => <ShedWeight text="Sharp at any size." sizes={5} />;

export const RemotionRoot = () => (
  <Composition
    id="ShedWeight"
    component={ShedWeightScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The same line is stacked at a growing size ladder, each row drawing in under a hairline rule with a small point-size label, and every size uses its own optical cut. Pass `text` and `sizes` for the number of rows; `showSizes` toggles the labels. It takes a `theme` prop and ships light and dark.
