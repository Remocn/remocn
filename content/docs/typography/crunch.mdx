## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Crunch } from "@/components/remocn/crunch";

const CrunchScene = () => <Crunch setup={{ slug: "Monday, 10:00 AM", line: "Maya had a launch on Friday." }} snag={{ slug: "Thursday, 11:40 PM", line: "Nine hours left, and still no video." }} />;

export const RemotionRoot = () => (
  <Composition
    id="Crunch"
    component={CrunchScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A timestamped story plays in three beats: a setup line fades out, a tense snag line sits in a column that squeezes tighter and tighter, then the walls release and a calm resolution line arrives. Pass `setup`, `snag` and `resolution`, each with a `slug` (timestamp) and `line`; beats stretch with the composition length.
