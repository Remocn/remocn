## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordStack } from "@/components/remocn/word-stack";

const WordStackScene = () => (
  <WordStack words={["Write", "it", "once", "ship", "it", "everywhere"]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordStack"
    component={WordStackScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word pushes in from below on its own beat, and the earlier words in the stack shift up and out to make room. The last word swaps to a serif italic with a gradient sheen that slowly drifts while the poster holds. Pass `words` as a list of short words; it ships light and dark through `theme`.
