## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UnmaskLine } from "@/components/remocn/unmask-line";

const UnmaskLineScene = () => <UnmaskLine lines={["Out of", "stealth."]} highlight={-1} />;

export const RemotionRoot = () => (
  <Composition
    id="UnmaskLine"
    component={UnmaskLineScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Dots appear for each letter, breathe, then open into monospace characters line by line, with the chosen line tinted green. Pass `lines` and `highlight` (a line index; -1 means the last line); it ships light and dark.
