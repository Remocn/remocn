## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HiddenWord } from "@/components/remocn/hidden-word";

const HiddenWordScene = () => (
  <HiddenWord
    text="Every founder deserves a launch video that feels expensive."
    word="love"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HiddenWord"
    component={HiddenWordScene}
    durationInFrames={186}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The sentence fades in line by line, the letters of `word` light up in order inside it, the rest dims, and each lit letter lifts out and flies into place to form a large serif italic word. Pass `text` (it must contain the letters of `word` in order, case-insensitive) and `word`; it ships light and dark through `theme`.
