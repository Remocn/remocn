## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LightsOut } from "@/components/remocn/lights-out";

const LightsOutScene = () => (
  <LightsOut title="SHIP IT." beat={10} hold={24} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="LightsOut"
    component={LightsOutScene}
    durationInFrames={112}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Five lights light up on the beat, hold, then go out and the headline slams in with a camera push and an accent period. Pass `title` (set in capitals), `beat` for the light interval and `hold` for the pause before they go out; it ships light and dark through `theme`.
