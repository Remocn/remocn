## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EmbargoLift } from "@/components/remocn/embargo-lift";

const EmbargoLiftScene = () => <EmbargoLift lines={["remocn is [free],", "[open source]", "and [out today]."]} slug="Embargoed until 9:00 a.m." liftedSlug="Embargo lifted, 9:00 a.m." />;

export const RemotionRoot = () => (
  <Composition
    id="EmbargoLift"
    component={EmbargoLiftScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The lines show with bracketed phrases hidden behind redaction bars under an embargo slug; the slug flips to the lifted version and the bars lift one at a time to reveal the words. Mark hidden phrases in `lines` with square brackets, and pass `slug`, `liftedSlug` and `highlight` (the bar that gets the accent).
