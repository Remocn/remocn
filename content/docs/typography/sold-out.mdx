## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SoldOut } from "@/components/remocn/sold-out";

const SoldOutScene = () => <SoldOut stock={64} unit="LEFT" stamp="SOLD OUT" tail="every launch." />;

export const RemotionRoot = () => (
  <Composition
    id="SoldOut"
    component={SoldOutScene}
    durationInFrames={155}
    fps={30}
    width={1280}
    height={720}
  />
);
```

'128 LEFT' punches in, the reels race down to ten, then tick down hard with a LOW STOCK flash and red figures. At zero the diagonal band slams across with the stamp, and a subline rises. Pass `stock`, `unit`, `stamp`, `lead` and `tail`; it ships light and dark through `theme`.
