## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StrobeWords } from "@/components/remocn/strobe-words";

const StrobeWordsScene = () => <StrobeWords words={["Plan.", "Write.", "Render.", "Ship."]} accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="StrobeWords"
    component={StrobeWordsScene}
    durationInFrames={115}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The words cycle on hard cuts across glow, dark and light fields, with beats that start slow and tighten, then the last word holds as a poster with the logo below. Pass `words` and optionally `rhythm` (frames per cut) and `logo`; it ships light and dark through `theme`.
