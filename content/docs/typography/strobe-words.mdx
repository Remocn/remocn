In Remotion, Strobe Words is a fast opener: big verbs such as Plan, Write, Render, Ship flash one after another on strobing color fields at a tightening, accelerating rhythm, then land on a poster with your logo. Use it as a hype intro for a launch video.

## Good to know

- Length: 128 frames of motion at 30 fps (256 at 60 fps) with the default props: 68 frames of strobe cuts, then the poster with the last word and the logo, whose glow rises for 60 more frames. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Manrope and Sora itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- `logo` takes any React node, so a real asset works: `logo={<Img src={staticFile("logo.svg")} style={{ height: 64 }} />}`.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StrobeWords } from "@/components/remocn/strobe-words";

const StrobeWordsScene = () => <StrobeWords words={["Plan.", "Write.", "Render.", "Ship."]} accent="#3B5BFD" />;

export const RemotionRoot = () => (
  <Composition
    id="StrobeWords"
    component={StrobeWordsScene}
    durationInFrames={230}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The words cycle on hard cuts across glow, dark and light fields, with beats that start slow and tighten, then the last word holds as a poster with the logo below. Pass `words` and optionally `rhythm` (frames per cut) and `logo`; it ships light and dark through `theme`.
