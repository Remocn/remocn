## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CaretLetter } from "@/components/remocn/caret-letter";

const CaretLetterScene = () => (
  <CaretLetter
    word="launch"
    stemIndex={0}
    subline="Ship the demo video in an afternoon."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CaretLetter"
    component={CaretLetterScene}
    durationInFrames={225}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A caret blinks in and types the word except for one letter, slides over to that spot, the word opens to make room, and the caret morphs into the letter, then a grey subline fades in. Pass `word` and `stemIndex` (the letter the caret turns into; pick a plain stem such as l, I or 1), plus `subline` and `accent`. It ships light and dark through `theme`, defaulting to light.
