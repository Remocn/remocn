## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FactorOut } from "@/components/remocn/factor-out";

const FactorOutScene = () => <FactorOut heads={["Write the scenes", "Pick the colors", "Fix the typos"]} tail="in your editor." />;

export const RemotionRoot = () => (
  <Composition
    id="FactorOut"
    component={FactorOutScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Short imperative lines enter one by one and align, then the shared tail merges out of them: lines collapse one at a time until a single stack sits above a big tail phrase. Pass `heads` (the repeated beginnings) and `tail` (the shared ending).
