## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EditRipple } from "@/components/remocn/edit-ripple";

const EditRippleScene = () => <EditRipple pairs={[{ cause: "Change one word,", effect: "every scene follows." }, { cause: "Swap the color,", effect: "every shot repaints." }]} />;

export const RemotionRoot = () => (
  <Composition
    id="EditRipple"
    component={EditRippleScene}
    durationInFrames={230}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each pair appears as a cause line followed by an effect line, and the effect words recolor in a ripple from left to right; then the pair exits and the next pair follows. Pass `pairs` (cause and effect strings); it spaces the pairs to fit the composition length.
