## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { EscalateCards } from "@/components/remocn/escalate-cards";

const EscalateCardsScene = () => (
  <EscalateCards words={["ONE", "CODEBASE", "EVERY", "LAUNCH"]} date="OCTOBER 30" accel={0.6} />
);

export const RemotionRoot = () => (
  <Composition
    id="EscalateCards"
    component={EscalateCardsScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

One word per card flashes in, each card shorter than the last, until the final word fills the frame and a date cuts in under it. Pass `words`, `date`, `firstBeat` and `accel`; it ships light and dark.
