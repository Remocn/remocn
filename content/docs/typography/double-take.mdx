## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DoubleTake } from "@/components/remocn/double-take";

const DoubleTakeScene = () => <DoubleTake text="One person wrote this entire launch video over a single lunch break." focus="One person" cue="Read that again." />;

export const RemotionRoot = () => (
  <Composition
    id="DoubleTake"
    component={DoubleTakeScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line crawls in word by word, stops, then rewinds and zooms back onto one phrase, which lights up in the accent color over a small cue line. Pass `text`, `focus` (the phrase to land on) and `cue`; it compresses to fit the composition length.
