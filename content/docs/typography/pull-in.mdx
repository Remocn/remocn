## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PullIn } from "@/components/remocn/pull-in";

const PullInScene = () => (
  <PullIn lead="Now in" places={["vertical.", "4K.", "your codebase."]} hold={24} />
);

export const RemotionRoot = () => (
  <Composition
    id="PullIn"
    component={PullInScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `lead` phrase holds while each entry in `places` pulls into view from a wide spread and then departs for the next. Pass `lead` and `places`, and tune `hold` for pace. It ships in light and dark through the `theme` prop.
