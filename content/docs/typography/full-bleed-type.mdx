## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FullBleedType } from "@/components/remocn/full-bleed-type";

const FullBleedTypeScene = () => (
  <FullBleedType words={["NO", "DAYS", "OFF", "SHIP"]} beat={11} />
);

export const RemotionRoot = () => (
  <Composition
    id="FullBleedType"
    component={FullBleedTypeScene}
    durationInFrames={96}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each word slams in huge in condensed caps, one per `beat` frames, and the last word is lit by a sunrise gradient. Pass `words` and `beat`; it ships light and dark.
