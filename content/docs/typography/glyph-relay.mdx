## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlyphRelay } from "@/components/remocn/glyph-relay";

const GlyphRelayScene = () => (
  <GlyphRelay line1={["Building a", "product"]} line2={["is", "easy."]} line3="Launching it?" />
);

export const RemotionRoot = () => (
  <Composition
    id="GlyphRelay"
    component={GlyphRelayScene}
    durationInFrames={146}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phrase is handed off glyph by glyph between lines until a giant question mark resolves into the final line. Pass `line1`, `line2` (each a pair of text parts) and `line3`; it ships light and dark, over a gradient ground you can change with `ground`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
