In Remotion, Focus Pan Text stacks status lines that blur as focus pans down to a final sentence with a small toolbar, like checks passing and then a ready message. Use it for a step-by-step status sequence in a deploy, CI or onboarding video.

## How to build this in Remotion

You don't need `TransitionSeries`, `Series` or `remotion-bits` for this. Install the component and pass your lines:

```bash
npx shadcn@latest add @remocn/focus-pan-text
```

The pan, each line's focus and the toolbar run on the schedule in `timeline.ts`: moves are `interpolate()` with `Easing` and the toolbar rises with `spring()`. Out-of-focus lines are a CSS `blur()`. Line widths are measured on a canvas before the first frame, held with `delayRender`. The ground is a live gradients.sh shader (`GshGround`).

## Good to know

- Length: 113 frames of motion at 30 fps (226 at 60 fps) with the default props. The demo plays 169 frames. The component exports `focusPanTextLength(lines, firstHold)`, which returns the length in 30 fps frames for your lines; double it at 60 fps. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `gsh`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Inter Tight itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The lines are plain text with no check-mark icon. The toolbar shows the `meta` text (default "Just now") followed by copy, thumbs-up and more icons drawn as inline SVG; those icons are not props, so edit them in the copied file.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FocusPanText } from "@/components/remocn/focus-pan-text";

const FocusPanTextScene = () => (
  <FocusPanText
    lines={["The scan is clean.", "All 48 checks passed.", "You're ready to launch."]}
    meta="Just now"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FocusPanText"
    component={FocusPanTextScene}
    durationInFrames={338}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each line is read in turn while earlier lines fall out of focus above; focus lands on the final line, the accent word lights up and a toolbar with `meta` text appears. Pass `lines` and `accentWord`; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.

## Common questions

### How do I stack status lines in Remotion that blur as focus pans down to a final ready message?

Install Focus Pan Text with `npx shadcn@latest add @remocn/focus-pan-text` and pass `lines`, `accentWord` and `meta`. Each line is read in turn, then focus lands on the last line and a toolbar appears.

### How long should the composition be?

Use the exported `focusPanTextLength(lines)` for the 30 fps length; at 60 fps hand Remotion twice that.

### Can I add check marks to each line?

Not through props. The lines are text only; add an icon in the copied file.
