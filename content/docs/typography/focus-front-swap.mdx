In Remotion, Focus Front Swap makes a three-line pitch where focus shifts from line to line: the old line blurs back while the next one comes forward, finishing on a logo and a ship-it call. Use it for a rhythmic pitch beat at the end of a launch or product video.

## How to build this in Remotion

You don't need `@remotion/transitions` or a blur `filter` per `Sequence`. Install the component and pass your lines:

```bash
npx shadcn@latest add @remocn/focus-front-swap
```

It is one scene: the lines' fronts, the push and the logo are placed by `timeline.ts`, the depth moves are `interpolate()` with `Easing`, the logo lands with `spring()`, and the focus is a CSS `blur()` filter. Line widths are measured before the first frame, held with `delayRender`. The ground is a live gradients.sh shader (`GshGround`).

## Good to know

- Length: 122 frames of motion at 30 fps (244 at 60 fps) with the default props. The demo plays 150 frames, which adds a hold. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `gsh`, `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Geist and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The logo is a separate element under the final line, not one of the lines: the last line is the ship-it call (default `Ship it {tonight}.`, with the braces marking the accent word). `logo` is a boolean that shows or hides the built-in Remocn mark; to show your own logo, replace the `RemocnLogo` element in the copied file.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FocusFrontSwap } from "@/components/remocn/focus-front-swap";

const FocusFrontSwapScene = () => (
  <FocusFrontSwap lines={["Remocn knows the beat", "You describe it once", "Ship it {tonight}."]} logo={false} />
);

export const RemotionRoot = () => (
  <Composition
    id="FocusFrontSwap"
    component={FocusFrontSwapScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each line in `lines` sharpens into focus while the previous one blurs back, and a mark appears under the final line. Wrap a word in `{}` such as `{tonight}` to accent it, and set `logo={false}` to drop the mark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop. It ships in light and dark through the `theme` prop.

## Common questions

### How can I make a three-line pitch in Remotion where focus shifts from line to line?

Install Focus Front Swap with `npx shadcn@latest add @remocn/focus-front-swap` and pass three `lines`. Each new line sharpens forward while the last one blurs back, then a mark lands under the final line.

### Can I use my own logo?

Not through a prop: `logo` only toggles the built-in mark. Swap the `RemocnLogo` element in the copied file for your SVG or `Img`, or set `logo={false}`.

### How do I accent one word?

Wrap it in braces inside the line, such as `Ship it {tonight}.`
