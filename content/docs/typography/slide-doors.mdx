## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SlideDoors } from "@/components/remocn/slide-doors";

const SlideDoorsScene = () => (
  <SlideDoors lines={["Scenes that move.", "Code you own.", "Arriving in your repo."]} highlight="repo." />
);

export const RemotionRoot = () => (
  <Composition
    id="SlideDoors"
    component={SlideDoorsScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each line slides apart like a pair of doors and the next line is revealed in the gap, ending with the last line and its highlight word in the accent colour. Pass `lines` and `highlight`; it ships light and dark.
