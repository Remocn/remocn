## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Exactly } from "@/components/remocn/exactly";

const ExactlyScene = () => <Exactly rounds={[{ objection: "It’s just code.", reply: "Exactly." }]} />;

export const RemotionRoot = () => (
  <Composition
    id="Exactly"
    component={ExactlyScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each round types an objection, which drops away as the reply lands beside it and reflows into the final answer; the next round follows. Pass `rounds` (objection and reply pairs); it compresses to fit the composition length.
