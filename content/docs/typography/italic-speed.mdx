## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ItalicSpeed } from "@/components/remocn/italic-speed";

const ItalicSpeedScene = () => (
  <ItalicSpeed title="FASTER" subtitle="Ship at race pace." accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="ItalicSpeed"
    component={ItalicSpeedScene}
    durationInFrames={84}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The word leans in from the side on speed strips, locks upright with an underline, and a serif italic subtitle fades in below. Pass `title` (set in capitals) and `subtitle`; it ships light and dark through `theme`.
