useWhen:
  - "A looping hold — an outro, a background title, a stream screen — needs constant, hypnotic typographic motion (the 225-frame track ends where it starts)."
  - "You want an editorial poster feel: heavy condensed type crushed and stretched like a print layout come alive."
  - "Two short words can share the frame — the two lines are forced to the same width, so pairs like a brand name and a tagline work best."
avoidWhen:
  - "You need an entrance or a reveal — this is a sustained loop, the type is fully visible from frame 0; use `kinetic-warp` for a punchy display moment."
  - "The copy must stay easily readable throughout — lines spend most of the loop crushed to a third of their height."
  - "You only need the vertical stretch without the perspective bend — drop-in alternatives like `per-character-rise` keep the type flat."

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PerspectiveSqueeze } from "@/components/remocn/perspective-squeeze";

const PerspectiveSqueezeScene = () => (
  <PerspectiveSqueeze
    upperText="REMOCN"
    lowerText="BEST"
    upperFontFamily="Impact, 'Arial Narrow', sans-serif"
    lowerFontFamily="Impact, 'Arial Narrow', sans-serif"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PerspectiveSqueeze"
    component={PerspectiveSqueezeScene}
    durationInFrames={225}
    fps={30}
    width={1920}
    height={1080}
  />
);
```

Both lines are forced to exactly the block's width via SVG `textLength`, so any
pair of words lines up flush. The vertical squeeze scales each line about its
own baseline, and the layout re-derives from the scaled heights every frame —
the gap between the lines never changes. The perspective is a true projective
corner-pin (`matrix3d`), interpolated on the corners, so straight lines stay
straight while parallels converge.
