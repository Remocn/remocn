## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpeedRampWord } from "@/components/remocn/speed-ramp-word";

const SpeedRampWordScene = () => (
  <SpeedRampWord text="Everything changes in an instant." keyWord="instant" hud />
);

export const RemotionRoot = () => (
  <Composition
    id="SpeedRampWord"
    component={SpeedRampWordScene}
    durationInFrames={121}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The phrase rushes across the frame, then time slows on the key word as it warms to a gradient, with a small timecode and speed readout slowing alongside. Pass `text` and `keyWord`; set `hud` to false to hide the readout. It ships light and dark.
