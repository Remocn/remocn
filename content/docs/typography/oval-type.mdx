## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { OvalType } from "@/components/remocn/oval-type";

const OvalTypeScene = () => <OvalType tagline={["Make", "it", "move"]} words={["Plan", "Cut", "Edit"]} accentWord={1} />;

export const RemotionRoot = () => (
  <Composition
    id="OvalType"
    component={OvalTypeScene}
    durationInFrames={115}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Capsules step left along a conveyor, stretching while they travel and bouncing tall when they land, each carrying one word from `words`. Then the `tagline` words land as tall poster ovals and the gaps close. Use `accentWord` to set one tagline word in italic serif; it ships light and dark through `theme`.
