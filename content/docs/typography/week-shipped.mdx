## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WeekShipped } from "@/components/remocn/week-shipped";

const WeekShippedScene = () => (
  <WeekShipped entries={[{ day: "Monday,", item: "captions that keep up." }, { day: "Tuesday,", item: "shaders you can scrub." }]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WeekShipped"
    component={WeekShippedScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each entry rolls in as a day name followed by its shipped item, stepping through the week at a fitted pace. Pass `entries` with `day` and `item` for each line. It ships in light and dark through the `theme` prop.
