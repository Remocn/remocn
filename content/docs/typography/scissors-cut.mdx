## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScissorsCut } from "@/components/remocn/scissors-cut";

const ScissorsCutScene = () => (
  <ScissorsCut before="Ship " cut="next quarter" after="." replacement="now" />
);

export const RemotionRoot = () => (
  <Composition
    id="ScissorsCut"
    component={ScissorsCutScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line appears, a dashed outline traces the `cut` phrase and a pair of scissors snips along it. The cut piece falls away, the line reflows, and the `replacement` slides into the gap. Pass `before`, `cut`, `after` and `replacement`. It takes a `theme` prop and ships light and dark.
