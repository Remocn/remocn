## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CursorFrame } from "@/components/remocn/cursor-frame";

const CursorFrameScene = () => (
  <CursorFrame title="Launch videos, in code." theme="light" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="CursorFrame"
    component={CursorFrameScene}
    durationInFrames={230}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Words fade in, a cursor presses and drags a selection frame over them, then resizes it so the headline rewraps onto two lines before the frame clears. Pass `title` for the headline; it ships light and dark through `theme` and defaults to light.
