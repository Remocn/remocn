## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoolingType } from "@/components/remocn/cooling-type";

const CoolingTypeScene = () => (
  <CoolingType
    text="What if your launch video could write itself?"
    accentWord="itself?"
    charFrames={1.6}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CoolingType"
    component={CoolingTypeScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Characters type in with a slightly irregular rhythm, each one starting in a hot color and cooling to the ink color; the accent word breathes in as serif italic and a caret finishes the line. Pass `text` and `accentWord`, and tune `charFrames` and `coolFrames` for pace; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
