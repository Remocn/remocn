In Remotion, Word Pullback opens on one giant word and pulls the camera back to reveal the full sentence, such as The cinematic toolkit for every launch. Use it as an opener that starts close and zooms out.

## Good to know

- Length: 96 frames of motion at 30 fps (192 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `gsh`, `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Serif, Inter Tight and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- Set `background` to a solid color to replace the shader ground.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordPullback } from "@/components/remocn/word-pullback";

const WordPullbackScene = () => (
  <WordPullback before="The" accentWord="cinematic" after="toolkit for every launch" />
);

export const RemotionRoot = () => (
  <Composition
    id="WordPullback"
    component={WordPullbackScene}
    durationInFrames={264}
    fps={60}
    width={1280}
    height={720}
  />
);
```

One big word is typed, then the camera pulls back in two moves to reveal the surrounding sentence and a logo before a gradient floods the frame. Pass `before`, `accentWord` and `after`; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
