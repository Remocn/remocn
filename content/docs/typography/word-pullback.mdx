## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordPullback } from "@/components/remocn/word-pullback";

const WordPullbackScene = () => (
  <WordPullback before="The" accentWord="cinematic" after="toolkit for every launch" />
);

export const RemotionRoot = () => (
  <Composition
    id="WordPullback"
    component={WordPullbackScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

One big word is typed, then the camera pulls back in two moves to reveal the surrounding sentence and a logo before a gradient floods the frame. Pass `before`, `accentWord` and `after`; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
