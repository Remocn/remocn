## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MacroPan } from "@/components/remocn/macro-pan";

const MacroPanScene = () => (
  <MacroPan title="Built to move." label="remocn" index="01" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="MacroPan"
    component={MacroPanScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera starts zoomed into the letters and pans across them, then pulls back to reveal the whole headline ending on a gradient while the corner label settles. Pass `title`, `label` and `index`; it ships light and dark through `theme`.
