## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LandingConfirmed } from "@/components/remocn/landing-confirmed";

const LandingConfirmedScene = () => (
  <LandingConfirmed
    from={800}
    confirm="Release confirmed"
    title="Live."
    subtitle="Version 2.0 is out."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LandingConfirmed"
    component={LandingConfirmedScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A giant altitude number counts down from `from` metres beside a gauge and a velocity readout, hard-stops at zero, flashes, and slams `confirm` across the frame. That line shrinks into a small label as `title` slams in as a gradient headline, with `subtitle` in serif italic and a logo beneath. The default logo is the Remocn wordmark, so pass your own through `logo`. It ships light and dark.
