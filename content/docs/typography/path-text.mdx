## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PathText } from "@/components/remocn/path-text";

const PathTextScene = () => (
  <PathText text="From rough to ready." italicWords={1} looseness={0.15} />
);

export const RemotionRoot = () => (
  <Composition
    id="PathText"
    component={PathTextScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The text is drawn along a wobbly path, then the path flattens and thins as the letters straighten into a clean line, with the last words in italic. Pass `text`, `italicWords` and `looseness`; it ships light and dark through `theme`.
