## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NameGloss } from "@/components/remocn/name-gloss";

const NameGlossScene = () => (
  <NameGloss
    parts={[
      { word: "Brand", gloss: "Your colors, your type, your logo." },
      { word: "kit", gloss: "Packed into every scene you install." },
    ]}
    why="So every film looks like yours."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NameGloss"
    component={NameGlossScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The name words rise in the middle as one phrase, then glide apart into columns across the top. Under each one its gloss builds word by word, and the `why` sentence resolves last in the accent color. Pass `parts` as `{ word, gloss }` pairs, usually two or three, and a closing `why`. It ships light and dark.
