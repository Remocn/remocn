## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordInsert } from "@/components/remocn/word-insert";

const WordInsertScene = () => (
  <WordInsert states={["Launch videos.", "Launch videos, as code."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordInsert"
    component={WordInsertScene}
    durationInFrames={174}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each entry in `states` is the same sentence with more words added, and the new words open a gap and slide in with a gradient. Pass `states` as successive versions of your line. It ships in light and dark through the `theme` prop.
