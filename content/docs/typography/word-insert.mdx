In Remotion, Word Insert edits a sentence on screen: it opens a gap and inserts new words in an accent gradient, growing a plain noun into a full promise. Use it for a tagline that builds up by insertion.

## Good to know

- Length: 116 frames of motion at 30 fps (232 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordInsert } from "@/components/remocn/word-insert";

const WordInsertScene = () => (
  <WordInsert states={["Launch videos.", "Launch videos, as code."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WordInsert"
    component={WordInsertScene}
    durationInFrames={348}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each entry in `states` is the same sentence with more words added, and the new words open a gap and slide in with a gradient. Pass `states` as successive versions of your line. It ships in light and dark through the `theme` prop.
