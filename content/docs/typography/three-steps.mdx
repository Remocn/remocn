## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ThreeSteps } from "@/components/remocn/three-steps";

const ThreeStepsScene = () => (
  <ThreeSteps
    steps={[
      { title: "Install", detail: "Add a scene with the CLI" },
      { title: "Compose", detail: "Arrange scenes in React" },
      { title: "Render", detail: "Export an MP4" },
    ]}
    outcome="Your launch video, shipped"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ThreeSteps"
    component={ThreeStepsScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line draws across the frame and ghost numerals appear, then a dot travels along it, lighting each numeral in a gradient as its title and detail rise in. The final step also shows the `outcome` in serif italic. Pass `steps` as `{ title, detail? }`, an `eyebrow` label, and the `outcome`. It ships light and dark; three steps fit best.
