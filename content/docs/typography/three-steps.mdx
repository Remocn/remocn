In Remotion, Three Steps builds a how-it-works scene: three large numerals light up along a line as a dot travels between them, each with a title and a short detail, ending on an outcome line. Use it to explain a product in three steps, such as install, compose, render.

## Good to know

- Length: 118 frames of motion at 30 fps (236 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads Instrument Serif and Manrope itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.
- The serif outcome line shows only when `outcome` is set; pass `outcome=""` to hide it.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ThreeSteps } from "@/components/remocn/three-steps";

const ThreeStepsScene = () => (
  <ThreeSteps
    steps={[
      { title: "Install", detail: "Add a scene with the CLI" },
      { title: "Compose", detail: "Arrange scenes in React" },
      { title: "Render", detail: "Export an MP4" },
    ]}
    outcome="Your launch video, shipped"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ThreeSteps"
    component={ThreeStepsScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

A line draws across the frame and ghost numerals appear, then a dot travels along it, lighting each numeral in a gradient as its title and detail rise in. The final step also shows the `outcome` in serif italic. Pass `steps` as `{ title, detail? }`, an `eyebrow` label, and the `outcome`. It ships light and dark; three steps fit best.
