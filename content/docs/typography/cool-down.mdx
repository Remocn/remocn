## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CoolDown } from "@/components/remocn/cool-down";

const CoolDownScene = () => <CoolDown title="Runs cool." label="a full launch film rendered, fans silent" />;

export const RemotionRoot = () => (
  <Composition
    id="CoolDown"
    component={CoolDownScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A short statement rises into place in large type, glowing in the accent color and cooling to the text color while a faint grid and heat shimmer calm down behind it, ending on a still frame with a small mono caption. Pass `title` and `label`.
