In Remotion, Half Built shows a roadmap as one sentence of verbs: each verb starts as a hollow outline and fills in as it ships, while tags such as Summer or Later mark what's still coming. Use it for a roadmap beat that shows what the product does now and what is next.

## How to build this in Remotion

You don't need opentype.js paths or `-webkit-text-stroke` experiments. Install the component:

```bash
npx shadcn@latest add @remocn/half-built
```

Each word is drawn twice: an outline with `WebkitTextStroke` and a filled copy revealed by a `clip-path` wipe that runs on `interpolate()` and `Easing`. Text is laid out while `delayRender()` holds the first frame.

## Good to know

- Length: 116 frames of motion at 30 fps (232 at 60 fps) with the default props. The demo plays 150 frames, which adds a hold. If the composition is shorter than the natural schedule plus a 30-frame hold, the whole schedule is compressed to fit. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion are doubled, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- The fill animates over time: the words fill one after another, up to `progress` (default 1.6). `progress` counts planned words, so a fraction partly fills the next one and the rest stay hollow.
- `when` is any short string on a part, such as `"Summer"` or `"Later"`; a part without `when` is already shipped.
- Font: loads Golos Text itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HalfBuilt } from "@/components/remocn/half-built";

const HalfBuiltScene = () => (
  <HalfBuilt parts={[{ text: "It cuts," }, { text: "captions,", when: "Spring" }, { text: "narrates", when: "Summer" }]} progress={1.6} />
);

export const RemotionRoot = () => (
  <Composition
    id="HalfBuilt"
    component={HalfBuiltScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

Each part of the sentence starts hollow and fills in as `progress` advances, with optional season tags such as Summer or Later marking what is planned. Pass `parts` and set `progress` to choose how far the roadmap has filled. It ships in light and dark through the `theme` prop.

## Common questions

### How do I show a roadmap in Remotion where outlined verbs fill in as they ship?

Install Half Built with `npx shadcn@latest add @remocn/half-built`, pass `parts` (each `{ text, when? }`) and set `progress` to how far the roadmap has filled.

### Does the fill animate, or is progress static?

It animates: each planned word fills in turn until `progress` is reached.

### What can `when` be?

Any label you like; it is shown as the tag on that part.
