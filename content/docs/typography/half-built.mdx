## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HalfBuilt } from "@/components/remocn/half-built";

const HalfBuiltScene = () => (
  <HalfBuilt parts={[{ text: "It cuts," }, { text: "captions,", when: "Spring" }, { text: "narrates", when: "Summer" }]} progress={1.6} />
);

export const RemotionRoot = () => (
  <Composition
    id="HalfBuilt"
    component={HalfBuiltScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each part of the sentence starts hollow and fills in as `progress` advances, with optional season tags such as Summer or Later marking what is planned. Pass `parts` and set `progress` to choose how far the roadmap has filled. It ships in light and dark through the `theme` prop.
