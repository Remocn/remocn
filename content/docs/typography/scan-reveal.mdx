## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScanReveal } from "@/components/remocn/scan-reveal";

const ScanRevealScene = () => (
  <ScanReveal title="Built frame by frame" subtitle="Launch films from components you own." />
);

export const RemotionRoot = () => (
  <Composition
    id="ScanReveal"
    component={ScanRevealScene}
    durationInFrames={142}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Guide marks appear, a scan line travels down to reveal the headline, then it moves up and parks while the subtitle fades in beneath. Pass `title` and `subtitle`; it ships light and dark.
