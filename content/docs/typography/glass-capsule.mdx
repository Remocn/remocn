## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlassCapsule } from "@/components/remocn/glass-capsule";

const GlassCapsuleScene = () => (
  <GlassCapsule lines={["Launch films", "that move."]} focus="move" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="GlassCapsule"
    component={GlassCapsuleScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The two lines rise in, then a glass capsule glides over `focus`, magnifies it and swaps it to a serif italic while the capsule glows. Pass `lines` and `focus` (a word that appears in them); it ships light and dark through `theme`.
