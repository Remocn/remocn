## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WhichMeans } from "@/components/remocn/which-means";

const WhichMeansScene = () => (
  <WhichMeans name="Live preview" label="New" steps={["Every edit shows up as you type,", "the first render is the one you ship."]} />
);

export const RemotionRoot = () => (
  <Composition
    id="WhichMeans"
    component={WhichMeansScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A labeled feature name appears, then the hinge phrase and each step in `steps` unfold as a chain of consequences. Pass `name`, `label`, `steps` and `hinge` to describe your own feature. It ships in light and dark through the `theme` prop.
