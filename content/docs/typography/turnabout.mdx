In Remotion, Turnabout flips one sentence into its mirror image word by word, for example effort for the tool turning into effort from the tool, and ends on an accent-colored phrase. Use it for a positioning beat that reverses the framing.

## Good to know

- Length: 106 frames of motion at 30 fps (212 at 60 fps) with the default props. That is the minimum for its `Sequence`; add your own hold on top. The Usage example below is a 60 fps composition, so the numbers it hands to Remotion (`durationInFrames`, `Sequence` lengths) are doubled. The component's own props counted in frames stay in 30 fps frames at any frame rate, see [Frame rate](/docs/getting-started/installation#frame-rate).
- Installs: `remotion`, `@remotion/google-fonts` from npm, plus the remocn helpers `glide`, `frame-rate`, `timeline`. The shadcn CLI copies the source into your project.
- Font: loads DM Sans itself through `@remotion/google-fonts`. Pass `fontFamily` to use your own face, and load that font in your project.

## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Turnabout } from "@/components/remocn/turnabout";

const TurnaboutScene = () => (
  <Turnabout before="You work for the video." after="The video works for you." highlight="you." />
);

export const RemotionRoot = () => (
  <Composition
    id="Turnabout"
    component={TurnaboutScene}
    durationInFrames={300}
    fps={60}
    width={1280}
    height={720}
  />
);
```

The `before` sentence enters word by word, then turns into the `after` sentence while shared words travel to their new spots. The `highlight` phrase in `after` lights up in the accent color. It ships in light and dark through the `theme` prop.
