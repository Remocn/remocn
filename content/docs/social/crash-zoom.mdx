## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CrashZoom } from "@/components/remocn/crash-zoom";

const CrashZoomScene = () => (
  <CrashZoom tease="Wait for it…" reveal="2 HOURS." tagline="to ship the launch video." />
);

export const RemotionRoot = () => (
  <Composition
    id="CrashZoom"
    component={CrashZoomScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A serif italic tease fades in (a trailing "…" types in dot by dot), then crash-zooms through a blur with speed lines into a huge solid reveal that lands with a flash and shake, followed by a tagline. Pass `tease`, `reveal` and `tagline` to make it yours; it ships dark and light via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
