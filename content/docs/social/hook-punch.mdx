## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HookPunch } from "@/components/remocn/hook-punch";

const HookPunchScene = () => (
  <HookPunch
    stop="Stop"
    scroll="scrolling."
    lead="This video took"
    payoff="1 day."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HookPunch"
    component={HookPunchScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

"Stop" and a serif italic "scrolling." slam in with a camera kick, a whip zoom wipes the first line away, and a lead-in plus a huge payoff slam in with a shake. Pass `stop`, `scroll`, `lead` and `payoff` to rewrite both beats; it ships dark and light via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
