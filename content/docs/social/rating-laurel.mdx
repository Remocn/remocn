## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RatingLaurel } from "@/components/remocn/rating-laurel";

const RatingLaurelScene = () => (
  <RatingLaurel
    rating={4.9}
    title="Loved by builders"
    subtitle="Rated in the **top 5%** of launch tools"
    reviewCount={298}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RatingLaurel"
    component={RatingLaurelScene}
    durationInFrames={270}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A laurel draws around a rolling `rating` number with a `title` and a subtitle (wrap words in `**` for emphasis). Category score chips appear, review cards fade up and glide sideways, and a "Show all reviews" button closes the beat. Pass `reviews`, `categories` and `reviewCount`; `device` picks a web card or a phone frame (portrait always uses phone). Ships light and dark via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
