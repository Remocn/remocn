## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpeedrunTimer } from "@/components/remocn/speedrun-timer";

const SpeedrunTimerScene = () => (
  <SpeedrunTimer
    category="Launch video · Any%"
    splits={[
      { name: "Script", time: 300, pb: 340 },
      { name: "Edit", time: 900, pb: 950 },
      { name: "Ship", time: 1500, pb: 1620 },
    ]}
    banner="World record"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SpeedrunTimer"
    component={SpeedrunTimerScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The panel slides in with a header and one row per split. The run clock starts, each split locks in with the time and a green or red delta against its personal best, and the last split goes gold before a banner lands. Pass `splits` (cumulative seconds for `time` and `pb`), `category` and `banner`; it ships dark and light via `theme`. The header uses the Remocn wordmark, swap `RemocnLogo` in the copied file for your own.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
