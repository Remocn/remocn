## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DuetSplit } from "@/components/remocn/duet-split";

const DuetSplitScene = () => (
  <DuetSplit
    beforeLabel="Before"
    afterLabel="With us"
    rows={[
      { before: "3 weeks", after: "1 day" },
      { before: "$12K", after: "$0" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DuetSplit"
    component={DuetSplitScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two slabs slide in, labelled by `beforeLabel` and `afterLabel`. The grey side types out wobbly serif values row by row; the after side then pushes in and shows the crisp replacements, and a wordmark rises at the bottom. Pass `rows` as `{ before, after }` pairs; it ships dark and light via `theme`. The closing wordmark is the Remocn logo, swap `RemocnLogo` in the copied file.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
