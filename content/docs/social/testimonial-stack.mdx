## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TestimonialStack } from "@/components/remocn/testimonial-stack";

const TestimonialStackScene = () => (
  <TestimonialStack
    quotes={[
      {
        text: "We shipped our launch video in an afternoon.",
        highlight: "in an afternoon",
        name: "Maya Chen",
        role: "Founder, Kitebase",
        handle: "@mayachen",
        source: "x",
      },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TestimonialStack"
    component={TestimonialStackScene}
    durationInFrames={236}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each quote card slides in from alternating sides and lands on a growing, slightly rotated pile; the highlighted phrase is marked inside the text. With `ending="fan"` the pile then spreads into a grid under a `title` (the fan adds about 60 frames). Pass `quotes` with name, role and optional handle, stars and highlight. Ships light and dark via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
