## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { YearInReview } from "@/components/remocn/year-in-review";

const YearInReviewScene = () => (
  <YearInReview
    stats={{ year: "2026", product: "Kitebase", videos: 42, percentile: 3 }}
    device="phone"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="YearInReview"
    component={YearInReviewScene}
    durationInFrames={480}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone (or flat card) plays five slides with a chapter rail: your year, videos shipped, top component, builder rank and a share card whose button gets tapped. Override any field of `stats` (year, product, videos, topComponent, runnersUp, percentile, minutes, crew, url) and rename the chapters with `chapters`. It has a single look and no `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
