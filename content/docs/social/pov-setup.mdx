## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PovSetup } from "@/components/remocn/pov-setup";

const PovSetupScene = () => (
  <PovSetup
    setup="your whole launch video rendered while you made coffee"
    lead="and it"
    punch="slaps."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PovSetup"
    component={PovSetupScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A small "POV:" label pops in, the setup line slides in word by word over a gradient ground, then the lead-in and a bold serif punch word land with a small shake. Pass `label`, `setup`, `lead` and `punch` for your own joke; it ships dark and light via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
