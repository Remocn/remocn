## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MilestoneRoll } from "@/components/remocn/milestone-roll";

const MilestoneRollScene = () => (
  <MilestoneRoll milestones={[100, 1000, 10000, 50000]} unit="signups" />
);

export const RemotionRoot = () => (
  <Composition
    id="MilestoneRoll"
    component={MilestoneRollScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A big counter races up to each milestone in turn; every hit flashes, shakes and shrinks the ring behind it. On the last milestone the number becomes a poster with the `unit` in serif italic and a wordmark. Pass ascending `milestones` and a `unit`; it ships dark and light via `theme`. The closing wordmark is the Remocn logo, swap `RemocnLogo` in the copied file.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
