## Usage

```tsx
// src/Root.tsx
import { Composition, staticFile } from "remotion";
import { ReelsFeed } from "@/components/remocn/reels-feed";

const ReelsFeedScene = () => (
  <ReelsFeed
    account="yourbrand"
    stories={[{ src: staticFile("story-1.png") }, { src: staticFile("story-2.png") }]}
    reelSrc={staticFile("reel.png")}
    pollQuestion="Shipping this week?"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ReelsFeed"
    component={ReelsFeedScene}
    durationInFrames={300}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone frame rises in beside three chapter headlines (Story, Poll, Reel). A tap on a story ring opens up to three stories with progress bars, a poll vote is cast, then a swipe moves to a reel where a double-tap bursts a heart and the like count ticks from `likes[0]` to `likes[1]`. Pass your own `stories` and `reelSrc` image URLs (up to three stories) plus `pollQuestion`, `pollOptions` and `account`. Without images it draws built-in art. Ships light and dark via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
