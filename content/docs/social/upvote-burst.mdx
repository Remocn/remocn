## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { UpvoteBurst } from "@/components/remocn/upvote-burst";

const UpvoteBurstScene = () => (
  <UpvoteBurst
    product={{ name: "Kitebase", tagline: "Launch videos from code", topic: "Video" }}
    startRank={4}
    startVotes={380}
    endVotes={1300}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="UpvoteBurst"
    component={UpvoteBurstScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A leaderboard sheet slides in with your `product` at `startRank`. A cursor presses the upvote, the vote count climbs from `startVotes` to `endVotes`, your row swaps past each rival above it, and a `badgeLabel` stamp lands with captions. Pass `product` and `rivals` (name, tagline, topic, optional `src` image) and the vote numbers. Ships light and dark via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
