## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StoryText } from "@/components/remocn/story-text";

const StoryTextScene = () => (
  <StoryText text="okay, it's live — the update you kept asking for is finally here" />
);

export const RemotionRoot = () => (
  <Composition
    id="StoryText"
    component={StoryTextScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Words pop in one at a time with a caret, each sitting on a merged rounded highlight bubble that wraps across lines. After the last word the highlight cycles through outline, plain and filled again. Pass your sentence as `text`; `measure` sets the line width as a fraction of the frame. Ships dark and light via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
