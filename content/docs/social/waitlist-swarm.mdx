## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WaitlistSwarm } from "@/components/remocn/waitlist-swarm";

const WaitlistSwarmScene = () => (
  <WaitlistSwarm value={12480} label="on the waitlist" count={760} />
);

export const RemotionRoot = () => (
  <Composition
    id="WaitlistSwarm"
    component={WaitlistSwarmScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Hundreds of dots and cursors fly in along curved paths from beyond the frame and settle into the outline and fill of a shape, while a counter climbs to `value` beside it with a `label`; a pulse ripples out when the last one lands. Pass `shape` (SVG path data, or parts with an `accent` flag) to swap the default R mark. Ships dark and light via `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
