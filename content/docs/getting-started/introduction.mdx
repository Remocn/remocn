## What Remocn is not

<NotCards icons={["editor", "cloud", "fork", "chat"]}>

- **Not After Effects or a video editor.** There is no timeline UI to drag things around in. You write or prompt code, and Remotion Studio previews the result.
- **Not a hosted service.** Nothing runs on Remocn servers. No account, no runtime, no usage limits. Rendering happens on your machine or wherever you run Remotion.
- **Not a fork of Remotion.** Remotion is a prerequisite, and Remocn is a set of components written against its public API. Remotion keeps [its own license](https://www.remotion.dev/docs/license); Remocn's own code is MIT.
- **Not only AI chat components.** The [AI section](/docs/ai) recreates chat composers and CLI screens because product demos need them often, but it is one category among text, transitions, backgrounds, layout, UI blocks and templates.

</NotCards>

<Aside icon="info">Remocn is an independent project. It is not affiliated with shadcn or with Remotion; it builds on the shadcn CLI and the Remotion library.</Aside>

## Remocn vs raw Remotion

<CompareTable>

| | Raw Remotion | Remotion + Remocn |
|---|---|---|
| Starting point | Empty composition | Composition plus a catalog of ready components |
| Animation code | Written per project | Copied in, then edited like any file you own |
| Timing | Decided per element | Each component states its natural length in frames |
| AI agents | Generic Remotion knowledge | Skill with catalog access, timing rules and scene recipes |
| Dependency | Remotion | Remotion, same as before. Remocn adds no runtime |

</CompareTable>

Nothing here replaces Remotion. If you already have a component library of your own, Remocn is a set of files to borrow from; if you are starting from a blank project, it is the fastest way to a first scene.

## FAQ

<Faq>

**Do I need to know how to code?**
Not necessarily, if you work through an AI coding agent. The [guides](/docs/guides) walk through building a video with prompts. Without an agent, you need to be comfortable with React and TypeScript.

**Do I need After Effects or a video editor?**
No. Everything happens in your editor and a browser preview.

**Is it free?**
Remocn is MIT licensed. Components copy onto your machine and stay yours.

**Does it work with any AI agent?**
The skill installs through [skills.sh](https://skills.sh) into agents that load skills, Claude Code among them. The components themselves are plain Remotion code and work with any agent or no agent at all.

**Is this the official shadcn registry for Remotion?**
No. It is a community registry that uses the shadcn CLI and registry format. shadcn and Remotion are separate projects with their own maintainers.

</Faq>
