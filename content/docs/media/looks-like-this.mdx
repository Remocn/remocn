## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LooksLikeThis } from "@/components/remocn/looks-like-this";

const LooksLikeThisScene = () => (
  <LooksLikeThis
    lead="Your next launch looks like"
    word="this"
    src="/shots/product.png"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LooksLikeThis"
    component={LooksLikeThisScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `lead` sentence writes in with a small thumbnail chip inline before the `end` punctuation. The chip then grows into a large framed image with player chrome while the italic `word` takes its place in the sentence. Pass your own image through `src`; the default is a `staticFile` image from the Remocn repo. The timeline scales with the composition length, and it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
