## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ThemeFlip } from "@/components/remocn/theme-flip";

const ThemeFlipScene = () => (
  <ThemeFlip
    fromSrc="/screens/light.png"
    toSrc="/screens/dark.png"
    origin={{ x: 1340, y: 33 }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ThemeFlip"
    component={ThemeFlipScene}
    durationInFrames={112}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera pushes in on a theme toggle, a cursor clicks it, and the new theme floods out from the click point across the window before the camera pulls back. With `reverse` it clicks again and flips back. Use the built-in mock, or pass `from` and `to` nodes, or `fromSrc` and `toSrc` images, with an `origin` in screenshot pixels. It has two looks built in, set by `startTheme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
