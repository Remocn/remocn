## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PanelSplit } from "@/components/remocn/panel-split";

const PanelSplitScene = () => (
  <PanelSplit
    name="Mara Okafor"
    role="Motion designer"
    headline={["Driven by motion,", "obsessed with", "the seamless."]}
    images={["/work/a.jpg", "/work/b.jpg", "/work/c.jpg"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PanelSplit"
    component={PanelSplitScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A single hero panel with the `name`, `role` and `headline` lines splits into four panels. They fill with a case-study image and `caption`, a `question` with `body` text, and a reel panel that floods with color and fans out preview cards. Pass your own `images`; the defaults are `staticFile` images from the remocn repo. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
