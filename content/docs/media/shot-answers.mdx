## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShotAnswers } from "@/components/remocn/shot-answers";

const ShotAnswersScene = () => (
  <ShotAnswers
    question="What if your launch video were just another pull request?"
    answer="Your launch video is just another pull request."
    src="/shots/studio.png"
    url="example.dev/studio"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShotAnswers"
    component={ShotAnswersScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The `question` writes in word by word and a framed screenshot slides in beside it. The shared words then glide into place while the rest swap, forming the `answer`, with new words appearing in the accent color. Pass your own `question`, `answer` and image through `src`; the default is a `staticFile` image from the remocn repo. The timeline scales with the composition length, and it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
