## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BeforeAfter } from "@/components/remocn/before-after";

const BeforeAfterScene = () => (
  <BeforeAfter
    before="/shots/raw.jpg"
    after="/shots/graded.jpg"
    title="Graded in one pass"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BeforeAfter"
    component={BeforeAfterScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A framed image appears with a grip handle. The divider sweeps across to reveal the after version, then returns to `pauseAt` before the grip fades. Pass your own `before` and `after` image URLs, with optional labels and a `title`. If neither is given, the built-in demo image shows a flat look against a graded look and uses a `staticFile` from the Remocn repo. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
