## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShardsToGrid } from "@/components/remocn/shards-to-grid";

const ShardsToGridScene = () => (
  <ShardsToGrid
    images={["/shots/one.jpg", "/shots/two.jpg", "/shots/three.jpg"]}
    title="Launch v1"
    headline="Every frame, written in code."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShardsToGrid"
    component={ShardsToGridScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Shards of your `images` drift through 3D space, converge and snap into a five-cell grid inside a window with a `title` and `status`. The hero cell writes in the `headline` word by word and the other cells show their `labels`. Pass your own `images`; the defaults are `staticFile` images from the remocn repo. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
