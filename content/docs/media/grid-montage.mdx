## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GridMontage } from "@/components/remocn/grid-montage";

const GridMontageScene = () => (
  <GridMontage
    images={["/shots/1.jpg", "/shots/2.jpg", "/shots/3.jpg", "/shots/4.jpg"]}
    beat={14}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GridMontage"
    component={GridMontageScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A full-frame shot splits into a 2x2 grid of new scenes, grows into a 3x3 grid that swaps tiles on every beat, then merges back into one closing shot. Pass your own `scenes` (React nodes) or `images`, and set `beat`, the number of frames between cuts. With neither, it shows built-in mock tiles. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
