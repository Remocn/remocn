## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ScreenshotTour } from "@/components/remocn/screenshot-tour";

const ScreenshotTourScene = () => (
  <ScreenshotTour
    src="/screens/dashboard.png"
    screenshotWidth={1440}
    screenshotHeight={900}
    stops={[{ x: 40, y: 120, width: 420, height: 200, label: "Every issue, grouped by status" }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ScreenshotTour"
    component={ScreenshotTourScene}
    durationInFrames={215}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A framed screenshot rises in and the camera travels between `stops`, pushing in on each region while the rest dims and a caption names it. After the last stop it pulls back to the full shot when `pullBack` is on. Pass your own screenshot through `src` or `children` with its `screenshotWidth` and `screenshotHeight`, and list `stops` in screenshot pixels. With neither it shows a built-in issue-tracker mock. It ships light and dark through `theme`. The length is `18 + stops * framesPerStop + 24` for three stops at 45 frames.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
