## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LayeredCutout } from "@/components/remocn/layered-cutout";

const LayeredCutoutScene = () => (
  <LayeredCutout
    tagline="Launch films, cut from components."
    layers={5}
    theme="light"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LayeredCutout"
    component={LayeredCutoutScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Between 4 and 6 cut sheets part in depth while the camera pushes through them. The innermost sheet, cut from gradient paper, ends up framing the core, where the logo and the `tagline` surface. Pass a `logo` node and your `tagline`; it ships light (card stock) and dark (charcoal) and the camera move ends at frame 140.
