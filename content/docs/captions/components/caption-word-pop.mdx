## Usage

`CaptionWordPop` puts one word on screen at a time. Each word pops in from
`popScale` on a spring with a small overshoot and is replaced the moment the
next word is spoken. After the last word of a sentence it holds, then fades out
instead of hanging through the pause.

It renders only the text block. One-word captions read best in the middle of the
frame, where the eye already is — see [Positioning](/docs/captions/getting-started/positioning)
for the centred recipe and [Get a transcript](/docs/captions/getting-started/get-a-transcript)
for producing `captions.json`.

```tsx
import { AbsoluteFill } from "remotion";
import { CaptionWordPop } from "@/components/remocn/caption-word-pop";
import captions from "./captions.json";

export const MyScene = () => (
  <AbsoluteFill style={{ justifyContent: "center", alignItems: "center" }}>
    <CaptionWordPop captions={captions} />
  </AbsoluteFill>
);
```
