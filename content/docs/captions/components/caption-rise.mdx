## Usage

`CaptionRise` takes a timed transcript and renders only the text block, so
place it inside your own `AbsoluteFill`. Every word sits in its own mask and
rises into place from below its baseline at its own start time. The space for
the whole phrase is reserved from the first word, so the line never reflows as
it builds. See [Positioning](/docs/captions/getting-started/positioning) for
safe placements and [Get a transcript](/docs/captions/getting-started/get-a-transcript)
for producing `captions.json`.

```tsx
import { AbsoluteFill } from "remotion";
import { CaptionRise } from "@/components/remocn/caption-rise";
import captions from "./captions.json";

export const MyScene = () => (
  <AbsoluteFill
    style={{
      justifyContent: "flex-end",
      alignItems: "center",
      paddingBottom: 108,
      paddingInline: 192,
    }}
  >
    <CaptionRise captions={captions} />
  </AbsoluteFill>
);
```
