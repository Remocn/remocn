## Usage

`CaptionUnderline` shows the whole page and keeps a single bar under the word
being spoken. When the voice moves on, the bar slides across to the next word
and stretches or shrinks to its width, so the eye follows one continuous mark
rather than a flicker of separate ones. On the first word of a page the bar
grows in from the left. The component renders only the text block, so place it
inside your own `AbsoluteFill` — see [Positioning](/docs/captions/getting-started/positioning).

```tsx
import { AbsoluteFill } from "remotion";
import { CaptionUnderline } from "@/components/remocn/caption-underline";
import captions from "./captions.json";

export const MyScene = () => (
  <AbsoluteFill
    style={{
      justifyContent: "flex-end",
      alignItems: "center",
      paddingBottom: 108,
      paddingInline: 192,
    }}
  >
    <CaptionUnderline captions={captions} underlineColor="#facc15" />
  </AbsoluteFill>
);
```
