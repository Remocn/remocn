## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GravityGrid } from "@/components/remocn/gravity-grid";

const GravityGridScene = () => (
  <GravityGrid
    name="remocn"
    caption="Launch videos, in components."
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GravityGrid"
    component={GravityGridScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A perspective grid recedes into the distance, a mass falls and bends it into a gravity well, and on impact the logo and `name` land at the bottom with `caption` beneath. Pass `name` or `logo`, and `caption`. Ships light and dark.
