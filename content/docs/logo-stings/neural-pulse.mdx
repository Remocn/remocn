## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NeuralPulse } from "@/components/remocn/neural-pulse";

const NeuralPulseScene = () => (
  <NeuralPulse
    input="Make a launch film"
    output="remocn"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NeuralPulse"
    component={NeuralPulseScene}
    durationInFrames={230}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The prompt splits into tokens that fly into a network, nodes fire layer by layer, and the pulse resolves into a single output that traces the R mark and reveals the name. Pass `input` (up to five words) and `output`, and `logo` to replace the R. Ships light and dark.
