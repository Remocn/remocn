## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FirstLight } from "@/components/remocn/first-light";

const FirstLightScene = () => (
  <FirstLight
    name="remocn"
    tagline="Every frame catches the light."
    speed={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FirstLight"
    component={FirstLightScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A band of light climbs along a baseline, lighting the name as it passes, then settles and a tagline fades in below. Pass `name` and `tagline`; a name of remocn is set as the real logo. Ships light and dark.
