## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BassDrop } from "@/components/remocn/bass-drop";

const BassDropScene = () => (
  <BassDrop
    build="THIS FALL"
    title="REMOCN"
    line="LAUNCH FILMS"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BassDrop"
    component={BassDropScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A widely tracked `build` line breathes in under rising tension, the frame cuts to silence, then the logo (or your own `title` word) slams in on the hit with a flash and a line cuts in beneath. Pass `build`, and optionally `title` and `line`. Ships light and dark.
