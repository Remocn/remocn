## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WordBurstCards } from "@/components/remocn/word-burst-cards";

const WordBurstCardsScene = () => (
  <WordBurstCards
    line="Every screen you built, in motion"
    caption="Launch films from your product"
    images={["https://example.com/a.jpg", "https://example.com/b.jpg"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WordBurstCards"
    component={WordBurstCardsScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The headline sits centred, then its words burst outward while cards and photos spread through 3D space; the logo and caption land last. Pass `line`, `caption` and `images` (your own URLs; the default photos only exist in the remocn repo). `reverse` plays the whole timeline backwards and `showLogo` toggles the mark. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
