## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SplitMatch } from "@/components/remocn/split-match";

const SplitMatchScene = () => (
  <SplitMatch
    words={["build", "ship", "launch", "remocn"]}
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SplitMatch"
    component={SplitMatchScene}
    durationInFrames={145}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two reels slam in and lock on the first word, then step to each next word in turn until the last one, where the seam closes and the gradient floods into the large logo. Pass `words`; length grows by 25 frames per extra word, and the file exports `splitMatchDuration(wordCount)` for the composition length. Ships light and dark.
