## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CollabLockup } from "@/components/remocn/collab-lockup";

const CollabLockupScene = () => (
  <CollabLockup
    left="remocn"
    right="Acme"
    joiner="×"
    caption="Launch videos, rendered from every workspace."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CollabLockup"
    component={CollabLockupScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two names or logos glide in from the sides, a joiner drops between them with an impact, a rule draws and the caption fades in under a glowing arc. Pass `left` and `right` (or `leftLogo` and `rightLogo`) and `caption`; the default right side is a placeholder partner. Ships light and dark.
