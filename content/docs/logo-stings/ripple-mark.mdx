## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RippleMark } from "@/components/remocn/ripple-mark";

const RippleMarkScene = () => (
  <RippleMark
    name="remocn"
    accent="#3B5BFD"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RippleMark"
    component={RippleMarkScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A field of dots ripples outward from the centre and the dots inside the R mark light up in the accent colour, then the camera pans and the name letters appear beside the mark. Pass `name` (Remocn is set as the real logo) or your own `logo` path. Ships light and dark.
