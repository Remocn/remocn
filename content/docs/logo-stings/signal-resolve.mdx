## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SignalResolve } from "@/components/remocn/signal-resolve";

const SignalResolveScene = () => (
  <SignalResolve
    name="emocn"
    caption="Less noise. More signal."
    traces={5}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SignalResolve"
    component={SignalResolveScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Several noisy scope traces run across the frame, a sweep cleans them into a flat line, the line draws into the R mark, and the name slides out of it as the caption fades in. Pass `name`, `caption` and `traces`. Ships light and dark.
