## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SpellOut } from "@/components/remocn/spell-out";

const SpellOutScene = () => (
  <SpellOut
    name="remocn"
    line="Say it once. Remember it."
    speed={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SpellOut"
    component={SpellOutScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Each letter of `name` drops in with a small impact and a hyphen between, holds spelled out, then closes up into the finished word while `line` rises beneath. Pass `name` and `line`; `speed` retimes it. Ships light and dark.
