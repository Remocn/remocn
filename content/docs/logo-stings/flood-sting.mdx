## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FloodSting } from "@/components/remocn/flood-sting";

const FloodStingScene = () => (
  <FloodSting
    icons={["cluster", "download", "globe", "gear", "brackets"]}
    pick={2}
    flood="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FloodSting"
    component={FloodStingScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A row of icon tiles plays a selection game: a highlight hops across them and slot-style rolls swap their glyphs until a press picks one. The picked tile floods the frame with colour and the logo lands between two dots. Pass `icons` from the built-in glyph set (cluster, download, globe, gear, brackets, spark, grid, diamonds), `pick` and the colours. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
