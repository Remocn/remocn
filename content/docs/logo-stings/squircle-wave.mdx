## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SquircleWave } from "@/components/remocn/squircle-wave";

const SquircleWaveScene = () => (
  <SquircleWave
    accent="#3B5BFD"
    theme="dark"
    speed={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SquircleWave"
    component={SquircleWaveScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dot grid fades up, then a diagonal wave of squircle cells sweeps across it and the cells inside the R mark lock in solid as the crest passes, leaving only the mark. There is no text prop and the mark is the baked-in remocn R. Pass `accent` for the wake colour. Ships light and dark.
