## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InkBloom } from "@/components/remocn/ink-bloom";

const InkBloomScene = () => (
  <InkBloom
    name="remocn"
    seed={3}
    theme="light"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="InkBloom"
    component={InkBloomScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A drop of ink falls onto the page, blooms outward in an organic shape, then thins and resolves into the lockup of logo and `name`. Pass `name`, or your own `logo`, and `seed` to change the bloom. The theme prop switches off-white paper with dark ink (default) to light ink on black.
