## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TitleConverge } from "@/components/remocn/title-converge";

const TitleConvergeScene = () => (
  <TitleConverge
    word="remocn"
    accent="#3B5BFD"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TitleConverge"
    component={TitleConvergeScene}
    durationInFrames={175}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera starts tight on the middle of the word and pulls out as each letter of `word` drifts in along its own straight path and locks into place, then two rules slide in above and below. remocn is set as the real logo. Pass `word`. Ships light and dark.
