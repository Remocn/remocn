## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NoiseForgeSting } from "@/components/remocn/noise-forge-sting";

const NoiseForgeStingScene = () => (
  <NoiseForgeSting
    tagline="Launch videos, built from parts."
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NoiseForgeSting"
    component={NoiseForgeStingScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A spark opens a seam of light, glyph slices forge the wordmark in a hot colour, then it cools to the ink colour and the tagline fades in word by word. Pass `tagline`; recolour with `hot`, `ink` and `accent`. The wordmark is the baked-in remocn logo. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
