## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { QuadtreeMark } from "@/components/remocn/quadtree-mark";

const QuadtreeMarkScene = () => (
  <QuadtreeMark
    name="emocn"
    accent="#3B5BFD"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="QuadtreeMark"
    component={QuadtreeMarkScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Coarse pixel squares subdivide step by step around the R mark until the edges are sharp, the camera pans, and the name appears beside the mark. Pass `logo` as an SVG path (or several) to subdivide your own mark and `name` for the text after it. Ships light and dark.
