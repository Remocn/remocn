## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GiantMarkBackdrop } from "@/components/remocn/giant-mark-backdrop";

const GiantMarkBackdropScene = () => (
  <GiantMarkBackdrop
    prompt="Make a launch film for our v2 release"
    placeholder="Describe your launch film"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GiantMarkBackdrop"
    component={GiantMarkBackdropScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The wordmark appears small on a shader ground, then a flood of colour rises as the mark balloons into a giant backdrop. A prompt card pops in, types the prompt and lights its send button. Pass `prompt` and `placeholder` to match your product and `accent` for your colour; the wordmark is the baked-in Remocn logo. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
