## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BounceLogo } from "@/components/remocn/bounce-logo";

const BounceLogoScene = () => (
  <BounceLogo
    brand="remocn"
    line="Hit the corner."
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BounceLogo"
    component={BounceLogoScene}
    durationInFrames={168}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The wordmark bounces off the frame edges on a path solved backwards so the final hit always lands in a corner, where it blooms, glides to the centre as the lockup and `line` rises beneath. Pass `brand` and `line`. Ships light and dark.
