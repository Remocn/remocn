## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LogoConstruct } from "@/components/remocn/logo-construct";

const LogoConstructScene = () => (
  <LogoConstruct
    name="emocn"
    accent="#3B5BFD"
    theme="light"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LogoConstruct"
    component={LogoConstructScene}
    durationInFrames={240}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A blueprint grid appears and the construction of the R is drawn: circles, guides, dimensions and an outline, which then fills with a mesh as the camera pulls back and the wordmark inks in. Pass `name` for the letters after the R, or `logo` to replace the R. The theme prop switches blueprint paper (default) to drafting film on black.
