## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlyphBlockDecode } from "@/components/remocn/glyph-block-decode";

const GlyphBlockDecodeScene = () => (
  <GlyphBlockDecode
    name="Remocn Studio"
    url="remocn.dev/studio"
    images={["https://example.com/a.jpg", "https://example.com/b.jpg"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GlyphBlockDecode"
    component={GlyphBlockDecodeScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Blocky fragments, some filled with photos or flat colour, scramble and decode into `name`; the `url` decodes after it and a rule draws underneath. Pass `name`, `url` and, to use your own pictures, `images` (the default photos only exist in the Remocn repo). Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
