## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CtaCollapseMark } from "@/components/remocn/cta-collapse-mark";

const CtaCollapseMarkScene = () => (
  <CtaCollapseMark
    cta="Ship your first launch film"
    url="remocn.dev"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CtaCollapseMark"
    component={CtaCollapseMarkScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The call to action fades in word by word with the URL beneath it, then its glyphs shed and fly into the cells of the R mark, which snaps together before the rest of the wordmark springs in. Pass `cta`, `url` and `accent` to make it yours; the wordmark is the baked-in Remocn logo. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
