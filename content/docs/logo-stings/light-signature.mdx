## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LightSignature } from "@/components/remocn/light-signature";

const LightSignatureScene = () => (
  <LightSignature
    eyebrow="The all-new"
    name="remocn"
    tagline="Launch-video scenes, ready to render."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LightSignature"
    component={LightSignatureScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A streak of light chases across the name, igniting it as it passes and returning to settle, then the eyebrow and tagline fade in around it. Pass `eyebrow`, `name` or `logo`, `tagline` and `lightColor`. Ships light and dark.
