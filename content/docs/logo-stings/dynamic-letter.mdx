## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DynamicLetter } from "@/components/remocn/dynamic-letter";

const DynamicLetterScene = () => (
  <DynamicLetter
    text="emocn"
    variants={["solid", "outline", "stripes", "dots"]}
    final="overflow"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DynamicLetter"
    component={DynamicLetterScene}
    durationInFrames={110}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The R mark and wordmark hold still while one letter (the first o by default) cuts through treatments such as outline, stripes and dots, tightening on the beat, then lands on the `final` treatment as the poster. Pass `text`, `letterIndex`, `variants` and `final`. Ships light and dark.
