## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PhotoHalo } from "@/components/remocn/photo-halo";

const PhotoHaloScene = () => (
  <PhotoHalo
    words={["Launch", "films", "for", "everything", "you", "ship"]}
    accentWord={3}
    images={["https://example.com/a.jpg", "https://example.com/b.jpg"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PhotoHalo"
    component={PhotoHaloScene}
    durationInFrames={138}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A line of words appears while photo cards pop around it, then the text drops away and the photos converge into a row of circular thumbnails with the logo landing beside them. Pass `words`, `accentWord` for the highlighted word, and `images` as URLs (the default photos only exist in the remocn repo). Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
