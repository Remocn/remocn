## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SnapClick } from "@/components/remocn/snap-click";

const SnapClickScene = () => (
  <SnapClick
    text="emocn"
    label="Animations for Remotion"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SnapClick"
    component={SnapClickScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The two halves of the lockup slam together at a seam with a flash and a small shake, then `label` types in beneath it with a caret. Pass `text`, `label` and, to move the split, `seam`. Ships light and dark.
