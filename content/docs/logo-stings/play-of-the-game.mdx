## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PlayOfTheGame } from "@/components/remocn/play-of-the-game";

const PlayOfTheGameScene = () => (
  <PlayOfTheGame
    title="Play of the game"
    role="Solo builder"
    stat="Shipped in 6 hours"
    highlight="6 hours"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PlayOfTheGame"
    component={PlayOfTheGameScene}
    durationInFrames={100}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A banner with `title` slices in over the remocn logo, which slams in as the player with a `role` label beneath. Then `stat` flashes on its own plate with `highlight` filled in the accent gradient and a final sweep. The player is always the remocn logo. Ships light and dark.
