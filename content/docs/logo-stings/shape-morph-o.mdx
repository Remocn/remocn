## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ShapeMorphO } from "@/components/remocn/shape-morph-o";

const ShapeMorphOScene = () => (
  <ShapeMorphO
    word="remocn"
    mark
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ShapeMorphO"
    component={ShapeMorphOScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A single shape appears centred and morphs through circle, cookie, clover, burst, pill and square, then flies into the first o of the word as the other letters reveal and the counter opens. Pass `word` and `mark`, which sets a leading r as the R mark. Ships light and dark.
