## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlipSting } from "@/components/remocn/flip-sting";

const FlipStingScene = () => (
  <FlipSting
    line="LAUNCH FILMS"
    accent="#3B5BFD"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FlipSting"
    component={FlipStingScene}
    durationInFrames={130}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera pulls out of the R while flat graphic frames flip inside the letters, slowing page by page until the last one lands and the logo fills with the gradient. A small tracked `line` rises under it. Pass `line` and `accent`. Ships light and dark.
