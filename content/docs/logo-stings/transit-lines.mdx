## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TransitLines } from "@/components/remocn/transit-lines";

const TransitLinesScene = () => (
  <TransitLines
    title="remocn"
    kicker="Next stop"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TransitLines"
    component={TransitLinesScene}
    durationInFrames={135}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Coloured line routes draw across a grid, stations pop as the lines pass, and all lines converge on a hub that grows and resolves into `title`, with `kicker` above it. Pass `title`, `kicker` and, to draw your own map, `lines`. Ships light and dark.
