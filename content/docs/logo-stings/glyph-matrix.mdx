## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GlyphMatrix } from "@/components/remocn/glyph-matrix";

const GlyphMatrixScene = () => (
  <GlyphMatrix
    label="remocn"
    accent="#3B5BFD"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="GlyphMatrix"
    component={GlyphMatrixScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A round LED dot matrix shows 3, 2, 1, then its dots arc and hop into a pixel R, which slides aside as `label` types in beside it. Pass `label`; Remocn types emocn so the lockup reads as the real logo. Ships light and dark.
