## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BlinkCut } from "@/components/remocn/blink-cut";

const BlinkCutScene = () => (
  <BlinkCut
    words={["Cut", "Fast", "Loud", "Snap"]}
    framesPerWord={6}
    brand="remocn"
    line="Launch films, built in Remotion."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BlinkCut"
    component={BlinkCutScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Words cut in one per beat in changing sizes, positions and backgrounds, then the frame cuts to the closing lockup with a one-line tagline. Pass `words` (strings, or objects to set layout, ground and beats), `framesPerWord`, `brand` and `line`. The cut part lasts `words.length` times `framesPerWord` frames and the lockup settles about 18 frames after it. Ships light and dark.
