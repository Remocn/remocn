## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { Introducing } from "@/components/remocn/introducing";

const IntroducingScene = () => (
  <Introducing
    eyebrow="Introducing"
    name="remocn"
    tagline="Launch-video scenes for Remotion. Copy, paste, render."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="Introducing"
    component={IntroducingScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A large eyebrow settles in the centre and lifts to make room, then the name lands with a sweep of light and the tagline rises word by word. Pass `eyebrow`, `name` or `logo`, `tagline` and `accent`. Ships light and dark.
