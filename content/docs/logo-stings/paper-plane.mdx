## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PaperPlane } from "@/components/remocn/paper-plane";

const PaperPlaneScene = () => (
  <PaperPlane
    steps={["Write", "Render", "Launch"]}
    url="remocn.dev"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PaperPlane"
    component={PaperPlaneScene}
    durationInFrames={220}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A paper plane loops along a dotted flight path past three labelled stops, heads for the wordmark and lands as its full stop, then `url` appears beneath. Pass `steps` (three labels), `url` and `logo`. The theme prop defaults to light paper and also ships dark.
