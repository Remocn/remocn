## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LightTrailWrite } from "@/components/remocn/light-trail-write";

const LightTrailWriteScene = () => (
  <LightTrailWrite
    finish="accent"
    accent="#3B5BFD"
    speed={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LightTrailWrite"
    component={LightTrailWriteScene}
    durationInFrames={160}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A point of light writes the path stroke by stroke, leaving a trail that cools behind it, then a sweep turns the script into the lit logo. Pass your own single-stroke SVG `path` and choose `finish`. This component renders on its own dark ground and has no theme prop.
