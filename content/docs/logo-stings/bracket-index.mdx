## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BracketIndex } from "@/components/remocn/bracket-index";

const BracketIndexScene = () => (
  <BracketIndex
    prefix="Motion for"
    words={["launches", "changelogs", "demos"]}
    product="remocn"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BracketIndex"
    component={BracketIndexScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prefix phrase sits on screen while brackets open around the first word and roll through each next word, then close around the product name as the prefix steps aside. Pass `prefix`, `words` and `product`; each extra word adds 38 frames. Ships light and dark.
