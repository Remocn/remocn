## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SequelNumeral } from "@/components/remocn/sequel-numeral";

const SequelNumeralScene = () => (
  <SequelNumeral
    name="remocn"
    numeral="2"
    tagline="Part two. Out now."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SequelNumeral"
    component={SequelNumeralScene}
    durationInFrames={140}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The name appears with a small superscript numeral, which drops and swells into a giant numeral beside it before the tagline fades in. Pass `name`, `numeral` and `tagline`; `accent` colours the numeral and is red by default. Ships light and dark.
