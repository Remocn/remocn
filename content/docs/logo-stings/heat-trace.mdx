## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HeatTrace } from "@/components/remocn/heat-trace";

const HeatTraceScene = () => (
  <HeatTrace
    name="remocn"
    tagline="Launch-video scenes for Remotion. Copy, paste, render."
    eyebrow="New"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HeatTrace"
    component={HeatTraceScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A heat line is traced along the name in warm-to-cool gradient colours, then the glow cools and the tagline rises word by word, with an optional `eyebrow` above. Pass `name` or your own `logo`, plus `tagline` and `accent`. Ships light and dark.
