## Usage

`ScanFix` is a full-frame scene with two layers. A bright line with a soft wash
behind it travels from the top of the frame to the bottom. Above the line you
see `after`, below it `before`. When the line passes the version chip, the chip
switches from the first version to the second.

```tsx
import { ScanFix } from "@/components/remocn/scan-fix";

export const Ship = () => <ScanFix />;
```

Without props it scans the demo dashboard: the drifted v1 with red redlines and
issue boxes turns into v2 with blue redlines. Pass your own frames, 1280×720
each, with the same layout so the sweep reads as a fix.

```tsx
import { Img, staticFile } from "remotion";
import { ScanFix } from "@/components/remocn/scan-fix";

export const Ship = () => (
  <ScanFix
    before={<Img src={staticFile("v1.png")} />}
    after={<Img src={staticFile("v2.png")} />}
    brand="Acme"
    versions={["v3.2", "v4.0"]}
  />
);
```

Set `brand=""` to hide the version chip.

## Timing

At 30 fps and `speed={1}`:

| Frames | Motion |
| --- | --- |
| 14–20 | The band fades in above the frame |
| 18–98 | The band sweeps top to bottom with a cubic ease-in-out |
| ~22 | The version chip flips as the band passes it |
| 92–100 | The band fades out below the frame |

`scanFixLength` is 100. `speed` scales the whole timeline.
