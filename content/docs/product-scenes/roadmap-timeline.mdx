## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RoadmapTimeline } from "@/components/remocn/roadmap-timeline";

const RoadmapTimelineScene = () => (
  <RoadmapTimeline
    dragProject="Public API"
    dragDays={14}
    today="Aug 26"
    milestone={{ name: "Public launch", date: "Nov 18" }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RoadmapTimeline"
    component={RoadmapTimelineScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A roadmap window draws month columns, project bars and dependency links, then sweeps in a today marker and a milestone flag. The cursor grabs `dragProject` and moves it `dragDays` days later; blocked projects shift to keep their gap and a toast announces the reschedule. Pass `projects` (name, start, end, status, progress, lead, color, dependsOn), `milestone`, `today` and `dragProject`. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
