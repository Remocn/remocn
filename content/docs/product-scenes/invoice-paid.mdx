## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InvoicePaid } from "@/components/remocn/invoice-paid";

const InvoicePaidScene = () => <InvoicePaid sender="Northwind Studio" customer="Acme Corp" number="INV-1007" theme="dark" />;

export const RemotionRoot = () => (
  <Composition
    id="InvoicePaid"
    component={InvoicePaidScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An invoice document and a status timeline appear side by side; a cursor presses Send, the timeline steps through Created, Sent, Viewed and Paid, a PAID stamp lands on the invoice, and a payout notification slides in. Pass `sender`, `customer`, `lines` and `events` to make it your own, and `payoutAccount` and `payoutArrival` for the notification. It has a `theme` prop and ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
