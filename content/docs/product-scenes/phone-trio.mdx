## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PhoneTrio } from "@/components/remocn/phone-trio";

const PhoneTrioScene = () => (
  <PhoneTrio
    name="Ines Marlow"
    role="Motion designer"
    headline="Driven by motion, obsessed with the"
    accentWord="seamless."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PhoneTrio"
    component={PhoneTrioScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Three phones rise one after another: a profile card with `name`, `handle`, `role` and `skills`, a photo feed that scrolls, and a third that receives a `liveLabel` banner as the trio fans forward. The headline joins `headline` with an accent-colored `accentWord`. Ships dark by default and light. The default `images` are files that only exist in the remocn repo, so pass your own photo URLs.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
