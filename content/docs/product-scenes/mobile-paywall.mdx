## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MobilePaywall } from "@/components/remocn/mobile-paywall";

const MobilePaywallScene = () => <MobilePaywall appName="Orbit Pro" title="Unlock every feature" cta="Start free for 7 days" theme="dark" />;

export const RemotionRoot = () => (
  <Composition
    id="MobilePaywall"
    component={MobilePaywallScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone slides in and a paywall sheet lists features and two plans. The second plan starts selected, the first is tapped, the CTA is double-clicked to pay, and a Welcome confirmation lists the trial dates. Pass `appName`, `title`, `features`, `plans` and `lines` (the headline beside the phone) to make it yours. It has a `theme` prop and ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
