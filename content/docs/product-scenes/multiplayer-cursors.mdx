## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MultiplayerCursors } from "@/components/remocn/multiplayer-cursors";

const MultiplayerCursorsScene = () => (
  <MultiplayerCursors boardTitle="Launch plan" stickyText="Record the hero demo by Friday" commentText="Love this. Ship it Friday." />
);

export const RemotionRoot = () => (
  <Composition
    id="MultiplayerCursors"
    component={MultiplayerCursorsScene}
    durationInFrames={270}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Four named cursors join a board: the first drops a sticky and types into it, the second marquee-selects a card, the third drags a shape, and the fourth leaves a typed comment. Pass `collaborators`, `boardTitle`, `stickyText` and `commentText` to make it yours. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
