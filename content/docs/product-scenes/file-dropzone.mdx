## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FileDropzone } from "@/components/remocn/file-dropzone";

const FileDropzoneScene = () => (
  <FileDropzone
    title="Upload files"
    destination="Research"
    files={[{ name: "Q3-board-deck.pdf", size: 4200000 }, { name: "customers.csv", size: 640000 }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FileDropzone"
    component={FileDropzoneScene}
    durationInFrames={195}
    fps={30}
    width={1280}
    height={720}
  />
);
```

An upload modal opens over an app window; file cards drop into the dropzone, rows appear with progress bars that finish at different times, then Upload is clicked and the files land in the table behind with a confirming toast. Pass `files` (name, size in bytes, optional type), `title` and `destination`. Pass `image` for the preview of image files; the default image only exists in the remocn repo. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
