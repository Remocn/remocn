## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TableFilter } from "@/components/remocn/table-filter";

const TableFilterScene = () => (
  <TableFilter
    title="Companies"
    filterAttribute="Stage"
    filterValue="Closed-won"
    bulkAction="Add to sequence"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TableFilter"
    component={TableFilterScene}
    durationInFrames={220}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A table window opens a filter popover and applies `filterValue` to `filterAttribute`, collapsing the list; the cursor then sorts by ARR, checks `selectCount` rows and a bulk-action bar slides up with `bulkAction`, which the cursor hovers and clicks. Pass `rows` (company, domain, stage, arr, owner, lastInteraction, color), `title` and `workspace`. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
