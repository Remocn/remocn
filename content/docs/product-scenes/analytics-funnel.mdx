## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AnalyticsFunnel } from "@/components/remocn/analytics-funnel";

const AnalyticsFunnelScene = () => (
  <AnalyticsFunnel
    title="Activation funnel"
    variantLabel="New onboarding"
    tooltipStep={2}
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AnalyticsFunnel"
    component={AnalyticsFunnelScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A funnel chart window grows its bars step by step, then a cursor clicks a variant toggle and the bars morph from control to variant with an uplift badge. A tooltip then opens on one step with a breakdown. Pass your own `steps` (control and variant counts), `title` and `breakdown`. It ships light and dark through the `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
