## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { RideTracking } from "@/components/remocn/ride-tracking";

const RideTrackingScene = () => (
  <RideTracking
    eta={4}
    pickup="214 Linden St"
    lines={["Book it in one tap.", "Watch it come to you.", "Your ride is here."]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="RideTracking"
    component={RideTrackingScene}
    durationInFrames={270}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone shows a map where the route draws, a trip card slides up with the driver and car, and the car follows the route while the ETA counts down from `eta` minutes. It ends on an arrival check. Pass `driver` (name, rating, car, plate), `pickup` and `eta`; `lines` are the three captions beside the phone. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
