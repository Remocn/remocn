## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HomeWidget } from "@/components/remocn/home-widget";

const HomeWidgetScene = () => (
  <HomeWidget
    appName="Acme"
    widgetName="Renders"
    size="medium"
    bars={[42, 58, 36, 70, 64, 88, 76]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HomeWidget"
    component={HomeWidgetScene}
    durationInFrames={290}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The home screen icons jiggle, the plus opens a widget gallery, the cursor picks a size and the widget lands on the page. Its headline number then counts up and the last bar grows live. Set `size` to `small` or `medium`, `stat` for the number and `bars` for the week; `lines` are the three captions beside the phone. Ships light (daytime wallpaper) and dark (dusk).

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
