## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { HeatDrainReveal } from "@/components/remocn/heat-drain-reveal";

const HeatDrainRevealScene = () => (
  <HeatDrainReveal
    headline="Plan the whole launch week."
    monthLabel="2026 / 11"
    events={[{ day: 19, label: "Launch", launch: true }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="HeatDrainReveal"
    component={HeatDrainRevealScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A month calendar rises in hot orange tones, then the heat drains out of the grid into a dithered glow while event labels appear and the launch event gets an accent chip. Pass `headline`, `monthLabel`, `events` (mark one with `launch: true`) and `upcoming`; use `firstDay`, `daysInPrevMonth` and `daysInMonth` to match the real month and `heat` for the five-stop heat palette. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
