## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AppStoreListing } from "@/components/remocn/app-store-listing";

const AppStoreListingScene = () => (
  <AppStoreListing
    appName="Acme"
    subtitle="Plan your week"
    rating={4.8}
    chartRank={3}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AppStoreListing"
    component={AppStoreListingScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone rises with the app listing: icon, info strip and a screenshot carousel. A tap on Get collapses the button into a progress ring, the screenshots swipe sideways while it downloads, and the button expands into Open. Pass `appName`, `subtitle`, `rating`, `iconSrc` and `screenshots` (each with a `src`) to match your app; `lines` are the four captions beside the phone. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
