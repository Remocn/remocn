## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FlowBuilder } from "@/components/remocn/flow-builder";

const FlowBuilderScene = () => (
  <FlowBuilder
    title="Welcome new signups"
    workspace="acme"
    toast="Live · runs on every signup"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FlowBuilder"
    component={FlowBuilderScene}
    durationInFrames={205}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A workflow window drops in nodes one by one with connecting curves; the cursor presses Run, a packet travels through each node and its run time appears, then Publish is clicked and a toast confirms the flow is live. Pass `nodes` (id, title, subtitle, icon, color, duration and `next` ids) to define your own graph, plus `title` and `toast`. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
