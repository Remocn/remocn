## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VideoWatchPage } from "@/components/remocn/video-watch-page";

const VideoWatchPageScene = () => (
  <VideoWatchPage
    title="Introducing Acme 2.0"
    channel={{ name: "Acme", subscribers: 48200 }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="VideoWatchPage"
    component={VideoWatchPageScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A watch page shows the player with a title, channel and stat row; the cursor hovers the player, clicks Subscribe and then Like while the subscriber, like, view and comment counts count up. Pass `title`, `channel` (name, subscribers), `stats` (from and to values) and a poster `src`, or `children` for custom player content laid out at 836 by 470. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
