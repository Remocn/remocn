## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TileSnakeLoader } from "@/components/remocn/tile-snake-loader";

const TileSnakeLoaderScene = () => (
  <TileSnakeLoader
    name="Lumen Studio"
    url="lumen.studio"
    headline={"Launch films,\ncut in minutes."}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TileSnakeLoader"
    component={TileSnakeLoaderScene}
    durationInFrames={178}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A product name builds letter by letter on a loader while media tiles snake across and a percentage fills. The tiles retract, a skeleton grows, and the window settles into a landing page with a headline, sub line and a hero video card. Pass `name`, `product`, `headline` (use a newline for a line break), `sub` and `url`. The default `images` are files that only exist in the Remocn repo, so pass your own image URLs. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
