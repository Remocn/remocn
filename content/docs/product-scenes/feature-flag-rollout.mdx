## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { FeatureFlagRollout } from "@/components/remocn/feature-flag-rollout";

const FeatureFlagRolloutScene = () => (
  <FeatureFlagRollout
    flagName="New checkout flow"
    steps={[5, 25, 100]}
    actor="Maya Chen"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="FeatureFlagRollout"
    component={FeatureFlagRolloutScene}
    durationInFrames={186}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A feature flag card appears, the toggle flips on at the first step, and a cursor drags the rollout slider through each percentage in `steps` while two guardrail charts (error rate and p95 latency) draw live and an audit log adds a row per step. Pass `flagName`, `flagKey`, `actor` and `steps` to match your product; `metrics` and `history` replace the charts and audit rows. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
