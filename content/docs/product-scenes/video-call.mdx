## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VideoCall } from "@/components/remocn/video-call";

const VideoCallScene = () => (
  <VideoCall meetingCode="abc-defg-hij" presenter={1} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="VideoCall"
    component={VideoCallScene}
    durationInFrames={300}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Up to six participants join the grid one by one, then the presenter's tile becomes a shared screen and the rest move to a side strip. A reaction tray pops up and emoji float up the screen. Pass `participants` (name, color, camera, muted), `meetingCode`, and your own `src` screenshot or `children` for the shared screen.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
