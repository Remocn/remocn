## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CalendarBooking } from "@/components/remocn/calendar-booking";

const CalendarBookingScene = () => (
  <CalendarBooking
    host={{ name: "Maya Chen", initials: "MC" }}
    day={18}
    pick="10:30am"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="CalendarBooking"
    component={CalendarBookingScene}
    durationInFrames={165}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A scheduling card shows the host, event details and a month grid; the cursor picks a `day`, then a time slot, and presses Confirm, which morphs the card into a scheduled confirmation with a drawn check and detail rows. Pass `host`, `event`, `slots`, `pick` and `day` for your own flow. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
