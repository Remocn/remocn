## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BentoBuild } from "@/components/remocn/bento-build";

const BentoBuildScene = () => (
  <BentoBuild
    eyebrow="Features"
    heading="Everything a launch video needs."
    highlightOrder={[0, 1, 4]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BentoBuild"
    component={BentoBuildScene}
    durationInFrames={170}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A heading and eyebrow appear over an empty grid, then tiles pop in with a stagger and lock into a bento layout; chosen tiles are lit one after another while the rest dim. Pass `tiles` (title, description, `span` as `[columns, rows]`, optional icon and visual), `highlightOrder` for the spotlight sequence, `heading` and `eyebrow`. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
