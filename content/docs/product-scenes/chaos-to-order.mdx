## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChaosToOrder } from "@/components/remocn/chaos-to-order";

const ChaosToOrderScene = () => (
  <ChaosToOrder
    items={["#launch-war-room", "Inbox", "Payment failed", "Standup in 2 min"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="ChaosToOrder"
    component={ChaosToOrderScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Windows, sticky notes and toast alerts drop onto the screen while an unread counter races up, then everything is pulled to the center and replaced by a clean issues tracker window. Pass `items` to relabel the chaos pieces in drop order, and `children` to replace the tracker with your own product window. Ships dark by default and light.
