## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PrMerge } from "@/components/remocn/pr-merge";

const PrMergeScene = () => (
  <PrMerge
    repo="acme/app"
    title="Add dark mode"
    number={128}
    branch="feat/dark-mode"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PrMerge"
    component={PrMergeScene}
    durationInFrames={210}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A pull request card enters with a list of CI checks that run and pass one by one. Once all are green, a cursor clicks Merge, confirms, and the checks collapse into a Merged state with a Delete branch prompt. Pass `repo`, `title`, `number`, `branch` and `checks` (plain names or `{ name, workflow, seconds }`) to make it yours; it ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
