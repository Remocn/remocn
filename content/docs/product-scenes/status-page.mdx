## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StatusPage } from "@/components/remocn/status-page";

const StatusPageScene = () => (
  <StatusPage brand="Acme" url="status.acme.dev" year={2026} />
);

export const RemotionRoot = () => (
  <Composition
    id="StatusPage"
    component={StatusPageScene}
    durationInFrames={240}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A status card builds a row of 90-day uptime bars per service, and the banner flips from an active incident to a resolved check. The cursor then arcs in to hover one incident bar, slides to a second to show its tooltip, and leaves. Pass `brand`, `url` and `components` (each with `uptime` and `incidents`) to describe your services; `hover` pins the first bar. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
