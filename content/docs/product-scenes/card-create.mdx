## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { CardCreate } from "@/components/remocn/card-create";

const CardCreateScene = () => (
  <CardCreate holder="Alex Rivera" last4="9034" accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="CardCreate"
    component={CardCreateScene}
    durationInFrames={370}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone slot prints a new card, a cursor taps through finish swatches, the holder name is engraved, the card flips and its full number scrambles into view, then it joins the wallet stack with a toast. Five caption lines beside the phone mark each beat. Pass `holder`, `last4`, `colors` with matching `finishes`, and `lines` to make it yours. The `theme` prop ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
