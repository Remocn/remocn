## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { VoiceAgent } from "@/components/remocn/voice-agent";

const VoiceAgentScene = () => (
  <VoiceAgent
    agentName="Ava"
    callerName="Maya Chen"
    summaryStatus="Booked"
    accent="#3B5BFD"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="VoiceAgent"
    component={VoiceAgentScene}
    durationInFrames={340}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A call window opens with live speaking bars for the agent and the caller. Turns stream word by word, one is interrupted mid-sentence, a tool call runs and resolves, the call ends and a summary card lands. Pass your own `turns`, names and `summary` rows to retell the call. It ships light and dark through the `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
