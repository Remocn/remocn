## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { InviteTeam } from "@/components/remocn/invite-team";

const InviteTeamScene = () => (
  <InviteTeam emails={["maya@kitebase.io", "leo@kitebase.io"]} role="Editor" workspace="Kitebase" />
);

export const RemotionRoot = () => (
  <Composition
    id="InviteTeam"
    component={InviteTeamScene}
    durationInFrames={215}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A project app opens behind an invite modal; a cursor types up to three emails into chips, switches the role in a select, clicks send, and avatars fly into the header while a toast confirms. Pass `emails`, `role` and `workspace` to make it yours, and `images` with your own project thumbnails (the default files only exist in the Remocn repo). It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
