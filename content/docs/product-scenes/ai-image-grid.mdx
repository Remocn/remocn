## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AiImageGrid } from "@/components/remocn/ai-image-grid";

const AiImageGridScene = () => (
  <AiImageGrid
    prompt="a ceramic teapot on a linen cloth, studio light"
    images={["/shots/teapot-1.png", "/shots/teapot-2.png"]}
    layout="3x2"
    pick={2}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AiImageGrid"
    component={AiImageGridScene}
    durationInFrames={240}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prompt card types in and the generate button is pressed. The card docks below a grid of tiles that diffuse into finished images one after another, then a cursor picks one tile, the others fall away, and the pick zooms into a detail view with a download button. Pass `prompt`, `model`, and `images` (your own image URLs, since the demo art is procedural) to make it yours; `layout` and `pick` control the grid. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
