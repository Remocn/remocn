## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { DeviceGrowsAround } from "@/components/remocn/device-grows-around";

const DeviceGrowsAroundScene = () => (
  <DeviceGrowsAround
    name="Launch Film"
    subtitle="Studio export"
    metric={48213}
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="DeviceGrowsAround"
    component={DeviceGrowsAroundScene}
    durationInFrames={186}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A project name and subtitle type in, a plays counter card appears, then a phone frame grows around it as the camera pushes back to show a chart, range tabs, a list and an all-time total counting up. Pass your own `name`, `subtitle`, `metric`, `delta`, `total` and `gain`. It ships dark and light through the `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
