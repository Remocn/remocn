## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LiveDashboard } from "@/components/remocn/live-dashboard";

const LiveDashboardScene = () => (
  <LiveDashboard workspace="Kitebase" change={15.1} theme="light" />
);

export const RemotionRoot = () => (
  <Composition
    id="LiveDashboard"
    component={LiveDashboardScene}
    durationInFrames={190}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dashboard window opens, the headline total counts up while the cumulative chart draws and KPI cards fill in. Three live payments then land one by one, extending the chart and pushing rows into the activity feed. Pass your own `workspace`, `series`, `metrics` and `live` payments. It ships light and dark through the `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
