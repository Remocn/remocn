## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PromptToApp } from "@/components/remocn/prompt-to-app";

const PromptToAppScene = () => (
  <PromptToApp
    prompt="Build a landing page for Lumen, a candle shop"
    projectName="lumen-site"
    deployUrl="lumen.remocn.app"
    siteName="Lumen"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PromptToApp"
    component={PromptToAppScene}
    durationInFrames={314}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prompt types into a chat, the assistant thinks and streams a short plan, then writes each file while a site preview builds beside it. A cursor clicks deploy, and the live URL pops in. Pass `prompt`, `plan`, `files`, `projectName`, and `deployUrl` for the chat side, and `siteName`, `siteHeadline`, `siteBody`, `siteLinks`, and `pours` for the built-in sample page, or pass your own React as `children` to replace the preview. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
