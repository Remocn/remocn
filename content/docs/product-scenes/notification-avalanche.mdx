## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NotificationAvalanche } from "@/components/remocn/notification-avalanche";

const NotificationAvalancheScene = () => (
  <NotificationAvalanche
    clearLabel="All caught up."
    total={128}
    counterLabel="unread before 10 am"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NotificationAvalanche"
    component={NotificationAvalancheScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Notification cards drop onto a phone lock screen at an accelerating pace while an unread counter climbs to `total`. A swipe groups them into one stack, then the screen clears to `clearLabel` with a check and `clearSubLabel`. Pass `notifications` (app, title, body, color), `clearLabel` and `total` to retell your inbox, and set `surface` to `desktop` for a laptop layout. The default `wallpaper` is a file that only exists in the remocn repo, so pass your own image URL. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
