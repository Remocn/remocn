## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WhatsNewModal } from "@/components/remocn/whats-new-modal";

const WhatsNewModalScene = () => (
  <WhatsNewModal
    brand="Acme"
    userName="Maya Chen"
    slides={[{ eyebrow: "New in 2.0", title: "Launch videos, built from components", body: "Drop in a scene and ship.", cta: "Try it now" }]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WhatsNewModal"
    component={WhatsNewModalScene}
    durationInFrames={250}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The app dashboard dims and a modal pops in with header art, an eyebrow, a title and a body; the slides swipe one by one, then a cursor clicks the final call to action. Pass `slides` (eyebrow, title, body, optional `cta` and `src`), `brand` and `userName`, and put your own app behind it with `children` or `src`. The default `images` are files that only exist in the remocn repo, so pass your own. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
