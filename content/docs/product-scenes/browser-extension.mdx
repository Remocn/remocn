## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BrowserExtension } from "@/components/remocn/browser-extension";

const BrowserExtensionScene = () => (
  <BrowserExtension
    title="Why small teams ship faster"
    extensionName="Acme"
    collection="Reading list"
    saveLabel="Save to Acme"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="BrowserExtension"
    component={BrowserExtensionScene}
    durationInFrames={200}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A browser window shows an article; the cursor clicks the extension icon, a popup reads the page, three passages are highlighted, a bullet summary fills in and the save button files it into a collection, ending with a toast. Pass `title`, `paragraphs`, `highlights` (text fragments that appear inside the paragraphs), `summary` and `extensionName` for your own story. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
