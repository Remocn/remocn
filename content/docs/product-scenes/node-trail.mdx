## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NodeTrail } from "@/components/remocn/node-trail";

const NodeTrailScene = () => (
  <NodeTrail
    prompt="A teaser for our spring release"
    headline="One prompt. Every format."
    boardName="spring-release.flow"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NodeTrail"
    component={NodeTrailScene}
    durationInFrames={193}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prompt field types your text and is pressed, then dotted lines draw out to each step node in turn, each arriving with a pop. The camera then pulls back to reveal the whole board with its name, and the headline rises in. Pass `prompt`, `steps` (label, icons, tint, columns), `headline`, and `boardName` to make it yours. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
