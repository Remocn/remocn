## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StockScrub } from "@/components/remocn/stock-scrub";

const StockScrubScene = () => <StockScrub ticker="ORBT" name="Orbit Labs" theme="light" />;

export const RemotionRoot = () => (
  <Composition
    id="StockScrub"
    component={StockScrubScene}
    durationInFrames={270}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone shows a stock page whose price line draws in, then a finger presses and scrubs the chart left and right while the price readout follows. It taps the 1Y tab to morph the chart, then taps Buy to raise a buy sheet. Pass `ticker`, `name`, `series` and `yearSeries`, and `lines` for the headline beside the phone. It has a `theme` prop and ships light and dark (dark by default).

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
