## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SocialScheduler } from "@/components/remocn/social-scheduler";

const SocialSchedulerScene = () => (
  <SocialScheduler
    text="We just shipped dark mode."
    brand="Acme"
    handle="acme"
    pick={1}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SocialScheduler"
    component={SocialSchedulerScene}
    durationInFrames={228}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A composer types `text`, attaches media and opens a time picker; the cursor chooses the slot at index `pick`, presses Schedule, and the post lands in the weekly queue with a confirming toast. Pass `text`, `brand`, `handle`, `slots` (label and optional hint), `queue` and `days` to match your product, and `mediaSrc` for the attached image. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
