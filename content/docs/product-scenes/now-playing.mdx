## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { NowPlaying } from "@/components/remocn/now-playing";

const NowPlayingScene = () => (
  <NowPlaying
    title="Launch Day"
    artist="Acme"
    tint="#B8553A"
    lyrics={["Shipped it at midnight", "and the build came green"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="NowPlaying"
    component={NowPlayingScene}
    durationInFrames={300}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone rises showing the player: a cursor taps play, the heart is liked, the lyrics panel opens and each line lights up in turn as the list scrolls. Pass `title`, `artist`, `lyrics` and `tint` (the gradient color); with `variant="mini"` the scene starts from a mini player that expands. Pass `src` for your own cover art, or omit it for the built-in artwork.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
