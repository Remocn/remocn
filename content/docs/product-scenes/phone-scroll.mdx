## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PhoneScroll } from "@/components/remocn/phone-scroll";

const PhoneScrollScene = () => (
  <PhoneScroll
    stops={[930]}
    label="Find your next stay in two taps."
    labelAccent="two taps."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PhoneScroll"
    component={PhoneScrollScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone springs up beside a headline, then flicks its tall screen to each scroll stop with motion blur and momentum while a touch dot marks the press. Pass `src` with a tall screenshot, or `children` with your own 393pt-wide screen (omit both for a built-in sample feed), `stops` for the scroll offsets, and `label` plus `labelAccent` for the headline. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
