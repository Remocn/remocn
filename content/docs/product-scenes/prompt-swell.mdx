## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PromptSwell } from "@/components/remocn/prompt-swell";

const PromptSwellScene = () => (
  <PromptSwell
    prompt="Build a pricing page for our scheduling app"
    src="/shots/app-hero.png"
    tiers={[
      { name: "Solo", price: "$9" },
      { name: "Team", price: "$29" },
    ]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="PromptSwell"
    component={PromptSwellScene}
    durationInFrames={156}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prompt card types your request and is sent, then it swells into a builder window with a checklist of steps on one side and a page preview on the other. The preview builds a hero, scrolls to pricing tiers and a waitlist, publishes, and a live toast appears. Pass `prompt`, `steps`, `tiers`, `url`, and `src` (your own hero image, since the default file only exists in the remocn repo). It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
