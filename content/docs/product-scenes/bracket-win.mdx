## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { BracketWin } from "@/components/remocn/bracket-win";

const BracketWinScene = () => (
  <BracketWin title="CHAMPION" caption="Season one" theme="dark" />
);

export const RemotionRoot = () => (
  <Composition
    id="BracketWin"
    component={BracketWinScene}
    durationInFrames={125}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Eight slots slide in, quarterfinals, semifinals and the final resolve in turn with scores ticking in, then the final node bursts into a gradient plate that slams in the champion title and logo. Pass your own `opponents`, `title`, `caption` and `rounds` labels. It ships dark and light through the `theme` prop.
