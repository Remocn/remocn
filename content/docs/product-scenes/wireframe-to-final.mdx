## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WireframeToFinal } from "@/components/remocn/wireframe-to-final";

const WireframeToFinalScene = () => (
  <WireframeToFinal
    captions={["Idea", "Product"]}
    measurements={["1440", "900", "288"]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="WireframeToFinal"
    component={WireframeToFinalScene}
    durationInFrames={225}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A blueprint-style stage draws the outline, dimension lines and gray wireframe blocks of a dashboard, then a light sweep fills it into the finished product UI while the caption swaps from `captions[0]` to `captions[1]`. Pass `src` with a screenshot of your product (a built-in dashboard shows if omitted), `captions` and `measurements`. Ships light and dark.
