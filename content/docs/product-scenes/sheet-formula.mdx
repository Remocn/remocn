## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SheetFormula } from "@/components/remocn/sheet-formula";

const SheetFormulaScene = () => (
  <SheetFormula
    formula="=D2/C2"
    formulaHeader="ARPU"
    valueFormat="currency"
    chartTitle="ARPU by month"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SheetFormula"
    component={SheetFormulaScene}
    durationInFrames={290}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A sheet window types `formula` into the first cell of a new column, the cursor drags the fill handle to copy it down every row, then the chart button drops an animated bar chart of the results. Pass `rows` (month, signups, paid, revenue), `formula` (references use columns A to D from row 2), `formulaHeader`, `valueFormat` and `chartTitle`; `lines` are three captions beside the sheet. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
