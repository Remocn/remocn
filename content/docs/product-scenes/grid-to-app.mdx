## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { GridToApp } from "@/components/remocn/grid-to-app";

const GridToAppScene = () => (
  <GridToApp storeName="Hearth & Co" pageTitle="Catalogue" accent="#ff6a2b" />
);

export const RemotionRoot = () => (
  <Composition
    id="GridToApp"
    component={GridToAppScene}
    durationInFrames={132}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Two rows of product tiles pull back into a store admin window with a sidebar, header and a product table. The product count rolls up, then the Publish button presses and flips to Store live. Pass `storeName`, `pageTitle`, `products` (name and price) and your own `images`, because the default images use `staticFile(...)` paths that only exist in the Remocn repo. The `theme` prop ships dark and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
