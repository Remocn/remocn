## Usage

`TokenTags` is a full-frame scene. Everything outside `focus` washes toward the
background. Then, tag by tag, a dot lands on the element, a leader line runs out
with one elbow and a dark chip with a color swatch and the token name settles at
its end.

```tsx
import { TokenTags } from "@/components/remocn/token-tags";

export const Tokens = () => <TokenTags />;
```

Without children it tags the demo dashboard's card row. For your own UI, pass it
as children in a 1280×720 frame and list the tags in frame pixels. With children
the wash is off unless you pass `focus`.

```tsx
import { TokenTags } from "@/components/remocn/token-tags";

export const Tokens = () => (
  <TokenTags
    focus={{ x: 300, y: 160, w: 680, h: 120 }}
    tokens={[
      { anchor: [340, 220], at: [420, 360], label: "bg/brand", swatch: "#7D52F4" },
      { anchor: [620, 200], at: [700, 400], label: "text/strong", swatch: "#0E121B" },
    ]}
  >
    <MyScreen />
  </TokenTags>
);
```

The leader leaves `anchor` diagonally, bends at the chip's height and runs
level into the chip at `at`, so place chips below or above their anchors.

## Timing

At 30 fps and `speed={1}`:

| Frames | Motion |
| --- | --- |
| 0–12 | The wash fades in around `focus` |
| 12 + n × `stagger` | Tag n's dot pops onto its element |
| 15 + n × `stagger` | Its leader line draws over 14 frames |
| 25 + n × `stagger` | Its chip rises in over 12 frames |

`tokenTagsLength` is 61 with the five demo tags. `speed` scales the whole
timeline.
