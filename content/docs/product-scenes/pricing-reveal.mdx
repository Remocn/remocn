## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { PricingReveal } from "@/components/remocn/pricing-reveal";

const PricingRevealScene = () => <PricingReveal heading="Pricing that scales with you." discountLabel="−20% this week" badgeLabel="Best value" />;

export const RemotionRoot = () => (
  <Composition
    id="PricingReveal"
    component={PricingRevealScene}
    durationInFrames={105}
    fps={30}
    width={1280}
    height={720}
  />
);
```

Three plan cards rise in with their features, then the featured plan lifts, strikes its old price and rolls in the new one with a discount tag and a Most picked badge, and its button is pressed. Pass `plans` (set `featured` and `was` on the one to highlight), `heading`, `discountLabel` and `badgeLabel`. It has a `theme` prop and ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
