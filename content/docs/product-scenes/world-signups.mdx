## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { WorldSignups } from "@/components/remocn/world-signups";

const WorldSignupsScene = () => (
  <WorldSignups title="Signups around the world" startCount={12847} accent="#3B5BFD" />
);

export const RemotionRoot = () => (
  <Composition
    id="WorldSignups"
    component={WorldSignupsScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A dotted world map fades in as signup pings land on their cities one by one, heating the map while a counter rolls up, the feed lists each new user and a top-countries strip fills in. Pass `signups` (name, city, country, lon, lat, plan and the frame `at`), `startCount`, `countries`, `title` and `counterLabel` to make it yours. It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
