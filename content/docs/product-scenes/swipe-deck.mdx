## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SwipeDeck } from "@/components/remocn/swipe-deck";

const SwipeDeckScene = () => (
  <SwipeDeck
    matchWith="Acme"
    initials="MC"
    lines={["Swipe right on what fits.", "Skip the rest.", "Install the match."]}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="SwipeDeck"
    component={SwipeDeckScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone shows a stack of cards: the cursor swipes the first right to like it, the second left to skip it and the third up to super-like it, then an It's a match modal pops in with two avatars, a heart and an Install button. Pass `cards` (title, meta, chips, and a `scene` or `src`), `matchWith` and `initials`; `lines` are the three captions beside the phone. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
