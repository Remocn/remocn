## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TiltSettleList } from "@/components/remocn/tilt-settle-list";

const TiltSettleListScene = () => (
  <TiltSettleList title="Your top scenes" heroTitle="Zoom Blur" heroMeta="Transition · 2.4k renders" />
);

export const RemotionRoot = () => (
  <Composition
    id="TiltSettleList"
    component={TiltSettleListScene}
    durationInFrames={126}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A title appears, a tilted player card swings in and settles while a checklist of lines steps forward one by one, then ranked rows with thumbnails slide in. Pass `title`, `heroTitle`, `heroMeta`, `lines` and `rows` to make it yours, and `heroSrc` plus `src` on each row with your own images (the default files only exist in the remocn repo). It ships dark and light through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
