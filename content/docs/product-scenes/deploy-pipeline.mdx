## Usage

```tsx
// src/Root.tsx
import { Composition, staticFile } from "remotion";
import { DeployPipeline } from "@/components/remocn/deploy-pipeline";

const DeployPipelineScene = () => <DeployPipeline project="orbit-web" domain="orbit.app" commitMessage="feat: ship dashboard" preview={staticFile("site.png")} />;

export const RemotionRoot = () => (
  <Composition
    id="DeployPipeline"
    component={DeployPipelineScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A deployment page opens with the project, commit and branch, then build logs stream line by line while a build timer counts up. When the last line lands the status flips to Ready and a site preview and Visit button appear. Pass `project`, `commitMessage`, `domain` and `logs`; the preview image defaults to a `staticFile("hero.png")` that only exists in the Remocn repo, so pass your own screenshot as `preview`. It has a `theme` prop and ships light and dark (dark by default).

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
