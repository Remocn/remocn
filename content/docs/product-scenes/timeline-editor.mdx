## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { TimelineEditor } from "@/components/remocn/timeline-editor";

const TimelineEditorScene = () => (
  <TimelineEditor
    projectName="Launch video"
    title="Meet Acme"
    audioName="soundtrack.wav"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="TimelineEditor"
    component={TimelineEditorScene}
    durationInFrames={360}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A video editor window drops up to three `clips` onto the V1 track one by one, then a `title` clip onto V2 and an `audioName` clip onto A1. A playhead scrubs through the monitor, then the cursor clicks Export and a progress panel finishes on Export complete. Pass `clips` (name, seconds, built-in scene), `projectName`, `title` and `audioName`. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
