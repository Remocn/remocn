## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { SendFountain } from "@/components/remocn/send-fountain";

const SendFountainScene = () => (
  <SendFountain prompt="Build a launch dashboard for the v2 release" stat={47200} statDelta="+18%" />
);

export const RemotionRoot = () => (
  <Composition
    id="SendFountain"
    component={SendFountainScene}
    durationInFrames={144}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A prompt bar types a request and presses send, the answer ejects as six cards that fly up and snap into a launch-board window, then a metric ticks up and signup avatars and a live badge arrive. Pass `prompt`, `appTitle`, `heroTitle`, `stat` with `statLabel` and `statDelta` to make it yours, and `images` with your own pictures for the hero and cover cards (the default image files only exist in the Remocn repo). It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
