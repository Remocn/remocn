## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { LeaderboardClimb } from "@/components/remocn/leaderboard-climb";

const LeaderboardClimbScene = () => (
  <LeaderboardClimb
    title="Top launches"
    toRank={3}
    self={{ name: "remocn", tagline: "Launch videos from code", from: 598, to: 1284 }}
  />
);

export const RemotionRoot = () => (
  <Composition
    id="LeaderboardClimb"
    component={LeaderboardClimbScene}
    durationInFrames={120}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A leaderboard panel lists up to eight products, then the highlighted row starts at the bottom and climbs past them one by one while its score counts up. It lands on a rank-up badge. Pass your own `entries`, `self` (name, tagline, start and end score) and `toRank`. It ships dark and light through the `theme` prop.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
