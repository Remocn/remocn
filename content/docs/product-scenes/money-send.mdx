## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MoneySend } from "@/components/remocn/money-send";

const MoneySendScene = () => <MoneySend recipient="Sam Rivera" amount={85} currency="EUR" note="Concert tickets 🎟" />;

export const RemotionRoot = () => (
  <Composition
    id="MoneySend"
    component={MoneySendScene}
    durationInFrames={260}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone opens on a keypad where the amount is typed digit by digit, then the note is typed on the keyboard with an emoji picked from the suggestion bar. Send flies the payment off, a progress ring spins, and a Sent confirmation shows a receipt. Pass `recipient`, `amount`, `currency` and `note`, and `lines` for the headline beside the phone. It has a `theme` prop and ships light and dark (dark by default).

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
