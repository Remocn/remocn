## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { AiAnswerSources } from "@/components/remocn/ai-answer-sources";

const AiAnswerSourcesScene = () => (
  <AiAnswerSources
    brand="atlas"
    query="How do I cut my cloud bill?"
    theme="dark"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="AiAnswerSources"
    component={AiAnswerSourcesScene}
    durationInFrames={419}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A question types into a search box and submits, a short thinking sequence runs, then the answer streams in with numbered citations and source chips. A cursor hovers a citation and clicks it, and a panel of the cited sources slides open. Pass `query`, `answer`, `sources`, `related`, and `brand` to make it yours; it ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
