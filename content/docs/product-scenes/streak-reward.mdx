## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { StreakReward } from "@/components/remocn/streak-reward";

const StreakRewardScene = () => (
  <StreakReward
    streak={7}
    title="Lesson complete"
    subtitle="No mistakes across 14 answers."
    cta="Continue"
  />
);

export const RemotionRoot = () => (
  <Composition
    id="StreakReward"
    component={StreakRewardScene}
    durationInFrames={180}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A phone shows a flame and a streak number counting up beside a row of week dots, then a tap swaps to a Lesson complete card with a medal, stat badges that count up and a Continue button. Pass `streak`, `stats` (label, value, kind), `title` and `cta` to match your app; `lines` are the two captions beside the phone. Ships light and dark.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
