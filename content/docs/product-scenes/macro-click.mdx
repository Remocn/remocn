## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { MacroClick } from "@/components/remocn/macro-click";

const MacroClickScene = () => (
  <MacroClick
    title="One click. It's live."
    url="acme.dev/launch"
    heroLine="Ship the launch today."
  />
);

export const RemotionRoot = () => (
  <Composition
    id="MacroClick"
    component={MacroClickScene}
    durationInFrames={150}
    fps={30}
    width={1280}
    height={720}
  />
);
```

The camera starts tight on the builder toolbar; the cursor clicks the publish button (`publishLabel`), which shows `busyLabel` and then `liveLabel`, the URL fills in, and the view pulls back to reveal the published hero page. The `title` headline fades in and a toast closes the beat. Pass `title`, `docTitle`, `url`, `heroLine` and `pages`. The hero photo defaults to a file that only exists in the Remocn repo, so pass your own `src`. Ships dark by default and light.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
