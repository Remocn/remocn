## Usage

```tsx
// src/Root.tsx
import { Composition } from "remotion";
import { ChannelReactions } from "@/components/remocn/channel-reactions";

const ChannelReactionsScene = () => (
  <ChannelReactions workspace="remocn" channel="launch" message="We just shipped v2. Take it for a spin." />
);

export const RemotionRoot = () => (
  <Composition
    id="ChannelReactions"
    component={ChannelReactionsScene}
    durationInFrames={220}
    fps={30}
    width={1280}
    height={720}
  />
);
```

A channel window opens, a launch message with a link preview appears, a cursor opens the emoji picker and reactions pop in one by one, then a thread opens and replies arrive. Pass `author`, `message`, `link`, `reactions`, `replies`, `workspace` and `channel` to make it yours, and `image` with your own picture for the link preview (the default file only exists in the Remocn repo). It ships light and dark through `theme`.

The ground is a live gradients.sh shader (`GshGround`), installed with the component as `@remocn/gsh`. Pick another look with the `ground` preset prop.
