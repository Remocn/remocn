# Cursor Gravity

The user approved implementing the eight creative concepts in order, one per
review cycle. First: cursor-gravity. Do not start layout-domino until the user
accepts this result and says to continue. Remaining order: type-fossil,
screen-loom, time-echo, negative-space-reveal, perspective-secret,
interface-pressure.

Revised direction from user review: start with an empty scene. A rounded
triangular cursor enters from outside the frame, approaches the screen edge,
and extracts a hidden button. The action should read as an entrance transition.
Two pulsed tugs, each with a hold and recoil, stretch the leading edge while the
back remains offscreen. A final pull frees the button, which settles in the
center; the cursor exits. No orbit or collection of visible tiles.

Six seconds at 30 fps. Use the actual composition edge for the extraction on
all aspect ratios. An SVG surface deforms into a narrow neck; lettering keeps
its shape. Expose label or custom content, tension, palette and speed. Verify
empty opening, offscreen back during the tugs, continuity, arbitrary seeking,
final hold and cursor exit. Render the revised sequence for review before
proceeding to another component.
